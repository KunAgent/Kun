# Personal assistant logos

Product icons shown next to the personal assistants a user connects to Kun, so they can recognise each one. Each mark belongs to its owner and is used only to identify that product.

| File | Product | Owner | Source |
| --- | --- | --- | --- |
| `cue.png` | Cue | Manus | manus.im site icon |
| `grok_bot.png` | Grok Bot | xAI | grok.com site icon |
| `muse.svg` | Muse | Meta | muse.ai site icon |
| `dots.png` | dots | OpenAI | openai.com site icon |
| `hark.png` | Hark | Hark | hark.com site icon |
| `today.png` | Today | Today AI | today.ai site icon |

Check each owner's brand guidelines before a public release. Custom assistants use an icon fetched at runtime from the website the user enters, kept only on that computer.
