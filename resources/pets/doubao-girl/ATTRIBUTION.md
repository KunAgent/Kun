# 豆包娘 / Kun chibi adaptation

Kun adaptation of a generic short-haired AI assistant motif; Doubao / ByteDance
retain rights in their official brand assets.
Reference record: [豆包 / Doubao](https://www.doubao.com/).
Archive: [shuaizenge/ai-girls](https://github.com/shuaizenge/ai-girls/tree/dcd69f5f4f2dff1a9c0031e82deb49e0fe949c76/characters/doubao).
The archive is a source index, not a blanket license for its contents.

## Kun changes

New AI-generated artwork, 2026-11-05. All nine animation states (57 frames)
use rounded chibi proportions, simplified cel shading, and a new costume.
A new face, freckles, curled hair tuft, bean clip, teal hoodie, coral apron and sprout pouch replace the official avatar's facial details and black-shirt silhouette.
No upstream character image, screenshot, voice sample or website code is bundled.
Provider marks are rendered separately as vector badges; their sources are
listed in [AI-BRANDS.md](../AI-BRANDS.md).
The animation layout reference is Kun's existing Whale Girl atlas.
