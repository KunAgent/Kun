## Written reference and adapted brief

Written reference: TreapGoGo and contributors,
[deepseek-whale-girl, Q-version prompt](https://treapgogo.github.io/deepseek-whale-girl/#prompts).
Reference revision: [1a47dcd](https://github.com/TreapGoGo/deepseek-whale-girl/blob/1a47dcdbe33beb1da1b342024675cd1bc9620ed5/site/index.html).

section, are shared under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
This text license covers the written reference, not the underlying character.

A friendly chibi whale humanoid with long cobalt-to-aqua hair, sapphire eyes,
fin-shaped ears, a curled ahoge, a white ruffled headband with blue bows,
a modest navy-and-white maid dress, a whale-emblem apron, white socks,
navy Mary Jane shoes, and a broad two-lobed navy whale tail. Use clear navy
outlines and restrained cel shading suitable for a small desktop companion.

Upstream reference sheets, gallery images, voice recordings, and
website code are not bundled. This is a community-inspired character, not
an official DeepSeek character or endorsement. Kun's code retains its own
license. Further source records are indexed in
[ai-girls](https://github.com/shuaizenge/ai-girls/blob/dcd69f5f4f2dff1a9c0031e82deb49e0fe949c76/NOTICE.md).

The DeepSeek whale emblem is integrated into the headband, apron and work
props throughout the sprite artwork. The existing emblem artwork is retained unchanged.
