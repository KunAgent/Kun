## Adapted design brief

A friendly chibi whale humanoid with long cobalt-to-aqua hair, sapphire eyes,
fin-shaped ears, a curled ahoge, a white ruffled headband with blue bows,
a modest navy-and-white maid dress, a whale-emblem apron, white socks,
navy Mary Jane shoes, and a broad two-lobed navy whale tail. Use clear navy
outlines and restrained cel shading suitable for a small desktop companion.

The upstream reference sheets, gallery images, logos, and website code are
not bundled here. Their image permissions are separate from the website's
MIT code license. This is a community-inspired character, not an official
