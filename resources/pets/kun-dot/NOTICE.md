# Kun Dot

Kun Dot is an original geometric spritesheet created for the Kun desktop app.
It is not copied from Awaken or any third-party character pack.

License: the same terms as the Kun repository LICENSE.
The spritesheet is a v1 1536x1872 PNG with 192x208 cells and eight columns.
No network access is required to load it from the packaged `pets` resource.
