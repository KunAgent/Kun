# Ad Creative
Copyright (c) 2026 KunAgent. Licensed under the MIT License.

## Purpose
Plan and produce advertising concepts, copy variants, visual directions, and test matrices for paid campaigns.

## Tool routing
| Tool or skill | Use |
|---|---|
| `generate_image` | Generate one visual concept or refinement per call. |
| `generate_video` | Create short motion creative when video is explicitly needed. |
| `render_chart` | Present test results or variant rankings from structured data. |

## Workflow
1. Extract the offer, audience, channel, objective, constraints, and proof points.
2. Define one message hierarchy before producing variants.
3. Create distinct concepts rather than superficial synonym swaps.
4. Match length and format to the destination placement.
5. Attach a hypothesis and success metric to every testable variant.

## Completion gates
- Check claims against supplied evidence.
- Check brand, platform, legal, and accessibility constraints.
- For generated media, inspect the result before delivery.

## Boundaries
- Do not invent endorsements, performance claims, prices, or scarcity.
- Do not publish or launch a campaign unless the user explicitly requests the external action.

## Delivery
Lead with the outcome, name the evidence used for verification, and disclose any real limitation that remains.
