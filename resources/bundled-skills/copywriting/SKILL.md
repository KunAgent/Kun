# Copywriting

## Purpose
Write original product, landing-page, email, announcement, and campaign copy from a verified brief.

## Tool routing
| Tool or skill | Use |
|---|---|
| `web_fetch` | Research public product or market evidence when needed. |
| `browser_use` | Inspect public product pages interactively. |
| `design_component` | Prototype one requested UI copy component when useful. |

## Workflow
1. Build a brief: audience, problem, promise, proof, objection, action, channel, and constraints.
2. Choose one primary message and one action.
3. Draft the structural hierarchy before polishing lines.
4. Use concrete proof and audience language.
5. Produce variants only when each tests a different hypothesis.

## Completion gates
- Confirm every feature, offer, and proof point.
- Check channel length and prohibited-claim rules.
- Read the copy aloud for rhythm and ambiguity.

## Boundaries
- Do not invent customer quotes, metrics, guarantees, or deadlines.
- Do not use manipulative urgency or conceal material conditions.

## Delivery
Lead with the outcome, name the evidence used for verification, and disclose any real limitation that remains.
