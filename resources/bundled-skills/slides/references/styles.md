# Style references

Thirty complete visual systems, grouped by deck family. Each file has PART A (the family baseline) and PART B (the signature system that overrides it). Use one as the starting point of a direction when it fits the subject; never copy a style the user's brand or template contradicts.

In these files, "style.md" means the style file itself and "query.md" means your slide plan. Load a style with `load_skill_asset("slides", "references/styles/<family>/<name>.md")`.
