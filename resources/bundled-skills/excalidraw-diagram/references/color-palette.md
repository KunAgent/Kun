# Color palette

Use these pairs only. Pair a darker stroke with a lighter fill.

| Role | Fill | Stroke / text |
|---|---|---|
| Paper / canvas | `#ffffff` | — |
| Ink / title | — | `#111827` |
| Subtitle | — | `#374151` |
| Detail / muted | — | `#6b7280` |
| Neutral shape | `#f3f4f6` | `#4b5563` |
| Start / input | `#d1fae5` | `#047857` |
| Process | `#dbeafe` | `#1d4ed8` |
| Decision | `#fef3c7` | `#b45309` |
| End / output | `#ede9fe` | `#6d28d9` |
| Accent (max two) | `#fee2e2` | `#b91c1c` |
| Evidence panel | `#111827` | `#e5e7eb` |
| Evidence accent | — | `#93c5fd` |
| Marker / timeline dot | `#1d4ed8` | `#1d4ed8` |
| Structural line | transparent | `#9ca3af` |

Titles use ink. Supporting labels use muted. Evidence artifacts (code or JSON samples) sit on the dark panel with evidence accent for keys.
