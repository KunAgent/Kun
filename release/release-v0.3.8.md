# Kun v0.3.8 Release Notes

本版本聚焦于**运行时稳定性、会话队列体验**与**智能化工作台**：引入持久化的运行时队列与公平调度，重构启动加载与对话轨迹视图，新增自动计划构建、项目看板、混合记忆基础与内置 GitHub 集成，并系统性加固了 SSE 事件流、Manager 交接、自更新与凭证安全等关键路径。

## ✨ 新功能

- **启动体验重构**：新增 Kun 吉祥物加载动画，支持随机加载场景、鸟姿态变化与动画场景道具，启动等待更友好 (#5727482c, #a40b1ecf, #050daeec, #766666be, #c1d2e5fc)
- **对话轨迹视图**：新增会话内轨迹查看（trajectory），支持与 harness 对齐的交互式渲染，并修复轨迹交互、角色颜色与原始/源细节对齐 (#f94403be, #4db6cba2, #7c7aeaee1, #7e7a6747f, #0691e896d, #37b4de73f, #d0e310339, #7a5ce850e)
- **自动计划构建模式**：计划支持自动构建（automatic build），接受自动模式后续输入，并抑制中途计划完成提示 (#e64539188, #da38c7949, #95f22a95e, #fa1d5c3f4)
- **会话看板**：新增会话级看板，支持项目看板计划元数据缓存、批量状态更新与工作区项目 kanban (#7c14866d1, #4bad5d50c, #ff345eae7, #c319d29a8)
- **混合记忆基础**：新增混合记忆 foundation，含蒸馏候选核心，修复后台回填覆盖前台更新等问题 (#1164465d4, #ba36b1c22)
- **运行时持久化队列**：为 Kun 运行时引入持久化的每线程 turn 队列与公平调度器，支持队列消息编辑、取消与两阶段准入，消除幽灵任务 (#e3a05a8fc, #1cfbe8374, #9ffef2b8e, #b0a5164cc, #46fd7aa47, #df139acdf)
- **排队消息体验**：采用附着在 composer 上的 QueueDock，支持折叠/展开、拖拽与键盘重排、恢复到输入框编辑和失败重试，并在每条排队消息上冻结执行设置 (#c1d2e5fc5, #42518d8ec, #73f83d230, #742192ad8, #5ca01ae6f, #f80b0a198)
- **内置 GitHub 集成**：新增内置 GitHub MCP 集成，GitHub 账号授权需显式确认 (#902b780e8, #eb859c3af)
- **内置技能**：内置 35 个 KunAgent 技能作为只读内置技能，并支持在设置 mock 中提供 bundled skills (#468cf03dc, #86207fad2)
- **加密凭证管理**：实现 AES-256-GCM 加密器与兼容加密器用于凭证管理，并增强遗留提供方设置迁移与凭证恢复 (#8870046a1)
- **扩展平台增强**：新增保护性密钥存储 API、可靠执行历史恢复、视图会话 pending 操作等待，并暴露 Agent 模型运行选项 (#6a3dedbe6, #a97b7dcda, #4b0d40db5, #d7942a38f)
- **提供方增强**：新增逐提供方代理选择、逐提供方拉取模型按钮，以及 keep-awake 偏好 (#9a53832cc, #3a0e54302, #80d73fb84)
- **Computer Use 原生驱动**：采用 CUA（Computer Use Agent）原生驱动 (#6e530ac9b)
- **模型错误透出**：聊天中透出提供方返回的模型错误，并支持 model-recommended 选项标记 (#3867b2ef3, #a01c08cbc)
- **代理人设与 Fast Context**：将 personas 从实验室转正；Fast Context 全局暴露，并支持在 Codex 作用域内配置 fast 模式 (#b2a500482, #cfa08d517, #498d585d7)
- **用量与状态栏**：token 计数 ≥10 亿时以 B 后缀显示；状态栏缓存指标在每次 LLM 请求时刷新；历史热度图与 GitHub contribution 网格对齐 (#91aa93f62, #1a7a1950a, #29aa93d39, #810692d1b)
- **项目看板实验室开关**：项目看板可通过实验室开关启用，并移除计划看板 (#6149fb1e6)

## 🐛 修复

### 运行时与会话

- SSE ACK 流程加固：仅在 HTTP reader 打开后才报告已连接，终结 ACK 超时回合，并以内存计数避免每次 append 都执行 stat (#b803fd553, #9b0c16407, #7ceff443e, #7ccd08114, #ff73d26bd)
- Manager 状态协同：合并重复的共享 JSON 写入，追踪 durable revision，并从损坏的 manager 状态中恢复，失败时降级 (#c690dba03, #b24b173f1, #26ae58dc0, #8b038201e, #856ca6da9)
- 交接安全性：在不可验证的属主身份上 fail-closed，完成静默 manager 交接，安全恢复属主丢失 (#170888bde, #a38c72993, #8b038201e, #0ad868614, #4d615c82d)
- 长时间执行加固：防止 turn 租约在停滞期间过期，避免用量停滞中止 turn，加固长时间 agent 执行 (#fb1442769, #42dc3b903, #452ce5cca, #f0b670f32)
- 单飞与竞态：保留超出 TTL 的 pending single-flights，拒绝自引用队列移动，关闭跨运行时队列取消/移动竞态 (#5f9934407, #c743f58f9, #b3ff49774, #df139acdf)

### 会话与索引

- 会话修复 torn 消息尾部，并在截断的事件 JSONL 尾部前提交完整最终事件 (#6fe0fa34c, #ff70af307, #d01794e06)
- 事件索引完整性加固：防崩溃残留自愈，索引重建避免覆盖竞态，稀疏索引增量重建 (#7f4439b27, #69ff6a586, #f77871149, #0b21d7c43, #9ffef2b8e)
- 混合存储回退：SQLite 索引写失败时透出错误而非丢弃线程；索引回填失败时回退到文件系统列表 (#33c14a4c6, #68d38f1bd, #697ee93c7)
- 用量索引：SQLite 用量索引降级时回退 JSONL 历史；聚合缩放，默认仪表盘为 7 天 (#1908741ad, #c0e876f0d, #335ac2ae3)

### 队列与 Composer

- 运行时接管前的排队行保持可恢复、可编辑、可取消；starting/in-flight 行在对应 turn 启动后从 QueueDock 消费，避免与时间线重复 (#af50782ba, #63f2e3c2b, #4a0ec8056)
- 队列投递在 admission 前持久化附件快照，并在 SSE ACK 超时时终结回合而不遗失排队状态 (#4a0ec8056, #7ccd08114)
- 排队消息在模式切换后不再"复活"，恢复排队消息到输入框编辑 (#2e2984be4, #5ca01ae6f, #f80b0a198)
- 自动提交时在准入前清空 composer，避免状态悬挂 (#1cd899c34)

### 提供方与设置

- 提供方删除持久化并守护 schema 迁移，避免删除后复活 (#d1c9d9a73)
- 代理请求体流类型对齐，media 生成经提供方代理路由（inline 配置）确保一致 (#990e33b6b, #de6f752b8, #e813b2cf2, #2a14b3dab)
- 共享提供方代理上报与原子 MCP 目录同步 (#b3a015eef, #a4c58cb47, #5f4f1ba71)
- 自定义 HTTP 提供方无 preset 源时要求 API key (#5caeb3fa4)

### 更新与发布通道

- 从 0.3.8 起停止独立 TUI 压缩包分发；桌面应用仍内置 Kun Runtime 与终端命令，统一随 GUI 更新。历史 0.3.7 独立包保留，但不再提供后续独立包升级。
- Windows 更新事务状态统一并加固恢复；更新交接保持不可逆；崩溃安全指针切换 (#6ed0c2d04, #44b5ca41a, #0e3134eef, #1869ee0bc)
- Windows 自更新锁交接给分离的更新器；仅保留的备份在启动恢复中保留 (#873d7e178, #766087bb1)
- 安装器绕过旧卸载器，保留更新恢复环境；CI 门禁放开打包更新校验 (#5f5faa41a, #f22791010, #0c75650f9, #c45f8666d, #3eac3b324)

### 扩展与 MCP

- 扩展视图会话失效恢复；陈旧视图激活恢复；保留新鲜历史完整性 (#6cee513a1, #369bf2ee0, #4dd6309ec, #5dd1b3189)
- MCP 连接/目录失败时关闭客户端，防止 stdio 泄漏；恢复 MCP 目录 (#27ec23035, #a4c58cb47)
