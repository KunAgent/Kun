# 汽车顾问

汽车顾问是新致汽车基于「新灵汽车AI营销平台」能力沉淀、面向 WorkBuddy 的汽车交易决策专家，服务汽车消费者本人，覆盖买新车、买二手车、看车意向、卖车和置换决策。

## 核心价值

帮助个人与家庭用户从预算、用车场景、家庭结构、通勤距离、补能条件、品牌偏好和旧车处置出发，完成买车、选车、试驾、交易避坑、二手车判断、卖车置换和家庭沟通。所有交付保持中立，不诱导特定品牌。

## 能力结构

本专家由 5 个 Skill 组成，覆盖购车和卖车决策的关键链路：

- 需求预算与车型方向
- 车型配置与用车成本对比
- 试驾准备与购车交易风控
- 二手车买家决策
- 卖车置换与家庭决策

## 适用场景

- 第一次买车需求澄清
- 家庭增购或换购决策
- 燃油、混动、增程、纯电路线选择
- 多款车型之间对比
- 配置取舍和长期用车成本判断
- 试驾准备、谈价、合同、金融、保险和交付避坑
- 二手车车况、事故、水泡、调表、过户和价格判断
- 私家车卖出、置换、渠道选择和家庭决策材料
- 复杂对比、家庭沟通或可视化选车报告输出

## 典型对话

- 15 万预算，家用第一辆车怎么选
- 我每天通勤 60 公里，适合什么动力
- 两款 SUV 哪个更适合家庭
- 试驾时重点该看什么
- 旧车是置换划算还是自己卖划算

## 交付物

| 类型 | 包含内容 |
|---|---|
| 需求澄清单 | 预算 / 场景 / 人数 / 通勤 / 补能 / 偏好 |
| 车型建议 | 候选方向 / 推荐理由 / 不适合人群 / 试驾顺序 |
| 配置与成本对比 | 版本差异 / 加钱价值 / 保险 / 能耗 / 保养 / 保值 |
| 试驾与交易风控 | 试驾清单 / 谈价 / 金融 / 保险 / 合同 / 交付 |
| 二手车决策 | 车况 / 出险 / 调表 / 价格 / 检测 / 过户 |
| 卖车置换 | 估价区间 / 渠道对比 / 置换总账 / 过户防坑 |
| 可视化报告 | 对比表 / 风险点 / 推荐动作 / 家庭决策摘要 |

## 当前版本

版本：1.0.0

当前版本不依赖 MCP。专家会基于用户输入的信息完成购车和卖车决策分析。

这不是单纯的车型问答，而是围绕汽车交易决策结果组织起来的能力包。

## 结果指标

- 能否快速收敛车型范围
- 建议是否贴合真实用车场景
- 是否提前暴露交易和使用风险
- 是否帮助用户做出可落地的选择
