# 试驾准备与购车交易风控

## 触发场景

用户准备看车、试驾、谈价、下订、办金融、买保险、验车或交付，需要提前知道看什么、问什么、合同里写什么。

## 🔴 关键核验点

先识别用户阶段：还在试驾看车，还是已经到下订/金融/合同/交付环节。不同阶段重点不同——试驾阶段关注"看什么试什么"，交易阶段关注"报价口径/金融捆绑/合同条款/交付确认"。同时核验待试驾车型、用户关注点、家庭乘坐需求。

## 暂停与降级条件

- 交定金前暂停：确认定金/订金、退款条件、车型配置、交付时间是否写入合同。
- 办金融前暂停：确认贷款金额、期数、利率/费率、手续费和提前还款规则。
- 提车签收前暂停：确认 VIN、发票、保险、外观、功能、随车资料一致。

## 试驾检查

- 静态：座椅、视野、储物、后排、后备箱、老人孩子上下车
- 动态：起步、刹车、转向、底盘、噪音、晕车感
- 智能座舱：车机流畅、导航、语音、手机互联
- 辅助驾驶：只体验能力边界，不把试驾演示当安全承诺
- 补能/售后：充电、保养、质保、门店覆盖

## 试驾任务设计

| 项目 | 怎么试 | 判断重点 |
|---|---|---|
| 坐姿视野 | 调到日常坐姿，模拟停车/掉头 | 盲区、A 柱遮挡、后视镜视野 |
| 家庭乘坐 | 带家人或模拟儿童座椅/老人上下车 | 后排腿部、头部、地台、开门角度 |
| 低速跟车 | 堵车路段或停车场 | 起步平顺、刹停点头、动能回收 |
| 高速/快速路 | 允许范围内体验并线和巡航 | 噪音、稳定性、辅助驾驶边界 |
| 颠簸路 | 过减速带/破损路面 | 底盘质感、异响、晕车感 |
| 车机 | 导航、语音、空调、音乐、手机互联 | 是否顺手，不只看屏幕大小 |

## 工作流程

1. 判断用户阶段：试驾前、试驾中、谈价、合同、交付。
2. 试驾前输出检查任务和必问问题。
3. 谈价阶段拆报价口径、金融、保险、装潢和置换条件。
4. 合同阶段逐项核对车型、价格、权益、定金和交付条款。
5. 交付阶段执行验车和资料清单，异常时暂停签收。

## 交易风险点

- 报价是否含税费、保险、上牌、装潢
- 金融是否有手续费、提前还款限制或捆绑
- 保险与装潢是否强制绑定
- 置换补贴是否有前置条件
- 定金/订金写法是否清楚
- 交付时间、配置、颜色、车架号、违约责任是否写进合同

## 合同检查项

- 车型、版本、颜色、配置、选装包是否写清。
- 价格口径是否写清：裸车、税费、保险、上牌、服务费、装潢。
- 优惠和赠品是否写清：现金优惠、置换补贴、保养、充电桩、精品。
- 金融条款是否写清：贷款金额、期数、利率/费率、手续费、提前还款规则。
- 交付条件是否写清：预计交车时间、违约处理、库存车/展车/试驾车排除。
- 定金/订金和退款条件是否写清。

## 交前自检清单

| 检查项 | 看什么 |
|---|---|
| 车辆身份 | VIN、合格证、发票信息一致 |
| 外观内饰 | 漆面、玻璃、轮毂、内饰划痕、随车工具 |
| 里程和日期 | 里程是否异常，生产日期是否过久 |
| 功能 | 灯光、空调、车机、钥匙、充电口/油箱盖 |
| 新能源专项 | 电池电量、充电枪/随车充、充电权益、三电质保 |
| 文件 | 发票、保险、临牌、保养手册、三包凭证、合同附件 |

## 输出模板

试驾版：

- 试驾路线和检查清单
- 销售顾问必问问题
- 家庭乘坐验证项
- 试驾后判断

交易风控版：

- 谈价注意事项
- 金融/保险/装潢风险点
- 合同和交付确认项
- 交车验车清单

## 常见风险应对

| 风险信号 | 应对 |
|---|---|
| 报价明显低 | 要完整明细，核查捆绑 |
| 强制保险/装潢 | 拆开算，要求写清或换店比价 |
| 大额定金催促 | 控制定金金额，合同写退款条件 |
| 交付时间含糊 | 写明日期、车辆配置和违约处理 |
| 置换估价低 | 多家评估，看旧车估价 + 新车优惠总账 |

## 失败分支

| 情况 | 处理 |
|---|---|
| 销售只给口头承诺 | 要求写入合同或补充协议；写不进去就不纳入决策 |
| 已交定金才发现条款不清 | 整理聊天记录、收据、合同，再判断能否协商退款 |
| 金融方案说不清总利息 | 要求还款计划表，算总支出而不是只看月供 |
| 交付车况异常 | 暂缓签收，拍照留证，要求书面处理方案 |

## 反例（不要做）

- 不把试驾车的演示功能当成量产车长期表现承诺。
- 不只问裸车价，不问保险、上牌、服务费和装潢。
- 不接受“以后补给你”的口头权益。

## 边界

- 不协助虚假报价。
- 不默认接受绑定销售。
- 不把销售口头承诺当作合同保障。
- 不把辅助驾驶体验当成安全保证。
- 不替用户保证优惠、金融审批或交付周期。
