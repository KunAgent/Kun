# 需求预算与车型方向

## 触发场景

用户只说“帮我选车”，或还不确定预算、动力路线、车型类别和候选车型，需要先把选车方向收敛。

## 🔴 关键核验点

先确认：预算是裸车还是落地（首次购车常把裸车预算误当落地）、家庭人数与主要乘坐者、每天通勤里程与长途频率、能否装家充、车身偏好。预算口径和补能条件是动力路线判断的两个关键，缺了就别给方向。

## 暂停与降级条件

- 预算口径不清时，先暂停：明确裸车价、落地价、首付/月供上限。
- 补能条件不清时，先暂停：明确能否家充、公司充、常用公共桩距离。
- 家庭主力车场景不清时，先暂停：明确主要乘坐者、儿童座椅、老人上下车和长途频率。

## 功能说明

通过预算、城市、家庭人数、通勤距离、充电条件、长途频率、品牌偏好和车身偏好，判断适合的动力路线和车型方向，输出 3-5 个候选。

核心是先把“能买”和“适合买”分开：能买看预算，适合买看家庭、通勤、补能、长途、车身尺寸和风险承受能力。

## 关键问题

- 预算是裸车价还是落地价？
- 购车资金来源：全款、贷款、家庭共同出资，月供上限是多少？
- 所在城市和日常路况？
- 家庭人数、主要乘坐者、是否有老人/孩子？
- 每天通勤里程和长途频率？
- 是否能装家充或稳定充电？
- 偏好轿车、SUV、MPV 还是无所谓？
- 有无品牌偏好或明确排斥？
- 预计持有几年，是否看重保值和售后便利？

## 预算边界判断

先把预算拆成四层，不只看裸车价：

| 预算项 | 判断方式 | 风险提醒 |
|---|---|---|
| 裸车价 | 车辆本体价格 | 低报价可能不含必要费用或绑定条件 |
| 落地价 | 裸车 + 税费 + 保险 + 上牌 + 必要服务 | 用户常把裸车预算误当落地预算 |
| 月供压力 | 首付、贷款期限、利率、提前还款限制 | 月供不应挤压家庭固定开支 |
| 后续成本 | 保险、保养、能耗、停车、折旧 | 买得起不等于养得轻松 |

判断建议：

- 第一次买车优先用落地预算收敛，不用裸车价收敛。
- 贷款购车要同时看总利息和月供压力，不只看首付低。
- 家庭主力车要留出保险、保养、轮胎和停车成本余量。

## 动力路线判断

| 条件 | 更适合 | 需要注意 |
|---|---|---|
| 有固定家充，日常通勤为主 | 纯电 | 长途频率、冬季续航、保值波动 |
| 无家充但城市补能方便 | 插混/增程优先 | 纯电体验会打折，补能时间成本高 |
| 经常长途、节假日跨城 | 混动/增程/插混 | 纯电需确认高速补能路线 |
| 低频用车、预算敏感 | 燃油/混动 | 别只被新能源配置吸引 |
| 家庭唯一车且补能不稳定 | 混动/增程/插混 | 优先保证使用确定性 |

## 车型方向映射

| 主场景 | 推荐车身 | 推荐动力 |
|---|---|---|
| 城市通勤为主、能装桩 | 轿车/紧凑 SUV | 纯电优先，插混次选 |
| 通勤 + 频繁长途 | 中型 SUV/轿车 | 增程/插混 |
| 家庭主力、多孩或三代 | MPV/大 SUV | 混动/增程 |
| 长途多、补能不便 | 轿车/SUV | 燃油或混动 |
| 商务接待 | 中大型轿车/MPV | 燃油/混动 |

## 输出要求

- 候选方向控制在 3-5 个。
- 每个候选说明适合谁、不适合谁、主要风险。
- 至少给一个稳妥选择和一个亮点选择。
- 没有指定品牌时保持中立，不诱导特定品牌。
- 明确下一步应该进入车型配置对比、试驾准备还是二手车判断。

## 工作流程

1. 确认预算口径和资金方式，输出预算边界。
2. 确认家庭、通勤、长途、补能和车身偏好，输出真实需求摘要。
3. 判断动力路线，排除明显不适合方向。
4. 收敛 3-5 个车型方向或代表车型，标注适合/不适合。
5. 给试驾顺序和下一步需要补充的信息。

## 输出模板

- 用户需求摘要
- 已知条件与缺失条件
- 预算边界与月供压力判断
- 动力路线建议
- 候选车型方向（类别 + 代表车型）
- 适合 / 不适合人群
- 先看优先级和试驾顺序
- 下一步补充信息

## 可视化输出

当用户需要给家人看、比较多个方向、或需要一页式选车摘要时，可输出 HTML 可视化报告。

## 失败分支

| 情况 | 处理 |
|---|---|
| 用户只给预算 | 先按落地价假设给 2-3 个方向，再追问城市、家庭、通勤、补能 |
| 预算覆盖不了目标车型 | 说明预算缺口，给降级车型、延后购车或二手车方向 |
| 想买纯电但没有稳定补能 | 先提示补能风险，给混动/增程备选 |
| 家庭成员诉求冲突 | 区分出资者、使用者、决策者，列不可妥协条件 |

## 反例（不要做）

- 不只按预算列热门车型。
- 不在补能条件未知时直接推荐纯电。
- 不把“配置多”当成家庭主力车的唯一判断。

## 边界

- 不把热门车型默认当最优解。
- 不给过长名单。
- 不把“能装充电桩”默认等同于“一定买纯电”。
- 不把低首付金融方案当成预算变宽。
- 不编造实时价格、优惠、库存或交付周期。
