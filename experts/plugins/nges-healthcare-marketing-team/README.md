# 腾讯健康NGES医药营销专家团

由主理人统一调度的医药营销专家团，整合 HCP 客户洞察、互动病例生成、合规审核三大能力，覆盖从客户情报分析到内容生产到合规检测的全流程。

## 类型

Team 型（专家团）

## 功能

专家团由主理人统一收集用户需求，根据需求类型调度对应专家：

- **HCP 分析需求** → 调度 HCP客户洞察专家：基于全球公网学术数据（PubMed、Semantic Scholar、ClinicalTrials.gov 等），分析医生学术画像、KOL 影响力评估、临床试验参与、竞品态度推断，输出拜访建议与话术。
- **互动病例需求** → 调度 互动病例专家：将诊疗指南/医学文献转化为可交互的 H5 模拟诊疗病例，支持医生"从学到练"，识别认知卡点与观念分级。
- **合规审核需求** → 调度 合规专家：基于三层检测框架（基础安全+医疗行业合规+不良事件扫描）审核医疗营销内容合规性，输出风险定级与合规改写方案。
- **复合需求** → 主理人按逻辑顺序分阶段调度多个专家，前一阶段产出作为后一阶段输入。

## 技能

| 技能名 | 说明 |
|--------|------|
| hcp-insight | HCP 数据检索与分析引擎，执行 PubMed/Semantic Scholar/ClinicalTrials.gov 等多源搜索 |
| interactive-medical-case | 互动病例生成工具，含病例数据结构规范、构建脚本与 HTML 模板 |
| regulations | 医疗营销合规法规知识库，包含 14 部中国医疗营销核心法规原文 |

## 团队成员

| 角色 | 名称 | 职责 |
|------|------|------|
| 主理人 | 专家团主理人 | 收集用户需求，识别需求类型，调度对应专家，汇总产出 |
| HCP客户洞察专家 | HCP客户洞察专家 | 基于公网数据做医生学术画像、KOL 评级、拜访建议 |
| 互动病例专家 | 互动病例专家 | 将指南/文献转化为可交互 H5 模拟诊疗病例 |
| 合规专家 | 合规专家 | 审核医疗营销内容合规性，输出风险定级与合规改写 |

## 使用示例

- "明天要去见协和肿瘤科张教授，帮我做一个拜访前的准备分析"
- "我有一篇诊疗指南文章，帮我生成一个可互动的病例"
- "帮我审核这段推广内容是否合规"
- "帮我分析张教授的学术画像，然后基于他的研究方向生成一个互动病例"（复合需求）
