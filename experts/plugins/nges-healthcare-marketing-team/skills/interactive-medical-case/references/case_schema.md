# 互动病例数据 Schema（case.json）

互动病例的所有内容由一个 `case.json` 文件描述。构建脚本会把它注入 HTML 模板，生成单文件成品。
**所有内容字段必须为简体中文。** 不要在 JSON 中放入营销夸大、未经循证支持的结论。

## 顶层结构

```jsonc
{
  "meta": { ... },          // 病例元信息（封面页）
  "patient": { ... },       // 患者详情（病情内容页）
  "questions": [ ... ],     // 互动问答，3~5 题，顺序即诊疗路径
  "summary": { ... },       // 方案解析（综合点评 + 治疗方案）
  "source": { ... }         // 来源信息（指南/文献，用于循证标注与免责声明）
}
```

---

## 1. meta —— 封面页

```jsonc
"meta": {
  "title": "高龄患者腰椎间盘突出合并多种基础疾病，如何实现安全有效治疗？", // 病例标题，问句形式，聚焦诊疗决策难点
  "intro": "高龄患者腰椎间盘突出，又伴有高血压、糖尿病、心肌缺血等多种基础疾病，治疗应如何权衡？……", // 导语，1~3 句，点出临床困境
  "specialty": "骨科",        // 科室
  "readingMinutes": 5,         // 预计学习时长（分钟）
  "createdDate": "2026/06/27", // 病例创建日期（展示用）
  "author": {                  // 作者简介（可选，没有就置 null）
    "name": "王留辉",
    "hospital": "郑州四六〇医院",
    "department": "骨科",
    "bio": ["中共党员、新乡医学院临床医学专业", "2023 至今 郑州四六〇医院 骨科中心工作"] // 每行一条
  }
}
```

字段说明：
- `title`：**必须是问句**，聚焦"如何决策/如何权衡/怎么选"这类诊疗判断点，而非陈述性标题。
- `intro`：把患者的核心矛盾讲清楚，引出后面要做的决策。

## 2. patient —— 病情内容页

```jsonc
"patient": {

  "pastHistory": ["高血压 15 年", "2 型糖尿病 8 年", "陈旧性心肌缺血"], // 既往史（数组，逐条）

    {
      "name": "血常规",
      "type": "table",     // table | text | image

        { "item": "白细胞(WBC)", "result": "8.86", "ref": "3.5-9.5", "unit": "10^9/L" },
```

## 3. questions —— 互动问答（核心，3~5 题）

题目顺序即诊疗路径。推荐覆盖：**诊断 → 治疗目标 → 治疗策略 → 临床获益 → 用药安全 → 随访管理**（按病例实际裁剪，不强求 5 题）。

```jsonc
"questions": [
  {
    "id": 1,
    "stage": "诊断",                 // 该题在诊疗路径中的阶段标签
    "conceptId": "concept-diagnosis-copd-cvd",  // 观念唯一标识（同一诊疗观念跨病例复用时保持一致，支撑“题目关联继承”）
    "conceptName": "慢阻肺合并心血管病的识别",   // 观念名称（可读）
    "type": "single",                 // single 单选 | multiple 多选
    "stem": "结合该病例，患者的最佳治疗方案是什么？", // 题干
    "media": {                        // 可选：题干上方的图文素材（检查报告/影像），结构同 patient.examinations 的单项
      "type": "image", "imageUrl": "", "caption": "腰椎 MRI 矢状位"
    },
    "options": [
      {
        "key": "A",
        "text": "仅采用保守治疗，如休息、物理治疗等",
        "concept": "miss",            // 见下方“卡点逻辑”
        "grade": 2,                   // 观念分级 1~5（见下方“观念分级”），选中该项即把医生定位到该级别
        "comment": "保守治疗可缓解症状，但对该患者神经压迫进展的风险评估不足……" // 选中该项后的针对性点评（可选）
      },
      { "key": "B", "text": "先保守治疗观察一段时间，若无效再考虑手术", "concept": "partial", "grade": 4 },
      { "key": "C", "text": "立即进行手术治疗", "concept": "wrong", "grade": 1 },
      { "key": "D", "text": "其他（请补充说明）", "concept": "open" }
    ],
    "correct": ["B"],                 // 推荐答案（正确观念对应的选项 key 数组）
    "evidence": {                     // 循证解析：作答后展示
      "conclusion": "该患者高龄、多基础病，手术风险高，指南推荐先行规范化保守治疗并密切随访，无效再评估手术。",
      "points": [                     // 循证要点，逐条
        "《XX 诊疗指南（2023）》指出，无进行性神经功能损害的腰椎间盘突出首选保守治疗。",
        "高龄合并心血管疾病者围手术期风险显著升高，需充分权衡。"
      ],
      "citation": "《XX 腰椎间盘突出诊疗指南（2023 版）》"  // 引用出处
    }
  }
]
```

### 卡点逻辑（concept 字段，对齐 AZ 观念分级方法论）

每个选项标注 `concept`，用于作答后生成"卡点分析"：

| concept 值 | 含义 | 作答反馈定位 |
|-----------|------|------------|
| `correct`  | 正确观念，符合指南推荐 | 巩固正确观念 |
| `partial`  | 部分正确/方向对但不完整 | 观念基本建立，需补全 |
| `miss`     | 遗漏关键观念（多选中未选全） | 存在认知盲区 |
| `wrong`    | 错误观念，与指南推荐相悖 | 关键卡点，需重点纠正 |
| `open`     | 开放项（"其他"），不计入卡点 | 收集自由反馈 |

- 单选题：`correct` 标在推荐项，其余按错误程度标 `partial`/`wrong`。
- 多选题：所有应选项标 `correct`，漏选即触发 `miss` 提示；干扰项标 `wrong`。
- 每题至少 1 个 `correct`。`correct` 数组需与标了 `correct` 的选项一致。

### 观念分级（grade 字段，对齐 CS/KS 问卷方法论）

为支撑"题目关联继承"和"观念分级验证"，每个**实质选项**（非 open）可标 `grade`（1~5）：

| grade | 含义（以"是否建立目标观念"为轴，从低到高） |
|-------|------|
| 1 | 完全未建立目标观念（典型卡点） |
| 2 | 初步意识到问题，但方向错误 |
| 3 | 方向正确，但观念不完整 |
| 4 | 观念基本建立，仅细节欠缺 |
| 5 | 完整、正确的目标观念 |

- `grade` 与 `concept` 配合：`correct` 项通常 grade=5，`wrong` 项通常 grade=1~2。
- 作答后，系统取所选选项的最高 grade 作为医生在该观念上的**当前分级**，汇总到学习小结。
- 同一 `conceptId` 在不同病例中复用时，分级口径保持一致，从而可跨病例对比同一医生的观念演进（即"题目关联继承"）。
- `conceptId`/`conceptName`/`grade` 均为可选；不做观念分级时可省略，模板会自动降级为纯卡点展示。

## 4. summary —— 方案解析页

```jsonc
"summary": {
  "analysis": "该患者为 82 岁男性，患有腰椎间盘突出及多种基础疾病……鉴于患者高龄及多基础病，手术风险较高，可考虑通过休息、物理治疗和药物治疗缓解症状，药物选择上需避免加重基础病……", // AI 综合点评（段落）
  "treatmentPlan": [        // 治疗方案分组
    {
      "group": "原发/基础疾病治疗方案",
      "items": [
        "布洛芬缓释胶囊(0.3g/粒) 口服 每日两次",
        "红光治疗 每日两次",
        "中频脉冲电治疗 每日两次"
      ]
    },
    {
      "group": "多模式镇痛治疗方案",
      "items": ["……"]
    }
  ],
  "keyTakeaways": [         // 核心带教要点（可选，3~5 条）
    "高龄多病患者治疗以安全为先，规范保守治疗优先。",
    "药物选择需规避加重基础病的风险。"
  ]
}
```

## 5. source —— 来源信息

```jsonc
"source": {
  "type": "guideline",            // guideline 指南 | literature 文献 | article 文章
  "title": "《XX 腰椎间盘突出诊疗指南（2023 版）》",
  "origin": "用户提供的诊疗指南文章",  // 数据来源说明
  "disclaimer": "本互动病例内容由 AI 基于所提供的医学文献生成，仅供医学专业人士学习参考，不构成诊疗建议。"
}
```

---

## 校验要点（生成后自检）

1. `questions` 长度 3~5，每题 `options` 2~5 个，至少 1 个 `correct`。
2. 每题 `correct` 数组与标注 `concept: correct` 的选项 key 完全一致。
3. `single` 类型题 `correct` 数组长度必须为 1。
4. 所有循证 `evidence.points` 必须能在用户提供的来源文献中找到依据；不得编造文献结论。
5. 全部文本为简体中文，无营销夸大用语。
