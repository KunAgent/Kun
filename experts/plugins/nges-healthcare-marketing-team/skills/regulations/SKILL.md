# 医疗营销合规法规知识库

## 功能说明

本技能提供 NGES 工程化引入的 14 部中国医疗营销合规核心法规原文，作为合规检测的权威法律依据。

## 法规清单

| 序号 | 法规名称 | 适用场景 |
|------|---------|---------|
| 1 | 中华人民共和国广告法 | 医疗/药品/器械/保健品广告基本规则（第16-18条、第46条） |
| 2 | 药品广告审查发布标准 | 药品广告内容的具体禁止性规定 |
| 3 | 中华人民共和国药品管理法 | 药品全生命周期管理，超适应症推广罚则（第90条） |
| 4 | 中华人民共和国药品管理法实施条例（2026修订） | 药品管理实施细则，营销行为约束 |
| 5 | 药品说明书和标签管理规定 | 药品说明书合规要求 |
| 6 | 医药代表管理办法（2026修订） | 医药代表行为规范、学术推广边界、禁止行为（第24条） |
| 7 | 医药企业防范商业贿赂风险合规指引 | 反商业贿赂合规体系，利益输送识别 |

| 10 | 中华人民共和国个人信息保护法 | 患者隐私、敏感个人信息、跨境传输 |

## 调用方式

### 查看法规全文

```
Read skills/regulations/references/{法规文件名}.md
```

### 搜索特定条款

```
Grep "关键词" skills/regulations/references/
```

## 使用原则

1. **按需触发，切忌滥用**：本技能存储的是法规原文全文。常规合规判定直接使用系统 prompt §三 中已内嵌的法规要点即可，速度更快。仅当用户**明确要求查看某部法规的原文全文或某条款的精确原文**时，才调用本技能 Read 对应的参考文件。
2. **确认现行有效**：引用前确认法规版本是否为最新（注意修订年份标注）
3. **原文引用**：输出法条时保留原文措辞，不可擅自简化或改写
4. **区分法律层级**：法律 > 行政法规 > 部门规章 > 行业准则

## 输出格式

```
**法规依据**：《{法规名称}》第{X}条
**原文**：「{法条原文}」
**适用分析**：{本案如何适用该法条}
```
