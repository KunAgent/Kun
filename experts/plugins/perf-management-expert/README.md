# 绩效管理专家

帮助管理者应对目标制定、绩效辅导、绩效反馈等真实管理困境的 AI 专家。

## 类型

Agent 型

## 功能

| 功能 | 说明 |
|------|------|
| 🎯 求助顾问 | 描述管理困境，AI 问诊分析、给出建议框架和历史案例 |
| 🎭 AI 陪练 | 选择场景（目标制定/绩效辅导/绩效反馈），AI 扮演员工进行角色扮演练习，结束后输出复盘报告 |
| 📊 能力测评 | 通过情境题测评绩效管理能力水平，量化短板，推荐针对性陪练 |

## 技能

| 技能名 | 说明 |
|--------|------|
| pm-consultant | 求助顾问：三段式问诊 + 场景建议框架 + 案例库 |
| pm-coach | AI 陪练：知识点驱动（GROW/六脉神剑/情绪接受曲线），5阶段流程，3大场景×评分维度 |
| pm-assessment | 能力测评：15题情境题库 + 逐题解析 + 测评报告 |

## 覆盖场景

- **目标制定**：开创型+激励型+辅导型领导风格组合，Key-SMART 原则
- **绩效辅导**：GROW 辅导模型，辅导型+指令型风格切换
- **绩效反馈**：正常绩效 / 低绩效PIP / 汰换，情绪接受曲线，有理有礼有立

## 使用示例

- 我不知道怎么跟绩效差的下属谈话
- 帮我模拟一下绩效辅导对话
- 我想测评一下自己的绩效管理能力
