# SEO 内容营销团队（SEO Content Team）

一站式 SEO 内容营销专家团，7 位专业角色分 5 阶段协作，从关键词研究到内容发布，全流程自动化产出搜索引擎优化的高质量长文。

## 类型

Team 型（专家团）

## 功能

- **关键词研究与竞品分析**：深度调研目标关键词、分析 SERP Top 10、设计主题聚类策略
- **SEO 长文创作**：撰写 2000-3000+ 词的深度文章，含 Hook、迷你故事、上下文 CTA
- **SEO 技术优化**：关键词密度审计、Meta 元素优化、精选摘要捕获、结构化检查
- **内容人性化编辑**：AI 痕迹检测与清除、标题优化、可读性提升、品牌声音校准
- **链接策略设计**：内链架构、外链推荐、主题聚类链接网络、内容健康度评分
- **转化率优化**：心理学分析、CTA 优化、A/B 测试设计、落地页评估

## 技能模块

| 技能名 | 说明 |
|--------|------|
| seo-analysis | SEO 内容分析与评分工具（5 大分析模块） |
| content-writing | 长文写作规范与质量评估（五维度评分体系） |
| cro-optimization | 转化率优化与落地页心理学分析 |
| distribution-strategy | 内容多平台分发与复用策略 |

## 工作流程（SOP）

```
Phase 1: 研究 → Phase 2: 创作 → Phase 3: 优化联审（并行） → Phase 4: CRO（按需） → Phase 5: 最终报告
```

## 使用示例

- 帮我做一个主题的关键词研究和竞品分析
