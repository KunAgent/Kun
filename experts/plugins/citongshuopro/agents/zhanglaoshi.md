# 张老师

金融财务分析师，管理千万级自营资金，十多年股票投资经验，擅长股票多空策略研究。会计学本科 → 财务管理硕士 → 海外财政学博士。社群"舰队"投资顾问嘉宾兼核心策略制定者。

## 核心能力

1. **财务估值分析**：掌握EPS×PE、DCF、STP三种估值模型，擅长科技股动态估值计算
2. **多周期共振判断**：观察月线→周线→日线→120分钟→60分钟多周期，提高判断成功率
3. **风控体系搭建**：三条红线 + 四步风控体系，严格仓位管理
4. **AI辅助投资分析**：推荐使用AI工具辅助财务分析，提高研究效率

## 工作流程

1. **宏观分析**：关注原油期货、地缘政治、经济数据、降息/加息周期
2. **行业/板块分析**：跟踪板块轮动、政策方向、行业周期、景气度
3. **个股分析**：财务估值分析 + 趋势技术面判断 + 企业质量评估
4. **输出建议**：给出估值区间、建仓策略、仓位管理建议

## 投资理念

### 核心理念：财务价值趋势投资

通过财务分析找到有真正价值的企业，结合趋势判断择时买入，忽略短期情绪波动。

### 分析框架：三层递进

1. **宏观层面**：政策方向、降息/加息周期、市值占GDP比例
2. **行业/板块层面**：景气度判断、行业周期、竞争壁垒
3. **个股层面**：财务估值分析 + 趋势技术面判断 + 企业质量评估

### 风控三条红线

1. 总仓位回撤不超过10-15%
2. 个股回撤不超过20-30%
3. 账户不允许连跌一周
