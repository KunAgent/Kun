# 腾讯云刊例价查询助手

专为腾讯云销售团队打造的 AI 询价助手，支持**产品咨询**和**刊例价查询**两大场景。

## 我能帮你做什么

### 🔍 产品咨询

不确定选什么产品 / 规格？先问我：

- "Redis 标准架构和集群架构怎么选？"
- "CVM 和 Lighthouse 有什么区别？"
- "MySQL 怎么计费的？"
- "我的场景适合用什么数据库？"

我会基于产品知识库给你分类对比、选型建议和参考价格区间，帮你快速锁定目标。

### 💰 快速查价

确定了产品和配置，直接告诉我：

- "CVM 4核8G 广州包月多少钱"
- "MySQL 双节点 4C8G 500G 存储 北京 一年"
- "国际站 新加坡 S5.MEDIUM2 按量"

秒级返回精确刊例价，支持跨可用区自动比价取最低。

### 📊 批量查价

上传 Excel / 图片配置清单，我会：

1. 解析配置 → 跟你**确认**每行规格、地域、计费模式是否正确
2. 你确认无误后，逐行查出实时刊例价
3. 自动抽检验证结果准确性
4. 生成带完整证据链的正式报价 Excel，给你下载链接

> 💡 第一轮**不会直接出价**，会先把解析结果给你看一遍——确认没歧义再走查价，避免"查完发现规格错了重做"。

### 🔁 多轮追问

在同一个会话里：
- 修正某行配置（"第 3 行地域改成上海"）
- 横向比价（"换成按量计费再算一遍"）
- 追加产品（"再加一台 CVM 64核 256G"）
- 询问报价里的细节（"那个 SPU Code 是啥意思"）

不用每次都重新发清单，对话上下文会自动延续。

## 使用示例

```
👤 查一台广州 4核8G 的 CVM 一年刊例价
👤 帮我批量查这个 Excel 配置清单的刊例价
👤 Redis 标准版和集群版价格差多少？
👤 国际站新加坡 MySQL 8.0 双节点怎么计费？
👤 [上传截图] 这张报价表能不能也帮我查一下？
```

> 📌 **支持的输入形式**：Excel（`.xlsx`）、图片截图、聊天截图、手写拍照、PDF 页面截图、纯文本表格——都能识别。

## 关于价格准确性

- 每一个价格数字都来自**实时内部询价 API**，不是网页爬取、不是历史缓存、不是 LLM 凭记忆编出来的
- 查不到的产品会如实告知"不支持 API 询价"，**绝不编造数字**
- 用了默认值（如默认包月、默认数量 1）会**明确标注**
- 估算价格会标"建议复核"
- 报价单 Excel 自带证据链，每一行价格都能追溯到 API 响应

> ⚠️ 输出的是**刊例价（目录价）**，实际成交价以合同折扣为准，请联系商务经理。

## 鉴权说明

本助手通过腾讯内部的 knot 平台调用询价能力，**首次使用需要配置一次 API Token**：

1. 助手第一次调用询价能力时，会检查 `KNOT_API_TOKEN` 环境变量
2. 如未配置，助手会引导你去 https://knot.woa.com/settings/token 申请，并自动帮你写入 shell profile
3. 配置一次后**永久生效**，所有终端工具（CodeBuddy / WorkBuddy / Claude Code 等）都能用
4. Token 过期时助手会提示重新申请，**永远不会向你索要 SecretId / SecretKey**

> 推荐使用**团队 token**（多人共用同一查价配额），个人 token 用于个人账户限频场景。

## 工作原理（可选阅读）

助手本身是一个轻量的"客户端代理"——把你的提问原样转给 knot 平台上的询价智能体，再把智能体的回答原样贴给你。

- **本地做的事**：解析 Excel / 识别图片 → markdown 表格、维护多轮对话上下文、透传请求与响应
- **服务端做的事**：解析配置语义、追问缺失维度、判断地域可用区合理性、调询价 API、生成报价单

这种设计的好处：
- 询价业务逻辑由后端智能体统一维护，本地客户端**不会用过期的产品知识或定价规则误导你**
- 客户端**不替你做决策**——服务端有疑问会原样转给你确认，避免"AI 自作主张猜错"
- 报价单生成、抽检验证等重活都在服务端，本地只负责把结果展示给你

## 反馈与支持

- 询价能力问题（价格不对、规格不支持、API 报错）→ 反馈给 knot 平台询价智能体的维护团队
- 客户端使用问题（脚本报错、token 配置）→ 提 issue 到本仓库
