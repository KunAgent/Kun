# 利唐智语AI面谈官 (LiTang AI Talker)

贯穿面谈全生命周期的企业级智能沟通助手：会前大纲生成、会中话术引导、会后纪要提炼，覆盖 9 大标准面谈场景。

## 类型

Agent 型（单专家）

## 功能

- **智能面谈大纲**：覆盖通用会议、面试记录、新员工融入、周期绩效复盘、绩效辅导、IDP面谈、1-on-1、项目复盘、离职复盘等 9 大场景
- **线上实时指引**：面谈过程中提供结构化话术与节奏引导
- **结构化纪要**：基于云录制自动生成含摘要、待办、转写摘要的结构化会议纪要
- **历史回溯**：搜索历史面谈记录，按需读取会话文档
- **人员选择**：通过 i人事系统模糊搜索、分页查询参与人员
- **深度集成 iHR CLI**：一键安装、自动认证、动态发现最新接口能力

## 技能

| 技能名 | 说明 |
|--------|------|
| ihr-shared | CLI 运行时、鉴权配置、JSON 协议、时间处理、错误排查等共享规则 |
| ihr-base | 基础选人组件，支持分页和姓名模糊搜索 |
| ihr-cli-operator | iHR CLI 核心操作器，安装/认证/版本管理/意图路由/安全策略 |
| ihr-conference | 面谈/会议业务：搜索历史记录、读取会话文档、创建并发起面谈 |
| ihr-interface | 原生网关调用兜底能力，支持 GET/POST/PUT/PATCH/DELETE/multipart |

## 工作流程

```
用户请求
    ↓
环境自检 (ihr-cli 安装/版本/登录)
    ↓
意图判断
    ├── 回溯历史 → +search → +documents
    └── 创建面谈 → +selectStaffs → +launch
              ↓
         输出结果/纪要/待办
```

## 使用示例

- 帮我为张三安排一次周期绩效复盘面谈，今天下午 3 点开始3 分钟，线下会议
- 帮我翻一下最近两个月聊过预算评审的会
- 我记得2月聊过一次年度规划，你帮我找出来
