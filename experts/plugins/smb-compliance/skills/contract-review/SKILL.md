# Contract Review

按中国法律框架审查合同：标记不利条款、识别责任风险、补充必备条款，并给出谈判 playbook 和替代措辞。

## 工作流

1. **提取关键条款**
   - 合同标的与服务范围
   - 价款 / 付款条件 / 开票约定
   - 违约责任、损害赔偿、责任限额（中国民法典语境，不用 indemnification）
   - 解除 / 续签 / 自动续约
   - 知识产权归属与许可
   - 保密条款（NDA / 保密协议）
   - 质量保证与免责
   - 争议解决与管辖（仲裁 vs 诉讼、管辖地）
   - 适用法律（一般是中华人民共和国法律）

2. **标出不利条款与缺失条款**
   - **不利**：单方责任上限过低或对方无上限、无通知自动续约、模糊履约范围、无任意解除权、违约金计算不对等、付款条件向对方倾斜
   - **缺失**：数据合规与个人信息保护（按《个人信息保护法》）、知识产权归属、不可抗力、审计权、SLA 与违约救济、税务与发票条款（增值税专票/普票/含税不含税）

3. **每条条款打风险分**（高 / 中 / 低）
   - **高**：违约责任无封顶、无解除权、知识产权强制归对方、无保密、付款条件严重失衡、争议解决约定到对方所在地不便诉讼
   - **中**：付款账期偏长、履约范围模糊、争议解决条款薄弱、违约金过高有被法院调减风险（按民法典第 585 条违约金过高可调减）
   - **低**：格式问题、非标但可接受的条款

4. **生成谈判 playbook** — 对每条标记条款：
   - 当前措辞（原文引用）
   - 风险说明（结合民法典/相关法律解释）
   - 建议替代措辞
   - 退一步底线（fallback）

5. **输出风险摘要与决策建议**
   - 总体风险等级（可签 / 修改后可签 / 不建议签）
   - 签前必谈条款
   - 锦上添花条款
   - 后续动作建议

## 中国合同必查清单（《民法典》合同编核心条款）

按民法典第四百七十条，合同一般具备：当事人信息、标的、数量、质量、价款或报酬、履行期限和方式、违约责任、争议解决方法。审查时按这八要素核对。

针对几类常见合同的额外重点：

| 合同类型 | 必看 |
|---------|------|
| 采购/服务合同 | 履约标准、验收方式、付款节奏与开票、违约金、不可抗力 |
| 销售合同 | 交付方式与风险转移、质量异议期、退换货、保修 |
| 技术开发/软件合同 | 知识产权归属、源代码交付、二次开发权、保密期限 |
| 劳动合同 | 试用期上限、社保公积金、加班与综合工时、竞业限制补偿、解除条件（按《劳动合同法》强制条款） |
| 租赁合同 | 租期、押金、转租、装修归属、提前解除违约金、税票 |
| 股东 / 投资协议 | 业绩对赌、回购、反稀释、知情权、退出机制 |

## 输出格式

```
## 合同风险摘要
- 合同类型：[采购 / 销售 / 服务 / 劳动 / 租赁 / 股东]
- 对方：[名称]
- 总体风险：[可签 / 修改后可签 / 不建议签]
- 适用法律：[一般为中华人民共和国法律]
- 争议解决：[XX 仲裁委员会仲裁 / XX 法院诉讼]

## 风险标记

### 高风险
1. [条款名] — [风险说明]
   - 原文："[引用]"
   - 建议措辞："[替代文本]"
   - 退一步底线："[fallback]"

### 中风险
1. [条款名] — [风险说明]
   ...

### 低风险
1. [条款名] — [备注]
   ...

## 缺失条款
1. [条款] — [为什么需要补，对应法律依据]

## 谈判 Playbook
- 必谈条款（不可妥协）：[数量]
- 锦上添花：[数量]
- 建议开盘立场：[摘要]

## 决策建议
[总体评估和下一步]
```

## Notes

- 本技能给出合同审查参考意见，不构成正式法律意见——重大合同（>50万 或 涉及关键业务）建议交由专业律师过一遍
- 涉外合同需额外考察适用法律选择、CISG 适用性、外汇管制；建议另行处理
- 合同条款引用法条时给到具体条款号（如《民法典》第 ××× 条），方便客户和对方法务对话
