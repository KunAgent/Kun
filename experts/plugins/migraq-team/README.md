# 腾讯云上云迁移专家团 (MigraQ Team)

WorkBuddy 专家团插件 — 由 7 位专家协作完成端到端上云迁移服务。

## 团队成员

| 角色 | 职责 |
|------|------|
| 解决方案专家（主理人） | 接收需求、编排分工、综合输出 |
| 腾讯云产品专家 | 产品选型、规格映射、能力评估 |
| Landing Zone 专家 | 着陆区规划、网络/安全基线设计 |
| 上云架构师 | 整体上云架构设计与方案评审 |
| 交付工程师 | 迁移实施与交付执行 |
| 运维工程师 | 迁移后运维保障与稳定性验证 |
| FDE 前置部署工程师 | 前置咨询与环境部署交付 |

## 使用方式

```bash
./build_team_zip.sh
```

生成 `migraq-team.zip`，解压后安装到 WorkBuddy 即可使用。

## 环境要求

| 项 | 要求 |
|---|---|
| Python | ≥ 3.7（脚本运行时会自检，低于此版本会以返回码 1 退出） |
| 强制 pip 依赖 | 无。脚本仅使用 Python 标准库 |
| 可选依赖 | `certifi`（强化 HTTPS 证书验证，缺失时自动回退到系统 CA） |

可选安装：

```bash
pip install certifi
```
