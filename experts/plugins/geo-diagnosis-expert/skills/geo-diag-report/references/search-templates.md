# GEO诊断报告 - 搜索查询模板

> 各阶段执行搜索时的标准查询模板，使用 `{brandName}` 和 `{productType}` 占位。
> 搜索执行规范（速率控制、重试容错、结果验证）详见 `references/search-strategy.md`。
> **v4.0优化**：合并重复搜索，减少总搜索次数；明确并行分组。

---

## 阶段1 搜索组（5次→3次并行）

### 组A：品牌+竞品（3次并行）

```
搜索1: "{brandName} {productType}" 品牌 介绍 官网
搜索2: "{productType}" 品牌 排名 推荐 2025
搜索3: "{brandName} {productType}" 评测 体验 对比
```

**执行策略**：3次WebSearch同时发起，不设间隔。
**结果提取**：
- 搜索1 → 官网URL、品牌介绍、产品矩阵
- 搜索2 → 竞品名称、市场份额、排名
- 搜索3 → 自媒体/权威媒体评测URL和标题

> **v4.0优化**：将原6次自媒体site搜索+5次权威媒体site搜索+4次竞品搜索，合并为3次通用搜索。
> 原因：site搜索覆盖率低，通用搜索结果更全面，AI可从通用结果中提取各平台信息。

### 组B：补充搜索（2次并行，可选）

> 仅当组A结果不足时执行。

```
搜索4: "{brandName}" site:36kr.com OR site:huxiu.com
搜索5: "{brandName}" 负面 投诉 问题
```

**执行策略**：2次WebSearch同时发起。
**结果提取**：权威媒体URL、负面舆情关键词。

---

## 阶段2 搜索组（2次并行）

```
搜索1: "{brandName} {productType}" 推荐 AI搜索
搜索2: "{brandName} {productType}" 哪家好 对比 评测
```

**执行策略**：2次WebSearch同时发起。
**结果提取**：品牌在推荐类问题中的真实提及数据。

---

## 阶段3 搜索组（3次并行）

```
搜索1: "{brandName}" 负面 投诉 问题 质量
搜索2: "{brandName}" 口碑 评价 体验 怎么样
搜索3: "{brandName}" 风险 纠纷 争议 安全
```

**执行策略**：3次WebSearch同时发起。
**结果提取**：负面关键词、正面口碑关键词、舆情趋势信号。

## 搜索次数对比

| 阶段 | v3.9搜索次数 | v4.0搜索次数 | 优化 |
|------|-------------|-------------|------|
| 阶段1 | 11次（6自媒体+5权威） | 3-5次 | -55~73% |

## 搜索缓存（v4.0新增）

执行搜索前，先检查 `diag-output/search-cache/{brand}-{product}-{type}.json` 是否存在且未过期：
- 基建缓存（infra）：30分钟
- 竞品缓存（competitor）：1小时
- 舆情缓存（sentiment）：15分钟

缓存命中时跳过搜索，直接使用缓存结果。详见 `references/search-strategy.md`。
