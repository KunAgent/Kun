# 编排模式

用户意图超出纯GEO诊断时，按以下模式扩展：

| 用户意图 | 编排模式 | 说明 |
|----------|----------|------|
| "诊断/可见度/曝光/GEO效果" | 标准 | 直接执行4阶段流水线 |
| "全面分析/深度分析/综合评估" | 深度 | 先结构化调研 → 再诊断 → 合并报告 |
| "市场规模/战略规划/TAM" | 战略 | 先市场测算 → 再诊断 → 合并报告 |

---

## 深度分析编排

在标准诊断前，增加结构化调研阶段，用 WebSearch 补充行业背景。

**调研步骤**：

```
1. 生成调研大纲（5-8个条目）
   条目示例（以"格力空调"为例）：
   - 中国空调行业2025-2026市场规模与增长
   - 空调行业主要竞品格局（格力/美的/海尔/小米）
   - AI搜索对家电行业的影响趋势
   - 格力品牌线上渠道与自媒体布局
   - 空调行业消费者决策路径

2. 逐条 WebSearch（每条1-2次搜索）
   → 中文用百度/BingCN，英文用Google/DuckDuckGo
   → 记录搜索次数和数据来源

3. 汇总（直接写入诊断报告 OVERVIEW.summary 前的背景段）
   → 每条目2-3句核心结论
   → 标注数据来源和时效性
```

**合并规则**：

| 来源 | 合并到报告位置 | 方式 |
|------|---------------|------|
| 行业趋势 | OVERVIEW.summary 前置背景段 | 摘要1-2句 |
| 竞品生态 | COMPETITOR.competitors 补充 | 市场占有率、融资信息 |
| 技术路线 | SUGGESTION.roadmap | 趋势对齐建议 |
| 交叉验证 | OVERVIEW.highlights/risks | 调研数据 vs 诊断数据冲突时标注 |

## 战略报告编排

在标准诊断前，增加市场规模测算阶段，用 WebSearch 获取行业数据后估算 TAM/SAM/SOM。

**市场测算步骤**：

```
1. 定义市场范围：产品/服务、地域、客群、时间

2. WebSearch 获取行业数据（3-5次搜索）
   → 搜索词："{行业} 市场规模 {年份}"、"{行业} 增长率"、"{品类} 渗透率"
   → 优先：行业报告、政府统计、协会数据

3. TAM/SAM/SOM 测算
   TAM = 行业总规模 × 相关比例
   SAM = TAM × 地域/客群/产品约束系数
   SOM = SAM × 现实渗透率（1-5%）
   验证：自上而下 vs 自下而上，差距>3倍需重估

4. 竞品市场占有率
   → WebSearch "{品牌} 市场份额 {年份}"
   → 补充到 COMPETITOR.competitors[i].marketShare
```

**合并规则**：

| 来源 | 合并到报告位置 | 方式 |
|------|---------------|------|
| TAM/SAM/SOM | OVERVIEW 新增 marketSizing 字段 | 3行数据+来源 |
| 竞品占有率 | COMPETITOR.competitors 补充 marketShare | 百分比+来源 |
| 消费者洞察 | SENTIMENT.keyDrivers 补充 | 消费决策因素 |
| 战略定位 | SUGGESTION.roadmap 新增 P0 | 市场空白+GEO优化交叉 |
