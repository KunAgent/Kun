# bh.DescribeUsers 字段说明

## Status（用户状态）

> **类型：String（字符串，非数字！）**  
> API 直接返回原始字符串值，禁止自行构造数字再映射。三个状态互斥，各状态数量之和必须等于 TotalCount。

| 值 | 含义 |
|----|------|
| `Normal` | 正常 |
| `Inactivated` | 未激活 |
| `Locked` | 锁定 |

**踩坑记录**：AI 编造数字映射导致的典型错误案例：实际 Locked=3 个，但输出 Locked=68 个；各状态占比之和超过 100%（如 2.2%+94.4%+75.6%=172.2%）。

## ActiveStatus（激活状态）

| 值 | 含义 |
|----|------|
| `0` | 未激活 |
| `1` | 已激活 |

## LockStatus（锁定状态）

| 值 | 含义 |
|----|------|
| `0` | 未锁定 |
| `1` | 已锁定 |

## AuthType（认证方式）

| 值 | 含义 |
|----|------|
| `0` | 本地认证 |
| `1` | LDAP 认证 |
| `4` | CAM 认证 |

## 用户来源分类（AuthType + RoleArn 组合）

| AuthType | RoleArn | 用户类型 |
|----------|---------|---------|
| `4` | 非空 | CAM 角色（不是真实用户） |
| `4` | 空 | CAM 用户（真实用户） |
| `0` | 空 | 本地用户 |
| `1` | 空 | LDAP 用户 |

## TotalCount 注意事项

`TotalCount` 包含 CAM 角色，展示"用户人数"时必须区分：  
`TotalCount` = 人类用户数 + CAM 角色数。  
判断方法：`RoleArn` 字段非空 → CAM 角色；`RoleArn` 为空 → 人类用户。
