# cfw.DescribeDefenseSwitch 字段说明

## BasicRuleSwitch / TiSwitch / VirtualPatchSwitch / BaselineAllSwitch（各子开关）

| 值 | 含义 |
|----|------|
| `0` | 关闭 |
| `1` | 开启 |

| 字段 | 说明 |
|------|------|
| `BasicRuleSwitch` | 基础防御规则开关 |
| `TiSwitch` | 威胁情报开关 |
| `VirtualPatchSwitch` | 虚拟补丁开关 |
| `BaselineAllSwitch` | 安全基线开关 |
