# cfw.DescribeBlockIgnoreList 字段说明

## RuleType（规则类型）

| 值 | 含义 |
|----|------|
| `1` | 封禁 |
| `2` | 外部 IP |
| `3` | 域名 |
| `4` | 威胁情报 |
| `5` | 资产实例 |
| `6` | 自定义策略 |
| `7` | 入侵防御规则 |

对应 `RuleTypeDataList` 返回各类型数量数组：`[封禁, IP地址, 域名, 威胁情报, 资产实例, 自定义策略, 入侵防御规则]`。

## Direction（方向）

| 值 | 含义 |
|----|------|
| `"0"` | 出站 |
| `"1"` | 入站 |
| `"3"` | 内网 |
| `""` | 全部方向 |

## Action（动作）

| 值 | 含义 |
|----|------|
| `1` | 封禁 |
| `2` | 放通 |

## ShowType（查询类型）

| 值 | 含义 |
|----|------|
| `"blocklist"` | 封禁列表 |
| `"whitelist"` | 白名单列表 |

> `RuleType` 与 `ShowType` 至少传一个，否则报 `InvalidParameter`。
