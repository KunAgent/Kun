# tcss.EventStatus 字段说明（通用）

> 适用于 TCSS 所有运行时告警接口（逃逸/异常进程/反弹Shell/高危系统调用/木马/恶意请求/K8sAPI 异常等）。

## 事件状态值（Filters 筛选时使用）

| 值 | 含义 | 适用场景 |
|----|------|---------|
| `EVENT_UNDEAL` | 待处理 | 逃逸/异常进程/反弹Shell/高危系统调用/木马/恶意请求 |
| `EVENT_DEALED` | 已处理 | 同上 |
| `EVENT_INGNORE` | 已忽略 | 同上 |
| `EVENT_ADD_WHITE` | 已加白 | 同上 |
| `SCAN_UNDEAL` | 待处理（木马专用） | 仅木马模块 |

> **注意**：木马的"待处理"状态值是 `SCAN_UNDEAL`，而其他模块是 `EVENT_UNDEAL`。agent.py 已统一翻译为"待处理"标签。

## 容器状态值

| 值 | 含义 |
|----|------|
| `RUNNING` | 运行中 |
| `PAUSED` | 暂停 |
| `STOPPED` | 停止 |

## 主机/Agent 状态值

| 值 | 含义 |
|----|------|
| `ONLINE` | 在线 |
| `OFFLINE` | 离线 |

## 网络隔离状态值

| 值 | 含义 |
|----|------|
| `NORMAL` | 正常 |
| `ISOLATED` | 已隔离 |

## 镜像扫描状态值

| 值 | 含义 |
|----|------|
| `SCANNED` | 已扫描 |
| `SCANNING` | 扫描中 |
| `NOT_SCAN` | 未扫描 |

## 风险等级值

| 值 | 含义 |
|----|------|
| `RISK_CRITICAL` | 严重 |
| `RISK_HIGH` / `High` | 高 |
| `RISK_MEDIUM` / `Middle` | 中 |
| `RISK_LOW` / `Low` | 低 |
| `RISK_NOTICE` / `Notice` | 提示 |

## 运行时告警模块优先级（报告/周报用）

| 等级 | 告警模块 | 分级理由 |
|------|---------|---------|
| P0 严重 🔴 | 反弹Shell | 等同已被入侵拿到交互式 Shell |
| P0 严重 🔴 | 异常进程 | 高危命令占比高，有拦截触发说明确有恶意行为 |
| P0 严重 🔴 | 恶意外联（恶意请求） | 访问了情报黑 IOC，C2 回连风险 |
| P0 严重 🔴 | 文件查杀（木马病毒） | 木马病毒零容忍 |
| P0 严重 🔴 | 应用防护（漏洞防御/内存马） | 漏洞利用/内存马注入事件 |
| P1 高危 🟠 | 文件篡改 | 数量大但全告警模式，需排查真实篡改 |
| P2 中危 🟡 | 高危系统调用 | 已处理/加白比例高，多为已知正常行为 |
| P3 低危 🟢 | K8sAPI 异常 | 误报较多 |
| P3 低危 🟢 | 容器逃逸 | 误报较多 |
