# cwp.DescribeFileTamperRules 字段说明

> 核心文件监控规则列表（也称"文件篡改检测"规则）。

## Status（规则状态）

> **⚠️ 反直觉！与事件 Status 含义相反。**

| 值 | 含义 |
|----|------|
| `0` | 已启用 |
| `1` | 已关闭 |

## Level（规则等级）

| 值 | 含义 |
|----|------|
| `0` | 无 |
| `1` | 高危 |
| `2` | 中危 |
| `3` | 低危 |

## RuleCategory（规则类型）

| 值 | 含义 |
|----|------|
| `0` | 系统规则 |
| `1` | 自定义规则 |
