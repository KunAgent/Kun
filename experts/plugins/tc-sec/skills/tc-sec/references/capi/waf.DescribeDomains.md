# waf.DescribeDomains 字段说明

## Status（WAF 防护开关）

| 值 | 含义 |
|----|------|
| `0` | 防护关闭 |
| `1` | 防护中 |

> **注意**：同名 `Status` 在 WAF 不同接口含义完全不同（域名 1=防护中；规则 1=开启；下载任务 1=完成；实例 1=运行中）。`Status` 与 `State` 是不同字段：Status=WAF 防护开关，State=DNS 解析/CLB 绑定状态。

## Mode（防护模式）

| 值 | 含义 |
|----|------|
| `0` | 观察模式 |
| `1` | 拦截模式 |

## Edition（WAF 类型）

| 值 | 含义 |
|----|------|
| `sparta-waf` | SaaS 型 WAF |
| `clb-waf` | CLB 型 WAF |

## Level（套餐版本）

| 值 | 含义 |
|----|------|
| `101` | 小微敏捷版 |
| `102` | 小微超轻版 |
| `2` | 高级版 |
| `3` | 企业版 |
| `4` | 旗舰版 |
| `6` | 独享版 |

## BotStatus（Bot 防护）

| 值 | 含义 |
|----|------|
| `0` / `1` | 关闭 |
| `2` / `3` | 开启 |

## ApiStatus（API 安全）

| 值 | 含义 |
|----|------|
| `0` | API 安全关闭 |
| `1` | API 安全开启 |

## ClsStatus（CLS 日志投递）

| 值 | 含义 |
|----|------|
| `0` | 日志投递关闭 |
| `1` | 日志投递开启 |

## State（SaaS 型域名 DNS 解析状态）

| 值 | 含义 |
|----|------|
| `0` | 正常 |
| `1` | 无 DNS 解析 |
| `200` | 源站不可达 |
| `311` | 证书过期 |

## FlowMode（CLB 型专用）

| 值 | 含义 |
|----|------|
| `0` | 镜像模式（不拦截） |
| `1` | 清洗模式（可拦截） |

## 服务端 Filters 支持字段

| Filter Name | 可选 Values |
|-------------|------------|
| `Edition` | `sparta-waf` / `clb-waf` |
| `Status` | `"0"` 防护关闭 / `"1"` 防护中 |
