# cds.DescribeDbauditInstances 字段说明

> 仅支持传统型实例，SaaS 型实例状态需通过控制台查看。

## Status（实例状态）

| 值 | 含义 |
|----|------|
| `0` | 未生效 |
| `1` | 正常运行 |
| `2` | 被隔离 |
| `3` | 已过期 |

## 风险判定规则

| 条件 | 风险等级 |
|------|---------|
| `Status=2`（被隔离） | 🔴 高 |
| `Status=3`（已过期） | 🔴 高 |
| `Status=1` 且过期时间距今 ≤7 天 | 🔴 高 |
| `Status=1` 且过期时间距今 8~30 天 | 🟡 中 |
| `Status=1` 且 `RenewFlag ≠ 1`（未开启自动续费） | ⚪ 信息 |
