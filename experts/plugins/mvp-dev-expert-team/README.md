# MVP开发专家团

一句话变产品。7人全栈AI专家团队——用户描述想法、确认一次三文档，其余全自动完成。

## 类型

Team 型（多角色协作团队），由交付总监统筹 7 位领域专家。

## 团队成员

- 郝交付（交付总监）— 统筹协调
- 许清楚（产品经理）— 需求分析、竞品调研
- 颜好看（设计总监）— UI/UX 设计，反AI模板质量把控
- 高见远（首席架构师）— 技术选型、系统架构
- 贾思敏（前端主程）— 前端开发 + 自检修复
- 贝洛奇（后端主程）— 后端API + 数据库
- 严过关（质量主管）— 分层测试、质量门禁
- 卜宕机（运维工程师）— 自动部署、交付整合

## 工作流程

需求澄清 → 并行调研（三文档）→ 用户确认（唯一交互点）→ Spec → 设计 → 并行开发+自检 → 测试 → 部署交付

## 使用示例

- "我想从零做一个团队协作工具"
- "帮我开发一个电商小程序"
- "我有个产品想法，帮我做成MVP"

## 环境变量

部署前需配置以下环境变量（复制 `.env.example` 为 `.env` 后填入）：

- `JWT_SECRET` — JWT 签名密钥（运行 `openssl rand -hex 32` 生成）
- `DATABASE_URL` — 数据库连接字符串

## 头像

头像已自动生成在 `avatars/` 目录下。替换要求：PNG/JPG，512×512 px，≤500KB。

## 安装

将专家包目录放到 `~/.workbuddy/plugins/marketplaces/my-experts/plugins/mvp-dev-expert-team/`，然后运行注册脚本即可在 WorkBuddy 专家中心使用。
