# tcloud-arch-diagram · 架构图绘制 Skill

> 专业的系统架构图绘制 AI 技能，支持腾讯云及通用架构场景，输出可二次编辑的 `.drawio` 文件。

---

## 功能特点

### 1. 专业架构图绘制

本 Skill 专门用于将文字描述的系统架构转换为专业、清晰的架构图，支持：

- **腾讯云系统架构**：VPC 网络拓扑、微服务集群、Serverless 架构
- **通用微服务架构**：服务分层、调用关系、数据流向
- **混合云架构**：本地数据中心与云端的连接拓扑
- **数据流架构**：消息队列、流处理、数据管道

生成的架构图遵循业界规范：分层布局清晰、连线走向明确、节点均匀分布、视觉风格统一。

---

### 2. 腾讯云官方图标 & 设计风格

自动使用腾讯云官方产品图标，完全符合腾讯云官方架构图设计规范：

**支持 33 个腾讯云产品图标：**

| 分类 | 产品 |
|------|------|
| 计算 | CVM、TKE、SCF、Lighthouse、弹性伸缩 AS |
| 网络 | CLB、CDN、NAT 网关、弹性公网 IP、专线接入 |
| 安全 | DDoS 防护、WAF、主机安全 CWP、容器安全 TCSS |
| 存储 | COS、CBS、CFS |
| 数据库 | TencentDB MySQL/Redis/MongoDB、TDSQL、TDSQL-C |
| 中间件 | API 网关、CKafka、TSF 微服务平台 |
| 监控 | 云监控 CM、CLS 日志服务、云拨测 CAT |
| 大数据 | EMR、Elasticsearch |

**设计风格规范：**
- 颜色体系使用腾讯云品牌色（#0052D9 主色）
- 各层容器配色区分（安全层红色、VPC 绿色、数据层紫色、监控层蓝色）
- 正交连线，箭头方向明确
- 字体统一（fontSize=11~13，fontColor=#333333）

---

### 3. 产出文件可二次编辑

输出的 `.drawio` 文件完全支持可视化拖拽编辑，无需重新生成：

| 操作 | 方法 |
|------|------|
| 移动节点 | 直接拖拽，连线自动跟随 |
| 修改文字 | 双击节点直接编辑 |
| 修改颜色/样式 | 右键 → Edit Style |
| 增加/删除节点 | 从工具栏拖入或 Delete 键删除 |
| 导出图片 | File → Export as → PNG / SVG / PDF |
| 调整连线 | 拖动连线路径点 |

**支持的编辑工具（任选其一）：**


## 使用方法

### 基本用法

直接用自然语言描述你的系统架构，AI 会自动生成架构图：

```
示例 1（简单）：
帮我画一个 Web 三层架构图，包含 CLB、两台 CVM 和 MySQL 数据库

示例 2（复杂）：
帮我画一个电商平台的微服务架构，
- 接入层：CLB + WAF + CDN
- 应用层：商品服务、订单服务、用户服务、支付服务（都用 TKE 部署）
- 数据层：MySQL（订单）、Redis（缓存）、COS（图片）、ES（搜索）
- 监控：云监控CM + CLS日志

示例 3（非腾讯云）：
帮我画一个通用微服务架构图，
- 网关层：Nginx + Kong
- 服务层：用户服务、商品服务、订单服务
- 数据层：MySQL、Redis、Kafka
```

### 生成流程

1. **AI 解析需求**：识别节点、层次和连接关系
2. **输出坐标规划表**：展示每个节点的位置规划，**可在此步骤纠正布局**
3. **生成架构图文件**：输出完整的 `.drawio` 文件
4. **自动注入图标**：腾讯云产品图标自动替换为官方图标
5. **交付总结**：说明架构分层和后续使用方式

### 首次使用（初始化图标库）

首次使用前需要运行一次图标库初始化脚本：

```bash
cd /path/to/tcloud-arch-diagram
python scripts/setup_icons.py
```

> 该脚本会从腾讯云官方下载图标包（约 1MB），解压并生成图标数据，只需运行一次。

## 常见问题

**Q：生成的图标显示为灰色文件图标怎么办？**  
A：运行 `python scripts/setup_icons.py` 重新初始化图标库，然后重新生成架构图。

**Q：能生成非腾讯云的架构图吗？**  
A：可以。非腾讯云节点使用圆角矩形文字节点，腾讯云产品节点才会显示官方图标。

**Q：生成的架构图可以导出为图片吗？**  
A：在 Draw.io 中打开后，通过 File → Export as 可导出为 PNG、SVG、PDF 等格式，适合放入文档或 PPT。
