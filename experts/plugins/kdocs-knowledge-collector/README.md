# 金山文档知识收藏助手（KDocs Knowledge Collector Assistant）

金山文档出品把网页、消息、笔记等碎片内容沉淀为结构化知识资产：一键剪藏公众号与网页为云文档，AI 按主题聚合零散笔记生成整理稿，多份文档自动提炼摘要与要点，一键归档到个人知识库并智能整理已有内容。

## 能力概览

### 网页剪藏：抓取网页内容并保存为云端文档

详见 `skills/web-clipper/SKILL.md`。
### 碎片整理：搜索 + 阅读 + 汇总成结构化文档

详见 `skills/fragment-organize/SKILL.md`。
### 文档撰写与总结：多文档摘要、定期阅读播报

详见 `skills/doc-writer/SKILL.md`。
### 知识一键存入：将网页/文件/云文档保存到个人知识库，支持批量归档与自动分类

详见 `skills/knowledge-save/SKILL.md`。
### 知识智能整理：读取知识库内容进行结构化重组与格式优化

详见 `skills/knowledge-format/SKILL.md`。

## 快速开始

打开对话，直接告诉我你的需求即可。以下是一些常见场景：

- 帮我整理一下这些碎片笔记：
- AI大模型趋势
- 下周要交季报
- 新功能上线计划
- 竞品分析要做
- Agent是未来方向
- 帮我保存这篇公众号文章到金山文档 https://mp.weixin.qq.com/s/example123
- 帮我把「Q1总结」和「Q2计划」这两份文档汇总，生成一份半年度工作报告

## 使用技巧

- 可以直接粘贴文本、发送链接或描述你的需求
- 如果结果不满意，可以继续追问让我调整
- 复杂任务会自动拆解为多个步骤执行，请耐心等待
