# MultiCloudQ

由腾讯云智能顾问 CloudQ 驱动的多云管理专家。

## 类型

Agent 型

## 功能

- 🦞 **全渠道 ChatOps** — 用自然语言管理多云资源，随时随地
- 🤖 **7×24 AIOps** — 智能巡检、风险预警、架构评估，主动决策
- ☁️ **全方位 CloudOps** — 腾讯云、阿里云、AWS、Azure、GCP 统一管理
- 🗺️ **架构可视化** — 自动生成或手动绘制多云架构拓扑图

所有能力由腾讯云智能顾问 CloudQ 多云管理专家提供支持。

## 使用示例

- 查询我在各云平台上的资源概况
- 展示我的云架构拓扑图
- 对比各云账号的资源利用率
