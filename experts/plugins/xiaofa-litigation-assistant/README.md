# 诉讼助手 Litigation Assistant

面向普通当事人的法律自助工具。11 类常见案件，7 大法律技能，从起诉到执行一站式指引。输出 DOCX 格式，Word/WPS 直接编辑。

## 类型

Agent 型（单个 AI 专家）

## 适用案件

| 类型 | 典型场景 |
|------|---------|
| 民间借贷 | 借了钱不还 |
| 简单买卖 | 交货不付款 / 付款不交货 |
| 劳动报酬 | 欠薪 / 拖欠工资 |
| 交通事故 | 对方全责不赔 |
| 邻里纠纷 | 漏水 / 噪音 / 物品损坏 |
| 房屋租赁 | 押金不退 / 房屋损坏 |
| 轻微人身损害 | 被狗咬 / 商场摔伤 |
| 物业服务 | 物业费争议 |
| 预付费消费 | 健身房/教培跑路 |
| 定金/订金 | 买车买房定金纠纷 |
| 不当得利 | 转错账 / 多付钱 |

## 核心能力

7 大法律技能：

1. **起草起诉状** — 模板填空即用，输出 DOCX
2. **证据整理** — 分类编号 + 证明目的
3. **流程指引** — 从立案到执行全流程
4. **强制执行** — 申请书 + 利息计算，输出 DOCX
5. **利息计算** — LPR 分段 + 迟延履行金
6. **DOCX 生成** — 法律文书直接导出 Word 格式

## 特点

- 普通人能看懂，不说法律黑话
- 模板即用，填空就能交
- 输出 DOCX，Word/WPS 打开即编辑
- 6 大技能加持，不只是聊天

## 知识库

默认公开网页检索（有幻觉风险），连接法律数据库 MCP 解锁满血模式。

## 外部依赖

### 法律幻觉校验 API（chineselaw.com）

法律幻觉校验技能依赖 `chineselaw.com` 开放 API 进行法条/案例引用真实性核验。

| 项目 | 说明 |
|------|------|
| 服务地址 | https://open.chineselaw.com |
| 接口 | `/open/hall_detect`（POST） |
| 认证方式 | `X-API-Key` 请求头 |
| 申请地址 | https://open.chineselaw.com（注册后获取 API Key） |
| 费用 | 参考官网定价 |

**申请步骤：**
1. 访问 https://open.chineselaw.com 注册账号
2. 进入控制台 → API 管理 → 创建 API Key
3. 将获取的 Key 填入 `legal-hallucination-check` 技能的 `YOUR_API_KEY` 占位处

**无 API Key 时的降级行为：**
- 法律幻觉校验技能将跳过 API 调用
- 输出报告顶部标注「未校验·人工终审必需」
- 建议通过 `flk.npc.gov.cn` 手动核实法条原文
