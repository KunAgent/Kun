# 案由字段定义结构说明

> 本文档说明 `app.js` 中 CLAIMS 和 FACTS 数据结构的规范，供修改案由模板时参考。

## 字段定义格式

### 通用格式

```javascript
[key, label, hint]
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `key` | string | 唯一标识符，格式为 `claim_01`, `facts_01` 等 |
| `label` | string | 显示标签。facts 中以 `【分组名】` 开头会自动创建分组标题 |
| `hint` | string | 占位符提示文本，同时作为 AI prompt 的填充参考 |

### 案由查找

每个案由用其 **案由 ID** 作为 key：

```javascript
const CLAIMS = {
  mjjd: [  // 民间借贷纠纷
    ['claim_01', '1. 本金', '截至 年 月 日止，尚欠本金 元'],
    ['claim_02', '2. 利息', '计算方式：...'],
  ],
};
```

## 诉讼请求字段 (getClaimFields)

所有案由的 ID 为 `claim_01`, `claim_02`, ... 等格式。

### 民间借贷纠纷 (mjjd) — 示例

```
claim_01  本金           "截至 年 月 日止，尚欠本金 元"
claim_02  利息           "计算方式：..."
claim_03  是否要求提前还款   "是□ / 否□"
claim_04  是否主张担保权利   "是□ 内容：..."
claim_05  是否主张实现债权费用 "是□ 明细：..."
claim_06  是否主张诉讼费用   "是□ 否□"
claim_07  其他请求         ""
claim_08  标的总额         ""
```

### 离婚纠纷 (lihun) — 示例

```
claim_01  解除婚姻关系      "（具体主张）"
claim_02  夫妻共同财产      "无财产□ / 有财产□ (房屋/汽车/存款/其他)"
claim_03  夫妻共同债务      "无债务□ / 有债务□ (债务清单)"
claim_04  子女直接抚养      "无此问题□ / 有此问题□ (子女归属)"
claim_05  子女抚养费        "金额及明细 / 支付方式"
claim_06  探望权           "行使主体 / 行使方式"
claim_07  离婚损害赔偿      "金额：..."
claim_08  是否主张诉讼费用   "是□ 否□"
claim_09  其他请求          ""
claim_10  诉前保全          ""
claim_11  是否已经诉前保全   "保全法院/时间/案号"
```

### 执行类申请书 — 特殊处理

执行类申请书（如 `zxsqs`）的 label 会自动变为"申请事项"而非"诉讼请求"。

## 事实与理由字段 (getFactsFields)

所有案由的 ID 为 `facts_01`, `facts_02`, ... 等格式。

### 分组语法

label 以 `【分组名】` 开头时，会创建可视化的分组标题：

```javascript
['facts_01', '【合同签订情况】1. 合同名称', '（合同全称）'],
['facts_02', '【合同签订情况】2. 签订时间', ''],
['facts_03', '【合同履行情况】1. 履行情况概述', ''],
```

这会产生两个分组：**合同签订情况**（含 facts_01, facts_02）和 **合同履行情况**（含 facts_03）。

### 通用模板 (general)

```
facts_01  基本事实（合同/法律关系建立情况）  ""
facts_02  合同/法律关系履行情况               ""
facts_03  违约/侵权/损害情况                  ""
facts_04  损失金额及计算方式                  ""
facts_05  担保情况（如有）                    ""
facts_06  其他需要说明的内容（可另附页）       ""
facts_07  请求依据（合同约定/法律规定）        ""
facts_08  证据清单（可另附页）                ""
```

## 添加新案由步骤

1. 打开 `assets/js/app.js`
2. 在 `CASE_TYPE_NAMES` 中添加新 ID → 名称映射
3. 在 `TEMPLATE_META` 中添加模板元信息
4. 在 `getClaimFields` 的 `CLAIMS` 对象中添加案由字段
5. 在 `getFactsFields` 的 `FACTS` 对象中添加案由字段
6. 在 `index.html` 的 `<select id="caseType">` 中添加新选项

## 模板元信息格式

```javascript
const TEMPLATE_META = {
  mjjd: {
    title: '民事起诉状（民间借贷纠纷）',   // 文书标题
    source: '2、民间借贷纠纷民事起诉状.docx',  // 来源范本文件名
    kind: '民事起诉状'                     // 文书种类
  }
};
```

`kind` 字段影响预览和导出的标题："起诉状" / "申请书" / "行政起诉状" / "刑事自诉状" / "国家赔偿申请书"。
