# 强制执行

## ⚠️ 认识论底线（全模式生效）

1. 金额计算（本金/利息/迟延履行金/诉讼费）必须有公式+依据，精确到分
2. 财产线索标注来源+置信度（★确定/◇可能/△推测），"听说"不得写入申请书
3. 利息分段计算注明：起算日/届满日/利率/天数，不可给"大约数"
4. LPR 变动时间点匹配央行公布的 LPR 调整日期
5. 执行风险诚实告知：执行不能/无财产/终本的可能性
6. 执行和解方案须当事人书面确认，律师不得越权承诺
7. 所有法条引用须经 `legal-hallucination-check` 验证——执行程序法条精确度要求高

### 🔴 CHECKPOINT-1：执行时效红线

- 申请执行时效 2 年（民诉法第 250 条），过期权利消灭
- 必须显式计算：生效日期 → 履行期限届满日 → 时效届满日
- 剩余 < 30 天 → 立即启动紧急通道（跳过财产线索深度调查）
- 已届满 → 检查中断/中止事由，无正当理由不建议提交

### 🔴 CHECKPOINT-2：执行不能/无财产告知（全流程 Node 7 入口）

- "终本"≠债权消灭，可随时恢复执行（无时效限制）
- 终本后失信名单/限制消费继续有效
- 每 6 个月申请一次网络查控是律师持续义务

### 🔴 CHECKPOINT-3：金额一致性（申请书生成前强制）

- 三版文书（传统式/要素式/利息明细）金额完全一致
- 迟延履行金与一般利息分开列项
- 申请总金额 = 本金 + 利息 + 迟延履行金 + 诉讼费

## 模式B：仅申请书（3 Step）

### Step 1 · 信息收集

| 要素 | 内容 | 重要性 |
|------|------|:----:|
| 执行依据 | 判决书案号+法院+生效日期 | 必填 |
| 申请执行人 | 姓名/名称+身份证号/统一社会信用代码+住址+电话 | 必填 |
| 被执行人 | 姓名/名称+身份证号/统一社会信用代码+住址+电话 | 必填 |
| 申请执行金额 | 本金+利息起算日+利率+诉讼费 | 必填 |
| 财产线索 | 银行账号/房产证号/车牌号/股权 | 强烈建议 |
| 履行期限 | 判决书载明的履行期限 | 必填 |
| 履行情况 | 各期已付/未付/部分付，逐笔核实 | 必填 |

### Step 2 · 利息与迟延履行金计算

> 🔗 优先调用 `legal-calculator` M1（逾期利息 LPR分段）+ M2（迟延履行金）

**两项利息同时主张，严格分开**：

| 项目 | 一般债务利息 | 迟延履行金（加倍部分） |
|------|-----------|-------------------|
| 依据 | 实体法（民法典/合同约定） | 程序法（民诉法第264条） |
| 计算 | 按判决/合同约定利率 | 日万分之一点七五（固定） |
| 起算 | 债务到期日/逾期日 | 判决履行期限届满次日 |
| 减免 | 可协商减免 | 原则上不可减免 |

**计算输出格式**：
```
┌──────────────────────────┬──────────────┬──────────────┐
│ 项目                     │ 计算公式     │ 金额         │
├──────────────────────────┼──────────────┼──────────────┤
│ ① 本金                   │ —           │ ¥XXX,XXX.XX  │
│ ② 一般债务利息（暂计至申请日）│ LPR分段     │ ¥XX,XXX.XX   │
│ ③ 迟延履行金（暂计至申请日） │ 0.0175%/日   │ ¥XX,XXX.XX   │
│ ④ 诉讼费（被执行人承担）   │ —           │ ¥X,XXX.XX    │
├──────────────────────────┼──────────────┼──────────────┤
│ 合计                     │              │ ¥XXX,XXX.XX  │
└──────────────────────────┴──────────────┴──────────────┘
```

### Step 3 · 申请书生成

> ## 🔴🔴 格式不得修改 —— 最高优先级铁律
> 
> **法院对文书格式要求极为严格，尤其是要素式表格。以下行为绝对禁止：**
> 
> | 禁止行为 | 说明 |
> |---------|------|
> | ❌ 修改表格列宽/行高 | 法院设定好的版式，任何微调都可能导致格式不符 |
> | ❌ 修改字体/字号/加粗 | 法院指定字体，不得换为其他字体 |
> | ❌ 修改页边距 | 法院预设边距即为规范 |
> | ❌ 删除/新增表格行 | 20行结构一行动不得 |
> | ❌ 修改合并单元格 | 合并状态不得改变 |
> | ❌ 修改标题行底色/样式 | 原范本什么颜色就什么颜色 |
> | ❌ 修改任何段落格式 | 对齐方式、行距、缩进一概不动 |
> | ❌ 复制到新文档 | 必须在范本原件上操作，另存为新文件 |
> 
> ✅ **唯一允许的操作**：定位到填写区单元格 → 仅替换该单元格内的文本内容。
> 
> **违规后果**：法院立案窗口可能以"格式不符"为由退回，重新提交浪费时间，可能导致执行时效过期。**这不是AI可以自行判断的事，这是法院的硬规定。**

> **格式基准**：传统式→法院标准执行申请书空白范本，要素式→法院标准要素式执行申请书范本。所有强制执行申请书格式以此为基准。

#### 3.1 传统式申请书（精确格式）

**生成工具**：`python-docx`（从零创建，非填表——传统式无范本文件，需按以下精确格式逐段生成）

**页面**：A4 | 上边距 3.0cm | 下边距 3.0cm | 左边距 3.2cm | 右边距 3.2cm

**标题**：`强制执行申请书`，黑体，一号（26pt），加粗，居中，行距1.5倍

**正文**：仿宋，四号（14pt），两端对齐（JUSTIFY），固定行距23pt（292100 EMU），首行缩进0.74cm

**结构**（严格按此顺序，板块间空行分隔）：
```
标题（黑体26pt居中 1.5倍行距）
[空行]
申请人：XXX，住所地XXX，统一社会信用代码 XXX。（法人适用）
       或：申请人：XXX，性别，出生年月，民族，身份证号码：XXX，住所地：XXX。（自然人适用）
负责人：XXX，（职务）。（法人适用，自然人不写此行）
被申请人：XXX，住所地XXX，统一社会信用代码 XXX。（或自然人格式同上）
负责人：XXX，（职务）。电话：XXX。（法人适用）
[空行]
执行依据：XXX法院（XXXX）XX号民事判决书/民事裁定书。（此行整段加粗）
申请事项：（此行加粗）
1、[具体请求，详见下文格式]
以上暂合计约XXX元。
2、本案执行费用由被申请人承担。
[空行]
事实与理由：（此行加粗）
[案情简述+判决生效+履行期限届满+催告无果，首行缩进0.74cm]
……特向贵院申请强制执行。
此致
XXX人民法院（左对齐，无缩进）
[空行]
                                申请人：XXX（右对齐）
                                XXXX年XX月XX日（右对齐）
```

**关键规则**（基于标准范本实测）：
- **当事人每项独立段落**——申请人/负责人/被申请人/负责人各一段，不合并；委托诉讼代理人不出现在传统式申请书中（当事人区和落款区均不写）
- **执行依据整段加粗**——不只是"执行依据"四字，是整个执行依据段落全部加粗
- **申请事项整段加粗**——"申请事项："四个字及冒号加粗
- **事实与理由整段加粗**——"事实与理由："四个字及冒号加粗
- 申请事项编号用"1、"而非"一、"
- 板块间必须有空段落分隔（见上述结构中的`[空行]`）
- 结尾"此致"段首行缩进0.74cm，"法院名称"左对齐无缩进
- 落款区（申请人/日期）右对齐，无缩进（不写委托诉讼代理人）

**申请事项模板**（根据执行依据类型微调）：
```
1、请求贵院依法强制执行XXX法院（XXXX）XX号民事判决书/民事裁定书/民事调解书，
   即：强制被申请人向申请人支付XXX元，并支付逾期利息（按XXX计算，自XXX起
   分段计算至实际清偿之日止，暂计至XXXX年XX月XX日约XXX元）及迟延履行期间的
   债务利息（按日万分之一点七五计算，自XXX起分段计算至实际清偿之日止，
   暂计至XXXX年XX月XX日约XXX元）。
以上暂合计约XXX元。
2、本案执行费用由被申请人承担。
```

#### 3.2 要素式申请书（20行标准表格）

> 🔴 **核心方法论**：不是"仿写"，不是"复制格式重建"，是**打开范本原件 → 定位填写区 → 仅替换填写区文本 → 另存为新文件**。所有标签、格式、表格结构、字体、字号、底色一概不动。法院版式即为规范，任何"优化"都构成违规。

**格式基准**：法院标准要素式执行申请书范本

**页面**：A4 | 四周边距 2.50cm

**非表格标题区**（表格上方段落）：
| 位置 | 字体 | 字号 | 对齐 |
|------|------|:---:|:---:|
| 主标题 `强制执行申请书` | 方正小标宋简体 | 22pt | 居中 |
| 副标题 `（申请执行用）` | 方正小标宋简体 | 18pt | 居中 |

**表格**：20行×2列，Table Grid样式，第1列宽3.95cm，第2列宽11.84cm

**表格字体**（全表统一）：
| 位置 | 字体 | 字号 | 对齐 |
|------|------|:---:|:---:|
| 分区标题行（第1/8/15行） | **方正小标宋简体** | **15pt** | 居中 |
| 左列标签 | 宋体 | 10pt | 左对齐 |
| 右列填写区 | 宋体 | 10pt | 左对齐 |

**填充脚本模板**（`fill_template.py`）：
```python
from docx import Document

# 🔴 打开范本原件
doc = Document(r"强制执行申请书（要素式·空白范本）.docx")
table = doc.tables[0]

# 🔴 仅替换填写区单元格文本，不得修改任何格式
def fill_cell(row_idx, text):
    """替换右列单元格全部文本（保留原格式）"""
    cell = table.rows[row_idx].cells[1]
    # 清空现有段落文本
    for p in cell.paragraphs:
        for r in p.runs:
            r.text = ""
    # 写入新文本到第一个run
    if cell.paragraphs[0].runs:
        cell.paragraphs[0].runs[0].text = text
    else:
        cell.paragraphs[0].add_run(text)

def fill_cell_multi(row_idx, lines):
    """多行填入——保留原段落数，逐run替换"""
    cell = table.rows[row_idx].cells[1]
    # 清空所有run文本
    for p in cell.paragraphs:
        for r in p.runs:
            r.text = ""
    # 仅填入第一段第一个run（避免破坏段落结构）
    if cell.paragraphs[0].runs:
        cell.paragraphs[0].runs[0].text = lines[0]
    # 追加行用 add_run（保持同段落、同格式）
    for line in lines[1:]:
        cell.paragraphs[0].add_run(line)

# 填写区（仅这些行需要修改）：
# Row 2:  申请执行人（自然人）→ fill_cell_multi(2, [...])
# Row 3:  委托诉讼代理人      → fill_cell_multi(3, [...])
# Row 6:  被执行人（自然人）   → fill_cell_multi(6, [...])
# Row 9:  文书类型            → fill_cell(9, "判决书  √裁定书...")
# Row 10: 执行依据作出机构    → fill_cell(10, "XXX法院")
# Row 11: 案由               → fill_cell(11, "XXX纠纷")
# Row 12: 文书号             → fill_cell(12, "(XXXX)XX号")
# Row 13: 生效日期           → fill_cell(13, "XXXX年XX月XX日")
# Row 14: 执行依据判项主文    → fill_cell_multi(14, [...])
# Row 17: 申请执行事项       → fill_cell_multi(17, [...])
# Row 18: 诉前/诉讼保全      → fill_cell_multi(18, [...])
# Row 19: 其他财产线索       → fill_cell(19, "...")

# 🔴 以下行绝对不动：
# Row 0, 1, 4, 5, 7, 8, 15, 16

doc.save("输出文件.docx")
```

> ⚠️ 上述 `fill_cell` / `fill_cell_multi` 函数为**示意**。实际操作时，因范本内右列单元格已有预设标签文本（如"姓名：""性别：男  女"等），最佳做法是**仅替换标签后的值**而非整体替换。具体实现：定位到对应`run`的文本，通过字符串操作将标签后的空白/占位符替换为实际数据。不得删除标签、不得修改标签格式。

## 注意事项

1. **执行时效 2 年——红线**：过期权利消灭，除非有时效中断事由
2. **利息分两段**：逾期利息（判决履行期届满前）+ 迟延履行金（履行期届满后，日万分之一点七五）——两段分开计算
3. **财产线索是核心**：没有财产线索，再好的申请书也是废纸
4. **终本≠放弃**：终本后随时可恢复执行，每 6 个月申请查控
5. **和解加担保**：和解协议须附加执行担保条款+恢复执行条款
6. **唯一住房可执行**：须提供廉租房或从变价款中扣除 5-8 年租金
