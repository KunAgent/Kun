# 强制执行各 Node 详细操作参考

> 本文件为「强制执行」技能各 Node 的详细操作指引，
> 由原「强制执行工作流」技能节点细节整理而来。
> 适用于全流程模式（模式A）下各 Node 的逐步操作。

---

## Node 1 · 执行依据确认

### 操作步骤

1. **核查执行依据类型**：判决书 / 裁定书 / 调解书 / 仲裁裁决 / 公证债权文书
2. **提取案号、法院、作出日期**
3. **计算生效日期**：
   - 一审判决：送达日 + 15日上诉期届满次日
   - 二审判决：送达日即生效（二审终审）
   - 调解书：双方签收之日生效
4. **计算履行期限届满日**：判决主文载明履行期限 + 届满次日
5. **计算申请执行时效届满日**：履行期限届满日 + 2年
6. **时效中断检查**：是否在2年时效内有过催收/对方还款等行为

### 输出物

`{案号}_执行依据核查表_{日期}.md`

包含：案号、依据类型、生效日期、履行期限届满日、时效届满日、剩余天数、中断事由（如有）。

## Node 2 · 财产线索调查

### 操作步骤

1. **向当事人询问**：银行账号、房产证号、车牌号、股权、微信/支付宝账号
2. **公开渠道查询**：
   - 企查查/天眼查：股权、对外投资、分支机构
   - 中国执行信息公开网：是否已被执行、执行标的
3. **法院网络查控**：立案后由法院通过执行系统统一查询（银行、不动产、车辆、证券、网络资金）
4. **线索分级**：
   - ★ 确定：当事人提供凭证 / 已查实
   - ◇ 可能：合理推测（如对方有固定工作→可能有工资）
   - △ 推测：间接推断

### 输出物

`{案号}_财产线索清单_{日期}.md`

## Node 4 · 执行措施跟进

### 操作步骤

1. **立案后7日内**：法院发起网络查控
2. **查控结果出来后**：根据财产类型采取对应措施
   - 银行存款→冻结（冻结期限1年）
   - 不动产→查封（查封期限3年）
   - 车辆→查封（查封期限2年）
   - 工资收入→扣留提取（需留必需生活费）
3. **终结本次执行程序（终本）风险告知**
4. **每6个月**：申请再次网络查控

### 输出物

`{案号}_执行措施时间线_{日期}.md`

## Node 5 · 执行异议应对

### 常见异议类型

| 异议类型 | 法律依据 | 应对 |
|---------|---------|------|
| 对执行行为异议 | 民诉法第232条 | 说明理由合法，请求驳回 |
| 案外人异议（房屋/车辆） | 民诉法第234条 | 审查案外人权利真实性 |
| 追加被执行人 | 变更追加当事人规定 | 审查是否符合追加条件 |

## Node 6 · 执行和解

### 操作步骤

1. **和解谈判**：计算对方可接受的最低金额/期限
2. **和解协议起草**：须包含执行担保条款 + 恢复执行条款
3. **提交法院**：和解协议不存档，由当事人自行持有；向法院提交《暂缓执行申请》

### 关键条款

```
1. 被执行人不履行和解协议 → 申请人可向法院申请恢复执行原生效法律文书
2. 和解协议履行完毕 → 法院作执行结案处理
3. 和解协议须有执行担保（第三人保证/财产抵押）
```

---

## Node 7 · 执行终结

### 终结方式

| 方式 | 适用 | 后续 |
|------|------|------|
| 执行完毕 | 全部款项执行到位 | 结案 |
| 终结本次执行（终本） | 无财产可供执行 | 随时恢复执行（无时效限制） |
| 执行和解结案 | 达成和解协议且履行完毕 | 结案 |
| 撤销申请 | 申请人主动撤销 | 可再次申请执行（时效内） |

### 终本后义务

- 失信名单 / 限制消费继续有效
- 每6个月申请一次网络查控（律师持续义务）
- 发现财产后立即申请恢复执行

---

## 注意事项

1. **执行时效2年——红线**：过期权利消灭，除非有时效中断事由
2. **财产线索是核心**：没有财产线索，再好的申请书也是废纸
3. **终本≠放弃**：终本后随时可恢复执行，无时效限制
4. **唯一住房可执行**：须提供廉租房或从变价款中扣除5-8年租金
5. **和解加担保**：和解协议须附加执行担保条款 + 恢复执行条款
