## 图标使用规范

### 基本原则

1. **统一性** - 同一类型事件使用相同图标
2. **可读性** - 图标大小适中，清晰可见
3. **辅助性** - 图标是视觉辅助，文字仍是主要信息
4. **一致性** - 遵循图标的本意，不要随意混用

### 图标位置

**时间轴中：**
```html
<span class="timeline-icon">📄</span>
<span class="timeline-title">申请注册商标</span>
```

**表格中：**
```html
<td>📄 申请注册商标</td>
```

**列表中：**
```html
<li>📄 商标申请受理通知书</li>
```

### 图标组合使用

**需要表示两个或多个含义时：**
```
📢⚖️ 向法院起诉（通知+诉讼）
💰📦 支付款项并完成交付（付款+交货）
⚠️📋 违约事实认定（违约+裁决）
```

## 争议焦点标记规范

### 级别划分

**🔴 核心争议焦点**（最多3个）
- 直接影响案件结果
- 双方主张存在根本对立
- 法律适用存在重大分歧

**⭐ 辅助争议点**（最多5个）
- 影响部分事实认定
- 次要法律适用问题
- 证据关联性争议

### 标记位置

**时间轴中：**
```
2019-04-12  [⚠️🔴] 商标局作出驳回决定
```

**事件明细表中：**
```
| 4 | 2019-04-12 | ⭐商标局作出驳回决定 | ... |
```

**争议焦点章节：**
```
## 争议焦点提炼 🔴

### 🔴 核心争议焦点一：引证商标的合法性
```

## 打印兼容性

### 黑白打印兼容

确保黑白打印时图标仍可识别：
- 使用线条清晰的图标（📄⚖️📋）
- 避免使用纯色填充的图标
- 图标配合文字使用，不单独依赖图标

### 建议优先使用的图标（黑白打印友好）

```
优先使用：📄 ✍️ 💰 📦 ⚠️ 📢 ⚖️ 📋 🔄
谨慎使用：💸 💳 🚫 🔥 ⚡
```

## 自定义图标场景

如需使用其他图标，遵循以下原则：

1. 使用标准Emoji（Windows 10+内置支持）
2. 图标含义直观，易于理解
3. 与现有图标风格协调
4. 避免使用冷门或特殊设备不支持的Emoji
