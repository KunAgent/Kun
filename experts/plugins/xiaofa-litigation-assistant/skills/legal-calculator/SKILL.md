### 🔴 CHECKPOINT 1：计算类型与公式确认（计算前必检）

> **在开始计算前，必须逐项确认：**
> 1. 适用的计算模块（M1-M8）—— 错误选择模块 = 公式全错
> 2. 所有输入参数是否完整（本金/利率/起算日/截止日/合同成立日等）
> 3. 参数缺失项标注"【待确认】"—— 不得猜测填充，但可给出"基于假设的试算"
> 4. LPR 数据是否最新（联网验证 boc.cn，距上次更新≤40天）
> 5. 公式的适用条件是否为当前场景（如民间借贷利率上限=LPR×4 仅适用于民间借贷，金融借贷/商业合同不适用）
>
> **常见模块选择错误 → 立即纠正：**
> - "逾期利息"（M1）vs "迟延履行金"（M2）—— 前者是实体法权利（合同违约），后者是程序法惩罚（判决后仍未履行）
> - "违约金"（M4）vs "逾期利息"（M1）—— 前者按合同约定比例计算，后者按LPR计算
> - "人身损害赔偿"（M5）中的残疾赔偿金 vs "劳动争议补偿"（M7）—— 前者是侵权赔偿，后者是劳动合同解除补偿，公式完全不同

### 🔴 CHECKPOINT 2：计算结果交叉验证（输出前必检）

> **计算结果输出前，必须执行以下交叉验证：**
> 1. 逆运算验证：本金+利息 = 合计（允许四舍五入至分的误差）
> 2. 司法上限验证：民间借贷利息+违约金 ≤ LPR×4；违约金 ≥ 实际损失×1.3 → 标注调减风险
> 3. 分段完整性验证：LPR各段天数之和 = 总天数
> 4. 金额合理性验证：利息不应为负数、不应超过本金数倍（除非超长期限）
> 5. 大写金额与小写金额一致性验证
>
> **任一验证未通过 → 标注具体验证项+异常值，回退修正后再输出。不得输出未经交叉验证的计算结果。**

## 第三层：各模块计算公式与法条

### M1 · 逾期利息（LPR 分段）

**法条依据**：《民法典》第 676 条 + 《民间借贷司法解释》第 25-29 条

**计算公式**：
```
逾期利息 = Σ(本金 × 该段LPR × 该段天数 ÷ 365)

关键规则：
- 起算日：约定还款日次日（无约定从催告后合理期限届满次日）
- 截止日：实际清偿日 / 起诉日 / 计算基准日
- LPR调整当日不切段，调整次日切新段
- 民间借贷利率上限 = 合同成立时 LPR × 4（超过部分不予支持）
- 默认使用一年期LPR
```

**分段计算示例**（本金 100,000 元，还款日 2023-05-15，算至 2024-12-20）：

| 段号 | 起始日 | 截止日 | 天数 | LPR | 段利息 |
|------|--------|--------|------|-----|--------|
| 1 | 2023-05-16 | 2023-06-19 | 35 | 3.65% | ¥350.00 |
| 2 | 2023-06-20 | 2023-08-20 | 62 | 3.55% | ¥603.01 |
| 3 | 2023-08-21 | 2024-07-21 | 336 | 3.45% | ¥3,175.34 |
| 4 | 2024-07-22 | 2024-10-20 | 91 | 3.35% | ¥835.21 |
| 5 | 2024-10-21 | 2024-12-20 | 61 | 3.10% | ¥518.08 |
| **合计** | | | **585** | | **¥5,481.64** |

### M2 · 迟延履行金

**法条依据**：《民事诉讼法》第 264 条 + 《迟延履行利息司法解释》

**计算公式**：
```
一般债务利息 = 按生效法律文书确定的方法继续计算
加倍部分利息 = 本金 × 0.0175%（日万分之一点七五）× 迟延天数

两项可同时主张：逾期利息（实体法权利）+ 迟延履行金（程序法惩罚），互相独立。
```

**计算示例**（本金 ¥1,000,000，判决生效 2025-06-01，履行期限 15 日，算至 2026-05-13）：
```
迟延起算日：2025-06-16 → 迟延天数：331 天

一般债务利息 = ¥1,000,000 × 3.45% ÷ 365 × 331 = ¥31,286.30
加倍部分利息 = ¥1,000,000 × 0.0175% × 331 = ¥57,925.00
迟延履行金合计 = ¥89,211.30
```

| 1 万-10 万元 | 2.5% | = 标的额 × 2.5% - 200 |
| 10 万-20 万元 | 2% | = 标的额 × 2% + 300 |
| 20 万-50 万元 | 1.5% | = 标的额 × 1.5% + 1,300 |
| 50 万-100 万元 | 1% | = 标的额 × 1% + 3,800 |
| 100 万-200 万元 | 0.9% | = 标的额 × 0.9% + 4,800 |
| 200 万-500 万元 | 0.8% | = 标的额 × 0.8% + 6,800 |
| 500 万-1000 万元 | 0.7% | = 标的额 × 0.7% + 11,800 |

### M4 · 违约金计算

**法条依据**：《民法典》第 585 条 + 《民法典合同编司法解释》第 64-65 条

**计算方式**：

| 方式 | 公式 | 适用 |
|------|------|------|
| 约定比例 | 合同总价 × 约定比例 | 合同明确约定 |
| 日费率累计 | 本金 × 日费率 × 逾期天数 | 合同约定日费率 |
| 参照LPR | 同 M1 | 无合同约定 |

**违约金调整规则**（Python判断逻辑）：
```python
if 约定违约金 > 实际损失 × 1.3:
    risk = "高（违约金可能被法院调减）"
elif 约定违约金 < 实际损失 × 0.7:
    risk = "低（可申请调增）"
else:
    risk = "适中（大概率被支持）"
```

**叠加规则**：借贷合同违约金+利息 ≤ LPR×4（超过部分不予支持）

### M5 · 人身损害赔偿

**法条依据**：《民法典》第 1179 条 + 《人身损害赔偿司法解释》（2022 修正）

| 赔偿项目 | 计算公式 |
|---------|---------|
| **医疗费** | 实际发生额 + 后续治疗费（以票据为准） |
| **护理费** | 护理人员收入 × 护理天数 |
| **误工费** | 日均收入 × 误工天数 |
| **住院伙食补助费** | 当地标准 × 住院天数（一般 50-200 元/天） |
| **营养费** | 当地标准 × 营养期（一般 20-50 元/天） |
| **交通费** | 实际发生额 |
| **残疾赔偿金** | 人均可支配收入 × 20年 × 伤残系数（60岁以上递减，75岁以上按5年） |
| **死亡赔偿金** | 人均可支配收入 × 20年（同年龄递减规则） |
| **被扶养人生活费** | 人均消费支出 × 扶养年限 ÷ 扶养人数 |
| **精神损害抚慰金** | 法院裁量（一般 5,000-50,000 元） |
| **丧葬费** | 职工月平均工资 × 6个月 |
| **鉴定费** | 实际发生额 |

**计算示例**（十级伤残，城镇户籍，35岁，人均可支配收入 ¥55,000/年）：
```
医疗费 ¥35,280.50 + 护理费 ¥6,000 + 误工费 ¥18,000
+ 伙食补助 ¥1,500 + 营养费 ¥1,500 + 交通费 ¥850
+ 残疾赔偿金 ¥110,000 + 精神抚慰金 ¥5,000 + 鉴定费 ¥2,600
= 合计 ¥180,730.50
```

### M6 · 诉讼时效计算

**法条依据**：《民法典》第 188-199 条

| 时效类型 | 时长 | 适用范围 |
|:------:|:---:|---------|
| 一般诉讼时效 | **3 年** | 绝大多数民事权利 |
| 国际货物买卖/技术进出口 | **4 年** | 《民法典》第 594 条 |
| 人寿保险金请求权 | **5 年** | 《保险法》第 26 条 |
| 劳动争议仲裁时效 | **1 年** | 《劳动争议调解仲裁法》第 27 条 |
| 撤销权 | **1 年**（自知道起） | 《民法典》第 152 条 |
| 最长权利保护 | **20 年** | 自权利受损日起 |

**计算逻辑**：确定时效类型→确定起算日→检查中断事由（重新起算）→检查中止事由（不计入）→计算届满日

### M7 · 劳动争议补偿

**法条依据**：《劳动合同法》第 46-47 条、第 87 条

| 补偿类型 | 计算公式 | 适用条件 |
|:------:|---------|---------|
| **经济补偿（N）** | 月均工资 × 工作年限 | 协商解除/期满不续/裁员 |
| **代通金（+1）** | 月均工资 × 1 | 未提前30日通知 |
| **赔偿金（2N）** | 月均工资 × 工作年限 × 2 | 违法解除/终止 |

**计算规则**：月均工资上限为职工月平均工资3倍；工作年限每满1年计1个月，6个月以上不满1年按1年，不满6个月计半个月。

### M8 · 天数计算器

**法条依据**：《民法典》第 200-204 条（期间计算）

```
规则一：开始的当日不计入，从次日开始计算
规则二：最后一日为法定节假日的，顺延至节假日结束次日
规则三：按月计算的，对应日；无对应日的为月末
规则四：工作日 = 自然日 - 周六 - 周日 - 法定节假日
```

## 注意事项

1. **LPR 实时更新**：每月 20 日更新——引用时确认是否最新
2. **地域差异**：人身损害赔偿"人均可支配收入"各省不同——以受诉法院所在地为准
3. **诉讼费减半**：简易程序/调解结案→减半收取
4. **强制执行利息到付**：利息计算至"实际清偿之日"→报告仅算至"计算当日"
5. **违约金叠加风险**：借贷合同违约金+利息超过 LPR×4 的部分不予支持
6. **劳动争议仲裁前置**：仲裁时效 1 年——比民事诉讼时效更短
7. **计算透明**：所有计算过程可逆→对方/法官可验算→增强可信度

## 失败模式与异常处理

> **定位**：dim3 失败模式覆盖 —— 计算结果异常/公式适用错误/LPR变化/司法上限验证失败等核心失败场景。

| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| LPR 数据过时（联网验证失败+内置数据距当前超过40天）——计算结果使用的利率可能不是最新的 | 强制在报告开头嵌入数据时效声明："计算时LPR数据来源：【联网验证/内置数据】，最后更新日期：【YYYY-MM-DD】。如LPR在此日期后发生调整，计算结果可能不准确，请以最新LPR重新计算。"→标注"【LPR数据可能过时·建议人工核实】" | 若用户要求必须使用最新LPR但联网持续失败（>3次），建议用户：①手动在中国人民银行官网查询最新LPR②将最新数据提供给系统重新计算③系统在报告中保留"待用户确认LPR数值"的标注 |
| 公式适用错误——将适用于民间借贷的"LPR×4上限"错误应用于金融借款/商业合同纠纷 | 立即复核计算类型与公式的匹配关系：民间借贷→LPR×4上限（《民间借贷司法解释》）；金融借款→无LPR×4上限（金融机构贷款不适用此规则）；商业合同违约金→按合同约定+《民法典》第585条调整规则。修正公式后重新计算 | 若无法确定计算类型（如用户描述模糊：是民间借贷还是投资款？），在报告中列出两种假设+两种计算结果→标注"【待确认法律关系性质后择一适用】"→请用户或律师确认法律关系后再出具最终报告 |
| 分段计算遗漏LPR变动节点——跨多个LPR区间的利息计算只用了首段利率或末段利率 | 逐段还原完整的时间轴→在每一段标注起始日/截止日/该段适用LPR→检查各段天数之和=总天数→检查LPR调整日期是否全部覆盖→补全遗漏段后重新计算各段利息和合计 | 若LPR变动频繁（2年内调整>5次），生成《LPR变动时间表+各段利息》明细表，防止手动核对遗漏 |
| 参数缺失时给出唯一数字但未标注"待确认"——如客户只说"诉讼费多少"，系统按默认标的额50万计算并给出"5800元"结论 | 立即找到参数缺失的输入项→补充"【待确认】"标注→生成基于假设的试算（标注假设参数）→同时给出最坏/中等/最好三种情形对应的费用→让客户对照实际标的额选择 | 若客户确认了实际参数且发现试算中使用的是错误假设，立即废弃旧报告→用正确参数重算→新旧报告差异对比→交付修订版 |
| 计算结果超出司法保护范围但未标注——违约金计算结果显示为实际损失的200%但未提示可能被调减 | 追加司法上限验证：违约金≤实际损失×1.3；民间借贷利率≤LPR×4；劳动者经济补偿月均工资上限≤职工月均工资×3。任一项超出上限→在报告中醒目标注司法调减风险+给出合规范围内的替代计算方案 | 若用户要求"就算超上限也按这个金额主张"，在报告中标注"本金额超出法定上限，主张金额中超出上限部分存在败诉风险"→请用户确认后方可输出，不得自动删除超出上限的计算结果 |
| 天数计算错误——将自然日与工作日混淆、起始日计入期限（应不计入）、节假日未顺延 | ①确认适用的计算规则（自然日/工作日）②复核起算日（从次日起算）③检查截止日是否为法定节假日（顺延至节后首个工作日）④复核天数。使用`M8 天数计算器`自动化计算，减少人工错误 | 若天数计算涉及大量日期（如计算30笔分期付款各自的逾期天数），分批计算→交叉验证→生成《逐笔天数明细表》→附在报告后供核对 |
| 逆运算验证不通过——计算结果无法通过"本金+利息=合计"等基本验证 | 立即逐步骤跟踪计算过程→查找中间计算错误（通常为：四舍五入时机不对/分段计算中有遗漏段/公式常数错误如利率未转小数）→修正后重新执行全部验证项 | 若反复修正仍无法通过逆运算验证（连续3次），可能是公式本身有内在缺陷→切换至备用计算方法（如用Excel/LibreOffice Calc 公式重算→对比结果差异）→在报告中标注计算工具和验证方法 |

## 反例与黑名单

> **定位**：dim9 反例 —— 法律计算中"不要这样做"的典型错误。

### 反例1：利率"大概"——"我记得LPR大概是3.5%，就用这个算吧"
**❌ 错误做法**：凭记忆或直觉使用LPR利率，不查证不联网核实。计算结果直接写入强制执行申请书中的利息明细表。
**为什么错**：LPR在2023-2025年间经历了3.65%→3.55%→3.45%→3.35%→3.10%→3.00%的连续调整。如果用3.5%而不是实际的3.45%计算一段100万的逾期利息，误差可达数百元——法院对利息计算的精确度要求是"分"，一分钱的误差都可能被对方质疑整个计算的可靠性。
**✅ 正确做法**：每次计算前联网核实最新LPR。无法联网时使用内置数据但标注"【未联网核实】"。计算报告中逐段标注每次LPR调整的具体日期和利率。利息金额精确到分且附完整计算公式。

### 反例2：只给结果不展示过程——"利息一共5800元，诉讼费2000元"
**❌ 错误做法**：直接输出一个数字，没有任何计算过程。客户问"怎么算出来的"时回答"按公式算的"。
**为什么错**：①客户无法信任一个没有推导过程的数字②法官无法核对计算的正确性③对方律师可以质疑计算依据而己方无法自证④出错后无法追溯到具体哪一步算错了。
**✅ 正确做法**：每个计算结果必须展示公式→代入参数→中间步骤→最终结果的完整链条。如：逾期利息 = 100000元 × 3.45% ÷ 365天 × 331天 = 100000 × 0.0345 ÷ 365 × 331 = ¥31,286.30。附带法条依据。确保任何一个持怀疑态度的人都能独立验证你的计算。

### 反例3：忽略司法上限——"合同怎么写就怎么算，违约金50%就50%"
**❌ 错误做法**：合同中约定违约金为合同总价50%，计算器直接按50%算出数字并输出，不提示任何风险。
**为什么错**：《民法典》第585条规定违约金超过实际损失30%部分法院可调减。直接算50%不给风险评估=让客户误以为法院会全额支持50%违约金=案件结果与客户预期严重不符。
**✅ 正确做法**：计算结果中醒目标注司法上限风险："本违约金为合同总价的50%（¥XX），根据《民法典》第585条及司法解释，超过实际损失30%的部分存在被法院调减的较高风险。建议：①预估实际损失金额②按实际损失×1.3计算可被支持的违约金上限③以合同约定金额起诉但做好法院调减的准备。"
