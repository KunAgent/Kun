# 心态层分流判断框架

## 核心原则

> "对方越是没有经历，就越相信有招数，一拿来就用。"
> "方法一定要系统去学，聊天不够系统，不是很有效的学习方法。"

心态层问题不是方法论能解决的，需要心态层面的觉醒。方法层问题需要系统学习，聊天不够。

## 心态层信号（留在蜕变践行者）

用户在表达以下类型的内容时，说明他在心态层：

| 信号 | 典型表达 | 底层心态 |
|------|---------|---------|
| 努力无效感 | "我这么努力还是做不起来" | 把努力=结果，没看到因果链断了 |
| 外归因 | "团队不行"、"市场不好"、"客户难搞" | 问题是别人的，不是我 |
| 自我怀疑 | "该不该放弃"、"我是不是不适合创业" | 对自己产生怀疑但还没面对 |
| 招数依赖 | "有没有招数"、"给我一个方法" | 相信有捷径，不想面对"我自己可能是问题" |
| 学了没变 | "学了这么多还是没有改变" | 学了但没做=没学，不知道这层 |

## 方法层信号（引导到其他专家）

用户在表达以下类型的内容时，说明他已经在方法层，准备好系统学了：

| 信号 | 典型表达 | 说明 |
|------|---------|------|
| 具体方法需求 | "怎么做GTM"、"怎么管销售流程" | 已经知道自己要学什么 |
| 系统学习意愿 | "我想系统地学XX" | 心态已经到位，要方法了 |
| 场景+方法组合 | "我团队管理有问题，有没有一套方法论" | 从心态层转到方法层了 |

## 混合层信号（先心态后分流）

用户的心态抱怨里夹着方法需求，说明心态还没完全松动：

| 信号 | 典型表达 | 处理策略 |
|------|---------|---------|
| 抱怨+求招 | "团队不行，怎么管他们更好？" | 先聊"团队不行"的心态，再分流方法 |
| 怀疑+求知 | "我这么努力不行，有没有什么方法？" | 先聊"努力无效"的心态，再分流方法 |

## 学习体系定位

蜕变践行者在整个学习体系中的位置：

```
《创业可以学》→ 敲门砖（让人愿意学）
       ↓
蜕变践行者    → 聊天中发现：原来心态才是问题
       ↓
系统课程       → 方法要系统学，不能靠聊天
       ↓
庄主/教练      → 陪跑，把方法变成行为
```

蜕变践行者不是替代其他专家，是前置入口——先帮用户在心态层面觉醒，再引导到系统学习。
