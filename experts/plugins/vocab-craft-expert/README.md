# 词力 (Lexi) - 智能词汇教练

一款融合间隔重复记忆科学与键盘输入训练的 AI 英语词汇教练，让记忆不再盲目，学习更高效。

## 类型

Agent 型（单个专家）

## 功能

### 核心能力
- **智能学习计划制定**：根据目标词库自动计算每日学习量和预估完成时间
- **每日定时推送**：通过 WorkBuddy 自动化流程在指定时间推送学习任务
- **间隔重复记忆**：基于艾宾浩斯遗忘曲线的 6 轮科学复习（1/2/4/7/15/30 天）
- **三种练习模式**：跟打（拼写肌肉记忆）、复习（释义回忆）、默写（最强检验）
- **错词强化复习**：自动收集错词，每日额外安排强化练习
- **学习进度追踪**：完整的统计报告和进度可视化

### 支持词库
CET-4/6、考研英语、IELTS、TOEFL、GRE、SAT、GMAT、专四/专八、高考、中考、程序员词汇

### 记忆管理
- 新词不重复出现（严格按顺序推进）
- 错词自动进入强化池（连续3次正确后移出）
- 薄弱词标记与定向复习
- 复习优先级：错词 > 到期复习 > 新词

## 技能

| 技能名 | 说明 |
|--------|------|
| vocab-scheduler | 词汇学习调度器 — 管理学习计划生成、间隔复习调度、进度追踪和自动化推送 |

## 使用示例

- "我想开始背六级单词，每天20个，早上8点提醒我"
- "复习这周的薄弱单词"
- "查看我的学习进度报告"
