# 保温话术模板库

场景 B 使用的 **话术正文底本**。此文件作为 **asset**，不需要全量读入 context，按 `references/warming-scripts.md` 第 5 节的"模板 ID"按需取用。

每个模板由三部分组成：
- **底本**：默认正文，含 `{{变量}}` 占位符
- **变量说明**：每个占位符如何填
- **个性化挂载点**：Hook 注入的位置（用 `<HOOK:xxx>` 标识）

---

## S1_welcome · 首次欢迎话术

**阶段**：刚签约、导师未绑定

**建议渠道**：招聘经理企微文字消息

**建议时机**：签约当天或次日

```
{{name}} 你好，

我是腾讯 {{bg_name_cn}} 的招聘经理 {{manager_name}}，很高兴你选择加入我们 ——
<HOOK:school_major>  <!-- 如：浙大计算机的背景、在我们这个岗位上会很有发挥空间 -->

从现在到 {{expect_entry_date}} 还有一段时间，我会陆续为你安排以下几件事：

1. 近期会确定你的导师人选，届时由 Ta 主动加你的企业微信
2. 团队会在入职前分阶段同步项目和文化资料
3. 你有任何问题都可以直接问我，我会在 1 个工作日内回复

如果你方便的话，能麻烦把你的常用微信号发我吗？方便后续联络。
期待在 {{w_city}} 见到你！

— {{manager_name}}
```

**变量**：

| 占位符 | 来源 |
|---|---|
| `name` | `name` |
| `bg_name_cn` | `bg_name_cn` |
| `manager_name` | `recruit_manager_name` |
| `expect_entry_date` | `expect_entry_date` |
| `w_city` | `w_city` |

**Hook 注入点**：
- `<HOOK:school_major>` — 学校 + 专业一句话致意

## S2_first_touch · 导师首次建联脚本

**建议渠道**：导师企业微信发送（招聘经理转发给导师使用）

**建议时机**：导师绑定后 3 天内

```

1. 你目前在学业/毕业流程上有什么时间节点？
2. 有没有什么特别关注或希望提前准备的方向？

不用着急回复，空了再说 👋

📄 入职前可以看的一些资料（技术栈 / 产品文档 / 必要背景）
📄 入职流程 FAQ（常见问题一次说清）

<HOOK:material_hook>  <!-- 如：考虑到你是前端方向，我特意加了我们团队的前端架构文档 -->

看完后有任何问题或想法，直接给我留言。

— {{sender_name}}

**Hook 注入点**：
- `<HOOK:material_hook>` — 针对候选人岗位方向，说明特别加入了哪类资料

• {{team_update_1}}

2. 你的工卡、企业邮箱、办公工位会在入职日前准备好
3. 你的导师 {{tutor_name_en}} 会在入职首周陪你完成入职融入

<HOOK:logistics_hook>  <!-- 如：住宿方面需要我帮你问下宿舍安排吗？ / 如果你来之前有空到深圳看看，可以提前告诉我 -->

如果有任何还没准备好的地方，或者临时有变化，请第一时间告诉我们，很多事情都还有调整空间。

— {{manager_name}}
```

**Hook 注入点**：
- `<HOOK:logistics_hook>` — 基于工作地与候选人归属地差异生成关怀点

## S6_reengage · 重新建联话术

**阶段**：距上次互动 ≥ 14 天

**语气要点**：**不问责、不施压**，只重新打开对话

```
{{name}}，

最近还好吗？最近工作/学校上忙起来，一转眼好久没聊。

<HOOK:reengage_hook>  <!-- 如：我们团队最近发了一个新项目，看你之前的实习方向应该会感兴趣 / 看到 XX 学校正在做毕业季，你应该也进入节奏了 -->

没有其他目的，就是想问问你最近的状态，以及入职前还有没有什么需要我们协助的。
不用急着回复，有空了告诉我就好。

— {{sender_name}}
```

**禁用**：

- ❌ "为什么都不回消息"
- ❌ "还是否打算入职"
- ❌ "是不是有其他 offer"
- ❌ 任何让候选人产生负担的追问

## S7_risk_check · 风险干预话术（招聘经理亲自出面）

**阶段**：`risk_level = high`，有 `cm_fb_result` 或 `suggestion` 风险反馈

**渠道**：**招聘经理本人**，不让导师代传

**首选动作**：电话/语音，其次企微文字

```
{{name}} 好，

我是 {{manager_name}}，是你的招聘经理。
最近这边收到一些反馈，觉得有必要直接跟你聊一下。

我希望了解的是：
1. 入职前这段时间，有没有什么顾虑或困扰是我们还没帮你解决的？
2. 有没有什么信息是你希望我们提前同步、但到现在还没到的？
3. 如果你最近在其他选择或方向上有新的考虑，也可以坦诚告诉我，我们一起看看怎么办。

这不是正式沟通，只是想听听你的真实想法。
方便的话，我们明天约一个 15-20 分钟的电话聊聊？你告诉我方便的时段就行。

— {{manager_name}}
```

**使用前必须自检**：

- [ ] 本条话术只由招聘经理发出，不转给导师
- [ ] 不提及任何其他候选人、offer 对比
- [ ] 真实邀约电话，不承诺加薪 / 调岗 / 其他条件
- [ ] 结果要沉淀到数仓 `cm_feedback` 字段（由招聘经理在系统中手动录入）

## 通用收尾签名

所有模板结尾的签名行，建议统一格式：

```
—
{{sender_name_cn}} · {{sender_role}}
{{bg_name_cn}} · 校园招聘
```

其中 `sender_role` 可选值：招聘经理 / 导师 / 直接上级。
