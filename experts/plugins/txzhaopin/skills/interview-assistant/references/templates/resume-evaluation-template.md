# 简历评估报告模板

> 基于三档评价体系的简历评估结构化输出模板。适用于场景 A1（单份评估）和 A2（多份对比中的单人报告）。

## 报告整体结构

```
1. 匹配度总评
2. 候选人概览
3. 各维度评估（含评分、档位、证据）
4. 红线筛查（S3 专用，非 S3 跳过）
5. 关键发现
6. 面试建议
```

---

## 一、匹配度总评

**要求**：一句话结论 + 量化摘要。

**格式**：
```
**匹配度总评**：[推荐面试 / 待定 / 不推荐]

[一句话核心理由]

| 指标 | 值 |
|------|---|
| 有效维度数 | X / Y（Y 为总维度数，X 为有证据可评的维度数） |
| 有效维度均分 | X.X / 5.0 |
| 推荐档（4-5分）| X 项 |
| 待定档（3分）| X 项 |
| 不推荐档（1-2分）| X 项 |
| 信息不足（N/A）| X 项 |
```

---

## 二、候选人概览

**要求**：从简历中提取关键信息，不做推测。

**格式**：
```
### 候选人概览

| 项目 | 信息 |
|------|-----|
| 姓名/编号 | [姓名或编号] |
| 学历背景 | [学校 + 专业 + 学历层次] |
| 工作/实习年限 | [年限或"应届"] |
| 核心经验 | [1-2 句话概括最相关的经历] |
| 技术栈/核心技能 | [列出主要技能] |
```

---

## 三、各维度评估

**要求**：逐维度评估，证据必须来自简历原文。

### 评分规则（简历评估专用）

| 分数 | 含义 | 简历中的体现 |
|------|------|-------------|
| 5 分 | 极为突出 | 简历中有明确的、强有力的证据证明该维度表现卓越 |
| 4 分 | 良好 | 简历中有足够的证据证明该维度表现良好 |
| 3 分 | 一般/待验证 | 简历中有部分证据但不够充分，需面试验证 |
| 2 分 | 较弱 | 简历中缺乏该维度的相关证据，或存在负面信号 |
| 1 分 | 明显短板 | 简历中有明确的负面证据 |
| N/A | 信息不足 | 简历中完全无法判断，标注为待面试验证 |

### 单维度输出格式

**有评分时**：
```
### [维度名称]：[X] 分 — [推荐/待定/不推荐]

**评价**：[1-2 句话核心判断]

**简历证据**：
- [从简历中摘出的具体信息] → [为什么支撑该评分]
- [从简历中摘出的具体信息] → [为什么支撑该评分]

**面试建议**：[建议面试中针对该维度如何追问]
```

**信息不足时**：
```
### [维度名称]：N/A — 信息不足

**说明**：简历中未体现该维度的相关信息。

**面试建议**：[建议面试中如何考察该维度]
```

## 四、红线筛查（S3 专用）

**仅 S3 业务使用**，非 S3 业务跳过此部分。格式同面评模板。

---

## 五、关键发现

**要求**：分正面和风险两个方面总结。

**格式**：
```
### 关键发现

**核心优势**（推荐档维度）：
1. [维度名称]：[一句话说明为什么突出]
2. [维度名称]：[一句话说明为什么突出]

**潜在风险**（不推荐档维度或负面信号）：
1. [维度名称/风险项]：[一句话说明风险]

**待验证项**（待定档 + N/A 维度）：
1. [维度名称]：[一句话说明需要验证什么]
```

---

## 六、面试建议

**要求**：基于简历评估结果，给出面试方向建议。具体面试问题通过「面试计划」场景单独生成。

**格式**：
```
### 面试建议

**是否建议面试**：[推荐 / 待定 / 不推荐]

**面试重点方向**：
1. [方向1]：[需要验证什么]
2. [方向2]：[需要验证什么]
3. [方向3]：[需要验证什么]

**建议面试时长**：[标准 / 加长（注明原因）]
```

> 💡 如需获取完整的面试问题清单和追问建议，请使用「面试计划」场景。

---

## 评价原则（简历评估专用）

1. **只基于简历信息**：不推测、不脑补简历未写的内容
2. **信息不足 ≠ 不具备**：简历没体现的能力标注 N/A，不默认为负面
3. **证据锚定**：每个评分必须指向简历中的具体内容（项目名称、数据、经历）
4. **保持校准**：校招简历信息量天然少于社招，评分标准要相应调整，不能因为"经验少"就全部低分
5. **突出面试价值**：简历评估的核心价值是指导面试方向，而不是替代面试判断

### 校招/社招评分校准规则

| 校准项 | 校招 | 社招 |
|--------|------|------|
| N/A 比例预期 | 30-50%（正常，信息量天然不足） | 10-20%（过高需警惕简历质量） |
| 3 分基线 | 3 分为正常基线，校招简历能到 3 分说明有一定体现 | 3 分代表中等水平，需有具体项目证据 |
| 4-5 分门槛 | 需要强证据（如获奖、突出项目成果、量化数据） | 需要项目成果 + 数据 + 影响力证据 |
| 1-2 分判定 | 谨慎使用，简历信息少 ≠ 能力差，优先标 N/A | 有明确负面信号时使用（如频繁跳槽、经历矛盾） |
| 评分侧重 | 潜力信号（学习能力、思考深度、自驱表现） | 实战验证（项目成果、方法论、数据证明） |
