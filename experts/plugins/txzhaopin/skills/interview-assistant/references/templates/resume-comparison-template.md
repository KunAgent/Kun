# 简历对比报告模板

> 适用于场景 A2（多份简历对比评估）。在每位候选人的独立评估报告之后，输出此对比汇总报告。

## 报告整体结构

```
1. 对比概览
2. 维度对比矩阵
3. 候选人排序
4. 逐人优劣势摘要
5. 对比分析
6. 推荐意见
```

---

## 一、对比概览

**格式**：
```
### 对比概览

| 项目 | 信息 |
|------|-----|
| 岗位 | [BG / 招聘类型 / 目标岗位] |
| 候选人数量 | X 人 |
| 评估维度 | X 项（含价值观红线 X 项 + 正向维度 X 项） |
| 评估日期 | [日期] |
```

---

## 二、维度对比矩阵

**要求**：一张表看清所有候选人在所有维度上的表现。

**格式**：
```
### 维度对比矩阵

| 维度 | 候选人A | 候选人B | 候选人C | ... |
|------|--------|--------|--------|-----|
| [维度1] | 4 🟢 | 3 🟡 | 2 🔴 | ... |
| [维度2] | N/A | 5 🟢 | 4 🟢 | ... |
| [维度3] | 3 🟡 | 3 🟡 | N/A | ... |
| ... | ... | ... | ... | ... |
| **有效维度均分** | **X.X** | **X.X** | **X.X** | ... |
| **推荐档数** | X | X | X | ... |
| **不推荐档数** | X | X | X | ... |
| **N/A 数** | X | X | X | ... |

> 图例：🟢 推荐（4-5分） 🟡 待定（3分） 🔴 不推荐（1-2分）
```

---

## 三、候选人排序

**排序规则**：
1. 红线一票否决 — 价值观红线不通过者直接排除，不参与排序
2. 关键维度优先 — 岗位级模型定义的核心维度加权 1.5 倍
3. N/A 不参与计算 — 只用有评分的维度算均分
4. 同分段看关键维度 — 总分接近时，按核心维度分差区分

**格式**：
```
### 候选人排序

| 排名 | 候选人 | 加权均分 | 匹配度 | 核心理由 |
|------|--------|---------|--------|---------|
| 1 | [姓名] | X.X | 推荐面试 | [一句话理由] |
| 2 | [姓名] | X.X | 推荐面试 | [一句话理由] |
| 3 | [姓名] | X.X | 待定 | [一句话理由] |
| — | [姓名] | — | 红线不通过 | [一句话理由] |
```

---

## 四、逐人优劣势摘要

**要求**：每位候选人用 3-5 句话总结核心特征，突出差异化。

**格式**：
```
### 逐人摘要

#### 候选人 A — [姓名]
- **核心优势**：[列出 1-2 个突出维度及理由]
- **主要短板**：[列出 1-2 个薄弱维度及理由]
- **待验证**：[面试需重点考察的点]
- **一句话画像**：[用一句话概括这个人的特征]

#### 候选人 B — [姓名]
...
```

---

## 五、对比分析

**要求**：从横向对比中提炼洞察，不仅仅是数据罗列。

**必须包含**：

### 5.1 差异化分析
```
各候选人之间差异最大的维度：
- [维度X]：A 得 5 分（[原因]），C 只得 2 分（[原因]）
- [维度Y]：B 表现最突出（[原因]），其他人均为 3 分
```

### 5.2 互补性标注（如存在）
```
候选人之间的短板互补：
- A 的 [维度X] 较弱（2分），但 B 在该维度突出（5分）
- B 的 [维度Y] 信息不足，而 A 在该维度有明确证据
```

### 5.3 共性风险（如存在）
```
所有候选人的共同短板：
- [维度Z]：所有候选人均为 3 分或以下，该维度可能需要降低要求或通过培训补足
```

---

## 六、推荐意见

**格式**：
```
### 推荐意见

**优先面试**：[候选人姓名]（排名第1）
- 理由：[2-3 句话]
- 面试重点：[建议重点考察的 1-2 个方向]

**建议面试**：[候选人姓名]（排名第2-3）
- 理由：[1-2 句话]

**暂不建议**：[候选人姓名]（如有）
- 理由：[1-2 句话]

**整体建议**：[对这批候选人的整体评价，如"质量较高，建议全部进入面试"或"整体偏弱，建议扩大简历来源"]
```

---

## 注意事项

1. **对比基于同一把尺子**：所有候选人使用完全相同的维度和评分标准
2. **N/A 的公平性**：如果某位候选人的 N/A 明显多于其他人（如简历信息量差异大），需在报告中说明这对排序公平性的影响
3. **避免锚定效应**：不因为先看到的简历质量影响后续简历的评分标准
4. **保持独立评估**：每份简历的评分必须独立完成，不受其他简历评分结果影响
