# 甄选能力评分量表

## 概述

本量表用于模块4评估面试官的甄选能力。采用定性描述而非数字打分，确保评估结果具体可操作。

## 评估结构

```
甄选能力
├── 提问质量
│   ├─ 提问有效性
│   └─ 提问针对性
├── 追问质量
│   ├─ 追问完整度（STAR覆盖）
│   ├─ 追问深度
│   └─ 追问灵活性
└── 判断质量
    ├─ 证据充分性
    └─ 证据-结论一致性
```

## 提问质量

### 提问有效性

| 评估等级 | 行为锚点 | 从转写中的识别方式 |
|----------|----------|-------------------|
| 优 | 主问≥70%为BEI行为事件题 | 含"请举一个""能讲一次""描述一个具体的"等引导过去行为的问法 |
| 良 | 主问50-70%为BEI题，其余为情景模拟题 | 含"如果遇到""假设"等引导思考的问法 |
| 中 | 主问30-50%为BEI题，存在较多理论题 | 含"你觉得""你认为""你怎么看"等观点类问法 |
| 弱 | 主问<30%为BEI题，大量封闭/引导题 | 含"是不是""你应该""对吧"等暗示答案的问法 |

### 提问针对性

| 评估等级 | 行为锚点 | 判断方法 |
|----------|----------|----------|
| 优 | 每个主问都能明确映射到一个考察维度 | 主问→维度映射，覆盖≥80%目标维度 |
| 良 | 大部分问题有方向，少数发散 | 映射覆盖60-80%目标维度 |
| 中 | 部分问题有方向，部分泛泛 | 映射覆盖40-60%目标维度 |
| 弱 | 问题散乱无主线，或全程只围绕一个维度 | 映射覆盖<40%，或单维度占比>80% |

## 追问质量

### 追问完整度（STAR覆盖）

| 评估等级 | 行为锚点 | 从转写中的识别方式 |
|----------|----------|-------------------|
| 优 | 核心事件均追到A+R层 | 面试官明确问了"你做了什么""结果怎样" |
| 良 | 核心事件追到A层，R层偶有缺失 | 追了行动但未必每次都问结果 |
| 中 | 部分事件只追到S+T层 | 问了背景和任务就切换话题 |
| 弱 | 大部分事件未追问，候选人说完就进下一个问题 | 面试官直接提新问题，无追问动作 |

### 追问深度

| 评估等级 | 行为锚点 | 从转写中的识别方式 |
|----------|----------|-------------------|
| 优 | 追到第一人称具体行为+可验证细节 | 候选人的回答中出现"我做了/我说了/我决定了"+具体对象和时间 |
| 良 | 追到具体行为，但偶尔接受模糊回答 | 有时候选人说"沟通了一下"未被追问具体沟通方式 |
| 中 | 追问了但候选人仍在概括层面，未继续深挖 | 候选人说"我负责XXX方面"，面试官未追"具体做了什么动作" |
| 弱 | 候选人用"我们"叙事时直接接受，未追个人角色 | 候选人说"我们做了"，面试官未追"你在其中做什么" |

### 追问灵活性

| 评估等级 | 行为锚点 | 从转写中的识别方式 |
|----------|----------|-------------------|
| 优 | 根据候选人回答质量灵活调整策略 | 详细时收拢、回避时换角度、跑偏时拉回 |
| 良 | 大部分时候能调整，偶尔机械 | 整体灵活但有1-2处候选人回避时直接放弃 |
| 中 | 基本按预设路径走，调整有限 | 追问路径固定，不因候选人回答而改变 |
| 弱 | 候选人一回避就放弃，或一直重复同一追问方式 | 连续3次用相同方式追问未获得新信息仍不换策略 |

## 判断质量

### 证据充分性

| 评估等级 | 行为锚点 | 判断方法 |
|----------|----------|----------|
| 优 | 每个评价维度有≥1条明确的行为证据 | 面评中每个结论都能找到转写中对应的候选人行为描述 |
| 良 | 大部分维度有证据，少数基于综合印象 | 1-2个维度证据链较薄 |
| 中 | 部分结论有证据，部分凭印象 | ≥30%结论缺少具体行为支撑 |
| 弱 | 结论多为印象/感觉，缺少行为事实 | 面评中大量使用"感觉""觉得""看起来" |

### 证据-结论一致性

| 评估等级 | 行为锚点 | 判断方法 |
|----------|----------|----------|
| 优 | 证据方向与结论方向完全一致 | 正向证据→正面评价，负向证据→存疑/不推荐 |
| 良 | 基本一致，个别维度轻微偏差 | 1-2处证据不太强但结论偏乐观 |
| 中 | 有明显不一致但不构成严重矛盾 | 证据中性但结论偏正面/负面 |
| 弱 | 证据与结论明显矛盾 | 转写中表现不佳但面评写"推荐"，或反之 |

## 使用说明

- 本量表为面试教练Skill内部参考，不直接呈现给面试官
- 评估结果用于生成模块4输出的行为诊断报告
- 评估时以转写文本中可观察的行为为唯一依据，不推断意图
- 如果某个维度因转写缺失无法评估，标注"信息不足"而非给低评
