# 面试计划模板

> 基于简历评估结果生成的结构化面试计划。适用于场景 B（面试计划）。
> 在简历评估（场景 A）通过后，用户确认需要时生成。

## 面试计划整体结构

```
1. 面试基本信息
2. 评估重点提示
3. 核心维度问题
4. 简历疑点追问
5. 风险核查项（旁敲侧击）
6. 面试注意事项
```

---

## 一、面试基本信息

**格式**：
```
### 面试基本信息

| 项目 | 信息 |
|------|-----|
| 候选人 | [姓名/编号] |
| 目标岗位 | [BG / 岗位名称] |
| 招聘类型 | [校招 / 社招 / 产培] |
| 简历评估结论 | [推荐面试 / 待定] |
| 评估维度数 | X 项 |
| 建议面试时长 | [45分钟 / 60分钟（注明原因）] |
```

---

## 二、评估重点提示

**要求**：基于简历评估报告，提炼面试需要重点验证的方向。

**格式**：
```
### 评估重点提示

**核心优势（面试中确认）**：
- [维度名称]：简历中表现突出（X 分），面试中进一步验证深度

**需重点验证（简历信息不足）**：
- [维度名称]：简历中为 N/A / 待定，面试中必须考察
- [维度名称]：简历中有轻微疑虑，需追问确认

**潜在风险（需旁敲侧击）**：
- [风险点]：[简要说明为什么需要关注]
```

---

## 三、核心维度问题

**要求**：针对每个评估维度设计 2-3 个 STAR 结构的面试问题。

**问题设计原则**：
1. 基于 STAR 法则（Situation-Task-Action-Result）
2. 开放式问题，不可以用「是/否」回答
3. 追问方向指向行为证据，而非态度和意图
4. 如有简历评估报告，N/A 和待定档维度加强问题设计

### 单维度输出格式

```
### [维度名称]（简历评估：[X 分 / N/A]）

**考察意图**：[简要说明该维度的考察目的]

1. [主问题1 — STAR 结构引导]
   - 追问 A：[深入行为细节]
   - 追问 B：[考察思考过程]

2. [主问题2 — STAR 结构引导]
   - 追问 A：[验证具体成果]
   - 追问 B：[考察反思能力]

💡 **评判要点**：[什么样的回答是好的 / 什么信号是负面的]
```

---

## 四、简历疑点追问

**要求**：基于简历评估中发现的待验证项和潜在风险，设计针对性追问。

**格式**：
```
### 简历疑点追问

#### 疑点 1：[疑点描述]

**简历中的表现**：[简述简历中的相关信息]

**追问问题**：
1. [针对性问题] → 预期好的回答方向 / 需警惕的信号
2. [针对性问题] → 预期好的回答方向 / 需警惕的信号

#### 疑点 2：[疑点描述]
...
```

**特殊情况**：
- 如果简历评估无明显疑点，此部分写：「简历信息一致性良好，无明显疑点需要追问。」
- 如果有 N/A 维度较多，提示面试官需在有限时间内优先覆盖核心维度

---

## 五、风险核查项（旁敲侧击）

**要求**：根据招聘类型生成对应的风险核查问题。采用旁敲侧击方式，不直接追问。

### 校招风险核查

```
| 核查项 | 旁敲侧击方式 | 注意信号 |
|--------|-------------|---------|
| 学历真实性 | 询问专业课程、毕业论文细节 | 回答含糊、细节对不上 |
| 身心健康 | 询问压力应对、作息习惯 | 情绪波动大、回避问题 |
| 亲属回避 | 自然聊到「家人从事什么行业」 | 刻意回避、紧张 |
```

### 社招风险核查

```
| 核查项 | 旁敲侧击方式 | 注意信号 |
|--------|-------------|---------|
| 竞业限制 | 询问上家公司对离职有什么要求 | 含糊其辞、回避竞业话题 |
| 背景核实 | 确认项目中的具体角色和贡献 | 关键细节说不清 |
| 被动离职风险 | 询问离职决策过程和时间线 | 前后矛盾、被动离职迹象 |
```

### 产培风险核查

```
| 核查项 | 旁敲侧击方式 | 注意信号 |
|--------|-------------|---------|
| 转岗动机 | 询问为什么对新方向感兴趣 | 对现岗位过多负面描述 |
| 原部门关系 | 了解原部门的工作氛围和协作 | 人际冲突信号 |
| 绩效情况 | 询问过去的项目成果和评价 | 回避绩效话题 |
```

## 六、面试注意事项

**格式**：
```
### 面试注意事项

**时间分配建议**：
| 环节 | 时间 | 说明 |
|------|------|-----|
| 开场寒暄 | 3-5 分钟 | 营造轻松氛围 |
| 核心维度考察 | 25-35 分钟 | 每个维度 8-12 分钟，优先考察重点维度 |
| 简历疑点追问 | 5-10 分钟 | 如无疑点可合并到维度考察中 |
| 风险核查 | 5 分钟 | 自然融入对话中 |
| 候选人提问 | 5 分钟 | 观察候选人关注点 |

**追问深度要求**：
- 核心维度和风险点：必须追问到具体事例（STAR 完整），不接受泛泛而谈
- 一般维度：至少追问一层

**氛围营造**：
- 保持轻松对话氛围，避免审问式提问
- 适当给予正面反馈，鼓励候选人展开描述
- 如果候选人紧张，可以先从简单话题切入

**记录要点**：
- 记录候选人的具体回答和行为事例，便于后续面评
- 标注打分直觉：每个维度结束后简单标注初步印象分
```

---

## 评价原则（面试计划专用）

1. **问题基于维度**：每个问题都要对应明确的评估维度
2. **证据导向**：问题设计指向可观察的行为证据，而非自我评价
3. **简历衔接**：充分利用简历信息设计追问，让候选人难以准备套路答案
4. **因材施教**：校招侧重潜力考察（学习能力、思考深度），社招侧重实战验证（项目成果、方法论）
5. **时间效率**：问题排列按优先级排序，确保有限时间内覆盖最关键维度
