# 类目 ⑥ 复盘 · 多场成长报告（G-growth-self）

> **场景**：面试官**给自己**看最近 N 场（默认 5 场）面试的成长趋势——不是单场评估，而是基于已存档评估**做横向对比**，识别进步项 / 持续短板 / 系统性问题。
>
> **触发词**：看我面试成长报告 / 我最近面试趋势 / 我面试有进步吗 / 复盘成长 / 看我最近 5 场表现

---

## G-0 · 进入门槛与硬规则

| 规则 ID | 内容 |
|---|---|
| G-RULE-1 | **数据驱动**——本类目**不读转写**、**不再做单场评估**，只读 `coach-archive/` 已存档 JSON |
| G-RULE-2 | 数据 < 3 场 → **不出报告**，引导用户先用 E 类目累积；3-9 场 → 基础趋势；≥10 场 → 完整成长报告 |
| G-RULE-3 | 默认 limit = 5，**禁止默认 10 场**（token 治理 + 趋势有效样本平衡） |
| G-RULE-4 | 输出**必须**先说进步项再说短板（正向激励原则） |
| G-RULE-5 | 改进建议聚焦**最高优先级 1-2 条**——不堆砌全部短板 |
| G-RULE-6 | 引用具体面试片段作为证据（如"上次张三那场，候选人说'我们重构了系统'你直接进入下一题"），证据**必须**是面试官行为而非候选人话术 |

---

## G-1 · 数据探活

调 `scripts/aggregate_coach.py`：

```bash
python3 scripts/aggregate_coach.py \
  --interviewer-login <当前用户 SSO loginName> \
  --limit 5 \
  --scope all
```

读 stdout JSON 的 `n_evaluations`：

| 场数 | 处理 |
|---|---|
| 0 | "你还没有任何复盘记录。先用 `/复盘最近一场` 跑一次单场复盘，至少累积 3 场后回来看成长" |
| 1-2 | "目前只有 N 场记录，不足以做趋势分析（至少需要 3 场）。可以等再做 (3-N) 场单场复盘后回来" |
| 3-4 | 基础版：能出趋势但样本量小，**报告头部标注「⚠️ 样本量较小，趋势仅供参考」** |
| 5-9 | ⭐ **推荐区间**：完整成长报告 |
| ≥10 | 提示用户："最近 10 场数据较多，建议看 5 场或选时间窗（最近 1 个月）" |

---

## G-2 · 用户参数确认（仅一次问）

如果用户没指定，直接默认 5 场 + scope=all。如果用户说了"最近 10 场"或"只看自评"，按用户的来。

```
默认参数：
  --limit 5
  --scope all       # all=自评+他评都看 / self=只看自评

用户可改：
  "看最近 3 场"    → --limit 3
  "只看我自己评的" → --scope self
```

## G-3 · 加载知识 + 投喂 LLM 撰写报告

把 aggregate 的 JSON + 以下知识投喂给 LLM：

```
1. references/coach/bei-framework.md       ← 用于解读维度名义
2. references/coach/scoring-rubric.md      ← 评级语义
3. references/coach/widget-spec.md §3      ← 输出 6 区块结构
4. aggregate.json                          ← 数据
```

让 LLM 产出报告。报告必须包含 6 个区块（widget-spec §3）：

1. 概览条（场数 / 日期范围 / 进步项数 / 持续短板数）
2. 雷达图叠加 N 场
3. 行为规范达标趋势条
4. 维度趋势横向条
5. 面试记录表
6. 趋势发现 + 改进建议

## G-5 · 进阶问题处理

### 5.1 用户问"为什么追问深度老是中/弱"

LLM 应该结合 aggregate.json 的 `evaluations[*].improvements` 引用具体场次的具体证据：

```
你 5 场中提到追问深度的有：
· 张** 那场（06-08）："候选人说我们重构了系统"——你切到下一题
· 王** 那场（05-28）："候选人说我们设计了 XX"——你转到了系统设计
· 孙** 那场（05-14）：3 次"我们"叙事均未追个人

模式：候选人用群体代词时你倾向于接受不追。
建议训练动作：每次听到"我们" → 立即追"你具体做什么"
```

### 5.2 用户问"和我同部门面试官比怎样"

⚠️ 当前 skill 单机存档，**不能**横向比较。明确告知：

> "成长报告基于你本地存档的数据，不能跨人对比。如果你是招聘经理想看你团队**多个面试官**的横向，用 `H-coach-others` 类目。"
