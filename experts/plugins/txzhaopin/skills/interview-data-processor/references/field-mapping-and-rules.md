# 字段映射与归一化规则参考

> 完整的字段别名列表，供 CodeBuddy 在映射时查阅。

## 字段映射别名表

映射规则：大小写不敏感，优先精确匹配，其次包含匹配，同一列不重复占用。

### 必选字段

| 标准字段 | 映射优先级 | 支持的列名 |
|---------|-----------|----------|
| **name** | 1 | 候选人ID、简历ID、候选人、姓名、name、候选人名称、员工姓名、candidate_id |
| **comment** | 2 | 面试评价、文字评价、评价、面试评语、评语、comment、综合评价、考核评价 |
| **grade** | 3 | 面试评级、面试结果*、面试等级、评级、grade、rating、绩效等级 |
| **result** | 4 | 面试流程结果、本环节处理意见、是否通过、result、录用结果、考核结论 |
| **round** | 5 | 环节名称、面试环节、面试轮次、轮次、round、面试阶段 |
| **position** | 6 | 职位名称（岗位）、面试职位、position、职位名称 |
| **bg** | 7 | 招聘岗位BG、面试BG、事业群、BG、department |
| **dept** | 8 | 招聘岗位组织、面试组织全路径、部门、事业部、组织 |

> *注：社招数据中列名"面试结果"的内容实际是评级（S/A+/A），不是通过/淘汰。

### 次重要字段

## 归一化值映射表

### result → pass / fail / pending

| pass | fail | pending |
|------|------|---------|
| 通过、是、录用、pass、yes、offer | 淘汰、否、不通过、fail、no、reject | 待定、观望、pending、需讨论 |
| 推荐录用、建议录用、达标、合格 | 不推荐、建议淘汰、不达标、不合格 | 待确认、再议、待观察 |
| **提交**（社招特有） | **放弃**（社招特有）、PIP | 需改进、待提升 |

### grade → S / A+ / A / A- / B

| S | A+ | A | A- | B |
|---|----|----|----|----|
| S、s、S级 | A+、a+、A+级 | A、a、A级 | A-、a-、A-级 | B、b、B级 |
| 优秀、卓越 | 杰出 | 良好、good | | 一般、average |
| 5分、超出期望 | | 4分、符合期望 | | 3分、待提升 |

> 无法匹配时返回空串。

### BG → 标准简称

标准列表：CDG、CSIG、IEG、PCG、TEG、WXG、S1、S2、S3

常见全称映射：
- 互动娱乐事业群 → IEG
- 云与智慧产业事业群 → CSIG
- 平台与内容事业群 → PCG
- 技术工程事业群 → TEG
- 微信事业群 → WXG
- 企业发展事业群 → CDG

### dept → 第二层组织

按 `/` 分割路径，第一段含 BG 名称则去掉，取第二段：
- `互动娱乐事业群/光子工作室群/XX` → `光子工作室群`
- `IEG/光子工作室群` → `光子工作室群`
- `光子工作室群`（无 BG 前缀）→ `光子工作室群`
