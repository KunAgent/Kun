# 面试数据处理器（interview-data-processor）

把面试评价 Excel 清洗成干净的标准数据。

## 谁需要这个 Skill

- 你有一份从系统导出的面试评价 Excel，字段名五花八门、评级写法不统一、有些记录缺评价文字
- 你想基于这些数据做分析，但数据太脏没法直接用

## 怎么用

上传面试评价 Excel，对 CodeBuddy 说：

> 帮我处理这份面试数据

全程自动执行，你只需要在最后确认分析哪个职位。

## 它做了什么

| 步骤 | 说明 |
|------|------|
| 字段识别 | 自动识别候选人、评价、评级、结果、职位、部门等字段 |
| 数据标准化 | 评级统一为 S/A+/A/A-/B，结果统一为通过/淘汰/待定 |
| 数据过滤 | 去掉空评价、超范围职级等无效记录 |
| 质量检查 | 数据不够用或字段缺失时，明确告诉你哪里不对、怎么补 |

## 输出

- `cleaned_data.json` — 标准化后的数据
- `quality_report.md` — 数据质量报告

## 支持范围

| 支持 | 不支持 |
|------|--------|
| 社招面评、校招面评 | 活水（内部转岗）数据 |
| Excel (.xlsx/.xls) 和 CSV | Word、PDF 等格式 |
| 几十到几千条数据 | — |

## 和"面试建模器"的关系

本 Skill 只负责清洗数据。如果你的目标是**生成岗位能力模型**，请安装 **interview-talent-modeler**（面试建模器），它会自动调用本 Skill 完成清洗，你不需要手动分两步操作。
