> ⚠️ **本 Skill 仅服务社招场景**，校招（doc `41`）/ 产培（doc `35`）模型不再加载。

> 本索引列出所有可通过 recruit-mcp 拉取的软素质模型（公司级 / BG 级 / 岗位级 / 红线）。  
> 调用方式：见 `SKILL.md → 🔌 MCP 文档调用规范`。  
> **本索引仅维护 documentId 与匹配规则，不存储模型正文**。模型正文统一从 MCP 实时拉取。

## 一、使用前必读

### 1.1 用途
软素质模型用于环节②的 **Part 2：软素质胜任力模型**，作为 LLM 在素质词典 25 项中做推荐时的"现成参照"，提升与公司/BG/岗位实际语境的对齐度。

### 1.2 加载策略：逐级叠加（不是回退）
- 公司级 + BG级 + 岗位级 三层**全部叠加**，维度去重合并
- S3 红线模型独立于正向评分，不参与 1-5 分打分（详见下方 §4）
- 命中几条就拉几条；都没命中就走 Step 2 从素质词典全新推荐

### 1.3 失败兜底（强制）
- 单个 documentId 拉取失败 → 静默跳过该文档，其余照常使用
- 全部失败 → 退化为"无现有模型参考"模式，仅基于素质词典 + 需求识别生成
- ⚠️ 任何情况下不阻塞环节②的产出

### 1.4 权重规则
- 各模型自带权重：核心维度（标 ⭐）= 1.5x，一般维度 = 1.0x
- 跨层级出现同名维度时，以**岗位级 > BG 级 > 公司级**优先级覆盖

## 六、MCP 调用快查（粘贴即用）

```
工具：mcp_call_tool
serverName: recruit-mcp
toolName:   CallAPI
arguments:
{
  "apiId": "recruit.recruit-ai-service.get_document",
  "params": { "documentId": "<上表中的 documentId>" }
}
```

**返回路径**: `response.data.data` = markdown 全文。  
**成功判定**: `response.status === 200` AND `response.data.code === "200"` AND `response.data.success === true` AND `response.data.data` 非空字符串。  
**常见失败码**: `50050`（文档不存在）/ `500`（服务异常）— 任一失败信号命中均视为失败，按 SKILL.md 兜底规则静默跳过。
