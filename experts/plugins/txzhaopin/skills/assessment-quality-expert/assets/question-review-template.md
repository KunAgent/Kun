```markdown
# 📋 题目审核报告

**审核日期**：{YYYY-MM-DD}
**审核模型**：{活跃模型名称}（{维度数}个维度）
**题目数量**：{N} 道

## 逐题审核

### 题目 {序号}

**题目内容**：{题目原文摘要}
**声称考察维度**：{声称的维度名}

| 检查项 | 结果 | 说明 |
|--------|------|------|
| 考察点准确性 | ✅ 准确 / ⚠️ 偏差 / ❌ 不匹配 | {具体分析} |
| 实际考察维度 | {Skill 判断的实际维度} | {判断依据} |
| 追问链质量 | ✅ 充分 / ⚠️ 不足 / ❌ 缺失 | {具体分析} |
| 评判要点清晰度 | ✅ 清晰 / ⚠️ 模糊 / ❌ 缺失 | {具体分析} |
| 社会期许偏差 | ✅ 无 / ⚠️ 轻微 / ❌ 严重 | {是否容易给出"正确答案"} |

**修改建议**：
{如有偏差，给出具体修改建议}

| 维度覆盖率 | {百分比} |
| 未覆盖维度 | {列表，如有} |

{1-3 句话总结建议}
```
