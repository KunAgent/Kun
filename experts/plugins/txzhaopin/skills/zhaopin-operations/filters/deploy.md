# 工作地可调配筛选条件 🌏

筛选是否服从工作地调配的候选人。

## 📋 参数信息

| 项目 | 值 |
|------|-----|
| **参数名** | `is_deploy` |
| **类型** | `number` 或 `null` |
| **必填** | ❌ 否（不填或传null表示不筛选） |
| **逻辑** | 布尔筛选 |

## 🎯 可选值

| 值 | 含义 |
|----|------|
| `1` | 服从调配 |
| `0` | 不服从调配 |
| `null` 或不传 | 不筛选（包含所有候选人） |

## 💡 使用示例

### 示例1：筛选服从调配的候选人

```javascript
{
  is_deploy: 1
}
```

**效果**：只筛选愿意服从工作地调配的候选人

### 示例2：筛选不服从调配的候选人

```javascript
{
  is_deploy: 0
}
```

**效果**：只筛选不愿意服从调配的候选人

### 示例3：不筛选调配意愿

```javascript
{
  is_deploy: null  // 或不传此参数
}
```

**效果**：包含所有候选人，无论是否服从调配

## ⚠️ 注意事项

1. **数字类型**：参数值是数字（`0` 或 `1`），不是布尔值（`false` 或 `true`）
2. **AND 逻辑**：与其他筛选条件（如学校、专业、期望工作地）是 AND 关系
3. **配合期望工作地使用**：
   - 通常与 `work_city` 参数配合使用
   - 例如：筛选"期望北京且不服从调配"的候选人
4. **自填信息**：是否服从调配是候选人自行选择的，非强制填写

## 🤔 常见问题

**Q: 为什么要筛选"服从调配"的候选人？**

A: 在某些情况下，企业需要在多个城市间调配人员。筛选服从调配的候选人可以增加人才配置的灵活性。

**Q: null 和 0 有什么区别？**

A: 
- **`null`**：不筛选，包含所有候选人（服从、不服从、未填写的）
- **`0`**：明确筛选"不服从调配"的候选人（排除服从的和未填写的）

**Q: 如果候选人未填写此项，会被筛选出来吗？**

A: 取决于你的筛选条件：
- `is_deploy: null` → **会**筛选出所有候选人（包括未填的）
- `is_deploy: 1` 或 `0` → **不会**筛选出未填的候选人
