# 应聘职位筛选条件 💼

筛选候选人应聘的具体职位。

## 📋 参数信息

| 项目 | 值 |
|------|-----|
| **参数名** | `station` |
| **类型** | `number[]` （数字数组） |
| **必填** | ❌ 否（不填或传空数组表示不筛选） |
| **逻辑** | OR（数组内满足任意一个即可） |

## 🎯 获取可选值

### 方式一：接口获取（推荐）

调用职位树接口获取完整职位列表：

```javascript
GET /tool/resume/api/web/campus_post/campus_position_tree
```

**返回数据结构：**
```json
{
  "code": 200,
  "data": [
    {
      "id": 2,
      "title": "技术",
      "children": [

          "id": 75,
          "title": "软件开发类",
          "children": [
            {
              "id": 101,
              "title": "软件开发-后台开发方向"
            }
          ]
        }
      ]
    }
  ]
}
```

## 💡 使用示例

### 示例1：筛选单个职位
```javascript
{
  station: [101]  // 软件开发-后台开发方向
}
```

### 示例2：筛选多个职位（OR逻辑）
```javascript
{
  station: [101, 102, 103]  // 后台开发 OR PC客户端 OR 移动客户端
}
```

### 示例3：筛选整个技术类（需传入所有技术职位ID）
```javascript
{
  station: [101, 102, 103, 104, ...]  // 技术类下的所有402个职位ID
}
```

## ⚠️ 注意事项

1. **使用数字ID**：必须使用职位的ID（数字），不是职位名称
2. **OR 逻辑**：数组内多个职位是 OR 关系（满足任意一个即可）
3. **AND 逻辑**：与其他筛选条件是 AND 关系
4. **分类筛选**：如需筛选某个分类下的所有职位，需要传入该分类下所有具体职位的ID数组
5. **数据时效性**：职位可能随时间变化，建议定期调用接口更新

## ❓ 常见问题

### Q1: 如何筛选"所有技术类"职位？
A: 技术类包含402个职位，需要传入所有技术类职位的ID数组。由于数量较多，建议：
1. 调用 `/tool/resume/api/web/campus_post/campus_position_tree` 接口
2. 遍历 `data` 中 `id=2` 的分类（技术类）
3. 提取所有 `children` 的ID（递归获取所有子节点）

### Q2: 能否只传分类ID（如2-技术）？
A: 不可以。`station` 参数只接受具体职位的ID，不接受分类ID。需要将分类展开为所有子职位ID。

### Q3: 如何知道某个ID对应的职位名称？
A: 三种方式：
1. 查看本文档的"常用职位速查表"
2. 调用职位树接口，搜索对应ID
3. 使用浏览器开发者工具，在页面上查看职位选择器

### Q4: 职位数据多久更新一次？
A: 腾讯校招职位会根据业务需求动态调整，建议：
- 开发阶段：使用本文档的常用职位ID
- 生产环境：每次执行前调用接口获取最新数据

### Q5: 接口返回的职位树如何解析？
A: 数据结构是递归的树形结构：
```javascript
// 伪代码：提取所有职位ID
function extractPositionIds(node) {
  let ids = [];
  if (!node.children) {
    // 叶子节点就是具体职位
    ids.push(node.id);
  } else {
    // 有children的是分类，继续递归
    for (let child of node.children) {
      ids = ids.concat(extractPositionIds(child));
    }
  }
  return ids;
}
```
