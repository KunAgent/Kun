# 院校等级筛选条件 🏫

筛选候选人就读的院校等级（211/985/C9/海外名校等）。

## 📋 参数信息

| 项目 | 值 |
|------|-----|
| **参数名** | `schoolLevel` |
| **类型** | `string[]` （字符串数组） |
| **必填** | ❌ 否（不填或传空数组表示不筛选） |
| **逻辑** | OR（数组内满足任意一个即可） |

## 🎯 可选值列表（11个，静态）

院校等级的可选值是**前端硬编码**的，共11个固定选项：

### 国内顶尖高校（5个）

| 选项值 | 说明 | 典型院校 |
|--------|------|---------|
| `"211"` | 211工程院校 | 所有211院校（包含985和C9） |
| `"985"` | 985工程院校 | 所有985院校（包含C9） |
| `"C9"` | C9联盟（九校联盟） | 清华、北大、复旦、上交、浙大、中科大、南大、哈工大、西安交大 |
| `"T28"` | 顶尖院校分级 T28 | 具体名单由系统统一维护 |
| `"T60"` | 顶尖院校分级 T60 | 具体名单由系统统一维护 |

### 国内普通高校（3个）

| 选项值 | 说明 |
|--------|------|
| `"国内普通高校"` | 非211的本科和专科院校 |
| `"大陆普通本科"` | 非211的本科院校 |
| `"大陆普通专科"` | 专科（高职）院校 |

### 海外与港澳台（3个）

| 选项值 | 说明 | 典型院校 |
|--------|------|---------|
| `"海外 QS100 高校"` | QS世界大学排名前100 | MIT、斯坦福、哈佛、牛津、剑桥、新加坡国立等 |
| `"海外高校"` | QS排名100之后的海外大学 | 其他国家和地区的大学 |
| `"港澳台院校"` | 香港、澳门、台湾地区高校 | 港大、港中文、港科技、台大等 |

## 💡 使用示例

### 示例1：筛选985院校

```javascript
{
  schoolLevel: ["985"]
}
```

**效果**：筛选出所有985院校的候选人（包含C9）

### 示例2：筛选C9联盟

```javascript
{
  schoolLevel: ["C9"]
}
```

**效果**：只筛选出C9联盟9所大学的候选人

### 示例3：筛选国内顶尖 + 海外名校

```javascript
{
  schoolLevel: ["985", "海外 QS100 高校", "港澳台院校"]
}
```

**效果**：筛选出985院校 **或** 海外QS100高校 **或** 港澳台院校的候选人

### 示例4：不筛选院校等级

```javascript
{
  schoolLevel: []  // 空数组
}
```

**效果**：不限制院校等级，包含所有候选人

## ⚠️ 注意事项

1. **精确匹配**：选项值必须与上表完全一致（区分大小写、标点符号）
2. **包含关系**：
   - 选择 `"211"` 会包含985和C9院校
   - 选择 `"985"` 会包含C9院校
   - 这是因为 C9 ⊂ 985 ⊂ 211
3. **OR 逻辑**：数组内多个值是 OR 关系
4. **AND 逻辑**：与其他筛选条件（如成绩排名、专业）是 AND 关系
5. **静态列表**：这11个选项是固定的，无需调用接口获取

## 🤔 常见问题

**Q: 为什么选择"211"会包含985院校的学生？**

A: 因为所有985院校都是211院校。这是包含关系：C9 ⊂ 985 ⊂ 211。选择"211"实际是选择"所有211工程院校"，自然包含985和C9。

**Q: 如何只筛选211但不包含985？**

A: 系统没有直接提供这个选项。如果需要，只能获取结果后二次过滤，或在前端UI上单独勾选非985的211院校。

**Q: T28和T60包含哪些学校？**

A: T28 / T60 是平台内置的院校分级筛选选项，具体名单由系统统一维护，不在本文档中展开。如有特定校名筛选需求，建议改用精确的 `school` 字段。
