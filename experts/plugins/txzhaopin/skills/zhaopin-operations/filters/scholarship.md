# 奖学金筛选条件 🏅

筛选获得过奖学金的候选人。

## 📋 参数信息

| 项目 | 值 |
|------|-----|
| **参数名** | `scholarships` |
| **类型** | `string[]` （字符串数组） |
| **必填** | ❌ 否（不填或传空数组表示不筛选） |
| **逻辑** | OR（数组内满足任意一个即可） |

## 🎯 获取可选值

### 方式：前端静态列表

奖学金选项是**前端下拉框提供的固定列表**，常见的奖学金类型包括：

**国内奖学金：**
- 国家奖学金
- 国家励志奖学金
- 校级奖学金
- 省级/市级奖学金

**企业奖学金：**
- 微软学者奖
- 谷歌博士奖学金
- 百度奖学金
- 腾讯奖学金
- 阿里巴巴奖学金

**其他奖学金：**
- 其他企业奖学金
- 其他类型奖学金

⚠️ **注意**：完整的奖学金列表可以通过查看前端页面的下拉选项获取，不同时期可能会有调整。

## 💡 使用示例

### 示例1：筛选国家奖学金获得者

```javascript
{
  scholarships: ["国家奖学金"]
}
```

### 示例2：筛选企业奖学金获得者

```javascript
{
  scholarships: ["微软学者奖", "谷歌博士奖学金", "百度奖学金"]
}
```

**效果**：筛选获得过微软学者奖 **或** 谷歌博士奖学金 **或** 百度奖学金的候选人

### 示例3：筛选多种奖学金

```javascript
{
  scholarships: ["国家奖学金", "国家励志奖学金", "微软学者奖"]
}
```

### 示例4：不筛选奖学金

```javascript
{
  scholarships: []  // 空数组
}
```

## ⚠️ 注意事项

1. **字符串数组**：使用奖学金名称字符串
2. **精确匹配**：奖学金名称必须与前端选项**完全一致**
3. **OR 逻辑**：数组内多个值是 OR 关系（满足任意一个即可）
4. **AND 逻辑**：与其他筛选条件（如学校、学历）是 AND 关系
5. **自填信息**：奖学金是候选人自行填写的，系统不验证准确性

## 🤔 常见问题

**Q: 如何获取完整的奖学金列表？**

A: 奖学金列表是前端下拉框提供的固定选项，可以通过以下方式获取：
- 在筛选页面查看"奖学金"下拉框的所有选项
- 查看前端页面源码中的奖学金选项配置
- 咨询系统管理员或查看内部文档

**Q: 奖学金名称区分大小写吗？**

A: 是的，必须严格匹配前端选项中的名称（包括大小写、标点符号）。

**Q: 如果候选人未填写奖学金，会被筛选出来吗？**

A: 取决于你的筛选条件：
- 使用空数组 `[]` → **会**筛选出所有候选人（包括未填的）
- 指定特定奖学金 → **不会**筛选出未填的候选人
