# 成绩排名筛选条件 📊

筛选候选人的成绩排名百分位（前5%/前10%/前20%/其他）。

## 📋 参数信息

| 项目 | 值 |
|------|-----|
| **参数名** | `schoolRank` |
| **类型** | `string[]` （字符串数组） |
| **必填** | ❌ 否（不填或传空数组表示不筛选） |
| **逻辑** | OR（数组内满足任意一个即可） |

## 🎯 获取可选值

### 方式：字典接口（动态）

调用 `get-filter-dictionary` 接口获取：

```javascript
GET /resume/campus/api/v1/dictionary/?types=SchoolRank
```

**返回示例**：
```json
{
  "status": 0,
  "data": {
    "SchoolRank": [
      {"did": 1, "name": "前5%", "ordering": 1},
      {"did": 2, "name": "前10%", "ordering": 2},
      {"did": 3, "name": "前20%", "ordering": 3},
      {"did": 4, "name": "其他", "ordering": 4}
    ]
  }
}
```

### 可选值列表（4个）

| 选项值 | did | 说明 |
|--------|-----|------|
| `"前5%"` | 1 | 成绩排名在年级/专业前5%的学生 |
| `"前10%"` | 2 | 成绩排名在年级/专业前10%的学生 |
| `"前20%"` | 3 | 成绩排名在年级/专业前20%的学生 |
| `"其他"` | 4 | 成绩排名在20%之后，或未填写排名信息 |

## 💡 使用示例

### 示例1：筛选成绩优异的学生（前10%）

```javascript
{
  schoolRank: ["前5%", "前10%"]
}
```

**效果**：筛选成绩排名前10%的候选人

### 示例2：筛选成绩中上等学生（前20%）

```javascript
{
  schoolRank: ["前5%", "前10%", "前20%"]
}
```

**效果**：筛选成绩排名前20%的候选人

### 示例3：仅筛选顶尖学生（前5%）

```javascript
{
  schoolRank: ["前5%"]
}
```

### 示例4：不筛选成绩排名

```javascript
{
  schoolRank: []  // 空数组
}
```

**效果**：不限制成绩排名，包含所有候选人（包括未填写成绩的）

## ⚠️ 注意事项

1. **精确匹配**：必须使用接口返回的 `name` 字段值（如 `"前5%"`），不能写成 `"前5％"` 或 `"前 5%"`
2. **"其他"的含义**：包含成绩排名在20%之后的学生，**也包含未填写成绩排名信息的学生**
3. **OR 逻辑**：数组内多个值是 OR 关系
4. **AND 逻辑**：与其他筛选条件（如院校等级、专业）是 AND 关系
5. **自填信息**：成绩排名是候选人自行填写的，系统不验证准确性

## 🤔 常见问题

**Q: 如果候选人未填写成绩排名，会被筛选出来吗？**

A: 取决于你是否选择了"其他"选项：
- 选择 `["前5%", "前10%"]`（不含"其他"）→ **不会**筛选出未填写的候选人
- 选择 `["前5%", "前10%", "其他"]`（包含"其他"）→ **会**筛选出未填写的候选人
- 使用空数组 `[]` → **会**筛选出所有候选人（包括未填写的）

**Q: 成绩排名是如何计算的？**

A: 成绩排名是候选人在简历中自行填写的信息，通常指在年级或专业中的排名百分位。系统不会自动计算或验证。
