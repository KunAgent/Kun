# 测评记录筛选条件 ✍️

筛选候选人的测评完成状态。

## 📋 参数信息

| 项目 | 值 |
|------|-----|
| **参数名** | `assessmentFinishStatus` |
| **类型** | `number[]` （数字数组） |
| **必填** | ❌ 否（不填或传空数组表示不筛选） |
| **逻辑** | OR（数组内满足任意一个即可） |

## 🎯 可选值

| 值 | 含义 |
|----|------|
| `0` | 测评未完成 |
| `1` | 测评已完成 |
| `2` | 测评通过 |

## 💡 使用示例

### 示例1：筛选测评已完成的候选人

```javascript
{
  assessmentFinishStatus: [1, 2]  // 已完成或通过
}
```

### 示例2：筛选测评通过的候选人

```javascript
{
  assessmentFinishStatus: [2]  // 仅通过
}
```

### 示例3：不筛选测评记录

```javascript
{
  assessmentFinishStatus: []  // 空数组
}
```

## ⚠️ 注意事项

1. **数字类型**：参数值是数字数组
2. **OR 逻辑**：数组内多个值是 OR 关系
3. **AND 逻辑**：与其他筛选条件是 AND 关系
