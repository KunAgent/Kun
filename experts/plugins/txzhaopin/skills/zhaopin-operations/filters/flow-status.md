# 流程状态筛选条件 📋

筛选候选人在招聘流程中的状态。

## 📋 参数信息

| 项目 | 值 |
|------|-----|
| **参数名** | `flow_status` |
| **类型** | `number[]` （数字数组） |
| **必填** | ❌ 否（不填或传空数组表示不筛选） |
| **逻辑** | OR（数组内满足任意一个即可） |

## 🎯 获取可选值

### 方式一：接口获取（推荐）

调用字典接口获取最新流程状态：

```javascript
GET /resume/campus/api/v1/dictionary/?types=Flow
```

**返回数据结构：**
```json
{
  "status": 0,
  "data": {
    "Flow": [
      {
        "did": 0,
        "name": "待筛选",
        "type": "Flow",
        "ordering": 1
      }
    ]
  }
}
```

**🔍 流程状态分类：**

1. **筛选阶段**：待筛选(0)、已锁定(1)、待分配(16)、已分配(17)
2. **面试阶段**：集体面试(2)、初试(3)、复试(4)、GM/面委会/EVP面试(5)、HR面试(6)
3. **Offer阶段**：offer审批中(26)、学生意向确认(25)、实习生offer确认中(28)、毕业生offer确认中(30)
4. **录用阶段**：实习已录用(12)、录用评估中(24)、实习生考核转推荐(14)、毕业生已录用(15)
5. **异常/放弃**：面试流程放弃(8)、offer流程放弃(27)、实习生考核淘汰(13)、入职流程放弃(31)
6. **项目锁定**：已锁定在项目(22)、已锁定在项目面试官(23)

## 💡 使用示例

### 示例1：筛选待筛选的简历
```javascript
{
  flow_status: [0]  // 待筛选
}
```

### 示例2：筛选所有面试阶段的候选人
```javascript
{
  flow_status: [3, 4, 5, 6]  // 初试、复试、GM面试、HR面试
}
```

### 示例3：筛选已录用的候选人
```javascript
{
  flow_status: [12, 15]  // 实习已录用、毕业生已录用
}
```

### 示例4：筛选Offer相关状态
```javascript
{
  flow_status: [26, 25, 28, 30]  // offer审批中、学生意向确认、实习生offer确认中、毕业生offer确认中
}
```

### 示例5：排除已放弃的候选人（反向筛选需在业务逻辑中实现）
```javascript
{
  // 传入所有非放弃状态的ID
  flow_status: [0, 1, 16, 17, 2, 3, 4, 5, 6, 26, 25, 28, 30, 12, 24, 14, 15, 22, 23]
}
```

## ⚠️ 注意事项

1. **使用数字ID**：必须使用状态ID（数字），不是状态名称
2. **OR 逻辑**：数组内多个状态是 OR 关系（满足任意一个即可）
3. **AND 逻辑**：与其他筛选条件是 AND 关系
4. **状态更新**：候选人的流程状态会随着招聘流程推进而自动更新
5. **并行状态**：某些状态的ordering相同（如28、30都是13），表示它们是并行的选择

## ❓ 常见问题

### Q1: 如何筛选"面试中"的候选人？
A: 面试阶段包含多个状态，需要传入所有面试相关状态ID：
```javascript
{ flow_status: [2, 3, 4, 5, 6] }  // 集体面试、初试、复试、GM面试、HR面试
```

### Q2: "待筛选"和"已锁定"有什么区别？
A: 
- **待筛选(0)**：简历刚投递，还没有人处理
- **已锁定(1)**：某位面试官已锁定该简历，准备发起面试

### Q3: 如何筛选所有"正常流程"的候选人（排除放弃/淘汰）？
A: 排除以下状态：面试流程放弃(8)、offer流程放弃(27)、实习生考核淘汰(13)、入职流程放弃(31)

### Q4: 流程状态的ordering有什么用？
A: `ordering`表示状态在流程中的顺序，数字越小越靠前。相同ordering表示并行状态（如实习生/毕业生offer确认）。

### Q5: 如何判断候选人是否已拿到offer？
A: 包含以下任一状态即表示已有offer意向：
- offer审批中(26)
- 学生意向确认(25)
- 实习生offer确认中(28)
- 毕业生offer确认中(30)
- 实习已录用(12)
- 毕业生已录用(15)
