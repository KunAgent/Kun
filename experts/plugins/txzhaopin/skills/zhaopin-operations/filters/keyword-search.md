# 关键词模糊搜索筛选条件 🔍

通过关键词在简历全文中进行模糊搜索，支持搜索学校、专业、技能、项目经历、实习公司等多种信息。

## 📋 参数信息

| 项目 | 值 |
|------|-----|
| **参数名** | `keyword` |
| **类型** | `string` （字符串） |
| **必填** | ❌ 否（不填或传空字符串表示不使用关键词搜索） |
| **逻辑** | 模糊匹配（全文搜索） |

## 🎯 功能特点

### ✅ 优势

1. **全文搜索**：在简历的**所有字段**中进行模糊匹配
   - 学校名称
   - 专业名称
   - 技能标签
   - 项目经历描述
   - 实习公司名称
   - 个人评价
   - 其他自填内容

2. **非硬匹配**：使用模糊算法，容错性强
   - 支持部分匹配：搜"北大"可以匹配"北京大学"
   - 支持同义词：系统可能识别相关关键词
   - 支持分词：搜"机器学习"可能匹配"机器"和"学习"

3. **灵活性强**：可以搜索任何你关心的内容
   - 技术关键词：Python、Java、前端、后端、算法
   - 业务关键词：推荐系统、广告、游戏、AI大模型
   - 公司名称：腾讯、字节、阿里、美团、Google
   - 竞赛名称：ICPC、蓝桥杯、数学建模

4. **提取能力强**：可以提取非常多的关键词
   - 即使某些信息没有专门的筛选字段（如具体的项目名称、技术栈细节）
   - 也可以通过关键词搜索找到相关候选人

## ⚠️ 注意事项

### 🔴 0. keyword 使用的两条铁律（CRITICAL — 必须遵守）

**铁律一：已有筛选字段的维度，禁止写入 keyword**

以下维度已有专用结构化参数，**必须使用对应参数，禁止放入 keyword**：

| 维度 | 必须使用的参数 | ❌ 禁止的 keyword 写法 |
|------|---------------|----------------------|
| 学校名称 | `school` | `keyword: "清华大学"` |
| 专业 | `specialityList` | `keyword: "计算机科学"` |
| 院校等级 | `schoolLevel` | `keyword: "985"` |
| 学历 | `education` | `keyword: "硕士"` |
| 城市 | `work_city` | `keyword: "深圳"` |
| 技能标签 | `skillList` | （当标签能精确覆盖时优先用标签） |

**keyword 只用于没有专用筛选字段的内容**：技术栈细节、项目经历、业务领域、实习公司等。

**铁律二：keyword 中 AND（`+`）最多 2 个**

keyword 中 `+`（AND 逻辑）**最多 2 个**，即最多 3 个词的 AND 组合。

- ✅ `"Python+推荐系统"` — 1 个 AND，OK
- ✅ `"Python+推荐系统+大模型"` — 2 个 AND，OK
- ❌ `"Python+推荐系统+大模型+NLP"` — 3 个 AND，**禁止！** 会导致结果为 0

超过 3 个 AND 条件时，必须拆分到多轮搜索中分别执行。

### 1. 搜索精度

- **优点**：模糊搜索，容错性强，能搜到更多结果
- **缺点**：可能包含不太相关的结果（如"北大"可能匹配到"北大街"等无关内容）

**建议**：
- 使用完整名称（如"北京大学"而不是"北大"）可以提高精度
- 如果搜索结果太多，结合其他筛选条件缩小范围

### 2. 与专用筛选条件的互斥关系（🔴 硬性规则）

| 场景 | 必须使用 | 原因 |
|------|---------|------|
| 筛选学校 | `school` 参数 | 精确强过滤，不会误匹配 |
| 筛选专业 | `specialityList` 参数 | 精确强过滤，不会误匹配 |
| 筛选院校等级 | `schoolLevel` 参数 | 精确强过滤 |
| 筛选学历 | `education` 参数 | 精确强过滤 |
| 筛选城市 | `work_city` 参数 | 精确强过滤 |
| 模糊搜索技术栈 | `keyword` 参数 | 全文搜索，能匹配到项目描述中的技术栈 |
| 搜索实习公司 | `keyword` 参数 | 实习公司字段可能填写不规范，关键词搜索更灵活 |
| 搜索业务领域/项目经历 | `keyword` 参数 | 没有专用字段，只能用关键词 |

**核心原则**：
- 🔴 **有专用筛选字段的维度 → 禁止写入 keyword，必须用结构化参数**
- ✅ **没有专用筛选字段的内容 → 使用 keyword**

### 3. 空值表示不筛选

```javascript
{
  keyword: ""  // 空字符串，不使用关键词搜索
}
```

### 4. 与其他条件的逻辑关系

- **AND 逻辑**：关键词搜索与其他筛选条件是 **AND** 关系
- 示例：`keyword: "机器学习"` + `schoolLevel: ["985"]` → 筛选出985院校**且**简历中包含"机器学习"的候选人

### 5. 性能考虑

- 关键词搜索是全文搜索，性能开销较大
- 建议结合其他条件缩小搜索范围（如先按学校、学历筛选，再用关键词搜索）

### 实践1：搜索小众技能/特定领域（OR组合搜索）⭐ **强烈推荐**

**场景**：搜索"做过可玩广告/试玩广告"的候选人

**❌ 错误做法**：单一关键词搜索
```javascript

```

**✅ 正确做法**：OR组合多个关键词变体
```javascript
{
  keyword: "可玩广告|playable ads|试玩广告|playable|互动广告|H5游戏|小游戏广告|interactive ads",
  graduate_time_begin: "2027-01-01",
  graduate_time_end: "2027-12-31",
  startInterviewEnable: 1
}
```

**效果**：
- 结果：39条精准结果
- 自动去重（同一简历只返回一次）
- 覆盖中文、英文、同义词等所有可能的表达方式

**核心策略**：
1. **列出所有关键词变体**
   - 中文表达：可玩广告、试玩广告、互动广告
   - 英文表达：playable ads、playable、interactive ads
   - 近似概念：H5游戏、小游戏广告、游戏化广告

2. **用 `|` 连接成OR组合**
   ```
   关键词1|关键词2|关键词3|...
   ```

3. **精读验证**：搜索结果需要逐一验证简历详情
   - 读取实习经历和项目经历
   - 确认是否真实做过相关工作

**适用场景**：
- ✅ 小众技术领域（如可玩广告、WebRTC、区块链等）
- ✅ 多种表达方式的技能（前端/Front-end/FE）
- ✅ 中英文混合场景（Machine Learning/机器学习/ML）

## 🤔 常见问题

### Q1: 关键词搜索是精确匹配还是模糊匹配？

A: **模糊匹配**。系统会在简历全文中搜索包含该关键词的内容，使用分词和相似度算法。

**示例**：
- 搜索"北大" → 可能匹配"北京大学"
- 搜索"机器学习" → 可能匹配"ML"、"深度学习"等相关词

---

### Q2: 可以同时搜索多个关键词吗？

A: 可以！系统支持三种语法：

#### 语法说明

| 语法 | 示例 | 逻辑 | 说明 |
|------|------|------|------|
| `"双引号"` | `"C++"` | 全匹配 | 精确匹配完整关键词 |
| `+` | `清华+北大` | AND | 必须同时包含所有关键词 |
| `\|` | `清华\|北大` | OR | 包含任意一个即可 |

#### 示例1：AND逻辑（必须同时包含）

```javascript
keyword: "Python+机器学习"
```

**效果**：只匹配**同时包含**"Python"和"机器学习"的简历

---

#### 示例2：OR逻辑（包含任意一个）⭐ **推荐用于小众领域**

```javascript
keyword: "可玩广告|playable ads|试玩广告|playable|互动广告"
```

**效果**：匹配包含**任意一个**关键词的简历

**优势**：
- ✅ 一次搜索覆盖多个关键词变体（中英文、同义词）
- ✅ 系统自动去重（同一简历只返回一次）
- ✅ 效率高（1次请求 vs N次请求）

---

#### 示例3：精确匹配

```javascript
keyword: "\"C++\""
```

**效果**：精确匹配"C++"，避免匹配到"C语言"等

---

### Q3: 关键词搜索和专用字段（如 `school`）哪个优先？

A: **必须使用专用字段**，理由：
- 专用字段是严格过滤，不会有误匹配
- 关键词搜索可能匹配到无关内容
- 🔴 **有专用筛选字段的维度，禁止写入 keyword**

**示例**：
- ❌ `keyword: "北京大学"` → 禁止！可能匹配到"毕业于北京大学附属中学"
- ✅ `school: ["北京大学"]` → 严格过滤，只匹配目标学校

---

### Q4: 如何搜索"有Python和Java经验"的候选人？

A: 两种方式：

**方式1：使用关键词搜索**
```javascript
keyword: "Python Java"
```

**方式2：使用技能标签（更精确）**
```javascript
skillList: ["Python", "Java"]  // 需要先查询技能标签ID
```

**建议**：优先使用方式2（技能标签），因为更精确。

### Q6: OR组合搜索 vs 逐轮关键词搜索，该如何选择？

A: **强烈推荐使用OR组合搜索**

#### 对比分析

| 维度 | OR组合搜索 | 逐轮关键词搜索 |
|------|-----------|---------------|
| **接口调用次数** | ✅ 1次 | ❌ N次（N=关键词数量） |
| **总耗时** | ✅ ~3秒 | ❌ ~3秒 × N |
| **去重处理** | ✅ 系统自动去重 | ❌ 需手动编写去重逻辑 |
| **结果完整性** | ✅ 完整（并集） | ✅ 完整（需正确合并） |
| **代码复杂度** | ✅ 一行代码 | ❌ 需循环、合并、去重 |
| **服务器压力** | ✅ 低 | ❌ 高 |

#### 示例对比

**OR组合搜索**（推荐）：
```javascript
// 一次搜索，系统自动去重
keyword: "可玩广告|playable|试玩|互动广告|H5游戏"

// 耗时：3秒
// 结果：39条（已去重）
```

**逐轮关键词搜索**（不推荐）：
```javascript
// 需要5次搜索 + 手动去重
const keywords = ["可玩广告", "playable", "试玩", "互动广告", "H5游戏"];
let allResults = [];

for (let kw of keywords) {
  const results = await 搜索(kw);  // 每次3秒
  allResults = allResults.concat(results);
}

// 手动去重
const uniqueResults = Array.from(
  new Map(allResults.map(r => [r.rid, r])).values()
);

// 耗时：15秒
// 结果：39条（手动去重后）
```

#### 效率对比

```
OR组合搜索耗时 = 1次搜索 = 3秒
逐轮搜索耗时 = N次搜索 = 3秒 × N

当N=9时，OR组合快 9倍！
```

#### 何时使用逐轮搜索？

**仅在以下情况使用逐轮搜索**：
1. ❓ 怀疑OR组合搜索有结果截断（结果数=50，且怀疑实际更多）
2. ❓ 需要单独分析每个关键词的匹配情况（如统计各关键词命中率）
3. ❓ OR组合搜索结果异常（如返回0条，但逐轮能找到）

**结论**：99%的场景应该使用OR组合搜索！

## 🔥 关键词搜索策略总结

### 单一关键词搜索
适用场景：关键词明确，不存在多种表达方式
```javascript
keyword: "北京大学"
```

### OR组合搜索 ⭐ **强烈推荐**
适用场景：小众技能、多种表达方式、中英文混合
```javascript
keyword: "可玩广告|playable ads|试玩广告|playable|互动广告"
```

**核心优势**：
- ✅ 一次搜索覆盖所有关键词变体
- ✅ 系统自动去重
- ✅ 效率高10倍
- ✅ 代码简洁

### AND组合搜索
适用场景：必须同时包含多个关键词
```javascript
keyword: "Python+机器学习"
```

🔴 **AND（`+`）最多 2 个**（最多 3 个词），超过则拆分到多轮搜索：
- ✅ `"A+B"` / `"A+B+C"` — OK
- ❌ `"A+B+C+D"` — 禁止，会导致结果为 0

### 精确匹配
适用场景：避免歧义（如C++）
```javascript
keyword: "\"C++\""
```

- 教育经历
- 项目经历描述
- 实习经历描述
- 技能标签
- 竞赛获奖
- 个人评价
- 其他自填内容

**注意**：具体搜索范围由后端决定，以上为推测。
