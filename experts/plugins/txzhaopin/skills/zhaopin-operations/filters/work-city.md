# 期望工作地筛选条件 🌍

筛选候选人期望的工作城市。

## 📋 参数信息

| 项目 | 值 |
|------|-----|
| **参数名** | `work_city` |
| **类型** | `number[]` （数字数组） |
| **必填** | ❌ 否（不填或传空数组表示不筛选） |
| **逻辑** | OR（数组内满足任意一个即可） |

## 🎯 获取可选值

### 方式：字典接口（动态）

调用 `get-filter-dictionary` 接口获取：

```javascript
GET /resume/campus/api/v1/dictionary/?types=RCity
```

**返回示例**（部分）：
```json
{
  "status": 0,
  "data": {
    "RCity": [
      {"did": 1, "name": "深圳总部"},
      {"did": 2, "name": "北京"},
      {"did": 3, "name": "上海"},
      {"did": 4, "name": "广州"},
      {"did": 5, "name": "成都"},
      // ... 共30个城市
    ]
  }
}
```

> ⚠️ **注意**：字典接口 `RCity` 返回的城市编码与搜索页面实际使用的 `hopeWorkCityOptions` 编码**完全不同**。搜索接口 `work_city` 参数必须使用下方映射表中的 did 值。

## 💡 使用示例

### 示例1：仅北京

```javascript
{
  work_city: [2]
}
```

### 示例2：北上广深

```javascript
{
  work_city: [1, 2, 3, 4]
}
```

**效果**：筛选期望工作地为深圳总部 **或** 北京 **或** 上海 **或** 广州的候选人

### 示例3：主要城市组合

```javascript
{
  work_city: [1, 2, 3, 11, 12]  // 深圳总部、北京、上海、杭州、南京
}
```

### 示例4：不筛选工作地

```javascript
{
  work_city: []  // 空数组
}
```

**效果**：不限制期望工作地，包含所有候选人

## ⚠️ 注意事项

1. **使用数字ID**：必须使用 `did` 字段的数字ID（如 `2`），**不能**使用城市名称（如 `"北京"`）
2. **OR 逻辑**：数组内多个城市是 OR 关系（满足任意一个即可）
3. **AND 逻辑**：与其他筛选条件（如学校、学历）是 AND 关系
4. **期望 vs 实际**：此参数是候选人的**期望工作地**，不是实际工作地
5. **"深圳总部"**：注意城市名称为"深圳总部"（did=1），不是"深圳"
6. **全选 = 不筛选**：选择所有30个城市等同于使用空数组 `[]`

## 🤔 常见问题

**Q: "期望工作地"和"实际工作地"有什么区别？**

A: 
- **期望工作地**（`work_city`）：候选人在简历中填写的期望工作城市
- **实际工作地**（`WCity`）：候选人实际被录用后的工作城市（系统分配）
- 简历筛选通常使用"期望工作地"

**Q: 如果候选人未填写期望工作地，会被筛选出来吗？**

A: 取决于你的筛选条件：
- 使用空数组 `[]` → **会**筛选出所有候选人（包括未填的）
- 指定特定城市 → **不会**筛选出未填的候选人

**Q: 如何获取完整的30个城市列表？**

A: 调用 `get-filter-dictionary` 接口，传入 `types=RCity`，返回所有城市的 `did` 和 `name` 映射。注意字典接口返回的 did 与搜索接口实际使用的 did 可能不一致，以本文档的映射表为准。
