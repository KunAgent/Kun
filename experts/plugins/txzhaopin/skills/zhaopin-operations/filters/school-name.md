# 学校查询筛选条件 🏫

筛选具体的学校名称（如清华大学、北京大学）。**此参数为严格过滤**，按最高学历的学校匹配。

## 📋 参数信息

| 项目 | 值 |
|------|-----|
| **参数名** | `school` |
| **类型** | `string[]` （字符串数组） |
| **必填** | ❌ 否（不填或传空数组表示不筛选） |
| **逻辑** | OR（数组内满足任意一个即可） |
| **过滤强度** | 🔴 **严格过滤**（按最高学历的学校匹配，只返回匹配的候选人） |

## 🎯 获取可选值

### 方式：搜索接口（动态）

调用 `search-school` 接口进行模糊搜索：

```javascript
GET /resume/campus/api/v1/dictionary/searchSchool?schoolName=北京&size=20
```

**返回示例**：
```json
{
  "status": 0,
  "data": [
    "北京大学",
    "北京航空航天大学",
    "北京邮电大学",
    "北京交通大学",
    "北京理工大学"
    // ... 更多匹配的学校
  ]
}
```

### 使用哪个值？

直接使用返回的学校名称字符串（如 `"北京大学"`）。

## 💡 使用示例

### 示例1：筛选清华大学

```javascript
{
  school: ["清华大学"]
}
```

### 示例2：筛选清华或北大

```javascript
{
  school: ["清华大学", "北京大学"]
}
```

**效果**：筛选就读于清华大学 **或** 北京大学的候选人

### 示例3：筛选C9联盟学校

```javascript
{
  school: [
    "清华大学",
    "北京大学",
    "复旦大学",
    "上海交通大学",
    "浙江大学",
    "中国科学技术大学",
    "南京大学",
    "哈尔滨工业大学",
    "西安交通大学"
  ]
}
```

### 示例4：不筛选学校

```javascript
{
  school: []  // 空数组
}
```

## ⚠️ 注意事项

1. **精确匹配**：学校名称必须与接口返回的名称**完全一致**
2. **先搜索后使用**：不要凭记忆填写学校名，必须通过搜索接口获取准确名称
3. **OR 逻辑**：数组内多个学校是 OR 关系（满足任意一个即可）
4. **AND 逻辑**：与其他筛选条件（如学历、专业）是 AND 关系
5. **严格过滤**：`school` 参数是严格过滤，只返回匹配学校的候选人。匹配基于**最高学历**的学校，因此搜索结果中可能出现"本科是目标学校但硕士是其他学校"的情况——这不是过滤失效，而是该候选人最高学历（硕士）学校恰好匹配目标
6. **禁止用 keyword 替代**：学校筛选必须使用 `school` 参数，禁止在 `keyword` 中写学校名称
7. **与院校等级的关系**：
   - `school` 参数指定具体学校名称
   - `schoolLevel` 参数指定院校等级（985/211等）
   - 两个参数可以同时使用，表示 AND 关系

## 🔍 如何搜索学校名称

### 步骤1：调用搜索接口

```bash
mcporter call recruit-mcp CallAPI apiId='recruit.campus-resume.get_api_dictionary_searchSchool' params='{"schoolName": "北京", "size": "20"}'
```

### 步骤2：从结果中选择

从返回的学校列表中选择需要的学校名称，添加到 `school` 参数数组中。

## 🔗 在搜索接口中使用

```javascript
POST /resume/campus/api/v1/resume/search

{

```

## 🤔 常见问题

**Q: 学校名称必须完整吗？可以简写吗？**

A: 必须使用完整的学校名称，不能简写。例如：
- ✅ `"清华大学"`
- ❌ `"清华"` 或 `"THU"`

**Q: 如何筛选985院校而不指定具体学校？**

A: 使用 `schoolLevel` 参数：
```javascript
{
  schoolLevel: ["985"],  // 不使用 school 参数
  school: []
}
```

**Q: school 和 schoolLevel 可以同时使用吗？**

A: 可以。两个参数是 AND 关系：
```javascript
{
  schoolLevel: ["985"],        // AND
  school: ["清华大学", "北京大学"]  // AND
}
```
效果：筛选985院校 **并且** 是清华或北大的候选人（此例中清华北大都是985，实际等同于只用 school）

**Q: 学校名称区分大小写吗？**

A: 是的，必须严格匹配。建议通过搜索接口获取准确名称，而不是手动输入。
