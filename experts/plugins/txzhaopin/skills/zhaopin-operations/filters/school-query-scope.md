# 学校查询范围筛选条件 🔍

选择按"全部学历"或"最高学历"筛选学校。

## 📋 参数信息

| 项目 | 值 |
|------|-----|
| **参数名** | `last_school` |
| **类型** | `number` |
| **必填** | ❌ 否（不填或传0表示"全部学历"） |
| **逻辑** | 单选 |

## 🎯 可选值

| 值 | 含义 | 说明 |
|----|------|------|
| `0` | 全部学历 | 查询候选人所有学历的学校（默认） |
| `1` | 最高学历 | 只查询候选人最高学历的学校 |

## 💡 使用示例

### 示例1：按最高学历查询（默认）

```javascript
{
  last_school: 0,  // 或不传此参数
  school: ["清华大学"]
}
```

**效果**：查询**所有学历**中有清华大学的候选人（本科清华或硕士清华或博士清华）

### 示例2：按最高学历查询

```javascript
{
  last_school: 1,
  school: ["清华大学"]
}
```

**效果**：查询**最高学历**为清华大学的候选人（如果候选人本科清华、硕士北大，则不会被筛选出来）

## ⚠️ 注意事项

1. **默认值**：不传参数或传 `0` 表示按"全部学历"查询
2. **配合 school 参数使用**：此参数必须与 `school` 参数配合使用才有意义
3. **最高学历定义**：系统按学历层次判断（博士 > 硕士 > 本科 > 专科 > 高中）
4. **AND 逻辑**：与其他筛选条件（如专业、成绩）是 AND 关系

## 🤔 常见问题

**Q: 为什么需要这个参数？**

A: 有些候选人本科是名校，硕士是普通院校（或相反）。这个参数允许你精确控制查询逻辑：
- **全部学历**：只要有一个学历是目标学校就匹配
- **最高学历**：必须最高学历是目标学校才匹配

**Q: "全部学历"和"最高学历"的区别？**

A: 以清华为例：
- **全部学历**（`last_school=0`）：本科清华、硕士北大的候选人 → **会**被筛选
- **最高学历**（`last_school=1`）：本科清华、硕士北大的候选人 → **不会**被筛选（因为最高学历是北大）

**Q: 如果不关心这个维度，应该传什么？**

A: 传 `0` 或不传此参数即可，表示按"全部学历"查询（更宽松的条件）。
