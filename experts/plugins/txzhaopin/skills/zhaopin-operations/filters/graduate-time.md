# 毕业时间筛选条件 📅

筛选候选人的毕业年月范围。

## 📋 参数信息

| 项目 | 值 |
|------|-----|
| **参数名** | `graduate_time_begin` / `graduate_time_end` |
| **类型** | `string` （日期字符串） |
| **必填** | ✅ **是**（搜索接口的必需参数） |
| **格式** | `YYYY-MM-DD` |

## 🎯 参数说明

毕业时间通过**起止日期**来筛选，使用两个参数：

- **`graduate_time_begin`**：毕业时间起始日期
- **`graduate_time_end`**：毕业时间结束日期

⚠️ **重要**：这两个参数是搜索接口的**必需参数**，即使不关心毕业时间，也必须提供一个范围。

## 💡 使用示例

### 示例1：筛选2027届毕业生

```javascript
{
  graduate_time_begin: "2027-01-01",
  graduate_time_end: "2027-12-31"
}
```

**效果**：筛选2027年1月1日至2027年12月31日之间毕业的候选人

### 示例2：筛选2026-2027届毕业生

```javascript
{
  graduate_time_begin: "2026-01-01",
  graduate_time_end: "2027-12-31"
}
```

**效果**：筛选2026年和2027年毕业的候选人

### 示例3：筛选2027年上半年毕业

```javascript
{
  graduate_time_begin: "2027-01-01",
  graduate_time_end: "2027-06-30"
}
```

### 示例4：不限制毕业时间（设置大范围）

```javascript
{
  graduate_time_begin: "2020-01-01",
  graduate_time_end: "2030-12-31"
}
```

**效果**：虽然必须提供日期范围，但可以设置一个足够大的范围来覆盖所有候选人

## ⚠️ 注意事项

1. **必需参数**：这两个参数是搜索接口的必需参数，不能省略或传空值
2. **日期格式**：严格使用 `YYYY-MM-DD` 格式（如 `"2027-06-30"`）
3. **闭区间**：起止日期都包含在筛选范围内（包含边界）
4. **逻辑关系**：begin ≤ 毕业时间 ≤ end
5. **AND 逻辑**：与其他筛选条件是 AND 关系

## 🤔 常见问题

**Q: 如果不关心毕业时间，可以不传这两个参数吗？**

A: 不可以。这两个参数是搜索接口的必需参数。如果不关心毕业时间，可以设置一个足够大的范围（如2020-2030）来包含所有候选人。

**Q: 毕业时间是候选人自己填写的吗？**

A: 是的。毕业时间是候选人在简历中填写的预期毕业日期。

**Q: 如何筛选"应届生"？**

A: 应届生通常指当年或次年毕业的学生。例如2026年招聘，应届生通常指2026年和2027年毕业的学生：
```javascript
{
  graduate_time_begin: "2026-01-01",
  graduate_time_end: "2027-12-31"
}
```
