# 面试记录筛选条件 📝

筛选具有特定面试记录状态的候选人。

## 📋 参数信息

| 项目 | 值 |
|------|-----|
| **参数名** | `select_tags` |
| **类型** | `number[]` （数字数组） |
| **必填** | ❌ 否（不填或传空数组表示不筛选） |
| **逻辑** | OR（数组内满足任意一个即可） |

⚠️ **重要**：`select_tags` 是一个**通用标签参数**，不仅用于面试记录，还可以包含其他类型的标签（如活动标签、实习考核标签等）。

## 🎯 获取可选值

### 方式：字典接口（动态）

调用 `get-filter-dictionary` 接口获取：

```javascript
GET /resume/campus/api/v1/dictionary/?types=ResumeSign
```

**返回示例**（筛选 `fid=2` 的项）：
```json
{
  "status": 0,
  "data": {
    "ResumeSign": [
      {"did": 104, "fid": 2, "name": "曾通过HR面试", "ordering": 5},
      {"did": 105, "fid": 2, "name": "未面试", "ordering": 6},
      {"did": 103, "fid": 2, "name": "曾通过复试", "ordering": 7},
      {"did": 102, "fid": 2, "name": "曾通过初试", "ordering": 8},
      {"did": 101, "fid": 2, "name": "面试过", "ordering": 9}
      // ... 还有其他 fid 类型的标签
    ]
  }
}
```

### 可选值列表（5个）

**面试流程标签**（`fid=2`）：

| 选项名称 | did | 说明 |
|---------|-----|------|
| 曾通过HR面试 | **104** | 已通过HR面试环节 |
| 未面试 | **105** | 从未参加过面试 |
| 曾通过复试 | **103** | 已通过复试环节 |
| 曾通过初试 | **102** | 已通过初试环节 |
| 面试过 | **101** | 参加过面试（不论结果） |

**使用哪个字段？**  
使用 `did` 字段（数字ID）作为参数值，**不是** `name` 字段！

## 💡 使用示例

### 示例1：筛选已通过初筛的候选人

```javascript
{
  select_tags: [102, 103]  // 曾通过初试 或 曾通过复试
}
```

### 示例2：筛选高质量候选人（通过HR面试）

```javascript
{
  select_tags: [104]  // 曾通过HR面试
}
```

### 示例3：筛选新简历（未面试过）

```javascript
{
  select_tags: [105]  // 未面试
}
```

### 示例4：筛选所有有面试记录的候选人

```javascript
{
  select_tags: [101]  // 面试过（不论结果）
}
```

### 示例5：全选（所有面试状态）

```javascript
{
  select_tags: [104, 105, 103, 102, 101]  // 全选
}
```

**或者使用空数组**（推荐）：

```javascript
{
  select_tags: []  // 不筛选
}
```

## ⚠️ 注意事项

1. **使用数字ID**：必须使用 `did` 字段的数字ID（如 `104`），**不能**使用文字名称（如 `"曾通过HR面试"`）
2. **筛选 fid=2**：从 `ResumeSign` 字典中筛选 `fid=2` 的项作为面试记录标签
3. **OR 逻辑**：数组内多个值是 OR 关系
4. **AND 逻辑**：与其他筛选条件（如学校、专业）是 AND 关系
5. **通用参数**：`select_tags` 还可以包含其他类型标签的ID（见下方说明）

## 🔍 ResumeSign 字典的其他标签类型

`ResumeSign` 字典包含多种标签类型（通过 `fid` 区分）：

| fid | 类型 | 说明 | 示例 did |
|-----|------|------|---------|
| 1 | 固定标签 | 院校等级标签 | 1(985)、2(211)、3(双一流) |
| **2** | **面试流程标签** | **面试记录状态** | **101-105** |
| 4 | 实习生考核流程标签 | 实习考核相关 | 301(考核转推荐) |
| 6 | 活动类标签 | 参加过的活动或项目 | 100(ACM精英)、107(产品创造营) 等 |

**混合使用示例**：

```javascript
{
  select_tags: [
    104,  // 曾通过HR面试（fid=2）
    100   // ACM精英（fid=6）
  ]
}
```

**效果**：筛选出曾通过HR面试 **或** 是ACM精英的候选人

## 🤔 常见问题

**Q: "面试过"和"曾通过初试"有什么区别？**

A: 
- **"面试过"（101）**：只要参加过面试就符合，不论结果
- **"曾通过初试"（102）**：明确表示已经**通过**了初试环节

**Q: 如何筛选"参加过面试但未通过的候选人"？**

A: 系统没有直接提供这个选项。由于 `select_tags` 是 OR 逻辑，无法直接实现排除逻辑。需要在获取结果后进行二次过滤。

**Q: 为什么参数名叫 `select_tags` 而不是 `interviewStatus`？**

A: 因为这个参数是**通用标签筛选参数**，不仅用于面试记录，还用于其他标签筛选（如活动标签、实习考核标签等）。
