# 应聘项目筛选条件 📋

筛选候选人应聘的招聘项目类型（校园招聘/日常实习/提前批等）。

## 📋 参数信息

| 项目 | 值 |
|------|-----|
| **参数名** | `recruit_project` |
| **类型** | `number[]` （数字数组） |
| **必填** | ❌ 否（不填或传空数组表示不筛选） |
| **逻辑** | OR（数组内满足任意一个即可） |

## 🎯 获取可选值

### 应聘项目代码映射（11个）

系统共支持11个应聘项目，分为两大类：

#### 应届生项目（fid=1，5个）

| did | name | 说明 |
|-----|------|------|
| **1** | 校园招聘 | 常规校招项目 |
| **9** | AI产品经理培训生 | AI产品经理专项培训 |
| **14** | 青云计划 | 腾讯青云计划（优秀人才项目） |
| **24** | 校招补录 | 校招补充录用 |
| **16** | 技术研发提前批 | 技术岗提前批次 |

#### 实习生项目（fid=2，6个）

| did | name | 说明 |
|-----|------|------|
| **4** | 日常实习 | 常规实习项目 |
| **5** | Pre留学生实习 | 针对留学生的预实习 |
| **2** | 应届实习 | 应届生实习项目 |
| **12** | 项目实习生 | 特定项目的实习生 |
| **25** | 技术提前批 | 技术实习提前批 |
| **20** | 青云实习 | 青云计划实习生 |

**使用哪个字段？**  
使用 `did` 字段（数字ID）作为参数值，**不是** `name` 字段！

## 💡 使用示例

### 示例1：仅校园招聘

```javascript
{
  recruit_project: [1]
}
```

### 示例2：校招+青云计划

```javascript
{
  recruit_project: [1, 14]
}
```

**效果**：筛选应聘项目为校园招聘 **或** 青云计划的候选人

### 示例3：所有应届生项目

```javascript
{
  recruit_project: [1, 9, 14, 24, 16]
}
```

**效果**：筛选所有应届生项目（不包括实习生）

### 示例4：所有实习生项目

```javascript
{
  recruit_project: [4, 5, 2, 12, 25, 20]
}
```

**效果**：筛选所有实习生项目（不包括应届生）

### 示例5：全选（会过滤掉无项目的简历）

```javascript
{
  recruit_project: [1, 9, 14, 24, 16, 4, 5, 2, 12, 25, 20]  // 全选所有11个项目
}
```

⚠️ **注意**：全选会排除没有关联任何项目的简历（约占0.3%）。

### 示例6：不筛选应聘项目

```javascript
{
  recruit_project: []  // 空数组
}
```

**效果**：不限制应聘项目，包含所有候选人（包括无项目关联的）

## ⚠️ 注意事项

1. **使用数字ID**：必须使用 `did` 字段的数字ID（如 `1`），**不能**使用项目名称（如 `"校园招聘"`）
2. **fid 表示类别**：fid=1 为应届生项目，fid=2 为实习生项目
3. **OR 逻辑**：数组内多个项目是 OR 关系（满足任意一个即可）
4. **AND 逻辑**：与其他筛选条件（如学校、学历）是 AND 关系
5. **全选 ≠ 不筛选**：全选所有项目会排除无项目关联的简历，而空数组 `[]` 则包含所有简历

## 🤔 常见问题

**Q: 如何区分"应届生"和"实习生"？**

A: 通过 `fid` 字段区分：
- **fid=1**：应届生项目（校招、青云计划等）
- **fid=2**：实习生项目（日常实习、应届实习等）

**Q: 全选所有项目和不筛选（空数组）有什么区别？**

A: 
- **全选**（选择所有11个did）：会排除没有关联任何项目的简历（约0.3%）
- **空数组 `[]`**：包含所有简历（包括无项目关联的）

推荐使用空数组 `[]` 表示"不限制应聘项目"。

**Q: "技术研发提前批"和"技术提前批"有什么区别？**

A: 
- **技术研发提前批**（did=16，fid=1）：应届生的技术岗提前批
- **技术提前批**（did=25，fid=2）：实习生的技术岗提前批
