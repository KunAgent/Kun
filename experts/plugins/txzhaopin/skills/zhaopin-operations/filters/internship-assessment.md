# 实习考核记录筛选条件 📊

筛选具有特定实习考核记录的候选人。

## 📋 参数信息

| 项目 | 值 |
|------|-----|
| **参数名** | `select_tags` |
| **类型** | `number[]` （数字数组） |
| **必填** | ❌ 否（不填或传空数组表示不筛选） |
| **逻辑** | OR（数组内满足任意一个即可） |

⚠️ **重要**：`select_tags` 是一个**通用标签参数**，不仅用于实习考核记录，还可以包含面试记录标签、活动标签等。

## 🎯 获取可选值

### 方式：字典接口（动态）

调用 `get-filter-dictionary` 接口获取：

```javascript
GET /resume/campus/api/v1/dictionary/?types=ResumeSign
```

从返回结果中筛选 `fid=4` 的项作为实习考核记录标签。

**返回示例**（筛选 `fid=4` 的项）：
```json
{
  "status": 0,
  "data": {
    "ResumeSign": [
      {"did": 301, "fid": 4, "name": "考核转推荐"}
      // ... 其他 fid=4 的标签
    ]
  }
}
```

### 实习考核记录标签（fid=4）

**完整列表**（2027-03-20 获取）：

| did | name | 说明 | ordering |
|-----|------|------|----------|
| **301** | 考核转推荐 | 实习考核通过并转为推荐录用 | 1 |

⚠️ **注意**: 
- 目前系统中 fid=4 只有 **1个标签**（考核转推荐）
- 实习考核标签可能随业务变化而调整，建议每次使用前调用接口获取最新列表
- 完整的 ResumeSign 字典还包含其他 fid 类型的标签（见下方说明）

**使用哪个字段？**  
使用 `did` 字段（数字ID）作为参数值，**不是** `name` 字段！

## 💡 使用示例

### 示例1：筛选考核转推荐的候选人

```javascript
{
  select_tags: [301]  // 考核转推荐
}
```

### 示例2：不筛选实习考核记录

```javascript
{
  select_tags: []  // 空数组
}
```

## ⚠️ 注意事项

1. **使用数字ID**：必须使用 `did` 字段的数字ID，**不能**使用文字名称
2. **筛选 fid=4**：从 `ResumeSign` 字典中筛选 `fid=4` 的项作为实习考核记录标签
3. **OR 逻辑**：数组内多个值是 OR 关系
4. **AND 逻辑**：与其他筛选条件是 AND 关系
5. **通用参数**：`select_tags` 还可以包含其他类型标签的ID（见下方说明）

## 🔍 ResumeSign 字典的其他标签类型

`ResumeSign` 字典包含多种标签类型（通过 `fid` 区分）：

| fid | 类型 | 说明 | 标签数量 |
|-----|------|------|---------|
| 1 | 固定标签 | 院校等级标签（985、211、双一流） | 3个 |
| 2 | 面试流程标签 | 面试记录状态 | 5个 |
| **4** | **实习生考核流程标签** | **实习考核相关** | **1个** |
| 6 | 活动类标签 | 参加过的活动或项目（ACM精英、产品创造营等） | 8个 |

**各类型详细列表**：

### fid=1 固定标签（院校等级）
- `did=1`: 985
- `did=2`: 211
- `did=3`: 双一流

### fid=2 面试流程标签
- `did=101`: 面试过
- `did=102`: 曾通过初试
- `did=103`: 曾通过复试
- `did=104`: 曾通过HR面试
- `did=105`: 未面试

### fid=4 实习生考核流程标签
- `did=301`: 考核转推荐

### fid=6 活动类标签
- `did=100`: ACM精英
- `did=107`: 产品创造营
- `did=108`: IEG用研练习生
- `did=109`: 腾讯技术菁英班
- `did=111`: 鹅创营项目研习生
- `did=4`: 开局一课学员-游戏策划
- `did=5`: 开局一课学员-游戏客户端
- `did=110`: 开局一课学员-游戏美术
- `did=112`: 开局一课学员-游戏运营

**混合使用示例**：

```javascript
{
  select_tags: [
    301,  // 考核转推荐（fid=4）
    104,  // 曾通过HR面试（fid=2）
    100   // ACM精英（fid=6）
  ]
}
```
