# 获取技术方向字典 - 技术方向列表接口

获取校园招聘的技术方向候选列表，用于简历搜索时的技术方向筛选。

## 接口信息

- **接口路径**：`/zhaopin/campus/campusCenterApi/v1/dictionary/getBusinessDictionary`
- **请求方法**：GET
- **接口说明**：获取业务字典数据，通过 `type` 参数指定字典类型

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | string | ✅ | 字典类型，`TECH_DIRECTION`=技术方向 |
| `_t` | number | ❌ | 时间戳（防缓存） |

## 输出结果

```json
{
  "message": "",
  "status": 0,
  "data": [
    {
      "did": "5",
      "name": "AI大模型",
      "description": null,
      "ordering": null,
      "extra": null
    },
    {
      "did": "9",
      "name": "基础架构",
      "description": null,
      "ordering": null,
      "extra": null
    }
  ]
}
```

### 关键字段说明

| 字段 | 说明 |
|------|------|
| `data` | 技术方向数组 |
| `did` | 字典项ID（数字字符串） |
| `name` | 技术方向名称 |
| `description` | 描述（当前为空） |
| `ordering` | 排序（当前为空） |
| `extra` | 额外信息（当前为空） |

## 在简历搜索中使用

技术方向使用 `techDirectionsTxt` 参数，值为**技术方向名称的字符串数组**（不是ID）。

### 示例

**单个技术方向**：
```json
{
  "techDirectionsTxt": ["AI大模型"]
}
```

**多个技术方向**：
```json
{
  "techDirectionsTxt": ["AI大模型", "基础架构", "大数据"]
}
```

**无筛选**：
```json
{
  "techDirectionsTxt": []
}
```

## 应用场景

1. **技术方向筛选**：在简历搜索时按技术方向筛选候选人
2. **技术方向选择器**：构建技术方向选择的UI组件
3. **技术方向统计**：分析各技术方向的简历分布

## 注意事项

**参数特点**：
- 技术方向使用**名称**而不是ID进行筛选
- `techDirectionsTxt` 参数接收字符串数组
- 名称必须完全匹配字典中的 `name` 字段（区分大小写）

**接口路径**：
- 技术方向字典使用 `campusCenterApi` 路径
- 与简历搜索接口的 `resume/campus/api` 路径不同
- 这是业务字典接口，可能还支持其他类型（通过 `type` 参数）

**数据更新**：
- 技术方向列表可能随业务发展而更新
- 建议在应用初始化时获取最新字典
- ID（did）是数字字符串，但筛选时使用名称

**筛选效果**：
- 空数组 `[]` = 不筛选
- 全选10个方向 ≈ 不筛选（但会排除未填技术方向的简历）
- 建议按实际需求选择特定技术方向进行筛选
