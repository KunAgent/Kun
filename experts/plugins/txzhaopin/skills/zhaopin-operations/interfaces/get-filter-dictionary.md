# 获取筛选条件字典 - 简历筛选必需接口

获取简历筛选所需的各类字典数据，包括招聘年份、城市、学历、流程状态等筛选维度的可选值。

## 接口信息

| 项目 | 值 |
|------|-----|
| URL | `/resume/campus/api/v1/dictionary/` |
| Method | GET |
| Content-Type | application/json |

## 输入参数

| 参数 | 类型 | 必填 | 来源 | 说明 |
|------|------|------|------|------|
| `types` | string | ✅ | 用户指定 | 需要获取的字典类型，多个用逗号分隔 |

**可选的 types 值**：
- `RecruitYear` - 招聘年份
- `RCity` - 期望工作城市
- `WCity` - 实际工作城市  
- `Education` - 学历
- `Flow` - 流程状态
- `ResumeRecruitProject` - 招聘项目
- `ResumeSign` - 简历标签
- `DefaultRCity` - 默认期望城市
- `DefaultWCity` - 默认工作城市
- `PraticeTime` - 实习时间
- `SchoolRank` - 院校等级（如 211/985）
- `PrizeTypeItem` - 奖项类型
- `ResumeViewedDays` - 简历查看天数
- `ResumeSortBy` - 排序方式

## 输出结果

```json
{
  "msg": "成功",
  "code": 200,
  "data": {
    "RecruitYear": [
      {"key": "2027", "value": "2027年"},
      {"key": "2026", "value": "2026年"}
    ],
    "Education": [
      {"did": 1, "psId": 4, "name": "大专", "type": "Education"},
      {"did": 2, "psId": 3, "name": "本科", "type": "Education"},
      {"did": 3, "psId": 2, "name": "硕士研究生", "type": "Education"},
      {"did": 4, "psId": 1, "name": "博士研究生", "type": "Education"},
      {"did": 6, "psId": 6, "name": "高中", "type": "Education"}
    ],
    "SchoolRank": [
      {"key": "985", "value": "985院校"},
      {"key": "211", "value": "211院校"}
    ]
    // ... 其他字典数据
  }
}
```

| 字段 | 说明 |
|------|------|
| `code` | 状态码，200 表示成功 |
| `msg` | 返回消息 |
| `data` | 字典数据对象，key 为请求的类型名 |
| `data.{type}[]` | 每个类型的选项数组 |
| `data.{type}[].did` | 选项ID（学历代码，用于接口传参）⭐ |
| `data.{type}[].name` | 选项的显示名称 |
| `data.{type}[].psId` | 优先级ID（数字越小优先级越高） |

### 学历代码映射（Education）

| did | name | psId | 说明 |
|-----|------|------|------|
| 1 | 大专 | 4 | 专科学历 |
| 2 | 本科 | 3 | 本科学历 |
| 3 | 硕士研究生 | 2 | 硕士学历 |
| 4 | 博士研究生 | 1 | 博士学历（最高优先级） |
| 6 | 高中 | 6 | 高中学历 |

**使用示例**：
- 仅博士：`education: [4]`
- 硕士+博士：`education: [3, 4]`
- 本科及以上：`education: [2, 3, 4]`
- 全选（等同不筛选）：`education: [1, 2, 3, 4, 6]`

### 应聘项目代码映射（ResumeRecruitProject）

系统共支持11个应聘项目，分为两大类：

**应届生项目**（fid: 1）：
- `1` - 校园招聘
- `9` - AI产品经理培训生
- `14` - 青云计划
- `24` - 校招补录
- `16` - 技术研发提前批

**实习生项目**（fid: 2）：
- `4` - 日常实习
- `5` - Pre留学生实习
- `2` - 应届实习
- `12` - 项目实习生
- `25` - 技术提前批
- `20` - 青云实习

**使用示例**：
- 仅校园招聘：`recruit_project: [1]`
- 校招+青云计划：`recruit_project: [1, 14]`
- 所有应届生项目：`recruit_project: [1, 9, 14, 24, 16]`
- 所有实习生项目：`recruit_project: [4, 5, 2, 12, 25, 20]`
- 全选（等同不筛选）：`recruit_project: [1, 9, 14, 24, 16, 4, 5, 2, 12, 25, 20]`

**注意**：全选所有项目会排除没有关联任何项目的简历（约占0.3%）。

### 实习时长代码映射（PraticeTime）

系统共支持6个实习时长选项：

| did | 时长 | 说明 |
|-----|------|------|
| `1` | 2周 | 短期实习 |
| `2` | 1个月 | 短期实习 |
| `3` | 2个月 | 中期实习 |
| `4` | 3个月 | 中期实习 |
| `5` | 3-6个月 | 长期实习 |
| `6` | 6个月以上 | 长期实习 |

**使用示例**：
- 仅6个月以上：`pratice_time_list: [6]`
- 3个月以上：`pratice_time_list: [4, 5, 6]`
- 中长期实习：`pratice_time_list: [3, 4, 5, 6]`
- 全选（会排除未填实习时长的简历）：`pratice_time_list: [1, 2, 3, 4, 5, 6]`

**注意**：
- 实习时长是可选字段，约66%的简历未填写此信息
- 全选所有时长 ≠ 不筛选（会过滤掉未填实习时长的简历）
- 如果不关心实习时长，应使用空数组 `[]` 而非全选

## 注意事项

- 这是简历筛选的第一步，必须先获取字典数据才能知道各筛选条件的可选值
- 不同的 types 返回的数据结构相同，都是 `{key, value}` 数组
- `key` 值用于后续简历搜索接口的参数传递
- 建议一次性获取所有需要的字典类型，避免多次请求
- 页面加载时会自动调用此接口获取所有字典数据
