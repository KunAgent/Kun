# 获取流程状态字典 - 流程状态列表

获取校园招聘的流程状态字典，用于筛选处于特定招聘流程阶段的候选人。

## 接口信息

- **接口路径**：`/resume/campus/api/v1/dictionary/`
- **请求方法**：GET
- **接口说明**：获取字典数据，通过 `types` 参数指定字典类型

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `types` | string | ✅ | 字典类型，`Flow`=流程状态 |

## 输出结果

```json
{
  "message": "",
  "status": 0,
  "data": {
    "Flow": [
      {
        "did": 0,
        "psId": 0,
        "fid": 0,
        "name": "待筛选",
        "cname": "",
        "type": "Flow",
        "description": "",
        "ordering": 1
      }
    ]
  }
}
```

### 关键字段说明

| 字段 | 说明 |
|------|------|
| `Flow` | 流程状态数组 |
| `did` | 流程状态ID（用于筛选） |
| `name` | 流程状态名称 |
| `ordering` | 排序序号 |

## 在简历搜索中使用

流程状态使用 `flow_status` 参数，值为**流程状态ID的数字数组**。

### 示例

**单个流程状态**：
```json
{
  "flow_status": [0]
}
```
筛选"待筛选"状态的简历

**多个流程状态**：
```json
{
  "flow_status": [0, 1, 16, 17]
}
```
筛选简历筛选阶段的所有状态

**面试阶段**：
```json
{
  "flow_status": [2, 3, 4, 5, 6]
}
```
筛选面试阶段的简历

**无筛选**：
```json
{
  "flow_status": []
}
```

## 应用场景

1. **流程跟踪**：查看候选人当前所处的招聘阶段
2. **待处理事项**：筛选需要处理的简历（待筛选、待分配等）
3. **面试管理**：查看处于各个面试阶段的候选人
4. **Offer管理**：跟踪offer审批和确认状态
5. **录用统计**：统计各阶段候选人数量
6. **异常处理**：筛选放弃/淘汰状态的简历

## 注意事项

**参数特点**：
- 流程状态使用**数字ID**进行筛选（不是名称字符串）
- `flow_status` 参数接收数字数组
- ID必须与字典中的 `did` 字段匹配

**流程顺序**：
- `ordering` 字段表示流程的先后顺序
- 相同 `ordering` 的状态可能是并行流程
- 数字越小表示越早的流程阶段

**状态分类**：
- 简历筛选阶段：0, 1, 16, 17
- 面试阶段：2, 3, 4, 5, 6, 8
- Offer阶段：26, 25, 28, 30, 27
- 录用阶段：12, 13, 24, 14, 15, 31
- 其他：22, 23

**筛选逻辑**：
- 空数组 `[]` = 不筛选
- 全选23个状态 ≈ 不筛选（但会排除无状态的简历）
- 建议按实际需求选择特定阶段的状态进行筛选

**业务场景**：
- 适用于招聘流程管理和跟踪
- 不同角色可能关注不同的流程状态
- 可以组合多个状态进行筛选
