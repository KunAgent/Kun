# 获取玩过的游戏品类列表 - 游戏品类字典接口

获取校园招聘简历筛选的游戏品类候选列表，用于筛选玩过特定游戏类型的候选人。

## 接口信息

- **接口路径**：`/resume/campus/api/v1/dictionary/getPlayGameCategories`
- **请求方法**：GET
- **接口说明**：获取玩过的游戏品类列表，用于游戏相关岗位的候选人筛选

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `_t` | number | ❌ | 时间戳（防缓存） |

## 在简历搜索中使用

游戏品类使用 `play_game_categories` 参数，值为**游戏品类名称的字符串数组**。

### 示例

**单个游戏品类**：
```json
{
  "play_game_categories": ["MOBA"]
}
```

**多个游戏品类**：
```json
{
  "play_game_categories": ["MOBA", "互动叙事", "休闲类"]
}
```

**无筛选**：
```json
{
  "play_game_categories": []
}
```

## 应用场景

1. **游戏经验筛选**：筛选有特定游戏类型经验的候选人
2. **游戏策划岗位**：匹配游戏策划岗位的候选人游戏经验
3. **游戏运营岗位**：筛选熟悉特定游戏类型的运营候选人
4. **游戏设计岗位**：查找有相关游戏类型设计经验的候选人
5. **用户研究岗位**：筛选有特定游戏类型用户研究经验的候选人

## 注意事项

**参数特点**：
- 游戏品类使用**名称字符串**进行筛选
- `play_game_categories` 参数接收字符串数组
- 品类名称必须完全匹配（区分大小写）

**接口特点**：
- 无需参数（除时间戳外）
- 一次性返回全部22个游戏品类
- 游戏品类列表相对固定，建议前端缓存

**筛选逻辑**：
- 空数组 `[]` = 不筛选
- 全选22个品类 ≈ 不筛选（但会排除未填游戏品类的简历）
- 多个品类之间的关系需要根据业务需求确定（AND/OR）

**适用岗位**：
- 该筛选条件主要用于游戏相关岗位
- 游戏策划、游戏运营、游戏设计、用户研究等
- 非游戏岗位一般不使用此筛选条件
