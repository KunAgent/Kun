# 获取应聘职位树 - 职位列表接口

获取校园招聘的应聘职位树形结构，包含所有可用职位及其分类关系。

## 接口信息

- **接口路径**：`/post/campus/api/v1/position/join/positionJoinQueryTree`
- **请求方法**：GET
- **接口说明**：获取校园招聘职位的完整树形结构

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `status` | number | ✅ | 职位状态，`1`=启用中 |
| `_t` | number | ❌ | 时间戳（防缓存） |

## 输出结果

```json
{
  "message": "",
  "status": 0,
  "data": [
    {
      "id": 2,
      "title": "技术",
      "children": [
        {
          "id": 101,
          "title": "后台开发",
          "children": [
            {
              "id": 102,
              "title": "后台开发-golang"
            },
            {
              "id": 103,
              "title": "后台开发-Java"
            }
          ]
        }
      ]
    }
  ]
}
```

### 关键字段说明

| 字段 | 说明 |
|------|------|
| `data` | 职位树数组（一级分类） |
| `id` | 职位/分类ID |
| `title` | 职位/分类名称 |
| `children` | 子职位/子分类数组 |

## 调用方式

此接口无 MCP 等价，改为读取本地数据文件：

```bash
# 岗位树数据
cat data/position-tree.json
```

## 应用场景

1. **职位筛选**：在简历搜索时通过 `station` 参数筛选应聘职位
2. **职位选择器**：构建职位选择的UI组件
3. **职位统计**：分析各职位的简历数量分布

## 注意事项

**数据结构：**
- 职位树采用三级结构：一级分类 → 二级分类 → 具体职位
- 只有三级（具体职位）的ID才能用于简历筛选的 `station` 参数
- 一级和二级分类仅用于组织结构，不能直接用于筛选

**接口调用：**
- `status=1` 参数必填，表示获取启用中的职位
- 返回的职位列表可能随招聘季节变化而更新
- 建议每次进入页面时重新获取最新职位树

**筛选使用：**
- 全选183个职位 ≈ 不筛选（但会排除未填应聘职位的简历）
- 空数组 `[]` = 不筛选
- 建议按业务需求选择特定职位进行筛选
