# 面试建模器（interview-talent-modeler）

上传面试评价 Excel，自动生成岗位能力模型、人才标准和评分表。

## 谁需要这个 Skill

你是招聘经理或 HRBP，想知道：
- 这个岗位最看重哪些能力？各占多大比重？
- 什么样的候选人算 S 级（杰出）？什么算 A 级（合格）？
- 不同部门在选人标准上有什么差异？

## 前提：需要同时安装数据处理 Skill

本 Skill 依赖 **interview-data-processor**（面试数据处理器）来清洗原始数据。请确保两个 Skill 都已安装：

| Skill | 作用 | 必须安装 |
|-------|------|---------|
| interview-data-processor | 清洗原始 Excel | ✅ 是 |
| interview-talent-modeler | 生成能力模型 | ✅ 是（本 Skill） |

安装好之后，你**不需要手动分两步操作**——直接上传 Excel 触发本 Skill，它会自动先清洗数据再建模。

## 怎么用

上传面试评价 Excel，对 CodeBuddy 说：

> 帮我生成岗位能力模型

就这一句话，后面全自动。

## 它会生成什么

**1. 能力模型** — 四个维度（背景资质 / 硬技能 / 软素质 / 文化匹配），每项有权重、定义和具体工作任务

**2. A+ 典型画像** — 一段话描述理想候选人的样子

**3. 五档评分标准** — 每个能力项从 S 到 B 的具体行为描述，面试官可以直接对照打分

**4. 招聘应用文档**（可选） — 基于模型一键生成 JD、结构化面试问题、评分表、简历筛选标准

## 支持范围

| 支持 | 不支持 |
|------|--------|
| 社招（按职级段拆分：10-11级 / 7-9级） | 活水（内部转岗）数据 |
| 校招（整体模型，不分职级段） | 实习生数据 |
| 单个 BG、单个职位 | 跨 BG 或跨职位的对比分析 |
| BG 内多个部门的差异分析 | — |
| 60 条以上有效记录 | 60 条以下（样本不足） |

## 典型流程

```
上传面试评价 Excel
      │
      ▼
  自动清洗数据（调用 interview-data-processor）
      │
      ▼
  确认职位 → 开始建模
      │
      ▼
  逐部门输出报告（跑完一个出一个）
      │
      ▼
  查看报告，按需调整
      │
      ▼
 （可选）生成 JD / 面试问题 / 评分表
```
