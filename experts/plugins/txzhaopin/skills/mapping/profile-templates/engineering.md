## 三、关键硬技能评估维度

**个贡 / Junior-Mid**：
- 语言熟练度（Go / Rust / Python / Java / C++）
- 算法基础（LeetCode 刷题量 + ACM 金牌）
- 项目经历深度（单机性能 / 分布式一致性 / 大规模数据）
- 论文 / 专利 / 开源（GitHub Star / 顶会一作）

**Senior / Mid（Tech Lead）**：
- 技术决策能力（选型 / 架构评审）
- Code Review 质量
- 带 3-10 人小团队经验
- 跨 team 协作（推动多方合作上线大项目）

**Top / VP / Director**：
- 技术战略（3 年技术路线图）
- 组织能力（50+ 人团队）
- 技术影响力（顶会 PC / 开源 founder / 行业演讲）
- 商业 sense（懂 P&L / 懂业务）

## 七、离职高发原因（outreach timing 信号）

- 🔴 股票归属完成（4 年到期，典型跳槽窗口）
- 🔴 业务线被砍 / ORG 调整（"原 leader 走了"）
- 🔴 晋升被拒（"P8 卡了 2 年升不上去"）
- 🟡 技术方向分歧（LLM 路线之争）
- 🟡 管理摩擦（"我带的 team 被合并了"）
- 🟢 跳 AI 创业公司（当前最大流向）
- 🟢 海外机会（跳 FAANG / 美股上市前公司）

## 八、水下挖掘高价值画像

- ✅ **应届顶会论文一作**（在校时已发 NeurIPS/ICML/CVPR）
- ✅ **开源项目作者**（有独立作品）
- ✅ **Big Tech 回流**（Google / Meta / MSR 回国）
- ✅ **博士后 / PhD 刚毕业**（清华姚班 / 北大图灵班 / MIT / Stanford）
- ✅ **国防 / 研究院系**（中科院计算所 / 自动化所 / 软件所 转工业界）
- ✅ **创业公司 CTO**（公司黄了想回大厂）

## 九、联系路径优先级

1. **GitHub star / 互相关注**（技术圈最自然破冰）
2. **论文合著 / 引用关系**（有共同研究话题）
3. **开源项目合作**（一起修过 bug 的情谊）
4. **顶会 Meetup / 线下技术分享**（面对面）
5. **校友（计算机系 / AI Lab）**
6. **前同事引荐**
7. **LinkedIn InMail**
8. **脉脉**（Junior 层效果好）

## 十、特殊注意事项

- ⚠️ **股票绑定极强**：互联网大厂 4 年 vesting + 锁定期，挖 Senior 要算"未归属股票 buyout"成本（通常 100-500W）
- ⚠️ **竞业协议**：大厂普遍有 6-24 个月竞业，实际执行看部门和级别
- ⚠️ **AI 行业保密严**：顶级大模型团队挖人要尊重保密期
- ⚠️ **避免夸大**：研发对"技术夸大"极敏感，JD 必须真实
