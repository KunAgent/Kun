## 三、关键硬技能 / 评估维度

**Junior-Mid**：
- **用研 & 数据**：会跑用研 + 懂 SQL + 会做 A/B
- **需求文档 PRD**：结构化 + 清晰 + 有数据支撑
- **项目推进**：对齐研发 / 设计 / 运营多方
- **产品 sense**：讲得清自己产品的 North Star 和价值主张

**Senior / Mid**：
- **端到端 ownership**：从 0-1 或 1-10 完整交付过
- **用户洞察 → 产品机会**：有原创方法论
- **跨团队协作**：能对齐 3+ 部门
- **商业 sense**：懂 P&L / LTV/CAC

**Top / Director**：
- **产品战略**：3 年产品规划 + 竞品地图
- **组织能力**：带 20-100 人产品团队
- **公司战略 sense**：能和 CEO 对话
- **行业影响力**：演讲 / 著作 / 公开方法论

## 七、离职高发原因（outreach timing 信号）

- 🔴 产品线被砍 / 业务下线
- 🔴 "产品被研发主导"（PM 觉得没话语权）
- 🔴 职级晋升被卡 / 晋升答辩失败
- 🟡 组织调整（产品合并到某 BU）
- 🟡 对公司战略失去信心
- 🟢 跳去做 0-1 产品
- 🟢 跳创业 / 独立 maker
- 🟢 跳到更大平台做类似方向

## 八、水下挖掘高价值画像

- ✅ **小公司 Core PM**（2-5 年，独立负责 0-1 产品）
- ✅ **海外产品经理回流**（Google / Meta / TikTok Ads 做过同赛道）
- ✅ **MBA / 海归 + 产品**（Wharton / Kellogg / Ross MBA + 2-3 年工作）
- ✅ **竞品公司同岗位**（推荐算法 PM 互挖）
- ✅ **创业公司 CPO**（公司没成，想回大厂拿 Offer）
- ✅ **产品转型的研发 / 运营**（对业务 sense 强的跨界）

## 九、联系路径优先级

1. **共同产品话题切入**（"看过你的那篇 PRD 分享"）
2. **前同事引荐**（产品圈小，大家都认识）
3. **公众号 / 知乎互动**（评论区 → 私信）
4. **即刻互关**
5. **校友 MBA 圈层**
6. **LinkedIn InMail**
7. **猎头**

## 十、特殊注意事项

- ⚠️ **产品能力难量化**：比研发更难客观评估，强依赖面试 + 作品集
- ⚠️ **"推不推得动"是核心**：问卷问题 4 里要强调沟通 / 推动能力
- ⚠️ **文化 fit 重要**：产品经理和组织文化契合度比研发更关键
- ⚠️ **作品集保密**：互联网 PM 的 PRD 多数涉密，不能外发，面试时带电脑演示
