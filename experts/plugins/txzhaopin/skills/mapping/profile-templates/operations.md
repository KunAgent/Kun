## 三、关键硬技能 / 评估维度

**Junior-Mid**：
- **数据驱动**：SQL / Excel / 数据分析基本功 + 看得懂 A/B 报告
- **执行力**：能独立推进一个活动从策划到复盘
- **内容 sense**：写得出标题党 / 文案 / 素材
- **工具熟练**：运营中台 / BI 工具 / 投放平台

**Senior / Mid**：
- **策略能力**：从业务问题定位到运营 lever
- **跨部门推动**：对齐产品 / 研发 / 商务 / 市场
- **ROI 思维**：懂投入产出比，能拿出业务数据
- **人员管理**：带 3-15 人小团队

**Top / Director**：
- **业务 owner**：直接 own GMV / DAU / 收入等核心指标
- **组织建设**：带 50+ 运营团队
- **战略视角**：能和 CEO / BU 老板对话
- **跨业态**：C 端 + B 端 / 国内 + 海外经验

## 七、离职高发原因（outreach timing 信号）

- 🔴 业务 KPI 连续未达 / 被 PIP
- 🔴 业务线被砍（如某品类下线）
- 🔴 被 AI 取代焦虑（内容审核 / 客服运营岗位缩编）
- 🟡 "总被压成执行岗"（策略能力不受重视）
- 🟡 老板换人 / ORG 调整
- 🟢 跳去做独立 IP / 内容创业
- 🟢 跳到出海公司
- 🟢 跳到 AI 原生产品

## 八、水下挖掘高价值画像

- ✅ **MCN / 红人公司出来的**（内容 sense + 商业化双能力）
- ✅ **出海独立站 / 跨境电商**（Anker / SHEIN / Shopify 店主 / 亚马逊运营）
- ✅ **创业公司 Core Ops**（2-5 年主导过一款产品的运营）
- ✅ **BD / 渠道背景**（懂资源整合）
- ✅ **懂 SQL 的运营**（比纯执行值钱 50%+）
- ✅ **内容 Creator 转运营**（自己做过号的）
- ✅ **咨询 / MBB 转运营**（策略能力 + 运营落地）

## 九、联系路径优先级

1. **小红书 / 抖音私信**（运营人自己活跃在社交平台）
2. **公众号 / 知乎评论区破冰**
3. **共同活动 / 线下大会**
4. **前同事引荐**（运营圈也很小）
5. **即刻 / 脉脉**
6. **LinkedIn InMail**
7. **校友**（运营岗位的学校背景分散，校友作用弱于产品研发）
8. **猎头**

## 十、特殊注意事项

- ⚠️ **运营能力最难评估**：面试很依赖"讲项目"，必须带数据 / 作品
- ⚠️ **AI 冲击严重**：内容审核 / 客服 / 基础投放岗正在被 AI 替代，有"被动求职"信号
- ⚠️ **海外运营需核实语言**：英语 / 小语种能力必须笔试 + 口试
- ⚠️ **薪酬弹性大**：同级别跨公司 gap 可达 50-100%，需要精确 benchmark
- ⚠️ **不要用纯"转化率"衡量**：运营是长链路工作，KPI 造假多，看**端到端 ownership**
