# 🧩 画像模板 · 通用 Fallback（Generic）

> 适用：当问卷问题 1 选"其他"业务线时，或画像模板中无明确匹配的岗位。
> 例如：法务 / 财务 / HR / 商务 BD / 设计 / PR / 战略 / 投关 / 供应链 等。
> 维护者：招聘 Mapping 团队
> 版本：v1.0.0

---

## 一、通用分层策略

| level_tier | 通用 Title 关键词 | 对应经验 |
|-----------|----------------|---------|
| **Top** | VP / Head / 总裁 / 首席 / Chief | 15+ 年 |
| **Senior** | Director / 总监 / 高级经理 / Principal | 8-15 年 |
| **Mid** | Manager / 经理 / Lead | 5-8 年 |
| **Junior** | Specialist / Senior / 专员 / 顾问 | 0-5 年 |

## 二、通用关键评估维度（所有白领岗位）

1. **行业 know-how**：对目标行业的理解深度
2. **项目经验**：完整交付过的关键项目（有数据支撑）
3. **协作能力**：跨团队 / 跨部门推动
4. **管理能力**（Senior+）：带团队规模 + 人才培养
5. **专业深度**：行业认证 / 证书 / 方法论

## 三、通用挖掘调度

**所有业务线共用的 3 级挖掘策略**：

### 第 1 级（必做）：公开信息
- LinkedIn Dorking（`linkedin-public-miner`）
- 公司官网 About / Team / Leadership 页（web_fetch）
- 基本 Google 搜索 + 公司名 + 岗位关键词

### 第 2 级（选做）：行业特定
根据岗位，从以下清单中**按相关性**选 3-5 项：

| 岗位类型 | 推荐渠道 |
|---------|---------|
| 法务 | Lexis Nexis / 中国裁判文书网 / 司法部律师查询 / 中伦 / 君合合伙人页 |
| 财务 / 审计 | 注册会计师公示 / 四大官网 alumni / CFO 圈公众号 |
| HR | HRoot / HRBP 社区 / MOKA BOSS 招聘平台  JD 发布者 |
| 商务 BD | 脉脉客户标签 / 行业白皮书联合署名 |
| 设计 | 站酷 / Behance / Dribbble / Figma Community |
| PR / 品牌 | 公司新闻稿署名 / 公关圈公众号 / 金瞳奖 / 金梧奖获奖名单 |
| 战略 / 投关 | 上市公司年报"高级管理层"章节 / IR 官网披露 |
| 供应链 | Gartner 报告 / 供应链管理协会 / 行业峰会 |

### 第 3 级（选做）：深度交叉
- `alumni-network-miner`（校友反查）
- 前员工跳槽追踪
- 脉脉 / RocketReach / SignalHire（付费）

## 四、通用水下画像（所有业务线通用模板）

"水下好人选"通用画像：

- ✅ **小公司升职快的**（同龄人在大厂卡 Junior，他在小公司已 Senior）
- ✅ **近期业务线被砍的**（被动求职但能力不差）
- ✅ **回国海归**（海外 3-5 年经验想回国）
- ✅ **MBA 刚毕业**（Top MBA + 行业转型意向）
- ✅ **创业公司核心员工**（公司不好想回大厂）
- ✅ **外企中国区资深**（想跳互联网）

## 五、通用联系路径优先级

1. **直接同事 / 前同事引荐**（所有行业都最有效）
2. **校友（本科 / MBA）**
3. **行业协会 / 证书群**（如 CFA、ACCA、HRBP 等）
4. **公众号 / 知乎内容 / 自媒体破冰**
5. **LinkedIn InMail**
6. **脉脉**
7. **猎头**

## 七、必做的澄清问题（当走到 generic fallback 时）

如果招聘经理选"其他"，**在进入阶段 3 挖掘前**必须追加问：

1. 这个岗位更接近以下哪一类工作性质？（选最近的）
   - 📋 需要专业知识的审核 / 顾问类（法务 / 财务 / 合规）
   - 🤝 需要对外关系维护的（商务 BD / PR / 政府关系）
   - 🎨 需要创造输出的（设计 / 内容 / 品牌）
   - 📊 需要数据分析决策的（战略 / 商业分析 / 数据）
   - 👥 需要组织管理的（HR / 行政 / 办公室）
   - 🔧 其他（人工补充）

2. 这个岗位**有没有行业认证**是通用的硬门槛？（如 CFA、FRM、HRBP、CIPP、PMP、注会等）

3. 这个岗位**有没有特定的行业资源**要求？（如"做过消费品公司法务"、"懂跨境税务"等）

根据这 3 个追加问题的答案，动态补齐 generic 模板的细节。

## 八、特殊注意事项

- ⚠️ **Fallback 模板覆盖不全**：强烈建议未来逐步沉淀独立模板（法务.md / 财务.md / HR.md 等）
- ⚠️ **不要硬套互联网口径**：传统行业的层级 / 薪酬 / 招聘节奏完全不同
- ⚠️ **诚实标注"覆盖度低"**：在最终报告的 `meta.coverage_confidence` 字段明确写"Generic fallback · 建议招聘经理补充行业 know-how"
