## 二、关键硬技能 / 评估维度

**通用**：
- 财务建模（DCF / LBO / Comps）
- 投委会 pitch 能力
- Deal sourcing 网络
- DD 经验（商业 / 财务 / 法务）
- 投后管理经验

**按赛道细分**（问卷问题 4 对应）：
- 🏭 **硬科技 / 半导体**：技术判断力（读 paper / 看 architecture） + 产业人脉
- 🤖 **AI / 大模型**：能和研究员对话 + 对 scaling law 有判断
- 🧬 **医疗 / 生物**：懂 FDA / CDE / 临床路径 / Biotech 估值
- 🛒 **消费**：品牌 sense + 单店模型 + 供应链
- 🏢 **To B SaaS**：懂 PLG / ACV / NRR / 销售组织
- 🎮 **文娱 / 游戏**：内容 sense + 用户行为
- 🌏 **出海**：多国法务 / 跨境税务 / 海外用户

## 三、薪酬基准（2026 年 · 人民币年包 Cash+Bonus，不含 Carry）

## 五、离职高发原因（给 outreach 提供 timing 信号）

- 🔴 基金募资不顺 / AUM 缩水
- 🔴 Carry 不分 / 分配不公
- 🔴 Partner 升不上去（"Associate 天花板"）
- 🟡 赛道切换（从消费转硬科技，原团队失势）
- 🟡 合规问题 / 监管压力
- 🟢 跳 portfolio 公司当 CFO/CEO（正常路径）
- 🟢 自己出来创业（SEED / 独立创投）

## 六、水下挖掘的高价值目标画像

典型"水下好人选"：
- ✅ 在 Tier 2 机构做了 3-5 年 VP，想跳 Tier 1
- ✅ 投行 IBD 3-5 年想转 buy-side
- ✅ 四大 FAS / MBB 咨询想做真金 deal
- ✅ 产业 CVC（腾讯/阿里/字节战投）想转市场化 VC
- ✅ 海归回流（MIT Sloan / Wharton / HBS 刚毕业）

## 七、联系路径优先级

1. 校友（北大 / 清华 / 复旦 / Wharton / HBS / Booth）
2. 同事（曾共事于投行 / 咨询 / 其他基金）
3. LP 关系（通过 LP / FOF 引荐）
4. Portfolio 被投 CEO 引荐（最高质量）
5. LinkedIn 冷 InMail
6. 猎头引荐（最后手段）

## 八、特殊注意事项

- ⚠️ 投资行业**签约即面世**：Offer 一旦签，7 天内 LinkedIn 就会改动态（便于"反查同行 recent hire"）
- ⚠️ **竞业严格**：美元 VC 通常 6 个月不得跳对手基金，挖人要算 buyout 成本
- ⚠️ **Carry 结转**：在旧基金未到期的 Carry 是主要跳槽谈判阻力
- ⚠️ **LP 关系**：挖某人等于挖他的 LP 关系网，要评估 LP 是否愿意跟着走
