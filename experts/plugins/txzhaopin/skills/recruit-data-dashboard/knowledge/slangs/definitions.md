## 四、用工类型 / 用工分类

### 用工分类（employment_classification_name）

| 维度值 | 关联条件 |
| --- | --- |
| 集团正式用工 | 管理主体=集团本部 且 员工子类型=正式聘用制 |
| 非集团正式用工 | 管理主体=全部 且 员工子类型 ≠ 正式聘用制 |

### 用工类型（employment_type_name）

| 维度值 | 关联条件 |
| --- | --- |
| 集团本部正式 | 管理主体=集团本部 且 员工子类型=正式聘用制 |
| 集团直管子公司用工 | 管理主体=全资-直管 且 员工子类型 ∈ {正式聘用制, 毕业生, 应届实习生, 日常实习生} |
| 集团本部人力服务外包 | 管理主体=集团本部 且 员工子类型=人力服务外包 |
| 集团本部学生 | 管理主体=集团本部 且 员工子类型 ∈ {毕业生, 应届实习生, 日常实习生, 项目实习生} |
| 集团本部顾问 | 管理主体=集团本部 且 员工子类型 ∈ {长期顾问, 部门顾问} |

### 员工类型映射

| 类型 | 子类型 |
| --- | --- |
| 正式（正式员工） | 正式聘用制 |
| 外包（外包人员） | 项目外包、人力资源外包备份、人力资源外包、人力资源外包驻场 |
| 顾问 | 长期顾问、部门顾问、特聘顾问、荣誉顾问 |
| 非正式 | 集团正式用工之外的其他类型，可用：① 员工类型≠正式 且 管理主体≠集团本部 ② 用工分类≠集团正式用工 |

## 六、异动（在 `Report_Wide_Public_Staff_Change_Record` 中识别）

| 术语 | 圈人 WHERE |
| --- | --- |
| 流入 | `(move_type_name='雇佣' AND to_org_full_name LIKE 'X')` 或 `(move_type_name='调动' AND to_org_full_name LIKE 'X' AND from_org_full_name NOT LIKE 'X')` |
| 流出 | `((move_type_name='离职' AND from_org_full_name LIKE 'X') OR (move_type_name='调动' AND from_org_full_name LIKE 'X' AND to_org_full_name NOT LIKE 'X'))` |
| 调入 | `move_type_name='调动' AND to_org_full_name LIKE 'X' AND from_org_full_name NOT LIKE 'X'` |
| 调出 | `move_type_name='调动' AND from_org_full_name LIKE 'X' AND to_org_full_name NOT LIKE 'X'` |

| 活水调出 | 调出 + `huoshui_flag_desc='是'` |
| 跨BG | 通过【是否跨BG调动】标签识别 |
| 跨部门 | 通过【是否跨部门调动】标签识别 |
| 跨中心 | 通过【是否跨中心调动】标签识别 |
| 跨线 | 通过【是否跨线调动】标签识别 |

| 被动离职 | `dimission_type_name = '被动离职'` |

| 管理晋升 | `异动子场景类型 = 管理晋升`，职级从低到高 |
| 管理降职 | `异动场景子类型 = 管理降职`，职级从高到低 |
| 管理免职 | `异动子场景类型 = 管理免职`，管理职级从有到无（可伴随专业职级变化） |

## 七、管理者流入 / 流出（针对组织）

- **管理者流入**：
  1. 入职 (`异动场景类型=入职`)
  2. 调入 (`异动场景类型=调动`)
  3. 新任 (`异动子场景类型=管理新任`)
- **管理者流出**：
  1. 离职 (`异动场景类型=离职`)
  2. 调出 (`异动场景类型=调动`)
  3. 免职 (`异动子场景类型=管理免职`)

## 八、转正

| 术语 | 定义 |
| --- | --- |
| 转正 | ① 是否事实转正 = '是'（在职/离职都可判）；② 转正日期 < 当前日期 且 员工状态 = '在职' |
| 转正率 | 已转正人数（事实转正='是'）/ 已过转正日期人数（转正日期 < 当前日期） |

## 九、外包转入 / 实习转正

- **外包转入**：外包先离职再以正式入职。员工 ID 不变，但企业微信 ID 和员工英文名会重新生成。"总表-员工基础信息表"只有最新状态。
- **实习转正**：先以"应届实习生"入职 → 实习答辩通过 → 以"毕业生"或"正式聘用制"重新入职。

## 十、下属 / 下级组织

### 下属（员工信息宽表）

- 查某人下属人数：通过员工中英文筛选，select 下面字段：
  - 主岗：`direct_main_post_subee_num` / `all_main_post_subee_num`
  - 含兼岗：`direct_subee_num` / `all_subee_num`
- 查某人直接下属：通过 `主岗直接上级` 筛选，select 员工明细。

### 下级组织

- 动态维度，基于组织全路径（组织层级 1/2/3 名称…）。
- 锚定输入组织名称，查询其下一层级。
- 加工维表：`catalog_dos_da_mcp.hrdw.a370651772b848cfa5dc7ef602243d69`。
