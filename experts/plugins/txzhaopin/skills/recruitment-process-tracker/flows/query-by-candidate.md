# 场景 · 按候选人查社招流程进度

> 当用户说"查 xxx 现在到哪一步 / xxx 流程进度"时进入。
>
> ⚠️ 仅查社招流程，校招请到 zhaopin.woa.com。

---

## 1. 提取候选人标识

用户输入通常是候选人姓名（可能要带模糊匹配）或一段描述：
- 姓名："查 <候选人姓名> 现在到哪一步"
- 模糊关键字："查那个产品策划候选人"

提取后调脚本：

```bash
# 按姓名（模糊匹配，对应接口 candidate 参数）
python3 ~/.codebuddy/plugins/marketplaces/my-experts/plugins/txzhaopin/skills/recruitment-process-tracker/scripts/fetch_process.py --candidate "<候选人姓名>"

# 按关键字（候选人/岗位/部门任意维度的模糊匹配）
python3 .../fetch_process.py --keyword "<关键字>"

# 如果在查别人负责的候选人（需要对应查询权限），组合 hrs
python3 .../fetch_process.py --hrs <招聘经理英文名> --candidate "<候选人姓名>"
```

> 注：本接口**不支持**按 email / RID 直查候选人——`candidate` 是姓名模糊匹配。
> 要按 email/RID 反查 → 走 `interview-assistant/scripts/resolve_social_rid.py`（社招简历 GUID 反查）。

## 2. 命中处理

### 命中 1 条 → 详细单条视图（脚本自动渲染）

```markdown
## 📋 王*明 的招聘流程

| 项 | 值 |
|---|---|
| 候选人 | 王*明（PII 水印）|
| 招聘 HR | <hr英文名> |
| 岗位 | <岗位名> |
| 部门 | <部门名> |
| 当前环节 | HR 资格面试 |
| 环节耗时 | 3.2 天 |
| 总耗时 | 18 天 |
| 状态 | 面试中 |
| 创建时间 | 2026-05-29 11:14:40 |
| 最后更新 | 2026-05-29 11:14:40 |
| 处理链接 | [处理](https://zhaopin.woa.com/...) |

💡 当前阻塞点：HR 资格面试已等 5.4 天未推进，建议主动推 HR 同事跟进 / 改走简历页手工安排。
```

### 命中多条 → 让用户选

候选人可能在多个岗位上（同名 / 一人多岗）：

```markdown
找到 3 条同名"王明"的流程：

| # | 候选人 | 招聘 HR | 岗位 | 部门 | 当前环节 | 处理链接 |
|---|---|---|---|---|---|---|
| 1 | 王*明 | <hr-A> | XTB-产品 | <部门A> | HR 资格面 | [处理](url) |
| 2 | 王*明 | <hr-B> | CDG-数据分析 | <部门B> | 部门面 | [处理](url) |
| 3 | 王*明 | <hr-C> | TEG-后台开发 | <部门C> | 推荐中 | [处理](url) |

请告诉我看哪一条（回 1/2/3 或继续提供更多信息，比如部门 / 岗位关键字）。
```

### 命中 0 条 → 主动给查询建议

```markdown
没找到名为「xxx」的进行中社招流程。

可能的原因：
- 候选人不在你负责的岗位上（且你没有跨人查询权限） → 改用 zhaopin-social-operations 全库搜简历
- 候选人在别的招聘经理名下（如你有对应查询权限）→ 试 `--hrs <对方英文名>`
- 姓名拼写不一致 → 试试关键字模糊匹配 `--keyword`
- 流程已结束（已入职/已淘汰） → 加 `--status-code Ending` 或 `Onboard` 看历史
- 该候选人是校招（本 skill 不覆盖）→ 登录 zhaopin.woa.com 校招后台

要不要我帮你切到「全库搜简历」？
```

## 3. 数据安全约束

- ❌ 不要主动暴露脱敏前的候选人姓名（一律走 PII 水印）
- ❌ 不要伪造"流程历史时间线"——接口的 `recruitStateAndLinks` 字段如果没返回就不渲染
- ❌ 不要给当前环节的真实测评分数 / 面评分数（与 interview-assistant D 流程红线一致，本 skill 同样适用）
- ✅ 处理链接直接用接口返回的 `url`，不要自己拼
