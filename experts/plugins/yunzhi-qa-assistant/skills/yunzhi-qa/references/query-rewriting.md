# 查询改写与泛化规则

> 在进入检索阶段前，必须按本文件规则对用户原始问题进行改写，产出多条并行检索 Query。

---

## 1. 主关键词保留

完整保留用户问题中的**产品名、品牌名、系统名等专有名词**，即使该词看似冗余也不可省略。

| 用户原始问题 | ✅ 改写示例 | ❌ 错误改写 |
|------------|------------|------------|
| 「云知 AI Copilot 怎么配置」 | 「云知 AI Copilot 配置方法」 | 「AI Copilot 配置」（丢失"云知"） |
| 「Knot 智能体平台 API 列表」 | 「Knot 智能体平台 API」 | 「智能体平台 API」（丢失"Knot"） |

---

## 2. 缩写识别与全称补全

自动识别缩写（如 CVM、CDB、CLB、COS、TKE、RAG、MCP、KB、ECM、CMS），还原为官方全称，**采用「缩写 + 全称」分别进行多维度检索**。

常见缩写参考表：

| 缩写 | 全称 | 检索 Query 示例 |
|------|------|---------------|
| CVM | 云服务器（Cloud Virtual Machine） | `CVM 实例规格`、`云服务器 实例规格`、`Cloud Virtual Machine 配置` |
| CDB | 云数据库 MySQL（Cloud Database） | `CDB 高可用`、`云数据库 高可用`、`Cloud Database MySQL` |
| CLB | 负载均衡（Cloud Load Balancer） | `CLB 监听器`、`负载均衡 监听器` |
| COS | 对象存储（Cloud Object Storage） | `COS Bucket`、`对象存储 Bucket` |
| TKE | 容器服务（Tencent Kubernetes Engine） | `TKE 集群`、`容器服务 集群` |
| RAG | 检索增强生成（Retrieval-Augmented Generation） | `RAG 架构`、`检索增强生成 架构` |
| MCP | Model Context Protocol | `MCP 协议`、`Model Context Protocol` |
| KB | 知识库（Knowledge Base） | `KB 检索`、`知识库 检索` |
| ECM | 企业内容管理（Enterprise Content Management） | `ECM 系统`、`企业内容管理` |

> 不在表内的缩写，按上下文合理推断并明确标注来源。

---

## 3. 多子问题拆解

将复合问题拆分为多个独立子查询并行检索：

| 用户原始问题 | 拆解结果 |
|------------|---------|
| 「A 和 B 的区别」 | ① A 的定义/功能；② B 的定义/功能；③ A B 区别对比 |
| 「X 怎么部署，并配置 SSL」 | ① X 部署方法；② X 配置 SSL；③ X SSL 证书 申请 |
| 「Y 报错 503 怎么解决」 | ① Y 报错 503；② Y 503 错误码；③ Y 服务不可用 排查 |

---

## 4. 意图补全

根据上下文补充隐含意图：

| 用户原始问题 | 意图补全后的 Query |
|------------|-------------------|
| 「怎么配置」 | `{产品名} 配置方法 操作步骤` |
| 「怎么用」 | `{产品名} 使用指南 入门教程` |
| 「报错怎么办」 | `{产品名} 错误排查 故障处理` |
| 「在哪里」 | `{产品名} 入口 控制台 路径` |

---

## 5. 同义词扩展

对核心概念生成同义/近义表达，并行检索：

| 核心词 | 扩展同义词 |
|--------|-----------|
| 报错 | 错误 / 异常 / 失败 / 故障 / error / fail |
| 创建 | 新建 / 添加 / 开通 / 申请 |
| 删除 | 移除 / 销毁 / 释放 / 卸载 |
| 配置 | 设置 / 开启 / 启用 / setup / config |
| 价格 | 计费 / 收费 / 费用 / 报价 / pricing |
| 文档 | 资料 / 手册 / 说明书 / 教程 |

---

## 6. 时间语义转换

将「最近 / 上周 / 去年 / 过去 3 个月」等模糊时间表达转换为具体日期范围。

**算法**：

1. 通过 shell 命令 `date` 取系统当前时间（**不要自己估算**，避免年份偏差）。
2. 按下表换算：

| 模糊时间 | 换算规则 |
|---------|---------|
| 今天 | `[今日 00:00, 今日 23:59]` |
| 昨天 | `[昨日 00:00, 昨日 23:59]` |
| 最近 24 小时 / 最近一天 | `[NOW - 1d, NOW]` |
| 最近一周 / 上周 | `[NOW - 7d, NOW]` |
| 最近一个月 | `[NOW - 30d, NOW]` |
| 最近 3 个月 / 季度 | `[NOW - 90d, NOW]` |
| 最近半年 | `[NOW - 180d, NOW]` |
| 今年 | `[YYYY-01-01, NOW]` |
| 去年 | `[(YYYY-1)-01-01, (YYYY-1)-12-31]` |

3. 把日期范围注入 Query（如「2026-04-18 至 2026-05-18 期间的 RAG 文档」）或在召回后做后置过滤。

---

## 输出形式

最终产出一份「检索 Query 清单」（建议 3~6 条，至多 8 条），每条 Query 必须：

- 完整保留主关键词；
- 显式覆盖至少一条改写规则（缩写补全 / 子问题拆解 / 同义词扩展 / 意图补全 / 时间转换）；
- 长度建议 8~30 个字符，过短易召回噪声，过长易漏召。
