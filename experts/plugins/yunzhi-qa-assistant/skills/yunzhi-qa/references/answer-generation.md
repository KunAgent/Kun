# 答案生成与引用规则

> 本文件规范基于检索片段产出最终答案的所有约束。

---

## 1. 严格基于检索结果

- 所有结论 **必须** 由检索返回的片段支撑，不得依赖预训练通用知识凭空回答。
- 对检索结果先做**甄别筛选**：
  - 与问题主语义直接相关的片段 → 保留并采纳；
  - 弱相关、广告位、目录页噪声 → 丢弃；
  - 标题命中但正文跑题 → 丢弃。
- **同一个 `target_id`** 的多个片段，合并到同一引用编号下，避免重复编号。

---

## 2. 引用标注规则

### 2.1 内部编号

把召回结果按相关性从高到低编号：

```
[知识点 1 begin]
{片段正文 / 摘要}
来源标题：{title}
来源链接：{url}
[知识点 1 end]

[知识点 2 begin]
...
[知识点 2 end]
```

### 2.2 内联引用

在答案的对应句子或论点之后**内联标注** `[citation:X]`：

✅ 正确：
> CVM 默认提供按量计费和包年包月两种模式 [citation:1]，包年包月相对更实惠 [citation:2]。

❌ 错误（不要把所有引用堆在末尾）：
> CVM 默认提供按量计费和包年包月两种模式，包年包月相对更实惠。
>
> 参考：[1][2]

### 2.3 多来源引用

同一句话有多个来源支撑时，分别紧贴标注：

```
xxx 内容 yyy 内容[citation:1][citation:3]
```

---

## 3. 结构化输出

### 3.1 通用结构

```markdown
## 简明结论
{1~3 句直击问题核心，关键论点带 [citation:X]}

## 详细说明
{展开内容，使用合适的排版}

## 参考资料
1. [citation:1] **{文档标题}**
   {可选：1~2 行原文片段}
   🔗 https://...
2. [citation:2] **{文档标题}**
   🔗 https://...

## 信息来源说明
- 内部知识库（乐享）：N 篇
- 数据来源：仅基于乐享知识库（不使用联网搜索）
```

### 3.2 题型适配

| 题型 | 推荐排版 |
|------|---------|
| 对比类（A vs B、X 和 Y 区别） | **Markdown 表格** |
| 步骤类（怎么做、如何配置） | **有序列表** |
| 罗列类（有哪些、列表给我看） | **无序列表** |
| 说明类（什么是 X、定义） | 段落 + 关键术语加粗 |
| 排查类（报错怎么办） | 「现象 → 原因 → 排查步骤 → 修复方案」 |

## 4. 信息不足时的拒答策略

### 4.1 触发条件

- 全部召回片段相关性低于阈值；
- 命中片段与用户问题语义不一致；
- 召回为空。

### 4.2 拒答步骤

1. **明确告知用户**：「抱歉，我在你绑定的乐享知识库中未检索到与该问题直接相关的内容。」
2. 给出建设性建议：
   - 换用更具体的关键词（如完整产品名、错误码、API 名）重新提问；
   - 或确认相关资料是否已上传至当前绑定的乐享知识库。
3. **严禁调用 WebSearch / WebFetch 等联网工具兜底**。
4. **严禁基于通用知识凭空作答 / 编造**。

### 4.3 部分命中场景

如果有部分命中（虽然命中数较少但确实相关），照常基于命中片段产出引用式回答；不要因为命中数少就拒答，但必须明确标注命中文档数。

---

## 5. 禁止行为

- ❌ **禁止虚构链接、文件路径、下载地址**：链接必须来自检索返回的字段。
- ❌ **禁止编造知识库中不存在的内容**。
- ❌ **禁止在没有引用支撑的句子里下断言**。
- ❌ **禁止把完整 Token / 用户私密信息回显给用户**。
- ❌ **禁止把所有 `[citation:X]` 堆在文末**：必须内联。
- ❌ **禁止跨越知识库说事**：不要拿 A 公司知识库的内容回答 B 公司的问题。
- ❌ **禁止使用 WebSearch / WebFetch 等联网工具兜底**：知识库无果时直接拒答。

---

## 6. 链接生成

按 `target_type` 区分云知 1.0 / 云知 2.0 两套 URL 模板：

| target_type | 文档版本 | URL 模板 |
|-------------|----------|----------|
| `disknode` | 云知 1.0（旧版团队文档 / 网盘节点） | `https://{domain}/docs/{target_id}` |
| `kb_entry` | 云知 2.0（乐享 AI 知识库条目，含 page/file/video/folder） | `https://{domain}/pages/{target_id}` |
| `kb_smartsheet` | 云知 2.0 智能表 | `https://{domain}/pages/{target_id}` |
| `attachment` | 附件 | 不直接拼查看 URL，按需调附件下载接口 |
| `ai_external_doc` | 外部抓取文档 | 使用原文档自带 URL，或不附链接 |

`{target_id}` 取 `search_kb_*` 返回的 `chunks[].target_id` / `docs[].target_id`。
`{domain}` 来自 `whoami` 返回的 `company.company_domain`，缺失时默认 `csig.lexiangla.com`。

禁止使用 `https://{domain}/teams/{team_id}/docs/{target_id}` 旧模板。

---

## 7. 质量自检

输出前快速过一遍以下检查：

- [ ] 每个关键论点都至少有一条 `[citation:X]`
- [ ] 「参考资料」区块的链接全部来自检索返回（无虚构）
- [ ] 对比题用了表格、步骤题用了有序列表
- [ ] 同一文档没有被分配到多个 `[citation:X]` 编号
- [ ] 没有回显完整 Token / 私密信息
- [ ] 「信息来源说明」明确标注"仅基于乐享知识库（不使用联网搜索）"
- [ ] 知识库无果时按拒答策略处理，未调用 WebSearch / WebFetch
