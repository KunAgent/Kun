# 文书骨架

本文件用于生成第一轮结构化草稿。不要假装缺失事实已经明确；缺什么，就明确列出来。

## 1. 民事起诉状骨架

### 建议输出结构
1. 受理法院
2. 原告信息
3. 被告信息
4. 诉讼请求
5. 事实与理由
6. 证据目录
7. 落款

### 草稿模板
**致：** [人民法院]

**原告：** [姓名 / 性别 / 出生年月 / 地址 / 联系方式]

**被告：** [姓名 / 主体信息 / 地址 / 联系方式]

## 诉讼请求
1. [请求 1]
2. [请求 2]
3. [如需，可加诉讼费用承担请求]

## 事实与理由
- 双方关系
- 关键事实时间线
- 违约 / 争议焦点
- 损失或影响
- 法律依据方向（高层级）

## 证据目录
1. [合同 / 协议]
2. [付款记录]
3. [聊天记录 / 通知]
4. [其他支持材料]

**具状人：** [原告]

**日期：** [日期]

## 2. 答辩状骨架

### 建议输出结构
1. 案件识别信息
2. 核心答辩观点
3. 事实争议点
4. 程序 / 法律抗辩点
5. 证据目录

### 草稿模板
## 答辩状

**答辩人：** [姓名]

就 [原告] 提起的案件，答辩如下：

### 主要答辩观点
1. [答辩点 1]
2. [答辩点 2]
3. [答辩点 3]

### 事实与理由
- 已承认的事实
- 有争议的事实
- 为什么原告诉求应被驳回 / 调整 / 进一步澄清

### 证据
1. [证据项]
2. [证据项]

## 3. 证据提纲骨架

### 建议输出结构
| 序号 | 证据名称 | 证明目的 | 来源 | 强度 | 弱点 / 备注 |
|---|---|---|---|---|---|
| 1 | 合同 | 证明双方关系 | 原件 / 签章件 | 强 | 需核对签字页 |

### 证据分类

输出证据提纲时，优先分三类：

- **核心证据**：合同、借条、转账记录、辞退通知、工资流水等直接证明关键事实的材料。
- **辅助证据**：聊天记录、邮件、催告记录、考勤、快递记录、会议纪要等补强材料。
- **缺口证据**：当前还缺、但会影响胜算或谈判力的材料。

## 4. 催告函 / 付款提醒骨架

适用于用户尚未决定起诉，想先书面催收或固定证据。

### 建议输出结构
1. 双方身份和基础关系
2. 欠款 / 违约事实
3. 要求履行的内容和期限
4. 逾期后可能采取的措施
5. 证据保存提醒

### 安全边界
- 语气应清晰、克制，不威胁、不夸大法律后果。
- 不写虚假的事实、金额、日期或律师身份。
- 发送方式应可留痕，例如短信、邮件、微信、快递等。

## 缺失事实清单

起草时，显式询问并标出以下缺失项：
- 双方完整身份信息
- 关键日期与时间线
- 争议金额
- 法院 / 管辖线索
- 已掌握的书面证据
- 是否发过催告 / 通知
- 是否临近时效、仲裁或举证期限

## 提醒

这些模板仅用于第一轮准备，不应直接视为可提交法院的最终版本，正式使用前应进一步审核。
