# 销售作战团队手册 (Sales Playbook)

本手册覆盖销售作战团队的全部 9 项核心能力。主理人根据用户需求自动选择合适的工作流。

---

## 1. 客户调研 (Account Research)

全面了解目标公司或个人，获取可执行的销售情报。

**触发词**: 调研公司、查客户、了解下这个客户

### 调研内容

| 维度 | 内容 |
|------|------|
| 公司概况 | 做什么、规模、行业、融资 |
| 近期动态 | 融资、管理层变动、产品发布 |
| 招聘信号 | 在招岗位 = 增长方向信号 |
| 关键人物 | 决策者、影响者、门禁人 |
| 痛点假设 | 基于调研推断的业务挑战 |

### 输出模板

```markdown
# 调研: [公司名称]
**日期:** [Date] | **来源:** 网络搜索

## 速览
[2-3句: 他们是谁，为什么可能需要你，最佳切入角度]

## 公司画像
| 字段 | 值 |
|------|---|
| 行业 | [X] | 规模 | [X] | 融资 | [X] | 总部 | [X] |

## 近期动态
- [新闻 + 与你的关联]

## 关键人物
| 姓名 | 职位 | 切入点 |

## 痛点假设 → 建议外联策略
```

## 2. 通话准备 (Call Prep)

为销售通话准备结构化简报。

**触发词**: 通话准备、call prep、明天要打电话

### 输出模板

```markdown
## 通话准备: [公司/联系人]
**日期:** [Date] | **类型:** [初次/跟进/演示/谈判]

### 关于他们: [概要 + 联系人背景 + 近期事件]

### 通话目标: 1.[主要] 2.[次要] 3.[信息收集]

### 话术要点
**开场:** [建立联系的话题]
**发现问题:**
1. [开放式 — 了解挑战]
2. [深入 — 量化影响]
3. [推进 — 了解决策流程]

**预期异议:**
| 异议 | 回应 |
|------|------|
| "已有方案" | [策略] |
| "预算有限" | [策略] |

### 下一步确认清单
- [ ] 下次时间 / 发送材料 / 引荐决策人
```

## 3. 通话摘要 (Call Summary)

从通话笔记或转录生成结构化摘要。

**触发词**: 通话总结、会议纪要、整理通话记录

### 输出模板

```markdown
## 通话摘要: [公司] — [日期]
**参会:** [名单] | **时长:** [X分钟]

### 关键要点 (Top 3)
### 客户痛点 (附原话引用)
### 决策和承诺
| 事项 | 负责人 | 截止日 |

### 商机信号 (BANT)
- 预算: [了解到什么]
- 权限: [决策人是谁]
- 需求: [具体需求]
- 时间线: [期望时间]

### CRM 更新建议
- 阶段: [建议] | 金额: [预估] | 下次跟进: [日期]
```

## 4. 竞品情报 (Competitive Intelligence)

生成面向销售的竞品战斗卡。

**触发词**: 竞品对比、战斗卡、客户提到了竞品

### 输出模板

```markdown
## 战斗卡: 我们 vs [竞品]

### 速览对比表
| 维度 | 我们 | 竞品 |
|------|------|------|
| 核心优势 / 典型客户 / 定价 |

### 我们赢的地方 (附客户案例)
### 他们赢的地方 (承认 + 重新框架)

### 常见话术应对
| 客户说... | 你回应... |

### 杀手问题 (暴露竞品弱点)
### 地雷 (提前埋下的问题)
```

## 5. 销售资产创建 (Create an Asset)

为客户创建个性化的自包含 HTML 销售材料。

**触发词**: 做个方案、客户演示、销售材料、着陆页

### 输入四要素

| 输入 | 内容 |
|------|------|
| 客户 | 公司/联系人/商机阶段/痛点 |
| 受众 | 高管/技术/运营/混合 |
| 目的 | 初次介绍/跟进/深度方案/关单 |
| 格式 | 着陆页/演示文稿/单页/工作流演示 |

### 格式选择

| 需要... | 选择... |
|--------|--------|
| 多标签交互体验 | 交互式着陆页 |
| 会议演示 | 演示文稿风格 |
| 会后材料 | 单页 |
| 展示系统连接 | 工作流演示 |

输出为自包含 HTML 文件，可离线使用。

## 6. 每日简报 (Daily Briefing)

生成面向销售的每日工作简报。

**触发词**: 每日简报、今天重点、销售日报

### 输出模板

```markdown
## 销售日报 — [日期]

### 📊 Pipeline 快照
| 阶段 | 商机数 | 金额 |
|------|--------|------|

### 🔥 今日重点 (Top 3 + 理由)
### 📅 今日日程 (时间/事项/准备)
### ⚠️ 需要关注 (超期/未跟进/需支持)
### ✅ 昨日回顾
```

## 7. 外联起草 (Draft Outreach)

创建个性化、高转化的销售外联内容。

**触发词**: 写邮件、冷邮件、跟进邮件、LinkedIn 消息

### 五原则

1. **个性化** — 通用模板 = 垃圾邮件
2. **简短** — 首封不超过 5 句
3. **价值优先** — 先说对他们的价值
4. **明确 CTA** — 一个清晰行动号召
5. **不卑不亢** — 你在提供价值

### 邮件类型

**冷邮件**: [个性化主题] → [引用近期动态] → [点出痛点] → [价值主张] → [CTA]

**跟进邮件**: [新价值点，不是"想确认你看到了吗"] → [新切入点] → [CTA]

**LinkedIn 消息**: 3 句以内，随意语气

### 触达序列

| # | 时间 | 渠道 | 目的 |
|---|------|------|------|
| 1 | Day 0 | 邮件 | 初次 + 价值主张 |
| 2 | Day 3 | LinkedIn | 建立连接 |
| 3 | Day 7 | 邮件 | 新价值/案例 |
| 4 | Day 14 | 邮件 | 最后触达 |

## 8. 销售预测 (Forecast)

基于 Pipeline 数据生成销售预测。

**触发词**: 销售预测、本月能做多少、预测报告

### 预测分类

| 类别 | 定义 | 置信度 |
|------|------|--------|
| 已关闭 | 合同已签 | 100% |
| 承诺 | 口头同意 | 90% |
| 最佳情况 | 进展顺利 | 60% |
| Pipeline | 活跃，需推进 | 30% |
| 风险 | 有不确定性 | 10% |

### 输出模板

```markdown
## 销售预测 — [时间范围]
| 类别 | 金额 | 商机数 |
|------|------|--------|
| **加权预测** | **¥[X]** | |
| **目标** | **¥[X]** | |
| **差距** | **¥[X]** | |

### 风险分析 → 提升建议
```

## 9. Pipeline 审查 (Pipeline Review)

系统性审查销售 Pipeline 健康度。

**触发词**: Pipeline 审查、商机清理、pipeline review

### 审查框架

| 因素 | 权重 |
|------|------|
| 预计关闭日期 | 30% |
| 金额 | 25% |
| 阶段 | 20% |
| 活跃度 | 15% |
| 风险 | 10% |

### 输出模板

```markdown
## Pipeline 审查 — [日期]

### 快照: 总商机 / 总金额 / 加权金额 / 平均周期 / 赢率

### 优先行动商机
| 商机 | 金额 | 阶段 | 下一步 | 风险 |

### 风险商机
| 商机 | 金额 | 风险信号 | 建议 |

### 数据清洁度 (缺日期/缺金额/缺下一步)

### 建议清除 (60天+无活动 → Closed-Lost)
```

**三原则**: 每周审查 / 果断清理死单 / 多线程联系人
