# KET备考专家团

由前剑桥英语考评部认证口语考官领衔，5位专项专家协同，为小学生提供从零起步到考前冲刺的KET全流程备考方案。

## 类型

Team 型（多角色协作团队）

## 专家团成员

| 花名 | 职位 | 核心职责 |
|------|------|---------|
| 柯全排（主理人） | KET备考总督导 | 统筹协调、流程调度、SOP管理 |
| 策准衡 | 首席规划与测评师 | CEFR学情定级 + 分阶备考路线图 |
| 纪基础 | 词汇与语法基石专家 | KET 1500词汇 + A2语法专项突破 |
| 闻听入 | 听阅输入导师 | 听力防陷阱 + 阅读扫读/精读技巧 |
| 言书成 | 口笔输出导师 | 口语Part1/2实战 + 写作模板训练 |
| 临试章 | 心态与实战辅导员 | 全真模考 + 考前心理建设 |

## 核心能力

- **学情诊断定级**：基于CEFR框架精准评估孩子现有英语水平，输出差距分析报告
- **词汇语法地基**：系统梳理KET高频1500词与A2核心语法，建立扎实基础
- **听说读写专项提分**：针对听力英音陷阱、阅读关键词扫描、口语回答框架、写作提示点覆盖逐项强化
- **全真考场模考**：模拟KET正式考场节奏，涵盖答题卡规范、时间管理与考后复盘
- **痛点精准突破**：专治"哑巴英语"、"语法混淆"、"拼写困难"、"听力失分"等国内小学生常见问题

## 适用场景

- 孩子零基础或弱基础，不知从哪开始备考KET
- 备考周期3-12个月，需要系统性规划
- 某项技能（听/说/读/写）明显薄弱，需要专项突破
- 考前1-3个月冲刺，目标Merit（优秀）或Distinction（卓越）等级

## 示例提示词

- **「帮我评估孩子的英语现状，制定一份KET备考计划」** → 触发全流程（学情测评→路线规划→专项训练→冲刺模考）
- **「孩子听力和写作总失分，怎么针对性提升？」** → 直接调用闻听入 + 言书成专项诊断
- **「距离KET考试还有3个月，请制定冲刺计划」** → 触发临试章主导的考前冲刺方案
- **「帮我出一套KET全真模拟题并批改」** → 触发模考与复盘全流程

## 专家背景

团队由前剑桥英语考评部认证口语考官、资深少儿英语教研总监以及一线提分名师组成，拥有超过10年MSE（剑桥通用英语五级）教研经验，深谙CEFR A2级别考查核心，已累计助力数千名基础各异的小学生以Merit（优秀）或Distinction（卓越）成绩斩获KET证书。

## 安装

将专家包目录放到以下路径：

```
~/.workbuddy/plugins/marketplaces/my-experts/plugins/ket-prep-team/
```

然后运行注册命令使其在 WorkBuddy 中可见：

```bash
python3 scripts/register_expert.py ~/.workbuddy/plugins/marketplaces/my-experts/plugins/ket-prep-team/
```
