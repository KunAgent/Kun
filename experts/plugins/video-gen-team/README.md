# 视频生成团队 (VideoGenTeam)

**AI视频创作工厂** — 三位一体，一键生成短视频。

## 类型

Team 型专家团（4位Agent）

## 团队成员

| 角色 | 名字 | 职责 |
|------|------|------|
| 主理人 | 主理人 (Team Lead) | 协调三位专家，驱动完整工作流 |
| 采集员 | 灵阅 (LingReader) | 从全网采集AI/科技热点内容 |
| 策划师 | 灵枢 (LingPlanner) | 筛选选题，写脚本，设计分镜 |
| 制作师 | 灵映 (LingProducer) | 调用HyperFrames渲染MP4（含配音+字幕） |

## 工作流程

```
用户输入选题
    │
    ▼
┌─────────┐  Markdown   ┌─────────┐  JSON/MD   ┌─────────┐  MP4
│  灵阅   │ ──────────→ │  灵枢   │ ─────────→ │  灵映   │
│Collector│             │ Planner │            │Producer │
└─────────┘             └─────────┘            └─────────┘
```

1. **灵阅采集**：使用 feedgrab 深度抓取 + multi-search-engine 广度搜索
2. **灵枢策划**：选题评估 → 脚本写作 → 分镜设计 → 旁白文案
3. **灵映制作**：Azure TTS 配音 → 字幕生成 → HyperFrames HTML 渲染 → MP4

## 技术栈

| 组件 | 工具 |
|------|------|
| 信息采集 | feedgrab、multi-search-engine |
| TTS配音 | Azure TTS |
| 字幕生成 | Whisper |
| 视频渲染 | HyperFrames（HTML → MP4） |

## 视频规格

- 默认时长：60秒（可配置30s/60s/90s/120s）
- 输出格式：MP4（H.264）
- 分辨率：1920×1080（横版）或 1080×1920（竖版）
- 视频风格：根据选题自动匹配合适风格

## 视频风格匹配规则

| 选题类型 | 推荐风格 |
|---------|---------|
| AI/科技新闻 | 科技风（深蓝+霓虹+数据流） |
| 知识科普 | 教育风（清新配色+图解动画） |
| 产品评测 | 评测风（实物特写+对比表格） |
| 行业分析 | 商务风（简洁大气+图表动画） |

## 使用示例

```
用户：帮我做一期AI周报视频，主题是大模型进展，60秒
  ↓
灵阅：搜索+抓取最新大模型相关文章
  ↓
灵枢：筛选选题，写出60秒完整脚本和分镜
  ↓
灵映：生成配音+字幕，渲染输出MP4
  ↓
用户：收到最终视频文件
```
