# Campaign Execution

## Overview

从 brief 到上线一条龙。本技能覆盖完整的营销活动生命周期：定义受众、写简报、产出可直接投放的素材（文案、视频脚本、封面规格、关键词），跑上线前 QA，最终汇编成可执行的 campaign 包。

## Workflow

### Step 1: Define Campaign Brief

Capture or clarify:

| Field | Content |
|-------|---------|
| **目标** | [如：新客获取、唤醒沉睡用户、复购、加微/留资] |
| **目标受众** | [按 CRM/线索数据描述的人群画像] |
| **主投渠道** | [如：抖音 + 小红书 + 视频号 / 公众号 + 朋友圈广告] |
| **承接路径** | [落地页 / 企微好友 / 小程序 / 私域社群] |
| **Offer/CTA** | [钩子产品、价格、用户下一步动作] |
| **时间** | [上线日期、持续时长] |
| **预算** | [广告投放预算，如有] |
| **核心 KPI** | [GMV / 加微数 / 留资数 / ROI] |

如用户提供的 brief 不完整，用追问补齐——不要对关键信息做假设。

### Step 2: Triage Target Audience

从线索清单 / CRM / 公众号粉丝池里：
- 筛出符合活动受众的人群
- 按互动状态分群（活跃、沉睡、冷启动）
- 估算每个分群的体量
- 体量过小（< 50 联系人）的分群标红，单独跑可能没意义

### Step 3: Create Content Plan & Brief

为每个分群产出：

```
## 内容简报 — [分群名]

| 元素 | 内容 |
|---------|--------|
| 钩子 | [对准用户痛点的开场抓人语] |
| 主张 | [用客户原话说出的核心价值] |
| 信任 | [社证 / 数据 / 案例] |
| CTA | [唯一、明确的下一步] |
| 调性 | [如：专业但有温度、紧迫] |
| 格式 | [如：抖音短视频、小红书图文、公众号长文、企微 1v1 话术、朋友圈广告] |
```

### Step 4: 产出可直接投放的素材

For each content brief, generate:

**文案变体：**
- 3 个标题/钩子句（A/B/C 测试）
- 2 个正文版本（短—适合短视频/朋友圈广告，长—适合公众号/小红书图文/落地页）
- CTA 文案（2 种：留资型 vs 转化型）

**渠道规格（按主投渠道选择）：**

| 渠道 | 主要尺寸 / 时长 | 备注 |
|------|---------------|------|
| 抖音 / 视频号 | 竖版 1080×1920，时长 15s/30s/60s | 前 3 秒决定完播率 |
| 小红书图文 | 竖版 1242×1660 (3:4)，6-9 张图 | 标题党 + 多 emoji |
| 小红书视频 | 竖版 1080×1920，时长 30s-60s | 封面字幕大 |
| 微信公众号头图 | 横版 900×383 | 不放二维码（折叠后看不到） |
| 朋友圈广告 | 大图 1080×1350 / 视频竖版 1080×1620 | 文案≤40 字 |
| 视频号横屏 | 1920×1080，时长 60s+ | 直播切片优先 |
| B站 | 横版 1146×717，时长 1-3min | 三连引导 |

**视频脚本（短视频渠道必备）：**
- 0-3s：钩子（数据 / 反常识 / 冲突）
- 3-15s：核心内容
- 15-25s：信任背书
- 25-30s：CTA + 评论区引导

**封面/字幕规格：**
- 标题字号、字重
- 主色、辅色（hex 代码）
- 图片方向（描述用于 AI 生成或剪映模板检索，不直接生成图片）

**素材搜索关键词（用于剪映/Canva 模板检索）：**
- 每种素材 5-8 个关键词（如 "电商促销 竖版"、"获客 落地页 简约"）

**输出格式：**
```
## 素材包 — [素材名]

### 标题/钩子
- A: [标题 1]
- B: [标题 2]
- C: [标题 3]

### 正文
- 短版（朋友圈/抖音字幕）: [文案]
- 长版（公众号/小红书）: [文案]

### CTA
- 留资型: [文案]
- 转化型: [文案]

### 视频脚本（如适用）
- 0-3s: [钩子]
- 3-15s: [核心]
- 15-25s: [信任]
- 25-30s: [CTA]

### 封面/排版
- 尺寸: [WxH]
- 标题: [字号] [字重]
- 副标题: [字号] [字重]
- 颜色: 主色 [#hex]、辅色 [#hex]、背景 [#hex]
- 图片: [描述]

### 模板检索关键词
[关键词 1]、[关键词 2]、[关键词 3]、[关键词 4]、[关键词 5]
```

### Step 5: Pre-Launch QA Checklist

上线前自查：

- [ ] 标题字数符合各渠道限制（抖音 55 字、小红书 20 字、公众号头图标题 30 字）
- [ ] CTA 唯一明确，没有相互冲突的引导
- [ ] 链接 / 二维码可用，并加 UTM 或活码统计
- [ ] 受众分群体量足够
- [ ] 文案无错别字，品牌名、产品名拼写一致
- [ ] A/B 测试变体只差一个变量（标题 / 封面 / CTA），不要一次改三处
- [ ] 落地页 / 企微欢迎语与广告口径一致，避免买量过来发现产品不对
- [ ] 涉及医疗、金融、教育等敏感行业，文案合规检查（不出现"最"、"100%"、"治愈"等违禁词）

### Step 6: Assemble Campaign Package

汇编成单一交付物：

```
## Campaign Package — [活动名]

### 摘要
- 目标: [from brief]
- 受众: [体量和分群]
- 素材: [数量和类型]
- 上线: [日期]

### 素材按渠道
| 渠道 | 素材 | 格式 | 文件位置 |
|------|------|------|---------|
| 抖音 | 短视频 A | 1080×1920 / 30s | [路径] |
| 小红书 | 图文 B | 1242×1660 ×6 | [路径] |
| 公众号 | 头条推文 | HTML | [路径] |
| 企业微信 | 1v1 话术 | TXT | [路径] |

### 上线节奏
1. [日期] — 小流量测试（投 20% 受众或限定地域）
2. [日期 + 2d] — 看素材表现，挑出优胜变体
3. [日期 + 3d] — 优胜变体放量
4. [日期 + 7d] — 期中复盘，决定是否追加预算

### 数据追踪
| 指标 | 目标 | 工具 |
|------|------|------|
| 点击率 / 完播率 | > X% | 巨量/磁力/视频号助手 |
| 单留资成本 | < ¥[X] | 投放后台 |
| 转化数 | [N] | 企微/CRM |
```

## Data Requirements

- Campaign brief（目标、受众、Offer、时间）
- 线索 / CRM 数据用于受众分群
- 品牌指南（颜色、字体、调性）—— 缺失时主动问
- 不要编造投放数据基准；如客户没有历史数据，用"行业典型区间"+"以小流量测试为准"提示

## Notes

- 每份素材都要可直接交付给投放或剪辑——不要给抽象描述，要给具体规格
- A/B 变体只差一个变量，否则没法判断哪个起作用
- Campaign 包要完整到非技术成员也能上线执行
- 涉及医疗、金融、教育、保健品等强监管行业，文案必须按《广告法》合规自审
