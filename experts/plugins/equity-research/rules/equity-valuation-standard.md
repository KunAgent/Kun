# 股权估值方法论标准

本标准适用于所有涉及估值判断的股票研究技能。

## 核心原则

1. **股权估值为重心**：所有估值工作以普通股权价值为最终输出。债务仅作为影响股权价值的输入（通过净债务、资本成本、杠杆、流动性、再融资风险或下行股权减值）。
2. **多方法交叉验证**：重大估值判断须使用至少两种独立方法论交叉验证。
3. **假设透明化**：所有关键假设必须显式列出，不得隐含在模型中。

## 估值方法论菜单

### 1. 内在价值法

#### DCF（现金流折现）
- **适用**：现金流可预测、有明确增长路径的公司
- **关键假设**：WACC、终值增长率、预测期限、资本结构
- **注意**：对终值假设高度敏感，必须做敏感性分析

#### DDM（股利折现）
- **适用**：稳定派息、高股息支付率的成熟公司
- **关键假设**：股利增长率、要求回报率

#### 残余收入模型
- **适用**：ROE 高于资本成本的公司
- **关键假设**：权益资本成本、ROE 持续性

### 2. 相对估值法

#### 可比公司分析（Comps）
- **适用**：有足够可比标的的行业
- **关键指标**：P/E、EV/EBITDA、P/B、P/S、EV/Revenue
- **注意**：选 comp 需考虑增速、规模、盈利质量、地域的可比性

#### 交易倍数法
- **适用**：有近期 M&A 交易的行业
- **关键指标**：交易 EV/EBITDA、EV/Revenue、P/E

### 3. 资产基础法

#### NAV（净资产价值）
- **适用**：资产密集型企业（地产、能源、资源）
- **关键**：资产重估、隐含折溢价

#### SOTP（分部加总）
- **适用**：多元化业务集团
- **关键**：各业务分部独立估值后加总，减去控股折价

### 4. 行业专用法

| 行业 | 首选方法 | 关键指标 |
|------|---------|---------|
| 银行 | P/B + ROE 回归 | P/TBV, Dividend Yield |
| 保险 | 内含价值法 | P/EV, NBV 倍数 |
| 地产 | NAV | P/NAV 折溢价 |
| SaaS | EV/ARR + Rule of 40 | EV/NTM Revenue |
| 生物医药 | rNPV（风险调整 NPV）| Pipeline 价值 |
| 电商/互联网 | EV/GMV, P/MAU | 用户经济学 |

## 估值输出标准

### 情景分析（必须）

| 情景 | 描述 | 概率权重 |
|------|------|---------|
| 牛市 | 最乐观合理假设 | 标注 |
| 基本 | 最可能路径 | 标注 |
| 熊市 | 合理悲观假设 | 标注 |

### 敏感性表格（DCF 必须）

展示目标价对关键 2 个变量的敏感性矩阵（通常为 WACC × 终值增长率，或收入增速 × 利润率）。

### 估值总结格式

```
方法论        | 估值范围      | 权重  | 备注
-------------|-------------|------|------
DCF          | ¥XX - ¥XX   | XX%  | WACC X%, g X%
Comps (P/E)  | ¥XX - ¥XX   | XX%  | Peer median XXx
Comps (EV/E) | ¥XX - ¥XX   | XX%  | ...
加权目标价    | ¥XX         |      |
当前价格      | ¥XX         |      | 截至 YYYY-MM-DD
上行/下行空间 | +XX% / -XX% |      |
```

## 质量检查清单

- [ ] 是否使用了至少两种方法论？
- [ ] 关键假设是否显式列出？
- [ ] 是否包含情景分析（牛/基本/熊）？
- [ ] 终值占比是否过高（>75% 需警示）？
- [ ] 可比公司选择是否合理论证？
- [ ] 估值结论是否给出明确评级和目标价？
- [ ] 是否标注数据截至日期？
