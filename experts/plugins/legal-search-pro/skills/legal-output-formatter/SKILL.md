# 法律检索 · 场景化输出适配

> 这是法律检索专家的**正文定稿工序**。检索引擎拿到准确依据后，由本 skill 按"场景识别"命中的场景，把结果格式化成用户真正想要的样子。若任务单标记【核验工作台：必用】，本 skill 完成正文定稿后必须把材料交给核验工作台，不得作为最终收尾。

## 工作步骤

### 0. 交付门禁（先判断，后输出）

读取任务单后先做门禁判断：
- 若【输出档位】为重量，或【核验工作台】为必用，或输出形态属于全面合规检索、文书引用素材汇总、诉讼仲裁支撑、非诉法律文书检索、企业合规体检、案例专题分析、刑事量刑参考、行政复议证据检索，则本 skill 只能生成 `answer.md` 所需正文，不得作为最终回复。
- 门禁命中时，必须立即交给 `legal-verification-workbench`；最终只能交付其模板 HTML。若资料未 capture/audit 完成，应回到检索引擎补齐来源，而不是手写 HTML 或降级内联输出。
- 若无法运行核验工作台，应如实报告"重量级报告未完成"，不得生成替代 HTML。

1. **取回命中场景**：从场景识别任务单读出命中的场景、输出标准、输出档位和【核验工作台】字段。
2. **选定输出形态**：查 `references/output-modes.md` 的「场景 → 输出形态映射」，确定用 14 种中的哪一种（可组合）。
3. **按形态要点格式化**：严格遵守该形态的"输出什么、不输出什么"边界——例如法条核验**只输出本条**、不拓展；公众简易咨询**不用专业术语**、给可执行步骤。
4. **执行路由动作**：若【核验工作台：不启用】，对话内联输出；若【核验工作台：必用】，先确认本次检索资料已通过 `legal-verify capture`/`persist` 形成段落库，且 `audit-sources` 无 blocker，再调用 `legal-verification-workbench` 按脚本流程生成 HTML 报告。不得自行写 HTML，不得先写 HTML 再验收。
5. **统一规范化**：
   - 法条引用：书名号全称 + 条款序号（第X条第X款第X项）+ **现行效力状态标注**（现行有效 / 已修订 / 已废止）。
   - 判例引用：标准案号格式（如（2023）京 03 民终 XXX 号）+ 裁判要点。
   - 文书引用场景：附"依据《XXX》第X条之规定……"的标准引用句式。
6. **来源呈现克制**：正文只呈现法规/案例名称、条号、效力状态和必要来源链接；不得说明使用了哪个数据库、MCP、Skill 或 Web 工具，也不得写"未接入某数据库所以改用公开检索"。模型知识不得作为正文依据。

## 14 种输出形态速查

1. 法条核验 · 2. 模糊记忆定位 · 3. 规定查询 · 4. 事实关联法规 · 5. 全面合规检索 · 6. 法律文书引用素材汇总 · 7. 诉讼仲裁支撑检索 · 8. 非诉法律文书检索 · 9. 企业合规体检检索 · 10. 案例专题分析检索 · 11. 法律教学案例检索 · 12. 公众简易咨询检索 · 13. 刑事量刑参考检索 · 14. 行政复议证据检索

每种形态的详细要点、示例与场景映射见 `references/output-modes.md`。

## 输出质量铁律

- **匹配场景标准**：输出结构必须命中"场景识别"任务单中锁定的输出标准，不多不少。
- **克制扩展**：核验类场景绝不主动堆砌无关法规、配套解释、参考案例；汇编类场景才做穷尽式覆盖。
- **效力必标**：每条法律依据都带现行效力状态，失效依据剔除或显著标注。
- **可溯源**：法条原文逐字准确，案号、出处可核对。
- **语言适配对象**：面向普通公众用通俗语言 + 可执行步骤；面向专业文书用规范法言法语 + 标准引用格式。
- **输出介质克制**：轻量/中量场景直接对话内联输出并附来源；凡任务单标记【输出档位】重量或【核验工作台】必用，必须交给核验工作台渲染 HTML。
- **重量级不得内联收尾**：全面合规检索、文书引用素材、诉讼仲裁支撑、非诉文书检索、企业合规体检、案例专题分析、刑事量刑参考、行政复议证据等重量级输出，完成正文定稿后必须进入核验工作台，不得只在对话中输出最终意见。
- **禁止手写 HTML**：核验必用时，任何人工拼出的 `.html` 都不合格；最终报告必须通过 `legal-verify assert-html --html <报告路径>` 验收；若验收因弱关联/待核验比例过高失败，必须回补检路由而非强行交付。
