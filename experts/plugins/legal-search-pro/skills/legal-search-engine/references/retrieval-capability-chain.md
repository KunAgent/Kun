# 多层检索能力链（能力 2-6 详解）

> 本文件是检索引擎的执行手册，对应法律检索专家能力构成中的第 2-6 项技能。五项能力串成一条"事实提炼 → 问题定位 → 对象与效力判定 → 策略生成 → 过滤排序"的流水线，其中第 5、6 项形成"检索-反馈-优化"闭环。

---

## 能力 2 · 法律事实提炼

**定义**：从用户自然语言描述中剥离无关信息，提取具有法律意义的事实要素，形成标准化法律事实框架。

**关键操作逻辑**：
1. 提取核心法律事实要素：主体身份、法律行为、法律关系、损害结果、争议焦点、证据类型。
2. 剔除情绪化表述、与法律评价无关的生活细节。
3. 用法律术语标准化描述，输出结构化事实清单，作为法律定位的直接输入。

**示例**：
- 用户原话："同事借我 5000 块拖着不还，只有微信转账聊天记录"
  → 法律关系 = 民间借贷合同关系；主体 = 出借人（自然人）、借款人（自然人）；行为 = 借款到期未清偿；证据 = 微信转账记录 + 聊天记录；争议焦点 = 借款本息返还请求权是否成立。
- 用户原话："超市牛奶过期，喝完拉肚子去医院花了 200 块"
  → 法律关系 = 买卖合同关系 + 产品责任关系；主体 = 消费者、超市；行为 = 销售超过保质期食品；损害结果 = 医疗费 200 元；证据 = 购物小票、过期牛奶、医疗费票据；争议焦点 = 是否有权主张价款十倍赔偿及医疗费赔偿。

## 能力 3 · 法律问题定位

**定义**：基于标准化法律事实，锁定对应部门法、细分制度，划定检索资料库边界。

**关键操作逻辑**：
1. 分级归类：一级部门法 → 二级细分领域 → 三级具体法律制度。
2. 区分本次检索核心目标：找法条 / 找判例 / 找监管规则。
3. 标记需要排除的无关法律领域。

**示例**：
- 事实：口头辞退、未签劳动合同 → 部门法 = 劳动法、劳动合同法；细分领域 = 劳动合同订立、违法解除劳动合同；检索目标 = 未签合同二倍工资法条 + 违法解除赔偿金法条 + 同类民事判例。
- 事实：销售过期食品致消费者人身损害 → 部门法 = 民法典、食品安全法；细分领域 = 买卖合同违约责任、食品安全惩罚性赔偿；检索目标 = 食品安全法第 148 条 + 产品责任判例。

---

## 能力 4 · 检索对象识别与效力层级判定

**定义**：完整识别全部可检索资料类型，区分法律渊源 / 司法文书 / 非法律参考资料，掌握完整效力优先级排序。详见 `effectiveness-hierarchy.md`。

**三大检索资料类别**：
1. **正式法律渊源**：法律 → 行政法规 → 地方性法规 → 自治条例/单行条例 → 部门规章 → 地方政府规章；强制性国家/行业标准效力等同于部门规章。
2. **司法类文书**：最高法指导案例、典型案例、各地法院判决书、仲裁裁决书、法官会议纪要、审判工作座谈会议意见。
3. **非法律渊源**：推荐性国家/行业/团体标准、行业惯例、学者专著论文、媒体行业新闻、监管部门工作答复、行业调研报告。

**内置效力排序规则**：法律渊源 ＞ 司法类文书 ＞ 非法律渊源；法律渊源内部按层级优先，强制标准与部门规章同级。

---

## 能力 5 · 动态检索策略生成

**定义**：结合大模型前置法律知识、用户意图、法律事实、法律定位，以及能力 6 反馈的检索结果质量，动态调整"知识推荐 + 多维度检索"方案，形成"检索-反馈-优化"闭环。

**关键操作逻辑**：
1. **大模型前置知识推荐**：直接推荐核心法律文件及关联规定。
2. **基础关键词策略**：核心词 + 法律术语组合、同义词扩展、反向词检索。
3. **进阶关联检索**：法条关联、案例关联、时间/地域限定。
4. **跨库检索适配**：法条库精准定位、案例库案由筛选、标准库强制/推荐区分。
5. **结果反馈优化**：接收能力 6 的"结果过多/过少/相关性低"信号，调整关键词精度或检索范围。

**示例**：
- "个人信息被平台泄露怎么办" → 推荐《个人信息保护法》第 69 条、《民法典》第 1034 条；检索"个人信息泄露 侵权责任 赔偿"；若反馈"结果过多"，细化为"个人信息泄露 平台责任 网络服务提供者"。
- "印象中有个规定'加班需支付 1.5 倍工资'，是哪部法" → 推荐《劳动法》第 44 条；检索"延长工作时间 工资报酬 150%"；若结果为空，调整为"加班工资 1.5 倍 法律规定"。

## 能力 6 · 检索结果过滤与排序

**定义**：对检索结果进行权威度、相关性、时效性筛选排序，并向能力 5 反馈结果质量，触发策略优化。

**关键操作逻辑**：
1. **相关性过滤**：保留与"争议焦点 + 法律关系"直接相关的结果，剔除泛泛提及的无关内容。
2. **时效性过滤**：自动标注并剔除已废止/失效文件。
3. **权威度排序**：按"法律 → 行政法规 → 部门规章/强制性标准 → 司法判例"层级排序。
4. **结果质量反馈**：向能力 5 输出"结果过多/过少/相关性低"信号，推动策略调整。

**示例**：
- 检索"加班工资 规定"后，过滤掉《公务员法》中关于公职人员加班的内容，保留《劳动法》《劳动合同法》及人社部规章，反馈"结果相关，无需调整"。
- 检索"口头辞退 合法解除 判例"后，仅找到 3 条且均为 2020 年前的，反馈"结果过少 + 时效性不足"，触发策略调整为"用人单位解除劳动合同 未书面通知 2023-2026"。

---

## 闭环执行总则

```
事实提炼(2) → 问题定位(3) → 对象与效力判定(4) → 策略生成(5) → 检索 → 过滤排序(6)
                                                  ↑__________反馈__________|
```

- 第 5、6 项之间是循环：过滤后若发现结果过多/过少/相关性低，回到第 5 项调整策略重新检索，直到结果质量达标（一般不超过 3 轮）。
- 每一轮检索都必须经过第 4 项的效力层级判定，确保最终输出按位阶有序、剔除失效。
