# 法律效力层级与检索资料类型规则

> 本文件是能力 4「检索对象识别与效力层级判定」的判定手册。所有检索结果在输出前都必须经过本规则的效力排序与时效核验。

## 一、三大检索资料类别

### 1. 正式法律渊源（效力最高）

按效力层级从高到低：

| 层级 | 制定主体 | 示例 |
|---|---|---|
| 宪法 | 全国人大 | 《宪法》 |
| 法律 | 全国人大及其常委会 | 《民法典》《劳动合同法》《刑法》 |
| 司法解释 | 最高法 / 最高检 | 关于适用某法的若干问题的解释 |
| 行政法规 | 国务院 | 《食品安全法实施条例》 |
| 地方性法规 | 地方人大 | 某省/市实施办法 |
| 自治条例 / 单行条例 | 民族自治地方人大 | — |
| 部门规章 | 国务院各部委 | 《食品经营许可管理办法》 |
| 地方政府规章 | 地方政府 | 某市政府规章 |

**强制性标准**：强制性国家标准 / 行业标准，效力等同于部门规章，违反将直接导致法律责任。

### 2. 司法类文书

最高法指导案例、典型案例、各地法院判决书、仲裁裁决书、法官会议纪要、审判工作座谈会议意见。

> 指导案例 > 典型案例 > 普通生效判决；同级别中，上级法院 > 下级法院，近期 > 久远。

### 3. 非法律渊源（参考性）

推荐性国家/行业/团体标准、行业惯例、学者专著论文、媒体行业新闻、监管部门工作答复、行业调研报告。

## 二、内置效力排序规则

```
法律渊源  ＞  司法类文书  ＞  非法律渊源
```

- 法律渊源内部按上表层级优先；
- 强制性标准与部门规章**同级**；
- 司法文书可作为法条适用的实证支撑，但不得替代法律渊源本身。

## 三、效力冲突处理示例

1. **食品合规检索**需包含：食品安全法 + 食安实施条例 + 强制性食品卫生国标 + 市场监管总局规章。
2. **产品质量纠纷**中，强制性国标可直接作为认定"产品缺陷"的法律依据，推荐性标准仅作合同约定参考。
3. **效力冲突**：
   - 地方政府规章与强制性行业标准冲突时，优先适用**强制性标准**；
   - 推荐性标准与部门规章冲突时，以**部门规章**为准；
   - 新法优于旧法、上位法优于下位法、特别法优于一般法。

## 四、时效性核验（强制）

- 任何输出的法条都必须标注现行效力状态：**现行有效 / 已修订（注明最近修订时间）/ 已废止**。
- 已废止、失效的依据必须剔除或显著标注，不得作为有效依据输出。
- 涉及溯及力问题时，需结合法律事实发生的时间节点判断应适用的版本。
