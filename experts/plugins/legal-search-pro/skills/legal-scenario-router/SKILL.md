# 法律检索 · 场景识别与意图路由

> 这是法律检索专家的**第一道工序**。每次接到用户的检索类问题，都必须先用本 skill 完成"识别意图 → 命中场景 → 锁定输出标准与工作流"，再进入检索引擎。**不要跳过本步骤直接检索。**

## 本 skill 解决什么

把用户一句自然语言的提问，转化为一份明确的「检索任务单」，包含：
1. **命中的检索场景**（来自场景决策表）
2. **该场景的核心应用目的、输出标准、典型工作流**
3. **检索范围、检索深度、所需资料类型**
4. **输出档位与核验策略**：必须写明【输出档位】、【核验工作台：不启用/必用】、【下一步技能】
5. **是否需要向用户澄清的缺口**

## 工作步骤

### 第一步：识别基础意图（五大基础意图）

先把用户问题归入以下五类之一，决定检索的"形状"：

| 基础意图 | 特征 | 检索范围 |
|---|---|---|
| **纯法条核验** | 指名某条/某部法，只问效力/内容/位阶 | 窄范围、仅本条，不扩展 |
| **类案对比** | 想找"和我情况相似"的判例 | 重点匹配事实高度相似判例 |
| **合规汇总** | 某业务/行为涉及哪些合规要求 | 全领域穷尽式、跨层级规范 |
| **风险排查** | 某行为会面临什么处罚/风险 | 配套监管文件、行政判例 |
| **简易咨询** | 普通人维权类、口语化提问 | 通用主流规则 + 简易类案 |

### 第二步：判断检索深度与资料类型

- 用户需要**窄范围精准结果**，还是**全领域穷尽式资料**？
- 是否需要**正反对立判例**、**地方性规范**、**监管文件**补充？
- 标记需要排除的无关法律领域。

### 第三步：命中具体场景（查决策表）

打开 `references/scenario-decision-table.md`，用「场景快速判别索引」把问题精确命中到某个三级场景（A1/A2/A3/B1/B2/B3 或类案对比）。命中后，**锁定该场景的三件事**：
- 核心应用目的（要达到什么）
- 输出标准（最终要长成什么样）
- 典型工作流（按什么步骤做）
- 输出档位与核验策略：按决策表和全局档位规则写入【输出档位】、【核验工作台】、【下一步技能】；凡重量级场景必须标记【核验工作台：必用】【下一步技能：legal-verification-workbench】

### 第四步：识别事实缺口，决定是否澄清

若属于事实关联类（B1/B3）且核心法律要件缺失（如未说明是否有书面约定）：
- **优先方案**：以互斥假设平行检索并分别输出（如"若书面约定则…/若仅口头约定则…"）；
- **必要时**：向用户提出**一个**关键澄清问题，并提供互斥选项供选择，收敛事实范围。
- 不要因为可澄清就停下不检索——能用假设覆盖的，先给出分支结果。

### 第五步：输出检索任务单

以如下结构小结，交给「多层检索引擎」skill 执行。任务单不是最终答案；输出后必须按【下一步技能】逐个交接。若任务单写【核验工作台：必用】或【输出档位：重量】，后续不得以内联回答或手写 HTML 收尾：

```
【命中场景】B1 法条关联（事实关联法规）
【基础意图】维权依据查找
【检索深度】配套法条 + 1 件高相似度类案
【资料类型】实体法条 + 生效判例；排除：刑事领域
【输出标准】主要法律问题 + 法规全称 + 条款号及原文 + 适用场景提示
【输出档位】中量：对话内联 + 来源链接
【核验工作台】不启用
【下一步技能】legal-search-engine → legal-output-formatter
【事实缺口】未说明是否签书面合同 → 按"已签/未签"两分支平行检索
```

### 输出档位与核验策略

档位不是按单个样例硬编码，而是按输出形态和交付目的判断：

| 输出档位 | 典型输出形态 | 核验工作台 |
|---|---|---|
| 轻量 | 法条核验、模糊定位、规定查询、公众简易咨询 | 不启用，对话内联 + 来源链接 |
| 中量 | 事实关联法规、一般类案对比、教学案例 | 默认不启用；用户要求存档、写入文书、逐条核验或高风险领域时升级为必用 |
| 重量 | 全面合规检索、法律文书引用素材汇总、诉讼仲裁支撑、非诉文书检索、企业合规体检、案例专题分析、刑事量刑参考、行政复议证据检索 | 必用，生成 HTML 报告 |

重量级场景任务单必须写：

```
【输出档位】重量：HTML 报告
【核验工作台】必用
【下一步技能】legal-search-engine → legal-output-formatter → legal-verification-workbench
```

常见重量级触发信号：用户要求“全面/系统/汇编/清单/体检/专题/报告/风险等级/整改建议/产品规避方案/文书素材/诉讼支撑/复议证据/量刑参考/存档/充分核验”。命中这些信号时，不得只以内联答案收尾。

## 关键约束

- 场景识别**只做判断与规划，不做实质检索**，检索交给下一 skill。
- 不确定命中哪个场景时，宁可向用户确认一句，也不要错判导致输出标准跑偏。
- 用户一个问题可能横跨多个场景（如既要法条又要类案），允许命中多个场景并在任务单中分别列出。
