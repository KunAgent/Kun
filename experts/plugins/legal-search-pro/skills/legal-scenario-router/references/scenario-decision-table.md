# 法律检索场景决策表

> 本表是场景识别的核心知识库。命中某个三级场景后，即可确定该场景的「核心应用目的」「输出标准」「典型工作流」，直接驱动后续检索与输出。
> 三级结构：场景分类（一级）→ 二级场景 → 三级场景。

---

## 一级场景：法律检索

法律检索专家服务于法律工作中的法律法规、案例与法律依据检索类需求。在此一级范围下，划分为两个二级场景、若干三级场景。

---

## 二级场景 A：法条信息确认

针对已有明确指向（某条/某部法律）的核验类需求，回答"这条/这部法律是什么状态、是什么含义"。

### A1. 法条内容核验

- **核心应用目的**：确认某个具体法条 / 某部具体法律是否有效、是否有最新修订或明令废止，遵循"新法优于旧法"。
- **输出标准**：法律法规准确名称 + 官方来源 + 现行效力状态 + 最近一次修订时间及内容 + 法条序号及完整原文 + 关联法律法规的规定。
- **典型工作流**：
  1. 提取提问中关键词，初步圈定相关的法律、行政法规或地方性法规、规章。
  2. 定位到法律文件的完整名称（全称）和具体条款序号（精确到"第X条第X款第X项"）。
  3. 核验法条当前效力状态，按实际状态输出有效/失效结果，以及修订废改记录、当前有效的条款内容。
  4. 以法条名称、现行效力给出结论，并提醒结果中法条的生效/失效情况，以及用户提问中可能涉及的其他法规情况。
- **典型提问示例**：
  - 《关于禁止有奖销售活动中不正当竞争行为的若干规定》当前是否仍然有效？
  - 《反不正当竞争法》关于互联网竞争的最新条款是如何约定的？

### A2. 法条效力核验

- **核心应用目的**：核验某部规定的效力位阶（法律—司法解释—行政法规—地方性法规—规章），遵循"上位法优于下位法"。
- **输出标准**：法律法规准确名称 + 官方来源 + 效力位阶 + 最近一次修订时间及内容 + 关联法律法规的规定。
- **典型工作流**：
  1. 提取提问中关键词，提取待核验的具体规定名称、颁布机关简称或核心业务关键字，初步圈定相关法律、行政法规或地方性法规、规章名称。
  2. 查明该法律文件的制定主体，依据《立法法》严格界定其所属效力层级（全国人大及其常委会为法律，最高法/最高检为司法解释，国务院为行政法规，地方人大为地方性法规，部委及地方政府为规章）。
  3. 核查该目标文件及具体条款当前的现行有效、修改或明令废止状态。
  4. 以文件核心关键字为基础进行纵向关联检索，向上查找其授权制定或需遵从的上位法依据，向下检索为其配套的实施细则或地方性下位规定。
  5. 结构化输出法律文件的层级、效力以及关联上下位规定。
- **典型提问示例**：
  - 《网络数据安全管理条例》属于部门规章还是行政法规？

### A3. 法条解析

- **核心应用目的**：分析该法条的适用情形，是否有但书条款、特定豁免情形或特殊主体适用例外。
- **输出标准**：具体法规条款内容 + 条款内容分析 + 法理解析。
- **典型工作流**：
  1. 将提取的事实要素转化为现行成文法的标准法律概念，初步定位并检索出适用该事实场景的一般性法律规则及具体法条原文。
  2. 在定位的目标法条原文中，直接检索并标记"但是""除……外""……的除外""不适用"等法定排除词，锁定条文内部自带的豁免结构。
  3. 若条文出现"法律、行政法规另有规定的依照其规定"等引致性表述，需排查同一位阶或上位法中是否存在优先适用的特别规定。
  4. 依据"一般规定适用"与"例外/特别规定优先适用"两类逻辑分别给出检索结论；针对上述两类情形，分别界定其适格主体、法定适用要件及举证责任分配规则，形成结构化法律适用意见。
- **典型提问示例**：
  - 刑事责任能力相关的法律规定中，存在哪些例外？
  - 《民法典》第506条规定的合同免责无效有哪些限制？

## 二级场景 B：事实关联法规 / 法律检索汇编

针对从碎片化事实出发、或从业务场景出发的检索需求，回答"我这个情况/这个业务，涉及哪些法律依据"。

### B1. 法条关联（事实关联法规）

- **核心应用目的**：根据碎片化的自然语言描述找到准确、可适用的法律条文。
- **输出标准**：识别出涉及的主要法律问题 + 对应的法律法规全称 + 适用的条款号及具体条款内容 + 简要适用场景提示。
- **典型工作流**：
  1. 梳理案件事实，将用户模糊描述转化为法律关键词，提取主体（权利人、网络平台、侵权网络用户）、客体（被控侵权的内容与账号）及客观行为（发出维权通知、要求平台采取断开链接或封号等必要措施）等核心事实要素。
  2. 针对缺失的法律要件，以不同假设为前提（如已书面约定和仅口头约定）平行检索并分别输出结果；或针对核心缺失要件向用户进一步确认问题，并提供互斥的定性选项供用户选择，收敛事实范围。
  3. 将提取的事实要素映射至标准法律概念，检索相似法条并筛选匹配度最高项，初步圈定目标法条范围。
  4. 在初步检索结果中，精准定位至具体法律规范的条、款、项，并与官方发布版本进行逐字核对验证。
  5. 确认上述提取条款的现行有效状态，剔除失效规范，最终严格按照"法律—司法解释—行政法规—地方性法规—规章"的位阶顺序重组检索结果，输出结构化的法律依据清单。
- **典型提问示例**：
  - 向平台发函要求其下架侵权内容、关停侵权账号，依据哪些法律法规？
  - 试用期工资发放有哪些法律规定？

### B2. 合规依据汇编

- **核心应用目的**：汇总某业务 / 行为 / 场景 / 功能涉及的全部合规法律要求。
- **输出标准**：按效力层级排列的法规清单 + 重点合规条款摘录 + 风险点（或风险等级）标注 + 产品或业务规避方案。
- **输出档位**：重量级 HTML 报告。
- **核验工作台**：必用。最终必须生成带来源资料库、关联依据、可关闭高亮层的 HTML 报告；首轮存在明显弱关联/待核验时，继续补充检索与补充关联后重建 HTML。
- **典型工作流**：
  1. 将用户输入内容映射为国家标准行业分类、法定行政许可概念及标准监管门类，明确对应的行政管理主管部门及法定的审批、备案或核准程序。
  2. 依据转化后的监管术语与合规关键词梳理案件事实，在将检索范围覆盖法律、行政法规的基础上，重点向下穿透至各部委制定的部门规章及行业主管机关发布的规范性文件、国家强制标准文件。
  3. 核实检索结果中实体法、行政法规、规章、相关司法解释及规范性文件，核验时效性与效力状态，剔除失效依据。
  4. 摘录具体条文，标注合规义务与风险点、规则适用条件和例外情形。
  5. 按照"法律—司法解释—行政法规—地方性法规—规章—行政规范性文件—国家强制标准"的效力位阶降序排列，输出体系化的合规依据清单。
- **典型提问示例**：
  - 开奶茶店涉及哪些食品安全法规？
  - 直播带货平台当前的监管规则？

### B3. 法律适用汇总

- **核心应用目的**：为诉讼 / 非诉文书准备可直接引用的依据。
- **输出标准**：检索说明目标 + 法条原文 + 法条适用的场景 + 文书引用格式示例。
- **典型工作流**：
  1. 提取用户输入中已知的争议主体、指向客体、客观行为与核心诉求，并对照法定构成要件，精准排查出缺失的核心法律事实要素。
  2. 针对缺失的法律要件，以不同假设为前提平行检索并分别输出结果；或针对核心缺失要件向用户进一步确认，并提供互斥的定性选项供用户选择，收敛事实范围。
  3. 将确认的事实要素映射为成文法体系中的标准请求权基础或法定案由概念，圈定适用的法律文件及指导性案例，并提取司法实践中的类案裁判尺度与经验数据作为支撑。
  4. 锁定法律适用涉及的具体条、款、项，并与官方公布的正式文本进行逐字核对验证。
  5. 查明提取条文当前的现行有效、修改或废止状态，并结合法律事实发生的时间节点，审查特定条款溯及力的适用情况，剔除不可适用的失效依据。
  6. 将确定的规范依据按"法律—司法解释—行政法规—地方性法规—规章"的效力位阶降序排列并列明具体法条原文，同时附具对应的指导性案例与类案裁判尺度，输出涵盖成文法规范与实务裁判规则的标准化引用清单。
- **典型提问示例**：
  - 这份案由为违法解除劳动合同的起诉状涉及哪些法条？
  - 视频制作合同中知识产权条款的法规支撑？

## 输出档位与核验工作台规则

**强制交接规则：**本表只负责判定档位和核验策略。只要命中重量档或升级信号，任务单必须写明【下一步技能】`legal-search-engine → legal-output-formatter → legal-verification-workbench`，且最终交付只能来自核验工作台模板 HTML，不得以内联答案或手写 HTML 替代。

| 输出档位 | 输出形态 | 核验工作台 | 交付方式 |
|---|---|---|---|
| 轻量 | 法条核验、模糊记忆定位、规定查询、公众简易咨询 | 不启用 | 对话内联 + 来源链接 |
| 中量 | 事实关联法规、一般类案对比、法律教学案例 | 默认不启用；命中升级信号时必用 | 默认内联；升级后 HTML 报告 |
| 重量 | 全面合规检索、法律文书引用素材汇总、诉讼仲裁支撑、非诉法律文书检索、企业合规体检、案例专题分析、刑事量刑参考、行政复议证据检索 | 必用 | HTML 报告 |

升级信号：用户要求系统性报告、汇编清单、风险等级、整改/规避方案、文书素材、诉讼支撑、复议证据、量刑参考、专题分析、存档、充分核验，或问题本身涉及高风险法律后果。命中重量级或升级信号时，任务单必须写【核验工作台】必用。
