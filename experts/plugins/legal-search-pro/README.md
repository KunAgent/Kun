# 法检 Pro（LexFinder Pro）

面向中国法律场景的增强版检索专家：先识别检索意图与场景，再按法源位阶系统检索法规与类案，验证效力并评估相似度，按场景适配 14 种输出形态（含可交互溯源 HTML 报告），杜绝编造。

## 类型

Agent 型（单个 AI 专家）

## 功能

法检 Pro 融合了两套成熟法律检索方法论的精华，按"识别 → 检索 → 类案 → 输出 → 核验"五层智能编排：

1. **场景识别与意图路由**：判断你的真实检索诉求，命中 6 大场景 + 延伸场景，锁定输出标准与检索深度。
2. **多层法规检索引擎**：法源位阶系统扫描 + 全面检索法（己方·对方·多路径）+ 效力验证（7 种状态）+ 法条适用性验证（构成要件逐项比对）+ 法言法语映射 + 公开来源隔离 + 行政执法特殊路径。内部先明确检查并优先调用北大法宝 `pkulaw` / `mcp__pkulaw*`、华宇元典 `yuandian-mcp` / `mcp__yuandian*` 等用户已配置专业库，再补充官方/公开来源；不向用户透传工具状态。
3. **类案深度检索**：三维比对（事实+焦点+适用）+ 三层递进相似度评估 + 复合命题相关性闸门 + 裁判分歧处理。
4. **场景化输出适配**：14 种输出形态，从法条核验到合规汇编到诉讼支撑，匹配你的场景。
5. **核验工作台**：重量级报告脚本化生成可点击溯源的 HTML 报告，三标签（已关联/弱关联/待核验）+ 补检闭环。

## 技能结构

```
skills/
├── legal-scenario-router/    # 场景识别与意图路由
├── legal-search-engine/      # 多层法规检索引擎（含效力验证、位阶扫描、法言法语映射）
├── case-retrieval/           # 类案深度检索（三维比对、相似度评估、复合命题闸门）
├── legal-output-formatter/   # 场景化输出适配（14 种输出形态）
└── legal-verification-workbench/  # 核验工作台（HTML 报告 + 溯源 + 补检）
bin/
└── legal-verify              # 核验流水线 CLI 入口
```

## 使用示例

- 我被公司口头辞退，入职半年没签书面劳动合同，能主张哪些赔偿？要法律依据加类案
- 对方引用的《合同法》第94条还有效吗，现在对应哪一条
- 开一家奶茶店涉及哪些合规法律法规和监管规则？请按效力层级汇编

## 检索来源策略

专家会在内部自动判断并优先使用当前可用的明确法律专业来源：北大法宝 `pkulaw` / `mcp__pkulaw*`、华宇元典 `yuandian-mcp` / `mcp__yuandian*`、其他法律 MCP/Skill 或团队知识库；不足时再用官方权威网页或公开 Web 来源补足。工具选择、连接状态和兜底路径不向用户透传；正文依据必须来自可核验来源，绝不编造。
