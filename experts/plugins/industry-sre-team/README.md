# 腾讯云行业 SRE

懂你的行业，也懂你的云。12 位行业 SRE 与你的团队并肩，把云架构的健康度看得更清楚一点。

## 类型

Team 型（专家团）

## 功能

腾讯云行业 SRE 由 12 位深耕一线的行业 SRE 组成，覆盖游戏、零售、教育、金融、出行、互联网、电商、医疗、工业制造、直播、社交通信、SaaS 十二个行业。每位专家都按所在行业的真实节奏来理解你的架构，统一以 **安全 · 可靠性 · 性能 · 成本 · 服务限制** 五维做巡检，输出可对照、可执行的治理建议。

## 技能

| 技能名 | 说明 |
|--------|------|
| general-sre-rules | 行业通用 SRE 故障诊断规则（160+ 条专家经验） |
| game-sre-rules | 游戏行业专属 SRE 诊断规则（20+ 条游戏场景专项） |

## 团队成员

| 角色 | 名称 | 职责 |
|------|------|------|
| 主理人 | 腾讯云首席 SRE | 需求分诊、专家调度、报告汇总 |
| 游戏 SRE | 游戏行业 SRE | 开服合服、战斗延迟、多地域部署 |
| 零售 SRE | 零售行业 SRE | FinOps 降本、闲置资源、弹性伸缩 |
| 教育 SRE | 教育行业 SRE | 直播课堂链路、容量预案、合规巡检 |
| 金融 SRE | 金融行业 SRE | 等保合规、灾备架构、RPO/RTO |
| 出行 SRE | 出行行业 SRE | 派单延迟、弹性容量、零中断 |
| 互联网 SRE | 互联网行业 SRE | 微服务优化、K8s 调优、容器迁移 |
| 电商 SRE | 电商行业 SRE | 大促保障、秒杀性能、配额预申请 |
| 医疗 SRE | 医疗行业 SRE | 数据合规、PACS 分层、互联网医院 |
| 制造 SRE | 工业制造行业 SRE | 边缘节点、IoT 接入、OT/IT 融合 |
| 直播 SRE | 直播行业 SRE | 全链路卡顿、CDN 成本、跨境质量 |
| 社交 SRE | 社交通信行业 SRE | 长连接、消息延迟、洪峰保障 |
| SaaS SRE | SaaS 行业 SRE | 多租户隔离、SLA 达标、配额管理 |

## 使用示例

- 大促/开服/开学季前，帮我做一次架构 Check。
- 上个月账单环比涨了，从闲置资源和计费方式两个角度盘一盘。
- 接近上限的服务配额清单，按风险高低排个序。
