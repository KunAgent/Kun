# Ncre Expert

NCRE 一至四级专家团 —— 按级别分工协作的智能备考团队，覆盖 Office 基础、程序设计、数据库、网络安全与工程师认证全体系。

## 类型

Team 型（多角色协作团队）

## 功能

- **分级辅导**：四位成员按 NCRE 一至四级严格划分，每级专家专注对应考纲，提供精准备考指导
- **需求诊断**：主理人"等考大师"先与用户沟通，确认报考级别、目标科目、现有基础和备考时间，再调度对应专家
- **备考方案生成**：涵盖知识点梳理、重难点突破、上机实操建议和时间规划，结构化的输出模板确保方案可执行
- **多级别晋级规划**：支持连续备考场景（如二级 C → 三级网络 → 四级网络工程师），主理人协调串并行策略
- **覆盖全科目**：
  - 一级：计算机基础、WPS/MS Office、Photoshop、网络安全素质教育
  - 二级：C/C++/Java/Python/Web 程序设计、Access/MySQL 数据库、Office 高级应用、公共基础知识
  - 三级：网络技术、数据库技术、信息安全技术、嵌入式系统开发技术
  - 四级：网络工程师、数据库工程师、信息安全工程师、嵌入式系统开发工程师

## 使用示例

- **单级备考**：「我想考二级 Python，零编程基础，还有 3 个月，帮我制定备考计划。」
- **级别咨询**：「一级和二级有什么区别？我大一想考计算机证书，应该报哪个？」
- **连续晋级**：「我打算从二级 C 语言开始，一路考到四级网络工程师，帮我规划整体晋级路线。」

## 安装

将专家包目录放到 WorkBuddy 插件目录中：

```

```

然后通过 WorkBuddy 专家中心进行注册。

### 如何新增科目

NCRE 考纲每年可能调整，新增科目按以下步骤操作：

1. **确定归属级别**：新科目属于一级/二级/三级/四级
2. **修改对应成员 Agent**：在对应 `ncre-levelX.md` 的「核心能力」章节添加新科目知识点清单
3. **更新主理人路由表**：在 `ncre-expert-team-lead.md` 的「关键词路由表」中补充触发关键词
4. **更新 plugin.json**：如有新增成员或科目标签，同步更新 `tags` 和 `members`
5. **更新 README.md**：在「功能」章节补充新科目说明
6. **在 CHANGELOG.md 中记录变更**

### 如何调整考纲

- **知识范围变更**：修改对应 `ncre-levelX.md` 的「核心能力」章节，保持列表结构
- **分值比例变化**：修改成员 prompt 中「输出规范」的分值/频率标注描述
- **考试形式变化**：在主理人的「简单问题直答」中更新考试形式描述

### 版本管理

- 所有 Agent MD 文件标题含 `v{主版本}.{次版本}` 标识
- plugin.json 的 `version` 字段与 CHANGELOG.md 保持一致
- 每次正式发布前更新 CHANGELOG.md

### 成员提示词模板

所有成员 Agent 遵循统一结构：

```markdown
# X级考试 - 成员名 vX.X
## 核心能力         ← 按科目分点，每点含具体知识点列表
## 工作流程         ← 4-5 步标准流程
## 输出规范         ← 格式化要求
## 降级处理         ← 知识盲区 / 超纲 / 异常回传
## SendMessage 回传  ← 回传主理人格式
```

新增成员时参照该模板编写，确保与现有风格一致。
