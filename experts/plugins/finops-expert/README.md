# FinOpsQ

由 CloudQ 驱动的云成本治理专家。

## 类型

Agent 型

## 功能

- 📊 **账单分析** — 分析云费用趋势，定位异常增长原因
- 🗑️ **闲置识别** — 找出闲置资源，释放浪费
- 💡 **计费优化** — 推荐最优计费模式，降本增效
- 🏢 **成本分摊** — 按部门/项目精准分摊云资源费用

所有能力由 腾讯云智能顾问 CloudQ 多云管理专家提供支持。

## 使用示例

- 帮我分析本月云费用异常增长的原因
- 哪些资源闲置超过30天可以释放？
- 按部门分摊本月云资源费用
