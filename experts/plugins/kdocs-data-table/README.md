# 金山文档智能建表助手（KDocs Smart Table Assistant）

金山文档出品将群聊接龙一键转为结构化表格，一句话生成可分享的信息收集表，智能美化表格并固化规则（条件格式高亮异常值、数据校验下拉约束、区域保护锁定表头）。擅长接龙识别、字段推断、格式规范与数据去重。

## 能力概览

### 接龙转表格：识别接龙文本结构并生成在线表格

详见 `skills/jielong-table/SKILL.md`。
### 信息收集表：根据需求字段生成可分享的收集表

详见 `skills/form-generator/SKILL.md`。
### 表格美化：格式规范化、条件格式高亮、数据校验约束、区域保护、筛选

详见 `skills/table-beautify/SKILL.md`。

## 快速开始

打开对话，直接告诉我你的需求即可。以下是一些常见场景：

- 帮我把这段接龙整理成表格：
1. 张三 2份牛肉
2. 李四 1份鸡排 3份牛肉
3. 王五 5份鸡排
- 帮我做一个班级春游报名表，收集姓名、联系电话、是否需要租车、午餐偏好
- 帮我优化一下这个客户信息表，有些手机号格式不统一，有些行是重复的

## 使用技巧

- 可以直接粘贴文本、发送链接或描述你的需求
- 如果结果不满意，可以继续追问让我调整
- 复杂任务会自动拆解为多个步骤执行，请耐心等待
