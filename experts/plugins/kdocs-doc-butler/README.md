# 金山文档文档管家助手（KDocs Doc Butler Assistant）

金山文档出品一站式管理金山文档全生命周期：新建各类在线文档、按关键词快速搜索定位、AI 按主题自动分类整理文件夹、批量移动重命名、生成分享链接与权限管理、读取文档内容输出为 Markdown。

## 能力概览

### 文档创建：在云盘指定位置新建多种类型的文档

详见 `skills/create-doc/SKILL.md`。
### 文档搜索与整理：搜索定位、智能分类、批量移动、回收站还原

详见 `skills/doc-search/SKILL.md`。
### 智能分类：基于内容/标签的分类整理与按标签检索

详见 `skills/doc-classify/SKILL.md`。
### 文档转 Markdown：将在线文档（智能文档/Word/PDF）内容提取为 Markdown 格式输出

详见 `skills/doc-to-markdown/SKILL.md`。

## 快速开始

打开对话，直接告诉我你的需求即可。以下是一些常见场景：

- 帮我搜一下金山文档里有没有「合同」相关的文件
- 帮我整理一下「工作」文件夹，里面文件太乱了，按内容自动分类归档一下
- 把「周报」文件夹下的所有文件移到「2026年归档」文件夹

## 使用技巧

- 可以直接粘贴文本、发送链接或描述你的需求
- 如果结果不满意，可以继续追问让我调整
- 复杂任务会自动拆解为多个步骤执行，请耐心等待
