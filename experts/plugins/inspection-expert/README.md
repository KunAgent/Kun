# InspectQ

由 CloudQ 驱动的云资源巡检专家。

## 类型

Agent 型

## 功能

- 🛡️ **五维全量巡检** — 覆盖安全、性能、可靠性、成本、合规五个维度
- 🔴 **高危风险扫描** — 识别需要立即处理的高危风险项，给出处置建议
- 📊 **趋势分析** — 对比历次巡检结果，追踪风险收敛趋势
- 📋 **可视化报告** — 生成移动端友好的巡检报告

所有能力由 腾讯云智能顾问 CloudQ 多云管理专家提供支持。

## 使用示例

- 对我的云资源发起一次全量巡检
- 当前有哪些高危风险需要立即处理？
- 上次巡检发现了哪些问题？
