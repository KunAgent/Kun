# 多平台数据分析框架

## 一、数据聚合架构

### 统一数据模型
多平台数据分析的核心挑战是各平台指标定义不统一。以下为标准化数据聚合框架：

```
原始数据层（各平台 API 返回）
    ↓ 数据清洗 + 口径统一
标准化数据层（统一指标定义）
    ↓ 聚合计算
分析层（跨平台对比 + 趋势分析）
    ↓ 洞察提炼
决策层（优化建议 + 行动方案）
```

| 平台 | 数据维度 | 数据延迟 | 特殊指标 |
|------|---------|---------|---------|

## 二、核心指标体系

### 通用核心指标（所有平台统一定义）

#### 曝光类指标
| 指标 | 统一定义 | 计算方式 |
|------|---------|---------|
| 曝光量 (Impressions) | 内容被展示的总次数 | 平台原始数据 |
| 触达人数 (Reach) | 看到内容的独立用户数 | 去重后用户数 |
| 播放量 (Views) | 视频被播放的次数 | 各平台有最低时长定义 |
| 完播率 (Completion Rate) | 完整观看的比例 | 完播次数 / 播放次数 × 100% |

#### 互动类指标
| 指标 | 统一定义 | 权重 |
|------|---------|------|
| 点赞数 (Likes) | 用户主动点赞/喜欢 | 1× |
| 评论数 (Comments) | 用户发表评论 | 3× |
| 分享数 (Shares) | 用户主动分享/转发 | 5× |
| 收藏数 (Saves) | 用户收藏/保存 | 2× |
| 关注转化 (Follows) | 通过内容新增关注 | 10× |

#### 转化类指标
| 指标 | 统一定义 |
|------|---------|
| 点击率 (CTR) | 点击次数 / 曝光次数 × 100% |
| 外链点击 (Link Clicks) | 点击个人主页/外链的次数 |
| 转化率 (Conversion Rate) | 转化动作数 / 点击数 × 100% |

### 综合计算指标

#### 标准互动率
```
互动率 = (点赞 + 评论 + 分享 + 收藏) / 曝光量 × 100%
```

#### 加权互动率（反映真实互动价值）
```
加权互动率 = (点赞×1 + 评论×3 + 分享×5 + 收藏×2) / 曝光量 × 100%
```

#### 内容质量分（Content Quality Score, CQS）
```
CQS = 互动率得分(40%) + 完播率得分(30%) + 粉丝转化得分(20%) + 分享率得分(10%)

每项得分 = min(100, (实际值 / 平台基准值) × 60)
总分范围：0-100
```

## 四、数据归一化方法

### 问题：各平台数据不可直接对比
- 平台用户量基数不同
- 算法推荐逻辑不同
- 互动行为成本不同（如B站三连 vs 抖音双击）
- 数据统计口径不同

### 归一化方案

#### 方案一：百分位排名法
将每个平台的数据换算为在该平台同量级账号中的百分位排名。
```
平台得分 = 该内容在同平台同量级中的百分位 × 100

示例：某视频在抖音10万粉级别的互动率排第70百分位 → 得分70
```

#### 方案二：基准比值法
将实际值与平台基准值做比值。
```
归一化值 = 实际值 / 平台基准值

示例：
- 抖音互动率 8%，基准 5% → 归一化 = 1.6（超标60%）
- YouTube互动率 6%，基准 4% → 归一化 = 1.5（超标50%）
结论：两个平台表现相当，抖音略好
```

#### 方案三：Z-Score标准化
```
Z = (X - μ) / σ
X = 当前值，μ = 历史均值，σ = 历史标准差

Z > 1.5：显著高于平均（爆款级别）
Z 0.5-1.5：高于平均（良好表现）
Z -0.5~0.5：正常范围
Z < -0.5：低于平均（需关注）
Z < -1.5：显著低于平均（需诊断）
```

## 五、效果评估模型

### 分发效率评估维度
| 维度 | 指标 | 计算 | 意义 |
|------|------|------|------|
| 覆盖效率 | 曝光/发布量 | 总曝光 ÷ 总发布数 | 单条内容平均曝光 |
| 互动效率 | 互动/发布量 | 总互动 ÷ 总发布数 | 单条内容平均互动 |
| 转化效率 | 新粉/发布量 | 新增粉丝 ÷ 总发布数 | 单条内容平均获粉 |
| 平台ROI | 平台贡献值 | 效果总值 ÷ 投入时间 | 各平台投入产出比 |

### 内容类型效果对比
分析不同内容类型在各平台的表现差异：
```
效果矩阵 = 内容类型 × 平台 × 指标

维度1：内容类型（教程/产品/故事/热点/互动/幕后）
维度2：平台（抖音/小红书/TikTok/YouTube/...）
维度3：指标（曝光/互动率/完播率/转化）
```

## 六、A/B 测试方法

### 可测试变量
| 变量 | 测试方式 | 样本量要求 |
|------|---------|-----------|
| 发布时间 | 同内容不同时间发布 | ≥10对 |
| 封面设计 | 同视频不同封面 | ≥5对 |
| 标题文案 | 同内容不同标题 | ≥10对 |
| 内容长度 | 长版 vs 短版 | ≥5对 |
| 标签策略 | 不同标签组合 | ≥10对 |
| 发布频率 | 高频 vs 低频周对比 | ≥4周 |
| 内容格式 | 图文 vs 视频（同主题）| ≥5对 |

### 测试设计原则
1. **单变量控制**：每次只改变一个变量，其他保持一致
2. **样本量充足**：结论需基于足够数据支撑，避免偶然性
3. **时间对齐**：对比组在相同时间段内执行（避免季节/热点影响）
4. **统计显著性**：差异超过20%且持续3次以上才能确认结论
5. **迭代验证**：初步结论需在下一轮重复验证

### 测试报告模板
```
## A/B测试报告

### 测试目标
[测试什么变量，期望什么结果]

### 测试设计
- 对照组(A)：[描述]
- 实验组(B)：[描述]
- 测试周期：[日期范围]
- 样本量：A组X条，B组X条

### 测试结果
| 指标 | A组均值 | B组均值 | 差异 | 显著性 |
|------|--------|--------|------|--------|
| | | | | |

### 结论
[明确结论：B优于A / A优于B / 无显著差异]

### 行动建议
[基于结论的具体执行建议]
```

## 七、竞品对标分析

### 竞品数据采集方式
- 公开数据：粉丝数、发布数、互动数（公开可见）
- 第三方工具：新榜/蝉妈妈/飞瓜/SocialBlade 等
- 手动记录：定期截图关键数据点
- 内容分析：爆款内容拆解

### 对标分析框架
| 维度 | 分析内容 | 数据来源 |
|------|---------|---------|
| 发布频率 | 各平台每周/月发布数量 | 主页统计 |
| 内容类型 | 视频/图文/直播比例 | 内容归类 |
| 互动水平 | 平均点赞/评论/分享 | 公开数据 |
| 增长速度 | 粉丝周增/月增趋势 | 定期记录 |
| 内容策略 | 话题/风格/发布时间 | 内容分析 |
| 爆款规律 | 高互动内容共同特征 | 内容拆解 |

### 竞品分析报告模板
```
## 竞品分析：[竞品名称]

|------|--------|---------|---------|---------|

- 热门话题：[常用话题和标签]

### 爆款内容分析（Top 5）
| 内容 | 平台 | 互动量 | 成功因素 |
|------|------|--------|---------|

- [我们的优势领域]
- [竞品的空白区域]
- [可借鉴的策略]
```
