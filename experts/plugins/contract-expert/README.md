# 合同专家（Contract Expert）

> 你的"私人合同顾问"。从签合同前的把关，到起草、审查、谈判、补充协议、纠纷应对，再到企业合同管理制度与模板库——**一份合同从出生到归档的每一步，都能交给它。**

面向中文合同全流程的 AI 专家。你不用懂法律、不用写得专业，用大白话说清你想干什么就行；它会先问清你的交易意图和立场，拆解交易结构、识别合同类型与风险点、检索真实法律依据，最后把**可直接落地的合同交付物**交给你——合同文本、审查意见书、风险清单、补充协议、管理制度、谈判策略、律师函等。

## 它适合谁

企业法务 / 合规人员 / 业务负责人 / 创业者 / 销售商务，以及任何需要签合同、审合同、管合同，但身边没有随时可问的法务的人。

---

## 🚀 怎么用（三步上手）

**1️⃣ 用大白话说你的事**
不用术语。例如"我想跟人合伙开网店，合同怎么签""这份合同帮我看看有没有坑""对方逾期不付款了怎么办"——它能听懂并自动判断你属于哪类合同工作。

**2️⃣ 配合回答它的反问**
它通常会先问几个关键问题：你是甲方还是乙方？这笔交易想达成什么？有没有底线/红线？——合同结论高度依赖这些细节，问清楚了它才动手，别嫌啰嗦。

**3️⃣ 把手头资料发给它（给得越多，做得越准）**
- 📄 **待审 / 待改的合同**（审查、补充协议）
- 📚 **公司自有的合同模板、惯用条款、审查规则、Playbook** —— 它会转成你的专属"条款库 / 审查清单"，之后**优先按你的标准**起草和审查，比通用模板贴合得多
- 🧾 **交易背景**（合作方名称、金额、商业目的）—— 帮它核查对方主体、算清风险

## 🎯 你可以这样找它

| 你想说的 | 它给你的成果 |
|---|---|
| "帮我起草一份 XX 合同 / 这个合作怎么签" | 量身定制的完整合同文本 + 风险批注 + 待填写项清单 |
| "这份合同帮我审一下有没有坑" | 站在你立场的逐条审查意见 + 分级风险清单 + 修改建议 |
| "审一遍并出报告 / 给我 Excel / 标批注" | **专业审查模式**：Excel 风险清单（2 Sheet）+ Markdown 风险报告 + Word 批注稿三项产物 |
| "签这个合同前我要注意什么" | 签约前背景评估：对方资质、交易模式、合同形式合法性 |
| "这个合同怎么跟对方谈" | 谈判策略与路线图（必争 / 可让 / 可换）+ 条款对比 |
| "对方违约了 / 履行出问题了怎么办" | 非诉应对方案 + 证据固定建议 + 催告函 / 律师函 |
| "原合同某条想改 / 怎么签补充协议" | 影响评估 + 补充协议文本 + 签署流程建议 |
| "帮公司建一套合同管理制度 / 模板库" | 管理架构、审批授权矩阵、全流程制度、分类模板库 |
| "我们有自己的模板 / 审查标准，按这个来" | 把你的资料转成专属条款库 / Playbook，之后优先按它执行 |

> 💡 不确定自己属于哪种？直接把事情说清楚，它会帮你判断该走哪条路、需要补哪些信息。

## 🔎 专业审查模式（原"审合君"已并入）

当你要"审一遍并出报告 / 给我 Excel / 标批注"时，会进入**专业审查模式**：

- **内置两份 Playbook 底座**：形式审查（9 类 19 条，查完整性与一致性）+ 通用实质审查（8 类 16 条，查实质条款）；你有自有 Playbook 则优先用你的、内置兜底。
- **逐条八步动作 + 定级矩阵**：每条规则走"定位→提取→比对→判断→四要素自检→影响×概率定级→法律依据→建议"，风险归入 **🔴高 / 🟡中 / 💡提示** 三级，定级有据不拍脑袋。
- **三项产物**：Excel 风险清单（2 Sheet：风险项 / 提示）+ 对话内 Markdown 风险报告 + Word 批注稿（批注署名"审合君"）。

> 只想要修订稿（在原文上改字 + 批注）？直接说"帮我改"，会出 Word 原生修订痕迹稿。两种交付按你的措辞自动切换。

## 🛠 能力构成（12 项核心能力 · 8 层技能编排）

围绕"合同思维 + 法律逻辑"，按"识别 → 交互 → 标准内化 → 检索 → 拆解 → 起草/审查 → 履行 → 输出"协同：

| # | 能力 | 一句话说明 |
|---|---|---|
| 1 | 交互采集 | 主动询问、澄清，锁定立场、交易事实与关注点 |
| 2 | 法律检索 | 查准适用法律、强制性规定、必备条款与效力风险（多层检索 + 本方/对方对抗检索 + 适用性验证） |
| 3 | 标准资料接入 | 把你的模板/规则/Playbook 转成专属条款库与审查清单，优先按你的标准；没有也会主动告知 |
| 4 | 交易结构拆解 | 识别商业目的、资金流向、主体关系，判断模式合法性 |
| 5 | 类型识别与审查点拆解 | 定位合同性质，罗列该类型必查的法律与商业要点 |
| 6 | 合同起草 | 优先拼装你的条款库，固定条款稳健、可变要素清晰占位，附风险批注 |
| 7 | 合同审查 | 站在本方立场、优先套你的 Playbook 逐条审查，输出分级风险清单与改法 |
| 8 | 背景评估 | 签约前评估相对方资格、交易模式、合同形式、特殊程序合法性 |
| 9 | 谈判支持 | 构建争点立场矩阵，明确必争/可让/可换底线 |
| 10 | 纠纷应急（非诉） | 止损固证、立场研判、函件与协商路径 |
| 11 | 全生命周期管理 | 合同管理架构、制度、模板库与补充协议 |
| 12 | 输出适配 | 按场景把成果定稿为最匹配的交付物，统一体例并附免责声明 |

## 覆盖场景（C1–C9）

合同管理架构、合同管理制度、合同模板库建设、具体合同起草、合同背景评估、合同条款审查、合同谈判支持、合同纠纷应急处置（非诉）、合同条款变更与补充协议。
