# 常见合同类型 → 适用法律 / 必备条款 / 效力风险点速查

> 本表辅助"合同类型识别"与"条款检索"：命中合同类型后，快速定位适用法律、法定必备要素与高发效力风险点。法条引用以《民法典》现行条文为准（《合同法》已废止）。具体引用前仍须真实检索核验效力状态。

## 一、通用底座（所有合同适用）

| 维度 | 主要依据 |
|---|---|
| 合同成立与效力 | 《民法典》总则编（民事法律行为）+ 合同编通则 |
| 无效情形 | 《民法典》第144、146、153、154 条（无民事行为能力、虚假意思表示、违反效力性强制性规定/公序良俗、恶意串通） |
| 可撤销情形 | 第147-151 条（重大误解、欺诈、胁迫、显失公平） |
| 格式条款 | 第496-498 条（提示说明义务、无效情形、不利解释） |
| 违约责任 | 第577-585 条（继续履行、赔偿损失、违约金及其酌增酌减） |
| 定金规则 | 第586-588 条（定金罚则、与违约金竞合择一） |
| 合同解除 | 第562-566 条（约定解除、法定解除、解除后果） |
| 不可抗力/情势变更 | 第180、533 条 |
| 争议解决 | 《民事诉讼法》（管辖）/《仲裁法》（仲裁协议有效要件） |

## 二、有名合同速查

| 合同类型 | 主要适用 | 法定必备/核心条款 | 高发效力/风险点 |
|---|---|---|---|
| 买卖合同 | 民法典合同编买卖合同章（第595条起） | 标的、数量质量、价款、交付与风险转移、检验、违约 | 标的物权属瑕疵、风险转移节点不清、质量异议期未约定 |
| 服务/委托合同 | 委托合同章（第919条起） | 服务内容标准、报酬、期限、任意解除权及后果 | 任意解除权风险、成果验收标准模糊、转委托 |
| 承揽/加工定作 | 承揽合同章（第770条起） | 工作成果、材料提供、验收、知识产权、定作人协助义务 | 定作物缺陷责任、贴牌加工的资质与商标侵权、留置权 |
| 租赁合同 | 租赁合同章（第703条起） | 租赁物、租金、租期、维修义务、转租、买卖不破租赁 | 超20年租期超出部分无效、转租未经同意、押金返还 |
| 技术合同 | 技术合同章（第843条起） | 技术内容、成果归属、后续改进分享、保密、验收 | 职务技术成果权属、非法垄断技术条款无效（第850条） |
| 建设工程合同 | 建设工程合同章（第788条起）+ 招投标法 | 工期、质量、价款、变更、竣工验收 | 违法分包转包无效、黑白合同、必须招标未招标 |
| 借款合同 | 借款合同章（第667条起）+ 民间借贷司法解释 | 金额、利率、期限、用途、还款 | 利率超司法保护上限（LPR四倍）、企业间拆借、砍头息 |
| 保证/担保 | 担保制度（民法典+担保制度司法解释） | 担保方式、范围、期间 | 保证期间约定不明、未明确连带/一般保证、上市公司对外担保程序 |
| 知识产权许可/转让 | 著作权法/商标法/专利法 + 合同编 | 权利范围、地域、期限、独占/排他/普通、权属保证 | 授权范围超权利人实际权利、独占性表述不清、转授权 |
| 合作/合伙经营 | 合伙企业法/公司法 + 合同编 | 出资、分工、收益分配、亏损承担、退出 | "名为合作实为借贷"、保底条款效力、未约定亏损分担 |

## 三、特殊监管前置的交易（须额外做合规检索）

| 交易类型 | 须额外核查的监管要求 |
|---|---|
| 特许经营/加盟 | 《商业特许经营管理条例》——特许人备案、信息披露义务、"两店一年"要求 |
| 食品贴牌/定制 | 《食品安全法》——委托方与受托方资质、标签标识、生产许可 |
| 数据出境/平台数据转移 | 《数据安全法》《个人信息保护法》——数据分类分级、出境安全评估/标准合同、个人信息单独同意 |
| 跨境交易 | 外汇管理、跨境支付、适用法律与争议解决地选择 |
| 涉个人信息处理 | 《个人信息保护法》——告知同意、委托处理协议、受托方义务 |
| 房屋/土地相关 | 不动产登记、城市房地产管理法、是否需网签备案 |

## 四、效力风险快速自检清单

起草或审查时，对照排查是否触雷：
- [ ] 是否违反效力性强制性规定（导致合同/条款无效）？
- [ ] 主体是否适格、是否具备法定资质？
- [ ] 是否为格式条款且未尽提示说明义务？
- [ ] 是否存在免除己方主要责任、加重对方责任、排除对方主要权利的无效格式条款？
- [ ] 违约金是否过分高于损失（可被酌减）或过低？
- [ ] 担保/保证条款是否完备、期间是否明确？
- [ ] 争议解决条款是否有效（仲裁机构是否明确唯一、管辖约定是否合法）？
- [ ] 知识产权/成果归属是否清晰？
- [ ] 是否涉及需前置审批/备案/登记的特殊程序？

## 五、专项法源动态匹配速查（审查时补充法律依据用）

> 审查（C5/C6）执行完所有规则后，额外做一轮法律风险扫描：识别规则未覆盖但合同真实存在的法律问题，按合同类型与特殊领域**动态补充**精确法源。引用须带条文要旨与现行效力，仍以真实检索核验为准。

### 5.1 合同类型 → 专项法源（民法典合同编精确章/条）

| 合同类型 | 专项法源 |
|---|---|
| 买卖合同 | 《民法典》合同编第二编第九章（第595-647条） |
| 租赁合同 | 《民法典》合同编第二编第十四章（第703-734条） |
| 借款合同 | 《民法典》合同编第二编第十二章（第667-680条） |
| 承揽合同 | 《民法典》合同编第二编第十五章（第770-787条） |
| 建设工程合同 | 《民法典》合同编第二编第十八章（第788-808条） |
| 技术合同 | 《民法典》合同编第二编第二十章（第843-887条） |
| 服务合同 | 参照《民法典》合同编通则及最相类似合同的规定 |
| 劳动合同 | 《劳动合同法》 |
| 股权转让 | 《公司法》股权转让及优先购买权相关条款 |

> 注：上述条文区间以《民法典》现行文本为准；引用具体条号前须真实检索核验，公司法条号以现行修订版本为准。

### 5.2 特殊领域 → 专项法源

扫描合同是否触及以下特殊领域，命中则引用对应法源：

| 特殊领域 | 法源 |
|---|---|
| 数据与个人信息 | 《个人信息保护法》《数据安全法》《网络安全法》 |
| 反垄断 | 《反垄断法》 |
| 消费者保护 | 《消费者权益保护法》 |
| 招投标 | 《招标投标法》《招标投标法实施条例》 |
| 国际贸易 | 《对外贸易法》、相关国际贸易术语解释通则（Incoterms） |

### 5.3 动态补充风险项的处理

发现规则未覆盖的法律风险时：
- 作为补充风险项输出，审查维度标注 `[动态识别] XXX` 前缀。
- "法律依据"字段标注具体法条引用（《法律名称》第X条 + 条文要旨）。
- "风险提示"按"风险说明 + 建议"格式输出。
- 在报告中单独说明动态补充的风险项数量。

> 动态补充必须基于明确的合同条款分析，不得臆测或过度引申。
