# 通用实质审查 Playbook — 通用类型合同审查

> **适用范围**：通用类型商业合同的实质性条款审查，可从甲方或乙方任一立场使用。
> **规则数量**：8 个分类，16 条规则
> **维度聚焦**：合法合规性 / 权利义务对等 / 违约责任救济 / 期限终止解除 / 争议解决管辖 / 条款完备性 / 主体资格授权 / 标的物履约标准

---

## 一、合法合规性

### 规则 1：合法合规性与效力瑕疵

- **审查点**：合法合规性与效力瑕疵
- **审查规则**：合同目的、交易模式及条款内容不得违反现行法律法规的强制性规定；不得存在涉嫌垄断、不正当竞争、侵犯第三方权益（如知识产权）、数据与隐私合规风险；不得存在导致合同整体或部分条款无效的法定情形。
- **法律依据**：《民法典》第143条（民事法律行为有效要件）、第153条（违反法律行政法规强制性规定无效）、第154条（恶意串通无效）、第496条至第498条（格式条款效力规则）、第506条（免责条款无效情形）；《反垄断法》；《个人信息保护法》；《数据安全法》
- **典型示例**：约定的违约金或利息超过法定最高保护上限；在数据流转条款中未明确已取得个人信息主体的单独同意；利用格式条款不合理地免除己方责任、加重对方责任。
- **修改建议**：明确指出触碰合规红线的具体条款，并建议直接删除或修改为合法表述（如将超额利息修改为"按全国银行间同业拆借中心公布的LPR的4倍计算"）；针对数据与隐私合规，补充"双方均承诺遵守数据安全及个人信息保护相关法律法规，并承担因违规造成的一切责任"的合规承诺条款。

## 二、权利义务对等

### 规则 2：权利与义务的对等性

- **审查点**：权利与义务的对等性
- **审查规则**：核心权利与义务应匹配我方商业诉求；对方不得将本应承担的责任转嫁给我方；不得存在单方霸王条款。
- **法律依据**：《民法典》第465条（依法成立的合同受法律保护）、第509条（当事人应当全面履行义务）、第533条（情势变更）
- **典型示例**：我方需承担无限期的保密义务，而对方无对等约束；我方付款条件苛刻，而对方交付条件宽松。
- **修改建议**：在提示中指明双方权利义务失衡之处，并提供平衡双方权利义务的修改话术（如增加"在合理范围内"、"经双方协商一致"等前置条件）。

## 三、违约责任与救济

### 规则 3：违约情形触发条件

- **审查点**：违约情形触发条件
- **审查规则**：违约情形的触发条件应明确具体，能够清晰判定何种行为构成违约。
- **法律依据**：《民法典》第577条（违约责任一般规定）、第578条（预期违约）、第580条（非金钱债务不履行或者履行不符合约定）
- **典型示例**：笼统约定"违约方需赔偿一切直接和间接损失"，未明确具体违约触发情形。
- **修改建议**：明确具体违约情形对应的违约金比例（如逾期按日万分之X计算）。

### 规则 4：违约金计算可操作性

- **审查点**：违约金计算可操作性
- **审查规则**：违约金计算方式应具备可操作性，应明确计算基数、比例和上限，避免模糊性表述；不得对我方设置不合理的惩罚性违约金。
- **法律依据**：《民法典》第585条（违约金约定及司法调整规则）
- **典型示例**：对我方单次轻微违约设定天价违约金；违约金计算方式不清晰难以执行。
- **修改建议**：明确具体违约情形对应的违约金比例（如逾期按日万分之X计算）。

### 规则 5：责任上限条款

- **审查点**：责任上限条款
- **审查规则**：合同应包含责任上限条款，限制我方在任何情况下承担的最大赔偿金额，不得缺失最高赔偿限额。
- **法律依据**：《民法典》第584条（损害赔偿范围：可预见性规则）、第585条（违约金调整）
- **典型示例**：无最高赔偿限额，导致我方面临无限责任风险。
- **修改建议**：强烈建议为我方增设责任上限条款："在任何情况下，我方承担的赔偿总额不超过本合同总金额的X%"。

## 四、期限、终止与解除

### 规则 6：合同生效与履行期限

- **审查点**：合同生效与履行期限
- **审查规则**：合同生效条件、履行期限应清晰明确，应有具体的起止日期。
- **法律依据**：《民法典》第502条（合同生效条件）、第510条（合同内容约定不明确时的补充协议）
- **修改建议**：明确合同具体的起止日期。

### 规则 7：自动续期条款

- **审查点**：自动续期条款
- **审查规则**：合同不应包含对我方不利的锁定式自动续期条款，如确有自动续期机制，应配套退出权安排。
- **法律依据**：《民法典》第510条（合同补充约定）、第563条（法定解除权）
- **典型示例**：包含"除非双方同意，否则本合同自动续期"的锁定条款。
- **修改建议**：对于自动续期条款，增加"任何一方在到期前X天书面通知即可终止"的退出权。

### 规则 8：单方解除权对等性

- **审查点**：单方解除权对等性
- **审查规则**：法定解除与约定解除权应明确，且我方应拥有与对方对等的单方解除权或合理的退出机制。
- **法律依据**：《民法典》第562条（约定解除）、第563条（法定解除）、第565条（解除权行使方式及程序）
- **典型示例**：对方享有任意解除权，但我方只有在对方严重违约时才能解除。
- **修改建议**：争取对等的单方解除权。

## 五、争议解决与管辖

### 规则 9：管辖机构明确性与便利性

- **审查点**：管辖机构明确性与便利性
- **审查规则**：管辖机构的约定应明确、唯一，不得同时约定仲裁和诉讼；管辖地应对我方（如我方所在地）便利。如管辖地约定为深圳市南山区人民法院，则默认对我方有利，无需对此提出风险审查意见。
- **法律依据**：《民事诉讼法》第24条（合同纠纷地域管辖）、第35条（协议管辖）；《仲裁法》第4条（仲裁协议自愿原则）、第16条（仲裁协议的形式和内容）、第18条（仲裁协议效力）
- **典型示例**：约定"向原告/被告所在地法院起诉"（过于模糊或对我方不利）；同时约定仲裁和诉讼（导致条款无效）。
- **修改建议**：明确约定"提交[我方所在地]有管辖权的人民法院诉讼解决"或明确具体的仲裁委员会名称。

## 六、条款完备性

### 规则 10：不可抗力条款

- **审查点**：不可抗力条款
- **审查规则**：合同应包含不可抗力条款，明确不可抗力的定义、通知义务及免责范围。
- **法律依据**：《民法典》第180条（不可抗力定义及免责）、第590条（不可抗力免责规则）
- **典型示例**：缺失"不可抗力"条款，导致突发事件发生时无法免责。
- **修改建议**：提供标准的不可抗力定义与免责程序条款。

### 规则 11：保密条款

- **审查点**：保密条款
- **审查规则**：合同应包含保密条款，明确双方对在签订和履行过程中知悉的商业秘密的保密义务。
- **法律依据**：《民法典》第501条（缔约过失中的保密义务）；《反不正当竞争法》第9条（商业秘密保护）
- **典型示例**：缺失"保密条款"，导致商业机密泄露无法追责。
- **修改建议**：补充标准的保密义务条款。

### 规则 12：知识产权归属

- **审查点**：知识产权归属
- **审查规则**：合同应明确履约过程中产生的衍生开发成果的知识产权归属。
- **法律依据**：《著作权法》第19条（委托作品著作权归属）；《专利法》第8条（委托发明创造专利申请权归属）；《民法典》第510条（合同补充约定）
- **典型示例**：缺失"知识产权归属"条款，导致履约过程中产生的衍生开发成果权属不清。
- **修改建议**：补充知识产权归我方所有的保护条款。

## 七、主体资格与授权

### 规则 13：签约主体一致性

- **审查点**：签约主体一致性
- **审查规则**：签约主体应明确、清晰，合同首部、正文、签署栏（含落款盖章）的主体名称应保持完全一致；不得存在代签或越权签字风险。
- **法律依据**：《民法典》第143条（民事法律行为有效要件）、第171条（无权代理）
- **典型示例**：抬头是A公司，落款盖章是B公司（如母子公司混用）。
- **修改建议**：统一合同首尾的主体名称。

### 规则 14：通知与送达地址完备性

- **审查点**：通知与送达地址完备性
- **审查规则**：合同应包含完备的通知与送达条款，明确法定文书及通知的联系人、邮箱、有效通讯地址，并约定按此地址发出的通知即视为有效送达。
- **法律依据**：《民法典》第510条（合同内容补充）、第565条（解除通知的送达）；《民事诉讼法》第87条至第92条（诉讼送达规则）
- **典型示例**：未约定明确的法定文书及通知的送达地址。
- **修改建议**：补充完善"通知与送达"条款，明确指定联系人、邮箱及有效通讯地址，并约定"按此地址发出的通知即视为有效送达"。

## 八、标的物与履约标准

### 规则 15：标的物质量标准具体化

- **审查点**：标的物质量标准具体化
- **审查规则**：交易标的（商品/服务/授权）的名称、规格、数量、质量标准应具体、唯一、可衡量，不得使用"提供优质服务"或"符合行业一般标准"等无量化指标的模糊表述。
- **法律依据**：《民法典》第511条（质量约定不明确时的履行规则）、第615条（出卖人质量保证义务）；《产品质量法》第26条（生产者产品质量责任）
- **典型示例**：仅表述"提供优质服务"或"符合行业一般标准"，缺乏量化指标。
- **修改建议**：细化质量/交付标准（可作为附件）。

### 规则 16：验收流程与异议期

- **审查点**：验收流程与异议期
- **审查规则**：合同应明确具体的验收流程，包括验收期限、异议期及未反馈的处理方式。
- **法律依据**：《民法典》第620条（买受人检验义务）、第621条（检验期限）、第622条（检验期限过短视为外观瑕疵异议期）
- **典型示例**：缺乏具体的验收流程（如验收期限、异议期）。
- **修改建议**：明确验收流程，例如"甲方应在收到交付物后X个工作日内反馈，逾期未反馈视为验收合格"。
