# 审查 Playbook 与合同条款库 · 模板与示例

> 本文件给 `contract-standards-ingest` 提供可直接套用的产出物模板，以及"从过往审查意见反向提炼规则"的范例。所有示例中的当事人、金额均为占位示意，实际转化只承载用户真实提供的内容。

---

## 一、审查 Playbook 规则项 · 完整字段模板

```
规则编号：R0XX
适用范围：____（合同类型/场景，如"所有采购合同""标的额>100万的合作合同"）
立场口径：____（甲方/乙方/中立；强势/弱势——继承用户口径）
审查点：____（如"付款条件""违约金""数据出境""排他性"）
标准要求（期望条款）：____（符合标准的理想表述或底线）
风险等级：高 / 中 / 低（命中违反时）
回退档（Fallback）：
  - 理想档：____
  - 可接受档：____
  - 触发红线档：____
红线（绝不可越）：____（突破即否决或上报）
修改建议模板：____（命中问题时建议怎么改，可含建议措辞）
来源：用户提供《____》第__条 / 第__页
```

### 规则项填写示例

```
R001
适用范围：所有采购合同
立场口径：甲方 / 强势
审查点：付款周期
标准要求：货物验收合格后 30 日内付款；预付款不超过合同额 30%
风险等级：高
回退档：
  - 理想档：货到验收后 30 日
  - 可接受档：30–45 日且约定逾期违约金
  - 触发红线档：>60 日或先款后货无担保
红线：预付全款且无任何履约/退款担保 → 否决，上报法务负责人
修改建议模板：增加"逾期付款按日万分之X计违约金"，预付款部分要求对方提供等额保函/质保金
来源：用户《采购合同风控清单 v3》#3、#7
```

## 二、合同条款库 · 结构模板

```
【合同条款库 · 来源：用户提供模板/范本】
适用主体：____（如"XX公司采购与合作业务"）
分类架构：买卖 / 服务 / 采购 / 承揽 / 租赁 / 授权许可 / 合作 / …

├─ 基础条款库（锁定 · 跨类型复用）
│   ├─ 定义条款
│   ├─ 保密义务
│   ├─ 违约责任（通用框架）
│   ├─ 不可抗力
│   ├─ 通知与送达
│   ├─ 争议解决与管辖（用户惯用：____仲裁委/____法院）
│   └─ 完整协议 / 生效与变更解除
│
├─ [采购合同] 核心条款模块（保留用户惯用表述）
│   ├─ 标的与规格
│   ├─ 价款与支付（用户惯用账期：____）
│   ├─ 交付与验收（用户惯用验收标准：____）
│   ├─ 质量保证与售后
│   └─ 专属违约/罚则（用户惯用违约金算法：____）
│   可变要素占位：【供方名称】【金额】【账期天数】【交付地点】【验收标准编号】
│
├─ [服务合同] 核心条款模块：…
│
└─ 入库体检备注：
    - 体检-01：模板第X条引用《合同法》第X条（已废止）→ 建议切《民法典》第X条【待用户确认，未擅改】
    - 体检-02：违约金约定可能过分高于损失，存在被酌减风险 → 提示用户【未擅改】
```

## 三、从「过往审查意见 / 批注合同」反向提炼规则（范例）

> 用户给的是过往的审查意见书或批注版合同，没有现成规则库时，把每一处批注当成一条隐含规则反推出来。

| 过往批注原文（用户资料） | 反向提炼出的 Playbook 规则 |
|---|---|
| "付款周期60天过长，建议改为货到30天内" | R: 采购合同付款周期 >45 天为高风险；标准≤30 天；建议加逾期违约金 |
| "未约定逾期交付违约金，对我方不利" | R: 缺逾期交付违约责任为中风险；标准为约定日比例违约金 + 上限 |
| "管辖约定对方所在地法院，改为我方所在地" | R: 争议管辖红线=不接受对方所在地；标准=本方所在地法院/约定仲裁 |
| "知识产权归属未写清，成果可能归对方" | R: 委托/开发类合同必须明确成果权属归本方；缺失为高风险 |
| "保密义务无期限，建议约定合作终止后2年" | R: 保密条款须有明确存续期；标准=终止后≥2年 |

> 提炼原则：一处批注 = 一条规则；把"个案修改"抽象成"可复用标准"（带审查点、风险等级、标准要求）。提炼后须经用户确认是否作为通用规则。

```

- 共识别规则 __ 条，其中红线 __ 条（如：付款红线、管辖红线、权属红线）
- 适用范围：____
- 待确认疑点：____

【合同条款库】
- 已入库合同类型 __ 类，核心条款模块 __ 个
- 基础条款库（锁定）__ 条
- 入库体检发现疑点 __ 处（已标注，未擅自改动）：____

确认后，我将在后续起草中优先拼装贵司条款库、审查中优先套用贵司 Playbook。
如需调整规则分级、红线或条款偏好，请直接指出。
```
