## 强制生效规则

> ⚠️ 以上三种场景在**生成/输出 `.xlsx` 文件之前**，AI **必须**已读取本文档，并按本文档规定的格式规范修改即将输出文件的列宽、颜色、表头等格式。禁止跳过本文档直接生成裸 Excel。

## 通用规则

### 腾讯云列高亮

当输出 Excel 的列名（表头文字）中含有以下任意关键字时，该列**整列**应用腾讯云品牌色：

| 关键字    | 说明                 |
| --------- | -------------------- |
| `腾讯云`  | 中文全称             |
| `腾讯`    | 中文简称             |
| `Tencent` | 英文（不区分大小写） |
| `tencent` |                      |

**颜色规范**：

| 单元格位置            | 背景色    | 说明         |
| --------------------- | --------- | ------------ |
| 品牌列表头行          | `#4472C4` | 腾讯云品牌蓝 |
| 品牌列数据行          | `#FFFFFF` | 白色         |
| 非品牌列（表头+数据） | `#FFFFFF` | 白色         |

> 匹配规则：列名**包含**任一关键字即触发，不要求完全相等。例如"腾讯云产品名""我方腾讯对标产品""Tencent Cloud CVM"均命中。
>
> 多列同时命中时，每列独立应用上述颜色，互不干扰。
>
> 只有含品牌关键字的列表头使用 `#4472C4`；其余所有单元格（含品牌列数据行、非品牌列表头和非品牌列数据行）统一使用白色 `#FFFFFF`。
