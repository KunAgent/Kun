# 如何查询四层编码（how-to-query-four-layer）

> **用途：为一条产品行查到它的四层编码（`productCode` / `subProductCode` …），用于选品加行。**
> 本流程**只做四层编码查询**，与价格无关，全程不涉及任何报价 / 估价动作。

## 何时使用

选品（C 段）走到某一行时，满足**全部**以下条件才调用本流程：

- 该行没有 SPUID；
- 该行没有自带四层编码；
- 按搜索关键字 / 选品意图的标准检索（方式 A→B→C→D）也没找到合适的 SPUID。

此时尝试查到四层编码，从而用四层编码把这一行加进选品。

## 先复用中间表已有结论（避免重复查询）

调用查询工具前，**先看中间表该行的「四层编码」列**：

| 该行「四层编码」列取值 | 含义               | 动作                         |
| ---------------------- | ------------------ | ---------------------------- |
| 真实四层编码           | 已经查到过         | **直接复用**，不再调用工具   |
| `未找到`               | 已经查过、确实没有 | **不再重复查**，该行选品失败 |
| 空 / `-` / 该行无记录  | 还没查过           | 执行下面的查询工具           |

> 「该行是否查过四层」以中间表里的上述显式取值为准（脚本可判定），**不靠猜测**。

## 查询工具与优先级

| 优先级 | 工具                                      | 取四层方式                                                                                    |
| ------ | ----------------------------------------- | --------------------------------------------------------------------------------------------- |
| ① 优先 | `tencent-cloud-pricing` 的 `tcloud-price` | `tcloud-price search <产品>` 拿 `productCode` → `tcloud-price quote --with-four-level` 返回四层字段     |
| ② 兜底 | `inquiry-price-parallel`                  | 读 run 目录的 `summary.xlsx` 的 **`four_layer` 列**（远端 `[四层]` 段原样搬运，成功行才有值） |

> ⚠️ 这两个工具底层也能返回价格，但本流程**只取四层编码字段，必须丢弃任何价格字段**，不把价格写进任何产物。
>
> ② 的 `four_layer` 列由 `inquiry-price-parallel` 协议层向远端刊例价助手显式索取 `[四层]` 段得到（成功结论才填，远端查不到则该列为空）；列为空即视为该工具没查到，按下面「输出与回填」转 `未找到`。

## 输出与回填

- 查到四层编码 → 回填该行「四层编码」列（逐字写工具返回值），状态标「待添加（四层）」，随后用 `row add --four-layer-codes` 加行。
- ①② 都查不到 → 该行「四层编码」列写显式 **`未找到`**，状态标「选品失败」。

## 铁律

- 四层编码**只来自工具实际返回**，本地零推断、零编造；查不到就写 `未找到`，不得自造编码或 SPUID。
- 本流程不读取、不产出、不解释任何价格字段。
