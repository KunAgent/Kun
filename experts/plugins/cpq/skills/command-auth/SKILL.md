# command-auth 鉴权操作指引

你读到此文档，说明 `cpq` 或 `tcloud-price` 返回了鉴权错误。你的任务是：完成 OAuth 授权流程，然后重新执行原来失败的命令。

---

## 第一步：确认当前状态

```bash
command-auth whoami
```

- 输出含 `✓ 已授权` → 鉴权正常，跳过登录直接重试原命令；若原命令仍报错，问题不在鉴权
- 输出含 `✗ 未授权` → 继续第二步

---

## 第二步：登录

运行以下命令——生成授权链接、尝试打开浏览器，并**自动在后台启动回调服务**：

```bash
command-auth login --async
```

输出示例：
```
=== 授权链接 ===

https://...（授权 URL）

[command-auth] 已在后台启动回调服务，等待浏览器授权完成…
```

若浏览器未能自动打开，把链接用 Markdown 格式展示给用户，提示点击打开。

> ⚠️ **无需手动运行 `--await`**——回调服务已在后台运行，用户完成浏览器授权后会自动捕获 token。

用户点击链接完成授权后，继续第三步。

---

### 用户无法通过浏览器回调完成授权

若用户说"浏览器跳转失败"、"localhost 页面打不开"或"复制了回调 URL"：

```bash
command-auth login --code "<用户提供的完整重定向 URL 或 code 值>"
```

---

## 第三步：验证并重试

每隔数秒轮询，直到授权成功：

```bash
command-auth whoami
```

- 输出含 `✓ 已授权` → 重新执行最初失败的命令
- 输出含 `✗ 未授权` → 用户尚未完成浏览器授权，稍后再试（**不要**重新运行 `--async`）

---

## 登出（清除本地凭证）

```bash
command-auth logout
```

托管环境（sandbox-token / platform-token）下此命令直接返回成功，凭据由环境变量管理，无需手动清除。

---

## 附：各命令预期输出速查

| 命令 | 成功输出（exit 0） | 失败输出（exit 1） |
|------|-------------------|-------------------|
| `whoami` | `✓ 已授权（用户: xxx）` | `✗ 未授权: <原因>` |
| `login --async` | 打印链接、后台启动回调服务，exit 0 | `❌ 异步登录启动失败: <原因>` |
| `login --await` | `✓ 授权成功。` | `❌ 授权失败: <原因>` |
| `login --code <url>` | `✓ 授权成功。` | `❌ 授权失败: <原因>` |
| `logout` | `✓ 已成功清除登录凭证！` | `❌ 清除凭证失败: <原因>` |
