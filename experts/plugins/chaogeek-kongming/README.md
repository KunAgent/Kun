# ChaoGeek 0x孔明

> 用一个好问题补上下文，用一次意图对齐驾驭 Agent，用认知反缴械守住判断力。

## 这是什么

ChaoGeek 0x孔明 是一个面向 OPC（一人公司 / 超级个体）的苏格拉底式 AI 思维搭子。

它不急着给方案，也不把用户拖进问卷。它会先抓住一个关键矛盾，用一个锋利问题帮你看清真实意图，再把想法整理成 Agent 能执行、人能验收的上下文包。

## 为什么做这个

AI 越强，越容易让人产生一种错觉：答案已经很完整，所以我已经想清楚了。

这就是认知缴械。

对 OPC 来说，这尤其危险。一个人做事，执行力可以被 AI 放大，但方向判断、风险承担、价值取舍不能外包。

所以 0x孔明 的价值不是多给你十个点子，而是帮你问出那个真正重要的问题：

**这个判断是你想清楚的，还是 AI 帮你说圆的？**

## 这版的交互原则

- 每轮默认只问 1 个问题。
- 需要用户补上下文时，优先使用 AskUserQuestion。
- 问题必须有趣、有本质，不做表单式审问。
- 用户不想回答时，按显性假设继续推进。
- 最后要落到 Intent Alignment Card、Context Pack、认知缴械检查或 72 小时验证动作。

## 三个核心能力

| 能力 | 作用 |
|---|---|
| `socratic-alignment` | 用一个锋利问题补足上下文、对齐真实意图、拆出关键假设 |
| `cognitive-disarmament` | 检查 AI 输出里的认知缴械风险，区分事实、证据、假设和漂亮话 |
| `agentic-opc-workflow` | 把想法整理成 Agent 可执行的上下文包、任务卡、验收标准和人类判断门 |

## 典型用法

- “用一个锋利问题帮我审视这个 OPC 想法”
- “帮我补齐上下文，并把意图对齐给 Agent”
- “帮我检查这次 AI 协作有没有认知缴械风险”
