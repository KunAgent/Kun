# Insert语句

## 格式

### 基本插入语句

```sql
INSERT [OVERWRITE] TABLE tablename1[COLUMNLIST] select_statement1 FROM from_statement
```

或者

```sql
INSERT [OVERWRITE] TABLE tablename1 PARTITION(par_key=value) select_statement1 FROM from_statement
```

`select_statement`字段数需要与表定义的字段数保持一致，即便`PARTITION`已经指定了分区名/分区kv，`select_statement`输出的字段中也必须包含分区字段。

**注意**：如果需要直接重写二级分区需要指定分区名：

```sql
INSERT [OVERWRITE] TABLE tablename PARTITION(prim_par_name,sub_par_name) select_statement FROM from_statement
```

### 多插入语句

```sql
FROM from_statement
INSERT [OVERWRITE] TABLE tablename1[COLUMNLIST] select_statement1
[INSERT [OVERWRITE] TABLE tablename2[COLUMNLIST] select_statement2] ...

COLUMNLIST : (col1 { , coli }*)
```

### 插入多行常量数据

注意这里没有`TABLE`关键字：

```sql
INSERT [OVERWRITE] INTO tablename[COLUMNLIST] VALUES (cnst1{,cnsti}*),(cnst1{,cnsti}*)*
```

## 说明

将查询语句的执行结果插入到指定的表中，TDW支持多条insert子句在一条语句中。如果目标表是分区表，则结果会自动插入到对应分区中。

## 注意事项

### INSERT语法差异

`INSERT`语句与常用的SQL `INSERT`语法有略微区别，非overwrite方式不用写`INTO`。

### INSERT OVERWRITE删除逻辑

`INSERT OVERWRITE TABLE`时，针对非分区表和分区表有不同的删除逻辑：

- 使用`PARTITION`指定分区时，如果查询结果不为空，覆盖指定分区的历史数据；
- 不使用`PARTITION`指定分区时，先清空数据，再将查询结果（无论有没有）按分区写入；
- 写入表为非分区表时，如果查询有结果，先清空数据，再将查询结果写入。

### 性能建议

尽量使用多insert子句的方式，可以减少了数据的扫描，提高运行效率。

### Hash分区表特性

如果目标表为hash分区表，则数据在入库时会进行排序，保证每个hash分区中的数据就hash分区key而言是有序的。

### 外表数据引号问题

外表中的数据引号问题，请看[这里的注意事项](建表语句相关文档)。

### 指定列插入

如果使用指定列插入的方式，必须保证被插入列（被插入表后面跟着的小括号内的字段列表）与插入列（select后面的字段列表）一一对应：字段数目相同，并且字段类型一一相同。

### 插入多行数据要求

插入多行数据，需要注意的是，插入的每行数据需要和表中的列对应，包括字段数目和字段类型的匹配。

- 目前只支持常量的插入，不支持复杂类型数据，不支持函数插入。
- 如果需要插入NULL，需要显示的使用`NULL`关键字，或者使用`insertcolumns`指定需要插入的列，而没有指定的列为空。
- 不支持`""`或者作为NULL输入。

## 特殊说明

### Protobuf表的repeated字段

protobuf表的repeated字段（对应为tdw中的array类型）中的单个元素不允许为空值。

例如表`src(key string, value array(int))`。目标表`desc`为protobuf格式，结构与src相同。

src中的一条记录：`"name" 1,null,3,4`

通过select insert语句insert到desc表后的结果为：`"name" 1,3,4`

### Array类型构造

array类型的表可以用`ARRAY(0,1)`构造，例如：

```sql
INSERT TABLE a_roncen_array SELECT 1, ARRAY(0,1) FROM a_cherry_part_1 LIMIT 1;
```

查询时用以下方式进行查询：

```sql
SELECT a, b[0] FROM test::a_roncen_array LIMIT 1000;
```

### Hash分区表限制

含有hash分区的表insert数据时候不支持指定列名的插入。

## 示例

### 示例1：基本插入

将表a和b的链接结果插入到表test中去：

```sql
INSERT OVERWRITE TABLE test SELECT * FROM a JOIN b ON(a.key = b.key);
```

### 示例2：多路插入

将查询结果插入到test和test2表中：

```sql
FROM a JOIN (SELECT * FROM b WHERE b > 10) c ON(a.key = c.key)
INSERT OVERWRITE TABLE test SELECT a.key, c.value
INSERT OVERWRITE TABLE test2 SELECT a.key, c.key;
```

### 示例3：指定列插入

```sql
INSERT OVERWRITE TABLE tablename(a, b) SELECT a, b FROM tbl2;
```

### 示例4：插入常量值

```sql
INSERT INTO tablename(a,b) VALUES(1,'a'),(2,'b');
```
