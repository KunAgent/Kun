# Load语句

## 格式

```sql
LOAD DATA INPATH 'filepath' [OVERWRITE] INTO TABLE tablename
```

## 说明

将文件拷入指定的表中，这里的表不能是分区表。

1. `filepath`可以是相对路径，绝对路径和URI（如 `hdfs://namenode:9000/user/hive/project/data1`）
2. `filepath`可以是目录，这时目录中所有文件将被拷贝到到表中，也可以是文件，这是该文件将被拷到表中。
3. 如果路径不是绝对路径，则`filepath`被解释成`/user/<username>`下的相对路径。
4. 如果`OVERWRITE`被指定，则表中的内容会先清除，然后再拷贝文件。如果`OVERWRITE`没有被指定，则文件会被插入到表中，此时需要注意：如果表中的文件名如果与插入的文件同名，则表中该重名的文件会被替换。

## 注意事项

- `filepath`不能含有子文件夹。
- TDW不对上传的文件的结构做任何检查，用户需要保证文件的格式复合表的定义。

## 示例

加载hdfs上的数据到表test中：

```sql
LOAD DATA INPATH "hdfs://name_node:9000/user/mydata" INTO TABLE test;
```
