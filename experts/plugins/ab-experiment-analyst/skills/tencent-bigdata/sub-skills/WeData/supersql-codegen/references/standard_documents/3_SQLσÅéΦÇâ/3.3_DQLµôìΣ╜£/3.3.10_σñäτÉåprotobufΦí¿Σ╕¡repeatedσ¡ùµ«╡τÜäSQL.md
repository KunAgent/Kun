# 处理protobuf表中repeated字段的SQL

## Lateral View + explode实现对repeated字段做sql计算

### 示例场景

假设广告展示表AdImpression的定义中每个广告展示的记录由一个页面的id和当前页面上展示的广告几个id的list组成，其proto定义为：

```protobuf
message AdImpression{
  required string pageid = 1;
  repeated int adid_list = 2;
}
```

当前表中有如下数据：

| string pageid | Array<int> adid_list |
|---------------|---------------------|
| "front_page"  | [1, 2, 3]          |
| "contact_page"| [3, 4]             |

### 基本EXPLODE用法

对表做lateral view + explode的SQL如下所示：

```sql
SELECT pageid, adid
FROM pageAds LATERAL VIEW explode(adid_list) adTable AS adid;
```

可以产生如下的输出：

| string pageid | int adid |
|--------------|---------|
| "front_page"  | 1       |
| "front_page"  | 2       |
| "front_page"  | 3       |
| "contact_page"| 3       |
| "contact_page"| 4       |

### 对explode结果进行聚合

对repeated字段explode后的结果做方便的计算：

```sql
SELECT adid, COUNT(1)
FROM pageAds LATERAL VIEW explode(adid_list) adTable AS adid
GROUP BY adid;
```

结果：

| int adid | count(1) |
|---------|---------|
| 1       | 1       |
| 2       | 1       |
| 3       | 2       |
| 4       | 1       |

## EXPLODE默认值功能

repeated字段的值可能为空，在TDW中为explode增加了设置缺省值的功能。（TDWV0.2R090开始支持）

### 示例：不使用默认值

```sql
SELECT id, testid FROM explodetest LATERAL VIEW explode(test) testdd AS testid;
```

结果：

| int id | count(1) |
|--------|---------|
| 2      | 3       |
| 2      | 4       |
| 2      | 5       |

### 示例：使用默认值

```sql
SELECT id, testid FROM explodetest LATERAL VIEW explode(test, 100) testdd AS testid;
```

结果：

| int id | count(1) |
|--------|---------|
| 2      | 3       |
| 2      | 4       |
| 2      | 5       |
| 3      | 100     |

### 默认值限制

在使用缺省值的时候限定如下：

1. 对于Map类型还有Struct类型无法支持，可以支持List类型
2. 对于基本类型可以支持int到bigint，float到double的自动类型提升，而List类型不能支持

## 重要注意事项

### WHERE子句使用限制

**当前直接对explode产生的列做where计算是会有问题**，需要将lateral view + explode产生的结果做为子查询，再对子查询的结果做where过滤。

#### 错误示例

例如查询id为3的广告都在哪些广告展示中出现：

```sql
SELECT pageid
FROM pageAds LATERAL VIEW explode(adid_list) adTable AS adid
WHERE adid = 3;
```

#### 正确示例

需要改写为：

```sql
SELECT pageid
FROM (
  SELECT pageid, adid
  FROM pageAds LATERAL VIEW explode(adid_list) adTable AS adid
) subq
WHERE adid = 3;
```

## Lateral View + posexplode实现对repeated字段做sql计算

### 说明

与explode不同的是，posexplode会记录当前值在原repeated字段中的位置。

### 示例

对表做lateral view + posexplode的SQL如下所示：

```sql
SELECT pageid, pos, adid
FROM pageAds LATERAL VIEW posexplode(adid_list) adTable AS pos, adid;
```

可以产生如下的输出：

| string pageid | int pos | int adid |
|--------------|---------|---------|
| "front_page"  | 0       | 1       |
| "front_page"  | 1       | 2       |
| "front_page"  | 2       | 3       |
| "contact_page"| 0       | 3       |
| "contact_page"| 1       | 4       |
