# Union [All]操作

## 格式

```sql
SELECT * FROM (
  select_statement
  UNION [ALL]
  select_statement
) unionResult
```

## 说明

目前支持union all操作和去重的union操作。

SQL中不包含`ALL`关键字则表示为去重union，将对结果集做去重操作。

## 注意事项

### select_statement别名要求

1. union [all]链接起来的select子句，**不能有别名**，例如上面的`select_statement`不需要别名。
2. union [all]整体**必须有别名**，例如上面的`unionResult`，外层select可以将`unionResult`当作临时表，引用它的列。

### 列名规则

每个`select_statement`选出的列，可以有别名，但是TDW会以UNION [ALL]的第一个select子句的列名或者别名作为`unionResult`的列名，供外层引用。

### 子查询包装要求

`select_statement`中有`GROUP BY`、`ORDER BY`、`SORT BY`、`CLUSTER BY`、`DISTRIBUTE BY`或`LIMIT`时，把`select_statement`包裹在另一select语句中，例如：

```sql
SELECT * FROM (
  SELECT id, value FROM (
    SELECT id, value FROM t1 ORDER BY id
  )
  UNION ALL
  SELECT id, value FROM (
    SELECT id, value FROM t2 LIMIT 10
  )
)
```

这么做是为了兼容最新SparkSQL的语法，下面的SQL在最新的SparkSQL中会报错：

```sql
SELECT * FROM (
  SELECT id, value FROM t1 ORDER BY id
  UNION ALL
  SELECT id, value FROM t2 LIMIT 10
)
```

## 示例

### Union后进行join操作

```sql
SELECT u.id, actions.date
FROM (
  SELECT av.uid AS uid, av.date AS date
  FROM action_video av
  WHERE av.date = '2008-06-03'
  UNION ALL
  SELECT ac.uid AS uid, ac.date AS date
  FROM action_comment ac
  WHERE ac.date = '2008-06-03'
) actions
JOIN users u ON (u.id = actions.uid)
```
