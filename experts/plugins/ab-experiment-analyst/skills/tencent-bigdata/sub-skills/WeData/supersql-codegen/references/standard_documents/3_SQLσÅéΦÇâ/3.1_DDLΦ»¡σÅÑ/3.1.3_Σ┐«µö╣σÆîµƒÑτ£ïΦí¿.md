# 修改和查看表

## 概述

本文介绍如何在TDW中修改表结构和查看表信息，包括重命名表、修改注释、修改表属性等操作。

## 表重命名

### 基本语法

```sql
ALTER TABLE <old_name> RENAME TO <new_name>;
```

### 说明

- 重命名表，如果新名已经被使用，则报错
- 用户须对表有alter权限

### 示例

```sql
ALTER TABLE test RENAME TO newtest;
```

## 更改comment

### 基本语法

```sql
COMMENT ON TABLE tblname IS 'the new comment';
COMMENT ON TABLE tblname IS NULL;
COMMENT ON VIEW viewname IS 'the new comment';
COMMENT ON VIEW viewname IS NULL;
COMMENT ON COLUMN columnname IS 'the new comment';
COMMENT ON COLUMN columnname IS NULL;
```

### 说明

- 用户不指定数据库时，默认修改的是当前数据库的表或视图
- 用户可以用`db::tbl`、`db::view`、`db::tbl.col`、`db::view.col`的形式指定数据库；如果是当前数据库，则可以省略db名
- 列名的指定形式为`tbl.col`、`view.col`。也可以在前面指定数据库名
- 当IS关键词之后是字符串时，是将comment修改为新的comment；如果是null，则是删除指定comment
- 用户须对表或视图有alter权限

### 注意事项

在更改表或视图的comment时，要留意自己要修改的是表还是视图。

### 示例

修改表comment：

```sql
COMMENT ON TABLE test::test_table IS 'the new comment';
```

修改字段comment：

```sql
COMMENT ON COLUMN test::test_table.cint IS 'the new comment';
```

## 增加、修改字段

### 重要说明

TDW默认不支持修改字段类型，`ALTER TABLE`只是修改表元数据中定义的字段类型，已存在的数据依然是修改前类型。用户需要谨慎考虑前后类型的兼容性，只建议用户修改无数据的表。

执行`ALTER TABLE`前需要添加参数：

```sql
SET hive.alterschema.without.check=true;
```

如果文件中字段类型与元数据定义类型不一致，读取数据时引擎会抛异常：

```
java.lang.ClassCastException: org.apache.hadoop.io.BooleanWritable cannot be cast to org.apache.hadoop.io.IntWritable
```

因此建议修改完字段类型后重写数据。

### 基本语法

增加字段：

```sql
ALTER TABLE <table_name> ADD COLUMNS (col_name data_type [COMMENT col_comment],...)
```

修改字段：

```sql
ALTER TABLE <table_name> CHANGE [COLUMN] col_old_name col_new_name new_data_type [COMMENT col_comment]
```

### 说明

0. 文本表暂不支持修改表结构
1. 建议对外表不要修改schema（禁止）
2. PB表不允许修改schema（[pb表字段更新参考](https://iwiki.woa.com/p/1426746897#更新pb表)）
3. 对内表中的分区字段和索引字段不允许修改schema
4. 增加字段的功能，只能加在表的末尾
5. 减少列和替换所有列（replace）功能暂时不支持（tdw做了存储压缩，数据结构化后，字段顺序固定了，目前要实现中间插入或删除比较难）
6. 用户必须对表有alter权限

### 注意事项

Hive官方版本支持所有字段的替换操作（replace功能），TDW目前不开放这个功能。

### 示例

给表增加两个INT型字段key1和key2：

```sql
ALTER TABLE test ADD COLUMNS (key1 INT, key2 INT);
```

修改列名：

```sql
ALTER TABLE test CHANGE COLUMN key1 key_1 INT;
```

修改字段类型：

```sql
SET hive.alterschema.without.check=true;
ALTER TABLE test_table CHANGE COLUMN oldname_column new_column INT COMMENT 'new col';
```

## 增加、修改table/serde properties

### 基本语法

```sql
ALTER TABLE table_name SET TBLPROPERTIES(KEY=VALUE);
ALTER TABLE table_name SET SERDEPROPERTIES(KEY=VALUE);
```

### 说明

常用的serde property：

- `field.delim`: 字段分隔符
- `line.delim`: 行分隔符
- `colelction.delim`: array类型中元素之间的分隔符
- `escape.delim`: 转义符

### 特殊的表属性

**orc.compress**：orc表设置默认的压缩格式，支持 ZLIB(默认)、SNAPPY、ZSTD(推荐)、LZO

示例：

```sql
ALTER TABLE test_orc_table SET TBLPROPERTIES('orc.compress' = 'ZSTD');
```

## 查看表信息

### 获得表的元数据信息

#### 基本语法

```sql
DESCRIBE [EXTENDED] <table_name>[DOT col_name]
```

或简写为：

```sql
DESC [EXTENDED] <table_name>[DOT col_name]
```

#### 说明

- 如果不带`EXTENDED`，则只返回表的列信息，或者指定的列信息
- 如果带有`EXTENDED`，则除了返回上面的信息，还会返回表的元数据信息

#### 示例

显示表kv的表字段信息：

```sql
DESCRIBE kv
```

结果：

```
key     int
value   string
key2    int
key3    int
```

显示表kv的详细信息：

```sql
DESCRIBE EXTENDED kv
```

结果：

```
key     int
value   string
key2    int
key3    int

Detailed Table Information

lastAccessTime:0, retention:0, sd:StorageDescriptor(cols:[FieldSchema(name:key, 
type:int, comment:null), FieldSchema(name:value, type:string, comment:null),

```

只返回某一列的信息。对表：

```sql
CREATE TABLE map_test (key MAP<INT,STRING>);
```

想获得key这个字段的信息：

```sql
DESCRIBE map_test.key
```

结果：

```
key     map<int,string>     from deserializer
```

### 获得列名中包含指定表达式的列定义信息

#### 基本语法

```sql
DESCRIBE <table_name> WHERE column_name CONTAINS "regexp";
```

#### 说明

`regexp`为正则表达式。

#### 示例

显示表kv的表字段信息：

```sql
DESCRIBE kv
```

结果：

```
key     int
value   string
key2    int
key3    int
```

显示表kv中列名中包含key的列信息：

```sql
DESCRIBE kv WHERE column_name CONTAINS "key.*";
```

结果：

```
key     int
key2    int
key3    int
```

## 使用注意事项

### 修改表注意事项

1. **重命名表**
   - 表重命名后，相关的视图和权限需要更新
   - 新表名不能与现有表冲突

2. **修改comment**
   - 注意区分表和视图
   - 可以使用NULL来删除comment

3. **修改字段**
   - 文本表不支持修改表结构
   - 修改字段类型需要谨慎，确保数据兼容性
   - 建议修改完字段类型后重写数据

4. **修改表属性**
   - 某些属性修改后不可逆
   - 建议在测试环境先验证

### 查看表注意事项

1. **权限要求**
   - 需要表的读权限才能查看表信息
   - DESCRIBE需要SELECT权限

2. **性能考虑**
   - DESC命令执行快速
   - DESC EXTENDED会返回更多信息，可能需要更长时间

## 完整示例

```sql
-- 创建测试表
CREATE TABLE test_table (
    id BIGINT,
    name STRING
)
COMMENT '测试表';

-- 1. 重命名表
ALTER TABLE test_table RENAME TO production_table;

-- 2. 修改表注释
COMMENT ON TABLE production_table IS '生产环境数据表';

-- 3. 添加字段
ALTER TABLE production_table ADD COLUMNS (
    age INT COMMENT '年龄',
    email STRING COMMENT '邮箱'
);

-- 4. 修改字段comment
COMMENT ON COLUMN production_table.age IS '用户年龄';

-- 5. 设置表属性（ORC压缩）
ALTER TABLE production_table SET TBLPROPERTIES('orc.compress' = 'ZSTD');

-- 6. 查看表结构
DESCRIBE production_table;

-- 7. 查看详细信息
DESCRIBE EXTENDED production_table;

-- 8. 查看特定字段
DESCRIBE production_table.name;

-- 9. 查看匹配的字段
DESCRIBE production_table WHERE column_name CONTAINS "a.*";
```
