# Delete语句

## 格式

```sql
DELETE FROM <table_name> [PARTITION(partname) tabalias] [WHERE where_definition]
```

## 说明

TDW支持三种删除数据的方式：

1. 对于非分区表，通过Delete语句的方式支持记录级的删除（TDWV0.2R090开始支持）。
2. 对于分区表，支持分区级的删除。
3. 当delete语句中包含`where_definition`时，分区表必须指定分区：
   - 如果包含二级分区则必须携带二级分区：`DELETE FROM table_name PARTITION(par_name, sub_par_name) p WHERE id > 1`
   - 如果只包含一级分区则必须携带一级分区：`DELETE FROM table_name PARTITION(par_name) p WHERE id > 1`
4. 可以参考update，来达到删除数据的目的。

`table_name`表中有些行满足由`where_definition`给定的条件，DELETE用于删除这些行。

如果编写的DELETE语句中没有WHERE子句，将删除表中所有的行。

## 注意事项

### 并发控制

如果被删除的表正在被使用，Delete操作的原子性无法保证，用户最好在确保表在未使用时进行Delete操作。

对于update、delete操作同一张表的时候，一定要保证这些操作是串行的，否则可能引发正在运行的select操作失败。只并行select操作同一张表是没有问题的。

### EXISTS子查询限制

- Delete语句中的`where_definition`如果使用exists，则只能使用单个exists，也不能使用and语句和其他条件一起使用。
- Delete语句中的`where_definition`如果使用exists，不能使用`NOT EXISTS`。

### HDFS外表操作

Delete操作可以对HDFS外表进行，但HDFS外表不支持带where条件的delete语句，不带where条件的delete语句相当于truncate，该操作会删除hdfs上的数据，操作需谨慎。

## 示例

### 示例1：删除全部数据

```sql
DELETE FROM table_name;
```

### 示例2：带条件删除（非分区表）

```sql
DELETE FROM table_name WHERE id > 100;
```

### 示例3：分区表删除（一级分区）

```sql
DELETE FROM table_name PARTITION(par_name) p WHERE id > 1;
```

### 示例4：分区表删除（二级分区）

```sql
DELETE FROM table_name PARTITION(par_name, sub_par_name) p WHERE id > 1;
```
