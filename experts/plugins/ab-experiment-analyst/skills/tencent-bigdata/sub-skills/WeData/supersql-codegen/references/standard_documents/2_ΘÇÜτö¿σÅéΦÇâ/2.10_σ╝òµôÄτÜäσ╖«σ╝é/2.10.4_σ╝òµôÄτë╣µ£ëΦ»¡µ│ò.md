# 2.10.4 引擎特有语法

## 概述

以下语法为引擎特有，**SuperSQL不会对其进行适配和改写**，仅支持直接路由至引擎执行，语义的一致性需要用户自己保证。

---

## StarRocks特有语法

| 语法/特性 | 说明 |
|-----------|------|
| `CROSS JOIN UNNEST` | 展开数组或MAP类型 |
| `SEMI / ANTI JOIN` | 半连接和反连接 |
| `bitmap类型` | 不支持bitmap类型及其相应功能 |
| `CREATE FUNCTION` | 目前暂未支持StarRocks的自定义UDF |
| Lambda表达式 | `parameter -> expression` 形式的Lambda |
| JSON类型 | 不支持json类型，如果返回结果为json，只会作为字符串返回。因此不支持`cast(expr as JSON)`也不支持常量`JSON '[[1, 23], 456]'` |
| `DELETE`指定分区名 | SuperSQL侧语法已支持，但仅支持THive，未面向StarRocks放开 |
| `INSERT`指定分区名 | 同理，INSERT指定分区名也仅支持THive |
| 导入语法 | `INSERT { INTO \| OVERWRITE } [db_name.]<table_name> [ PARTITION (...) ] ...` |
| 导出语法 | `INSERT INTO FILES()` |
| 其他命令SQL | 如`ALTER LOAD`、`SHOW LOAD` |
| 字典函数 | `dict_mapping` |
| 表函数 | `FILES`、`generate_series` |
| `transform_keys`/`transform_values` | 不支持lambda转换 |
| `JSON_EACH` | 不支持 |

---

## Presto特有语法

| 语法/特性 | 说明 |
|-----------|------|
| `CROSS JOIN UNNEST` | 展开数组或MAP类型 |
| 不支持的数据类型 | Floating-Point、Fixed-Precision、T-Digest、SetDigest、Quantile Digest、Network Address、UUID、HyperLogLog、KHyperLogLog |
| `CREATE FUNCTION` | 目前暂未支持Presto的自定义UDF |
| Lambda表达式 | `parameter -> expression` 形式的Lambda |
| JSON函数中的箭头 | `json_object_expr -> json_path` |
| Decimal Literals | `DECIMAL 'xxxxxxx.yyyyyyy'`（需要使用cast将常量转换为decimal类型） |
| JSON类型 | 不支持json类型 |
| Prepare Statement | `PREPARE statement_name FROM statement`（仅支持JDBC的prepare statement） |
| 执行Prepare Statement | `EXECUTE statement_name [ USING parameter1 [, ...] ]` |
| cast复杂类型 | 如`CAST(JSON '[null]' AS ARRAY(JSON))` |
| 调用过程 | `CALL procedure_name ( [ name => ] expression [, ...] )` |
| 其他命令SQL | 如`DESCRIBE INPUT statement_name` |

---

## 使用建议

### 何时使用透传模式

1. **StarRocks bitmap功能**
```sql
-- 必须使用透传模式到StarRocks
SELECT bitmap_count(user_ids) FROM stats;
```

2. **Lambda表达式**
```sql
-- StarRocks/Presto特有
SELECT transform(array_col, x -> x * 2) FROM table1;
```

3. **引擎特有的表函数**
```sql
-- StarRocks特有
SELECT * FROM FILES(...);
```
