# 2.17.3 语法差异

## VALUES子句

### 原始语法（不支持）

```sql
SELECT * FROM (
  VALUES (1, 2),
         (3, 4),
         (5, 6)
) AS t(col1, col2)
```

**问题**：直接使用VALUES构造表在某些引擎中不支持。

### 改写后的语法（推荐）

```sql
SELECT * FROM (
  SELECT 1 col1, 2 col2 FROM (SELECT 0 ZERO FROM supersql_temptable::default_table LIMIT 1) supersql_t0
  UNION ALL
  SELECT 3 col1, 4 col2 FROM (SELECT 0 ZERO FROM supersql_temptable::default_table LIMIT 1) supersql_t2
  UNION ALL
  SELECT 5 col1, 6 col2 FROM (SELECT 0 ZERO FROM supersql_temptable::default_table LIMIT 1) supersql_t4
) supersql_t6
```

**说明**：使用内置表`supersql_temptable::default_table`作为数据源。

## GROUPING SETS

### 原始语法

```sql
SELECT cint, cstring 
FROM test.supersql_temp 
GROUP BY cint, cstring, GROUPING SETS(cdouble, cstring)
```

### Spark要求的语法

```sql
SELECT cint, cstring 
FROM test.supersql_temp 
GROUP BY cint, cstring, cdouble
GROUPING SETS((cint, cstring, cdouble), (cint, cstring))
```

**说明**：Spark要求将GROUP BY涉及的字段提取到GROUPING SETS组合之前。

## GROUPING函数

### 函数对比

| 函数名 | THive/Spark | StarRocks/Presto |
|--------|-------------|------------------|
| 单列分组 | `GROUPING(col1, col2)` | 支持 |
| 多列分组ID | `GROUPING_ID(col1, col2)` | 支持 |
