# 运算符

## 概述

天穹 SQL 支持多种类型的运算符，用于构建 SQL 语句执行数据检索和操作。主要运算符类型包括：

- 关系运算符
- 算术运算符
- 位运算符
- 逻辑运算符
- 字符操作符

## 关系运算符

关系运算符用于比较两个值，返回 BOOLEAN 类型结果（TRUE、FALSE 或 NULL）。

| 运算符 | 说明 | 语法与规则 |
|--------|------|-----------|
| `=` | 等于 | `A = B`<br>• 若 A 或 B 为 NULL，返回 NULL<br>• A 等于 B 返回 TRUE，否则 FALSE |
| `<>` 或 `!=` | 不等于 | `A <> B` 或 `A != B`<br>• 若 A 或 B 为 NULL，返回 NULL<br>• A 不等于 B 返回 TRUE，否则 FALSE |
| `<` | 小于 | `A < B`<br>• 若 A 或 B 为 NULL，返回 NULL<br>• A 小于 B 返回 TRUE，否则 FALSE |
| `<=` | 小于等于 | `A <= B`<br>• 若 A 或 B 为 NULL，返回 NULL<br>• A 小于等于 B 返回 TRUE，否则 FALSE |
| `>` | 大于 | `A > B`<br>• 若 A 或 B 为 NULL，返回 NULL<br>• A 大于 B 返回 TRUE，否则 FALSE |
| `>=` | 大于等于 | `A >= B`<br>• 若 A 或 B 为 NULL，返回 NULL<br>• A 大于等于 B 返回 TRUE，否则 FALSE |
| `<=>` | 安全等于 | `A <=> B`<br>• 若 A 和 B 都为 NULL，返回 TRUE<br>• 若只有一个为 NULL，返回 FALSE<br>• 否则判断是否相等 |
| `IS NULL` | 判断为空 | `A IS NULL`<br>• 若 A 为 NULL 返回 TRUE，否则 FALSE |
| `IS NOT NULL` | 判断非空 | `A IS NOT NULL`<br>• 若 A 不为 NULL 返回 TRUE，否则 FALSE |
| `LIKE` | 模糊匹配 | `A LIKE B`<br>• A 为字符串，B 为模式<br>• `%` 匹配任意多个字符<br>• `_` 匹配单个字符 |
| `RLIKE` 或 `REGEXP` | 正则匹配 | `A RLIKE B`<br>• B 为正则表达式<br>• 匹配成功返回 TRUE |
| `IN` | 包含于 | `A IN (B, C, D...)`<br>• 若 A 在集合中返回 TRUE |
| `NOT IN` | 不包含于 | `A NOT IN (B, C, D...)`<br>• 若 A 不在集合中返回 TRUE |
| `BETWEEN AND` | 范围判断 | `A BETWEEN B AND C`<br>• 若 A 在 [B, C] 闭区间内返回 TRUE |
| `NOT BETWEEN AND` | 范围外判断 | `A NOT BETWEEN B AND C`<br>• 若 A 不在 [B, C] 闭区间内返回 TRUE |

### 使用示例

```sql
-- 等于
SELECT * FROM users WHERE user_id = '0001';

-- 不等于
SELECT * FROM users WHERE user_name <> 'admin';

-- 大于小于
SELECT * FROM products WHERE price > 100 AND price <= 500;

-- IS NULL
SELECT * FROM orders WHERE remark IS NULL;

-- LIKE 模糊匹配
SELECT * FROM users WHERE email LIKE '%@tencent.com';
SELECT * FROM users WHERE phone LIKE '138________';  -- 8个下划线

-- LIKE 转义
SELECT * FROM files WHERE filename LIKE '%.txt';    -- 匹配 .txt 结尾
SELECT * FROM codes WHERE content LIKE '%10\\%%';   -- 匹配包含 '10%' 的内容

-- IN
SELECT * FROM orders WHERE status IN ('pending', 'processing', 'shipped');

-- BETWEEN
SELECT * FROM employees WHERE age BETWEEN 25 AND 35;
SELECT * FROM logs WHERE create_time BETWEEN '2024-01-01' AND '2024-12-31';

-- 组合使用
SELECT * FROM users 
WHERE age > 18 
  AND city IN ('深圳', '北京', '上海')
  AND email IS NOT NULL;
```

### 注意事项

#### 1. NULL 值处理

大多数关系运算符遇到 NULL 时返回 NULL（而非 FALSE）：

```sql
SELECT NULL = 1;        -- 返回: NULL
SELECT NULL <> 1;       -- 返回: NULL
SELECT 1 IN (NULL, 2);  -- 返回: NULL

-- 判断 NULL 必须使用 IS NULL
SELECT col IS NULL;     -- ✅ 正确
SELECT col = NULL;      -- ❌ 错误，永远返回 NULL
```

#### 2. 安全等于 `<=>` 的使用

当需要比较两个可能为 NULL 的值时，使用 `<=>`：

```sql
-- 普通等于
SELECT NULL = NULL;     -- 返回: NULL

-- 安全等于
SELECT NULL <=> NULL;   -- 返回: TRUE
SELECT 1 <=> 1;         -- 返回: TRUE
SELECT 1 <=> NULL;      -- 返回: FALSE
```

#### 3. DOUBLE 类型比较

不建议直接对 DOUBLE 类型使用 `=` 比较，因浮点精度问题可能导致误判：

```sql
-- ❌ 不推荐
SELECT * FROM table WHERE price = 99.99;

-- ✅ 推荐：使用范围或 ABS
SELECT * FROM table WHERE ABS(price - 99.99) < 0.01;
```

## 算术运算符

算术运算符用于数值计算。

| 运算符 | 说明 | 语法与规则 |
|--------|------|-----------|
| `+` | 加法 | `A + B`<br>• 若任一为 NULL，返回 NULL |
| `-` | 减法 | `A - B`<br>• 若任一为 NULL，返回 NULL |
| `*` | 乘法 | `A * B`<br>• 若任一为 NULL，返回 NULL |
| `/` | 除法 | `A / B`<br>• 若任一为 NULL，返回 NULL<br>• **注意**：BIGINT 相除返回 DOUBLE 类型 |
| `%` | 取余（模） | `A % B`<br>• 若任一为 NULL，返回 NULL |
| `DIV` | 整除 | `A DIV B`<br>• 返回整数商，舍弃小数部分 |
| `+A` | 正号 | 返回 A 本身 |
| `-A` | 负号 | 返回 A 的相反数 |

### 数据类型说明

- **支持的类型**：BIGINT、DOUBLE、DECIMAL、STRING（会隐式转换为 DOUBLE）
- **隐式转换规则**：
  - STRING 参与运算时，会隐式转换为 DOUBLE
  - BIGINT 和 DOUBLE 混合计算时，BIGINT 转为 DOUBLE，结果为 DOUBLE
  - TIMESTAMP 类型可参与部分运算（日期加减）

### 使用示例

```sql
-- 基本运算
SELECT 10 + 5;          -- 返回: 15
SELECT 10 - 3;          -- 返回: 7
SELECT 10 * 2;          -- 返回: 20
SELECT 10 / 3;          -- 返回: 3.3333333333333335 (DOUBLE)
SELECT 10 % 3;          -- 返回: 1
SELECT 10 DIV 3;        -- 返回: 3 (整除)

-- 在查询中使用
SELECT 
    product_name,
    price,
    price * 0.9 AS discounted_price,      -- 打9折
    price * quantity AS total_amount       -- 总金额
FROM orders;

-- 日期运算
SELECT 
    order_date,
    order_date + INTERVAL 7 DAY AS delivery_date,
    DATEDIFF(CURRENT_DATE, order_date) AS days_ago
FROM orders;

-- 复杂计算
SELECT 
    sal,
    sal * 12 AS annual_salary,             -- 年薪
    sal * 12 * 0.2 AS annual_bonus,        -- 年度奖金（20%）
    (sal * 12) * (1 + 0.2) AS total_income -- 总收入
FROM employees;
```

### 注意事项

#### 1. 除法返回类型

```sql
-- BIGINT 相除返回 DOUBLE
SELECT 10 / 3;          -- 返回: 3.3333... (DOUBLE)

-- 如果需要整除，使用 DIV
SELECT 10 DIV 3;        -- 返回: 3 (BIGINT)

-- 或使用 CAST 转换
SELECT CAST(10 / 3 AS BIGINT);  -- 返回: 3
```

#### 2. 除零处理

```sql
SELECT 10 / 0;          -- 返回: NULL（不会报错）
SELECT 10 % 0;          -- 返回: NULL
```

#### 3. NULL 值传播

任何数值与 NULL 运算，结果都是 NULL：

```sql
SELECT 10 + NULL;       -- 返回: NULL
SELECT NULL * 5;        -- 返回: NULL
SELECT SUM(col) FROM table WHERE col IS NOT NULL;  -- 避免 NULL 影响
```

## 位运算符

位运算符按照二进制位进行运算。**注意：只允许 BIGINT 类型参与位运算，不支持隐式转换。**

| 运算符 | 别名 | 说明 | 示例 |
|--------|------|------|------|
| `BITAND` | `&` | 按位与 | `1 & 2` 返回 0<br>`BITAND(1, 3)` 返回 1 |
| `BITOR` | `\|` | 按位或 | `1 \| 2` 返回 3<br>`BITOR(1, 3)` 返回 3 |
| `BITXOR` | `^` | 按位异或 | `1 ^ 2` 返回 3<br>`BITXOR(4, 5)` 返回 1 |
| `BITNOT` | `~` | 按位非 | `~1` 返回 -2<br>`BITNOT(7)` 返回 -8 |

### 使用示例

```sql
-- 按位与
SELECT 5 & 3;           -- 返回: 1  (二进制: 101 & 011 = 001)
SELECT BITAND(12, 10);  -- 返回: 8  (二进制: 1100 & 1010 = 1000)

-- 按位或
SELECT 5 | 3;           -- 返回: 7  (二进制: 101 | 011 = 111)
SELECT BITOR(12, 10);   -- 返回: 14 (二进制: 1100 | 1010 = 1110)

-- 按位异或
SELECT 5 ^ 3;           -- 返回: 6  (二进制: 101 ^ 011 = 110)
SELECT BITXOR(12, 10);  -- 返回: 6  (二进制: 1100 ^ 1010 = 0110)

-- 按位非
SELECT ~5;              -- 返回: -6 (二进制取反后补码)
SELECT BITNOT(0);       -- 返回: -1
```

### 应用场景

位运算常用于：
- 权限管理（位标志）
- 状态位存储
- 高效的集合运算

```sql
-- 权限示例：读(1)、写(2)、执行(4)
-- 用户权限为 7 = 111b，表示拥有读写执行权限

-- 检查是否有读权限
SELECT (user_permission & 1) > 0 AS has_read;

-- 检查是否有写权限
SELECT (user_permission & 2) > 0 AS has_write;

-- 添加执行权限
SELECT user_permission | 4 AS new_permission;
```

## 逻辑运算符

逻辑运算符用于多条件组合。**只允许 BOOLEAN 类型参与运算，不支持隐式类型转换。**

| 运算符 | 说明 | 真值表 |
|--------|------|--------|
| `AND` | 逻辑与 | TRUE AND TRUE = TRUE<br>TRUE AND FALSE = FALSE<br>FALSE AND FALSE = FALSE<br>TRUE AND NULL = NULL<br>FALSE AND NULL = FALSE<br>NULL AND NULL = NULL |
| `OR` | 逻辑或 | TRUE OR TRUE = TRUE<br>TRUE OR FALSE = TRUE<br>FALSE OR FALSE = FALSE<br>TRUE OR NULL = TRUE<br>FALSE OR NULL = NULL<br>NULL OR NULL = NULL |
| `NOT` | 逻辑非 | NOT TRUE = FALSE<br>NOT FALSE = TRUE<br>NOT NULL = NULL |

### 使用示例

```sql
-- AND：所有条件都必须为 TRUE
SELECT * FROM users 
WHERE age > 18 
  AND city = '深圳' 
  AND status = 'active';

-- OR：任一条件为 TRUE 即可
SELECT * FROM orders 
WHERE status = 'pending' 
   OR status = 'processing';

-- NOT：条件取反
SELECT * FROM users 
WHERE NOT (age < 18);  -- 等价于 age >= 18

-- 组合使用
SELECT * FROM products 
WHERE (category = 'electronics' OR category = 'books')
  AND price < 1000
  AND stock > 0;
```

### 注意事项

#### 1. 短路求值

- `AND`：第一个条件为 FALSE 时，不再评估后续条件
- `OR`：第一个条件为 TRUE 时，不再评估后续条件

```sql
-- 利用短路特性避免除零错误
SELECT * FROM table 
WHERE count > 0 AND total / count > 100;
-- count > 0 为 FALSE 时，不会执行 total / count
```

#### 2. NULL 值处理

NULL 在逻辑运算中有特殊行为：

```sql
SELECT TRUE AND NULL;   -- 返回: NULL
SELECT FALSE AND NULL;  -- 返回: FALSE（短路）
SELECT TRUE OR NULL;    -- 返回: TRUE（短路）
SELECT FALSE OR NULL;   -- 返回: NULL
```

#### 3. 三值逻辑

SQL 采用三值逻辑（TRUE、FALSE、NULL），这与编程语言的二值逻辑不同：

```sql
-- 在 WHERE 子句中，只有结果为 TRUE 的行才会被返回
-- FALSE 和 NULL 都会被过滤掉

SELECT * FROM users WHERE age > 18;
-- 只返回 age > 18 为 TRUE 的行
-- age IS NULL 的行会被过滤（因为 NULL > 18 返回 NULL）
```

## 字符操作符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `\|\|` | 字符串连接 | `'Hello' \|\| ' ' \|\| 'World'` 返回 `'Hello World'`<br>等同于 `CONCAT('Hello', ' ', 'World')` |

### 使用示例

```sql
-- 字符串连接
SELECT 'Hello' || ' ' || 'World';  
-- 返回: Hello World

SELECT first_name || ' ' || last_name AS full_name FROM users;

-- 与 CONCAT 等价
SELECT CONCAT(first_name, ' ', last_name) AS full_name FROM users;

-- 连接多个字段
SELECT 
    '用户：' || user_name || '，年龄：' || CAST(age AS STRING) AS user_info
FROM users;
```

## 运算符优先级

运算符优先级从高到低排列（1 为最高优先级）：

| 优先级 | 运算符 |
|--------|--------|
| 1 | `IS (NOT) NULL` |
| 2 | `^` (异或) |
| 3 | `*`, `/`, `%`, `DIV` |
| 4 | `+`, `-` |
| 5 | `\|\|` (字符串连接) |
| 6 | `&` (按位与) |
| 7 | `\|` (按位或) |
| 8 | `=`, `<>`, `!=`, `<`, `<=`, `>`, `>=`, `LIKE`, `RLIKE`, `IN` |
| 9 | `BETWEEN AND` |
| 10 | `NOT` |
| 11 | `AND` |
| 12 | `OR` |

### 优先级示例

```sql
-- AND 优先级高于 OR
SELECT * FROM table WHERE a = 1 AND b = 2 OR c = 3;
-- 等价于: (a = 1 AND b = 2) OR c = 3

-- 使用括号改变优先级
SELECT * FROM table WHERE a = 1 AND (b = 2 OR c = 3);

-- 算术运算优先于比较运算
SELECT * FROM table WHERE price * 0.9 > 100;
-- 等价于: (price * 0.9) > 100

-- 复杂表达式
SELECT * FROM table 
WHERE col1 + col2 * 3 > 100 
  AND status IN ('A', 'B') 
  OR type = 'X';
-- 执行顺序: col2 * 3 → col1 + ... → > 100 → IN → AND → OR
```

### 最佳实践

1. **使用括号明确意图**，提高可读性：
   ```sql
   -- ✅ 推荐
   WHERE (status = 'active') AND ((age > 18) OR (vip_level > 3))
   
   -- ❌ 不推荐（依赖隐式优先级）
   WHERE status = 'active' AND age > 18 OR vip_level > 3
   ```

2. **复杂条件分行书写**：
   ```sql
   SELECT * FROM orders
   WHERE 
       (status = 'pending' OR status = 'processing')
       AND order_date >= '2024-01-01'
       AND total_amount > 1000;
   ```

## 常见问题

### Q1：为什么 `WHERE col = NULL` 查不到数据？

A：NULL 不能用 `=` 比较，必须使用 `IS NULL`：

```sql
-- ❌ 错误
WHERE col = NULL

-- ✅ 正确
WHERE col IS NULL
```

### Q2：如何处理可能为 NULL 的计算？

A：使用 `COALESCE` 或 `IFNULL` 提供默认值：

```sql
SELECT price * COALESCE(discount, 1) AS final_price FROM products;
SELECT price * IFNULL(discount, 1) AS final_price FROM products;
```

### Q3：BIGINT 除法为什么返回小数？

A：天穹 SQL 中，两个整数相除会返回 DOUBLE 类型。如需整除，使用 `DIV`：

```sql
SELECT 10 / 3;      -- 返回: 3.333...
SELECT 10 DIV 3;    -- 返回: 3
```
