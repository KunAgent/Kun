# with语句

## 格式

```sql
[INSERT [OVERWRITE] INTO TABLE destination]
WITH alias_name1 AS (subquery1),
     alias_name2 AS (subQuery2),
     ......
     alias_nameN AS (subQueryN)
SELECT col1, col2, ..., col3
FROM alias_name1, alias_name2, ..., alias_nameN
```

## 说明

1. 如果前面有insert，语法为`INSERT [OVERWRITE] INTO TABLE tablename`，这跟跟传统关系数据库可能会不一致。
2. 最后的主查询语句必须是select语句，暂时不支持update和delete。
3. 暂不支持`WITH RECURSIVE`这种递归调用的高级用法。
4. 主查询select语句from后面也可跟子查询，并不限于上面的示例。

## 示例

### 基本示例

```sql
WITH temp_table AS (
  SELECT id, name FROM users WHERE age > 18
)
SELECT * FROM temp_table WHERE name LIKE 'A%';
```

### 多个CTE

```sql
WITH
  sales_data AS (
    SELECT product_id, SUM(amount) AS total_sales
    FROM sales
    GROUP BY product_id
  ),
  product_info AS (
    SELECT id, name, category
    FROM products
  )
SELECT p.name, p.category, s.total_sales
FROM product_info p
JOIN sales_data s ON p.id = s.product_id;
```

### WITH + INSERT

```sql
WITH filtered_data AS (
  SELECT user_id, order_date, amount
  FROM orders
  WHERE order_date >= '2025-01-01'
)
INSERT OVERWRITE INTO TABLE summary_table
SELECT user_id, COUNT(*) AS order_count, SUM(amount) AS total_amount
FROM filtered_data
GROUP BY user_id;
```

## 注意事项

- 主查询必须是SELECT语句
- 不支持递归CTE
- CTE可以提高SQL可读性和维护性
- 多个CTE之间可以相互引用
