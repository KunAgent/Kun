# 数据类型转换

## 概述

数据类型转换是 SQL 中常见的操作，用于在不同数据类型之间进行转换。天穹 SQL 支持显式类型转换和隐式类型转换，了解转换规则有助于避免数据丢失和类型错误。

## 转换方式

### 显式类型转换

使用 `CAST` 函数或特定类型转换函数明确指定类型转换。

```sql
-- CAST 函数
CAST(expression AS target_type)

-- 示例
SELECT CAST('123' AS BIGINT);           -- '123' → 123
SELECT CAST(123.45 AS INT);             -- 123.45 → 123
SELECT CAST(CURRENT_TIMESTAMP AS STRING); -- 当前时间 → 字符串
```

### 隐式类型转换

在特定场景下，系统自动进行类型转换。

```sql
-- 数值运算中的隐式转换
SELECT 1 + 1.5;                         -- INT + DOUBLE → DOUBLE（结果 2.5）

-- 比较运算中的隐式转换
SELECT 100 = '100';                     -- STRING 转为 BIGINT 比较

-- 函数调用中的隐式转换
SELECT CONCAT('Total: ', 100);          -- INT 转为 STRING
```

## 数值类型转换

### 整数类型之间的转换

| 源类型 | 目标类型 | 说明 |
|-------|---------|------|
| `TINYINT` | `SMALLINT`/`INT`/`BIGINT` | 安全，无数据丢失 |
| `SMALLINT` | `INT`/`BIGINT` | 安全，无数据丢失 |
| `INT` | `BIGINT` | 安全，无数据丢失 |
| `BIGINT` | `INT`/`SMALLINT`/`TINYINT` | 可能溢出，需注意 |

**示例：**
```sql
-- 向上转换（安全）
SELECT CAST(100 AS BIGINT);             -- TINYINT → BIGINT: 100

-- 向下转换（可能溢出）
SELECT CAST(1000 AS TINYINT);           -- INT → TINYINT: 溢出（结果-24）
SELECT CAST(2147483648 AS INT);         -- BIGINT → INT: 溢出
```

### 整数与浮点数转换

| 源类型 | 目标类型 | 说明 |
|-------|---------|------|
| 整数 | `FLOAT`/`DOUBLE` | 可能损失精度 |
| `FLOAT`/`DOUBLE` | 整数 | 截断小数部分 |

**示例：**
```sql
-- 整数 → 浮点数
SELECT CAST(123 AS DOUBLE);             -- 123 → 123.0

-- 浮点数 → 整数（截断）
SELECT CAST(123.789 AS INT);            -- 123.789 → 123
SELECT CAST(-123.789 AS INT);           -- -123.789 → -123

-- 精度损失
SELECT CAST(9999999999999999 AS DOUBLE); -- 可能损失精度
```

### 浮点数之间的转换

| 源类型 | 目标类型 | 说明 |
|-------|---------|------|
| `FLOAT` | `DOUBLE` | 安全，无精度损失 |
| `DOUBLE` | `FLOAT` | 可能损失精度 |

**示例：**
```sql
-- FLOAT → DOUBLE（安全）
SELECT CAST(123.45 AS DOUBLE);

-- DOUBLE → FLOAT（可能损失精度）
SELECT CAST(123.123456789 AS FLOAT);
```

### DECIMAL 类型转换

| 转换类型 | 说明 |
|---------|------|
| 整数 → `DECIMAL` | 安全，保持精度 |
| 浮点数 → `DECIMAL` | 近似转换 |
| `DECIMAL` → 整数 | 截断小数部分 |
| `DECIMAL` → 浮点数 | 可能损失精度 |

**示例：**
```sql
-- 整数 → DECIMAL
SELECT CAST(123 AS DECIMAL(10,2));      -- 123 → 123.00

-- DECIMAL → 整数
SELECT CAST(123.789 AS INT);            -- 123.789 → 123

-- DECIMAL 精度调整
SELECT CAST(123.456 AS DECIMAL(10,1));  -- 123.456 → 123.5（四舍五入）
SELECT CAST(123.456 AS DECIMAL(5,2));   -- 123.456 → 123.46
```

## 字符串与数值转换

### 字符串 → 数值

```sql
-- 字符串 → 整数
SELECT CAST('123' AS BIGINT);           -- '123' → 123
SELECT CAST('-456' AS INT);             -- '-456' → -456

-- 字符串 → 浮点数
SELECT CAST('123.45' AS DOUBLE);        -- '123.45' → 123.45
SELECT CAST('1.23E5' AS DOUBLE);        -- '1.23E5' → 123000.0

-- 字符串 → DECIMAL
SELECT CAST('123.456' AS DECIMAL(10,2)); -- '123.456' → 123.46

-- 非法字符串转换
SELECT CAST('abc' AS INT);              -- 错误或 NULL
SELECT CAST('12.34.56' AS DOUBLE);      -- 错误或 NULL
```

### 数值 → 字符串

```sql
-- 整数 → 字符串
SELECT CAST(123 AS STRING);             -- 123 → '123'
SELECT CAST(-456 AS STRING);            -- -456 → '-456'

-- 浮点数 → 字符串
SELECT CAST(123.45 AS STRING);          -- 123.45 → '123.45'
SELECT CAST(1.23E5 AS STRING);          -- 123000.0 → '123000.0'

-- DECIMAL → 字符串
SELECT CAST(123.456 AS STRING);         -- 123.456 → '123.456'
```

## 日期时间类型转换

### 字符串 → 日期时间

```sql
-- 字符串 → DATE
SELECT TO_DATE('2024-01-15');           -- '2024-01-15' → DATE
SELECT TO_DATE('20240115', 'yyyyMMdd'); -- '20240115' → DATE

-- 字符串 → DATETIME
SELECT CAST('2024-01-15 10:30:00' AS DATETIME);
SELECT TO_DATE('2024-01-15 10:30:00', 'yyyy-MM-dd HH:mm:ss');

-- 字符串 → TIMESTAMP
SELECT CAST('2024-01-15 10:30:00' AS TIMESTAMP);

-- Unix 时间戳 → DATETIME
SELECT FROM_UNIXTIME(1705305600);       -- 1705305600 → '2024-01-15 10:00:00'
```

### 日期时间 → 字符串

```sql
-- DATE → 字符串
SELECT CAST(DATE '2024-01-15' AS STRING); -- DATE → '2024-01-15'

-- DATETIME → 字符串
SELECT CAST(DATETIME '2024-01-15 10:30:00' AS STRING);
-- → '2024-01-15 10:30:00'

-- TIMESTAMP → 字符串
SELECT CAST(CURRENT_TIMESTAMP AS STRING);

-- 格式化日期时间
SELECT DATE_FORMAT(CURRENT_TIMESTAMP, 'yyyy-MM-dd HH:mm:ss');
SELECT DATE_FORMAT(DATE '2024-01-15', 'yyyy/MM/dd');
```

### 日期时间 → Unix 时间戳

```sql
-- DATETIME → Unix 时间戳
SELECT UNIX_TIMESTAMP(DATETIME '2024-01-15 10:00:00');
-- → 1705305600

-- TIMESTAMP → Unix 时间戳
SELECT UNIX_TIMESTAMP(CURRENT_TIMESTAMP);

-- DATE → Unix 时间戳（视为当天 00:00:00）
SELECT UNIX_TIMESTAMP(DATE '2024-01-15');
```

### 日期时间类型之间的转换

```sql
-- DATE → DATETIME
SELECT CAST(DATE '2024-01-15' AS DATETIME);
-- → '2024-01-15 00:00:00'

-- DATETIME → DATE
SELECT CAST(DATETIME '2024-01-15 10:30:00' AS DATE);
-- → '2024-01-15'

-- TIMESTAMP → DATETIME
SELECT CAST(CURRENT_TIMESTAMP AS DATETIME);

-- DATETIME → TIMESTAMP
SELECT CAST(DATETIME '2024-01-15 10:30:00' AS TIMESTAMP);
```

## 布尔类型转换

### 布尔 → 数值

```sql
-- BOOLEAN → 整数
SELECT CAST(TRUE AS INT);               -- TRUE → 1
SELECT CAST(FALSE AS INT);              -- FALSE → 0
```

### 数值 → 布尔

```sql
-- 整数 → BOOLEAN
SELECT CAST(0 AS BOOLEAN);              -- 0 → FALSE
SELECT CAST(1 AS BOOLEAN);              -- 1 → TRUE
SELECT CAST(123 AS BOOLEAN);            -- 非0 → TRUE
```

### 布尔 → 字符串

```sql
-- BOOLEAN → STRING
SELECT CAST(TRUE AS STRING);            -- TRUE → 'TRUE'
SELECT CAST(FALSE AS STRING);           -- FALSE → 'FALSE'
```

### 字符串 → 布尔

```sql
-- STRING → BOOLEAN
SELECT CAST('TRUE' AS BOOLEAN);         -- 'TRUE' → TRUE
SELECT CAST('true' AS BOOLEAN);         -- 'true' → TRUE
SELECT CAST('FALSE' AS BOOLEAN);        -- 'FALSE' → FALSE
SELECT CAST('1' AS BOOLEAN);            -- '1' → TRUE
SELECT CAST('0' AS BOOLEAN);            -- '0' → FALSE
```

## 二进制类型转换

### 字符串 → 二进制

```sql
-- STRING → BINARY
SELECT CAST('hello' AS BINARY);
SELECT UNHEX('48656C6C6F');             -- 十六进制 → BINARY
```

### 二进制 → 字符串

```sql
-- BINARY → STRING
SELECT CAST(BINARY 'hello' AS STRING);
SELECT HEX(BINARY 'hello');             -- BINARY → 十六进制字符串
```

## 复杂类型转换

### 数组类型转换

```sql
-- 转换数组元素类型
SELECT TRANSFORM(ARRAY(1, 2, 3), x -> CAST(x AS STRING));
-- → ['1', '2', '3']

-- 数组 → 字符串
SELECT CONCAT_WS(',', ARRAY('a', 'b', 'c'));
-- → 'a,b,c'

-- 字符串 → 数组
SELECT SPLIT('a,b,c', ',');
-- → ['a', 'b', 'c']
```

### Map 类型转换

```sql
-- 转换 Map 的值类型
SELECT TRANSFORM_VALUES(MAP('a', 1, 'b', 2), (k, v) -> CAST(v AS STRING));
-- → {'a': '1', 'b': '2'}
```

### JSON 类型转换

```sql
-- 对象 → JSON 字符串
SELECT TO_JSON(MAP('name', 'Alice', 'age', 30));
-- → '{"name":"Alice","age":30}'

-- JSON 字符串 → 对象
SELECT GET_JSON_OBJECT('{"name":"Alice","age":30}', '$.name');
-- → 'Alice'
```

## 类型转换函数

### 通用转换函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `CAST(expr AS type)` | 通用类型转换 | `CAST('123' AS INT)` |
| `CONVERT(expr, type)` | 类型转换（别名） | `CONVERT('123', INT)` |

### 数值转换函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `TO_NUMBER(str)` | 字符串 → 数值 | `TO_NUMBER('123.45')` |
| `TO_CHAR(num)` | 数值 → 字符串 | `TO_CHAR(123)` |
| `ROUND(num, d)` | 四舍五入 | `ROUND(123.456, 2)` → 123.46 |
| `FLOOR(num)` | 向下取整 | `FLOOR(123.9)` → 123 |
| `CEIL(num)` | 向上取整 | `CEIL(123.1)` → 124 |
| `TRUNC(num, d)` | 截断 | `TRUNC(123.456, 2)` → 123.45 |

### 日期转换函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `TO_DATE(str [, fmt])` | 字符串 → DATE | `TO_DATE('2024-01-15')` |
| `DATE_FORMAT(date, fmt)` | 日期 → 格式化字符串 | `DATE_FORMAT(NOW(), 'yyyy-MM-dd')` |
| `FROM_UNIXTIME(ts)` | Unix时间戳 → DATETIME | `FROM_UNIXTIME(1705305600)` |
| `UNIX_TIMESTAMP([dt])` | DATETIME → Unix时间戳 | `UNIX_TIMESTAMP(NOW())` |

### 字符串转换函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `UPPER(str)` | 转大写 | `UPPER('hello')` → 'HELLO' |
| `LOWER(str)` | 转小写 | `LOWER('HELLO')` → 'hello' |
| `TRIM(str)` | 去除空格 | `TRIM('  hello  ')` → 'hello' |

## 隐式类型转换规则

### 数值运算中的隐式转换

```sql
-- 整数 + 浮点数 → 浮点数
SELECT 1 + 1.5;                         -- 2.5 (DOUBLE)

-- 不同精度整数运算 → 高精度整数
SELECT TINYINT(1) + BIGINT(2);          -- 3 (BIGINT)

-- DECIMAL 运算保持精度
SELECT DECIMAL(10,2) '123.45' + 100;    -- 223.45 (DECIMAL)
```

### 比较运算中的隐式转换

```sql
-- 数值与字符串比较：字符串 → 数值
SELECT 100 = '100';                     -- TRUE
SELECT 100 > '50';                      -- TRUE

-- 日期与字符串比较：字符串 → 日期
SELECT DATE '2024-01-15' = '2024-01-15'; -- TRUE
```

### 函数调用中的隐式转换

```sql
-- 字符串拼接：数值 → 字符串
SELECT CONCAT('Total: ', 100);          -- 'Total: 100'

-- 数学函数：字符串 → 数值
SELECT SQRT('16');                      -- 4.0
```

## 转换优先级

当多种类型混合运算时，转换优先级（从低到高）：

```text
TINYINT → SMALLINT → INT → BIGINT → FLOAT → DOUBLE → DECIMAL → STRING
```

**示例：**
```sql
-- TINYINT + INT → INT
SELECT TINYINT(1) + INT(2);             -- 3 (INT)

-- INT + DOUBLE → DOUBLE
SELECT INT(1) + DOUBLE(2.5);            -- 3.5 (DOUBLE)

-- DOUBLE + STRING → STRING 或 DOUBLE（取决于上下文）
SELECT DOUBLE(1.5) + '2.5';             -- 4.0 (DOUBLE)
SELECT CONCAT(DOUBLE(1.5), '2.5');      -- '1.52.5' (STRING)
```

## 转换中的注意事项

### 精度损失

```sql
-- 浮点数精度问题
SELECT CAST(0.1 + 0.2 AS STRING);       -- 可能不是 '0.3'

-- 大整数转浮点数
SELECT CAST(9999999999999999 AS FLOAT); -- 精度损失

-- 使用 DECIMAL 避免精度问题
SELECT DECIMAL '0.1' + DECIMAL '0.2';   -- 0.3（精确）
```

### 溢出问题

```sql
-- 整数溢出
SELECT CAST(2147483648 AS INT);         -- 溢出

-- 除零错误
SELECT 1 / 0;                           -- 错误或 NULL

-- 使用安全除法
SELECT 1 / NULLIF(0, 0);                -- NULL（不报错）
```

### NULL 值处理

```sql
-- NULL 转换结果仍为 NULL
SELECT CAST(NULL AS INT);               -- NULL
SELECT CAST(NULL AS STRING);            -- NULL

-- 转换失败返回 NULL
SELECT CAST('abc' AS INT);              -- NULL（非法字符串）
```

### 字符串格式问题

```sql
-- 严格格式匹配
SELECT TO_DATE('2024-1-5');             -- 可能失败，应使用 '2024-01-05'

-- 使用格式模板
SELECT TO_DATE('20240115', 'yyyyMMdd'); -- 成功

-- 处理非标准格式
SELECT REGEXP_REPLACE('2024/01/15', '/', '-'); -- '2024-01-15'
```

## 最佳实践

### 1. 明确类型转换

优先使用显式转换，避免依赖隐式转换：

```sql
-- ❌ 不推荐：依赖隐式转换
SELECT '100' + 50;

-- ✅ 推荐：显式转换
SELECT CAST('100' AS INT) + 50;
```

### 2. 选择合适的目标类型

```sql
-- 金额计算使用 DECIMAL
SELECT CAST('123.45' AS DECIMAL(10,2)) * 1.1;

-- 大整数使用 BIGINT
SELECT CAST(user_id AS BIGINT);

-- 文本使用 STRING
SELECT CAST(description AS STRING);
```

### 3. 处理转换异常

```sql
-- 使用 TRY_CAST 避免错误
SELECT TRY_CAST('abc' AS INT);          -- NULL（不报错）

-- 使用 COALESCE 提供默认值
SELECT COALESCE(TRY_CAST(value AS INT), 0) FROM table;

-- 使用 CASE 处理条件转换
SELECT 
    CASE 
        WHEN value RLIKE '^\\d+$' THEN CAST(value AS INT)
        ELSE 0
    END AS num_value
FROM table;
```

### 4. 验证数据格式

```sql
-- 转换前验证格式
SELECT 
    CASE 
        WHEN date_str RLIKE '^\\d{4}-\\d{2}-\\d{2}$' 
        THEN TO_DATE(date_str)
        ELSE NULL
    END AS valid_date
FROM table;
```

### 5. 注意性能影响

```sql
-- ❌ 性能较差：频繁类型转换
SELECT * FROM large_table
WHERE CAST(id_str AS BIGINT) = 123;

-- ✅ 性能更好：存储时使用正确类型
-- 或在应用层转换后传入
```
