# 保留字与关键字

## 概述

天穹 SQL 基于 Apache Calcite 动态数据管理框架构建其 SQL Parser。保留字（Reserved Words）和关键字（Keywords）是具有特殊含义的标识符，用于定义 SQL 语句的结构和语义。了解这些保留字和关键字有助于避免命名冲突和语法错误。

**重要说明**：
- SuperSQL 基于 Apache Calcite，其关键词和保留字请参考 Apache Calcite 官方文档
- **保留字是关键词的一个子集**
- 关键词集合非常庞大，包含数百个词汇

## 保留字 vs 关键字

| 类型 | 说明 | 使用限制 |
|------|------|---------|
| **保留字** | SQL 标准定义的核心语法词汇（加粗显示） | 不能用作表名、列名、别名等标识符 |
| **关键字** | 系统保留的特殊词汇（包含保留字） | 建议避免使用，必要时需用引号转义 |

## 标识符使用规则

如果 SQL 访问的某个数据源、表或列的名称（即标识符），与 SuperSQL 的一个保留字相同（例如 `default`），则需要在标识符前后加上引号字符来使用。

### 引号字符规则

引号字符由参数 `supersql.lex` 决定：

- `lex = MYSQL`：使用反引号（`` ` ``）
- `lex = ORACLE`：使用双引号（`"`）
- **默认值**：`MYSQL`（反引号）

**注意**：反引号位于键盘数字 1 的左边，不是单引号。

### 基本示例

```sql
-- 当列名与保留字冲突时，使用反引号
SELECT `default`, `order`, `table` FROM my_table;

-- 当表名与保留字冲突时
SELECT * FROM `user` WHERE `select` = 'value';
```

## 使用保留字作为标识符

### 反引号转义

如果必须使用保留字作为标识符，需要用反引号（`` ` ``）转义：

```sql
-- ❌ 错误：直接使用保留字
CREATE TABLE select (
    order INT,
    from STRING
);

-- ✅ 正确：使用反引号转义
CREATE TABLE `select` (
    `order` INT,
    `from` STRING
);

-- 查询时也需要转义
SELECT `order`, `from` FROM `select`;
```

### 推荐做法

虽然可以使用反引号转义，但强烈建议避免使用保留字作为标识符：

```sql
-- ❌ 不推荐：使用保留字
CREATE TABLE `order` (`select` INT, `where` STRING);

-- ✅ 推荐：使用有意义的命名
CREATE TABLE order_info (order_id INT, filter_condition STRING);
```

## 常见冲突示例

### 表名冲突

```sql
-- ❌ 错误示例
CREATE TABLE user (id INT, name STRING);      -- user 是保留字
CREATE TABLE order (id INT, amount DOUBLE);   -- order 是保留字
CREATE TABLE select (id INT);                 -- select 是保留字

-- ✅ 正确示例
CREATE TABLE user_info (id INT, name STRING);
CREATE TABLE order_detail (id INT, amount DOUBLE);
CREATE TABLE selection (id INT);
```

### 列名冲突

```sql
-- ❌ 错误示例
CREATE TABLE products (
    id INT,
    name STRING,
    desc STRING,          -- desc 是保留字
    timestamp BIGINT,     -- timestamp 是保留字
    index INT             -- index 是保留字
);

-- ✅ 正确示例
CREATE TABLE products (
    id INT,
    name STRING,
    description STRING,
    create_time BIGINT,
    idx INT
);
```

### 别名冲突

```sql
-- ❌ 错误示例
SELECT 
    product_id AS select,
    price AS order,
    category AS from
FROM products;

-- ✅ 正确示例
SELECT 
    product_id AS selected_id,
    price AS order_price,
    category AS source_category
FROM products;
```

## 命名规范

### 推荐的命名约定

1. **表名**：使用复数名词或业务实体名
   ```sql
   users, orders, products, user_profiles
   ```

2. **列名**：使用小写字母和下划线
   ```sql
   user_id, create_time, order_amount
   ```

3. **别名**：简短且有意义
   ```sql
   SELECT u.user_id, o.order_id
   FROM users u
   JOIN orders o ON u.user_id = o.user_id;
   ```

4. **避免使用**：
   - 保留字和关键字
   - 单字母名称（除非是短别名）
   - 数字开头的名称
   - 特殊字符（除下划线）

### 命名最佳实践

```sql
-- ✅ 好的命名
CREATE TABLE customer_orders (
    order_id BIGINT,
    customer_id BIGINT,
    order_date STRING,
    total_amount DECIMAL(10,2),
    order_status STRING
) PARTITIONED BY (dt STRING);

-- ❌ 不好的命名
CREATE TABLE `order` (
    `select` INT,
    `from` STRING,
    dt STRING,
    amt DOUBLE,
    `timestamp` BIGINT
);
```

## 关键字使用示例

### 正确使用关键字

```sql
-- DDL 语句
CREATE TABLE IF NOT EXISTS products (
    id BIGINT,
    name STRING,
    price DECIMAL(10,2)
) PARTITIONED BY (dt STRING);

-- DML 语句
INSERT OVERWRITE TABLE products PARTITION(dt='20240101')
SELECT id, name, price
FROM source_products
WHERE dt = '20240101';

-- 查询语句
SELECT 
    category,
    COUNT(*) AS total_count,
    SUM(price) AS total_price
FROM products
WHERE dt = '20240101'
GROUP BY category
HAVING COUNT(*) > 10
ORDER BY total_price DESC
LIMIT 100;

-- 窗口函数
SELECT 
    product_id,
    price,
    ROW_NUMBER() OVER (PARTITION BY category ORDER BY price DESC) AS rank
FROM products;

-- CASE 表达式
SELECT 
    order_id,
    CASE 
        WHEN amount < 100 THEN 'small'
        WHEN amount < 1000 THEN 'medium'
        ELSE 'large'
    END AS order_size
FROM orders;
```

### 转义使用示例

```sql
-- 必须使用保留字时的转义
CREATE TABLE `database`.`order` (
    `select` INT,
    `where` STRING,
    `from` STRING
);

-- 查询转义表
SELECT `select`, `where`, `from` FROM `order`;

-- JOIN 转义表
SELECT 
    o.`select`,
    u.`user`
FROM `order` o
JOIN `user` u ON o.user_id = u.id;
```

## 常见错误及解决方案

### 错误 1：使用保留字作为标识符

```sql
-- ❌ 错误
SELECT order, from FROM table;

-- ✅ 解决方案 1：使用反引号
SELECT `order`, `from` FROM `table`;

-- ✅ 解决方案 2：重命名（推荐）
SELECT order_id, source FROM data_table;
```

### 错误 2：关键字大小写混用

```sql
-- 虽然 SQL 关键字不区分大小写，但建议统一风格

-- ❌ 不推荐：大小写混用
Select * From users Where id = 1;

-- ✅ 推荐：统一大写
SELECT * FROM users WHERE id = 1;

-- ✅ 推荐：统一小写
select * from users where id = 1;
```

### 错误 3：保留字作为别名

```sql
-- ❌ 错误
SELECT user_id AS select FROM users;

-- ✅ 正确
SELECT user_id AS selected_id FROM users;
```

## SQL 风格指南

### 推荐的代码风格

```sql
-- 关键字大写，标识符小写
SELECT 
    u.user_id,
    u.user_name,
    COUNT(o.order_id) AS order_count
FROM users u
LEFT JOIN orders o ON u.user_id = o.user_id
WHERE u.status = 'active'
GROUP BY u.user_id, u.user_name
HAVING COUNT(o.order_id) > 0
ORDER BY order_count DESC
LIMIT 100;
```

### 格式化最佳实践

1. **关键字**：大写或小写统一
2. **缩进**：使用 2 或 4 个空格
3. **换行**：每个主要子句独立一行
4. **对齐**：列名和表达式对齐
5. **注释**：复杂逻辑添加注释
