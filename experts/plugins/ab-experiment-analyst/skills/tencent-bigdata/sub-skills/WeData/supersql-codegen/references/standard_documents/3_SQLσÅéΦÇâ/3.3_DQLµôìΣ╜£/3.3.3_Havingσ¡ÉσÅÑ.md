# Having子句

## 说明

ANSI规范和Oracle均不支持在Having子句中引用`<select list>`中的alias。

因此，如下语句：

```sql
SELECT city, AVG(age) AS age FROM users GROUP BY city HAVING age > 20;
```

是**错误的**，需要改写成：

```sql
SELECT city, AVG(age) AS age FROM users GROUP BY city HAVING AVG(age) > 20;
```

## 注意事项

- 不能在HAVING子句中直接使用SELECT列表中定义的别名
- 必须在HAVING子句中重复完整的聚合函数表达式
- 这是符合ANSI SQL标准的行为
