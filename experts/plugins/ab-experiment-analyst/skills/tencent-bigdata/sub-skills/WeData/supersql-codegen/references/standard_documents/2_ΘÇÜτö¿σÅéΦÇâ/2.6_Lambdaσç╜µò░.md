# Lambda函数

## 概述

Lambda 函数（Lambda Expression）是一种匿名函数表达式，允许在 SQL 语句中定义简单的内联函数。Lambda 函数常用于高阶函数（如 `TRANSFORM`、`FILTER`、`AGGREGATE` 等）中，用于处理数组和 Map 等复杂数据类型。

## 语法

```sql
parameter -> expression
(parameter1, parameter2, ...) -> expression
```

**语法说明：**
- `parameter`：Lambda 函数的参数，可以是单个参数或多个参数
- `->`：Lambda 运算符，分隔参数和表达式
- `expression`：Lambda 函数体，返回计算结果

## 基本用法

### 单参数 Lambda

```sql
-- 单参数不需要括号
x -> x * 2

-- 示例：数组元素乘以 2
SELECT TRANSFORM(ARRAY(1, 2, 3), x -> x * 2) AS result;
-- 结果: [2, 4, 6]
```

### 多参数 Lambda

```sql
-- 多参数需要括号
(x, y) -> x + y

-- 示例：计算两个数组对应元素的和
SELECT ZIP_WITH(ARRAY(1, 2, 3), ARRAY(4, 5, 6), (x, y) -> x + y) AS result;
-- 结果: [5, 7, 9]
```

### 无参数 Lambda

```sql
-- 无参数使用空括号
() -> 42

-- 示例：生成常量数组
SELECT TRANSFORM(ARRAY(1, 2, 3), x -> 100) AS result;
-- 结果: [100, 100, 100]
```

## 高阶函数

Lambda 函数主要与高阶函数配合使用，处理数组和复杂数据类型。

### TRANSFORM

对数组的每个元素应用函数。

```sql
-- 数组元素平方
SELECT TRANSFORM(ARRAY(1, 2, 3, 4), x -> x * x) AS squares;
-- 结果: [1, 4, 9, 16]

-- 字符串转大写
SELECT TRANSFORM(ARRAY('hello', 'world'), x -> UPPER(x)) AS result;
-- 结果: ['HELLO', 'WORLD']

-- 数组元素加索引
SELECT TRANSFORM(ARRAY('a', 'b', 'c'), (x, i) -> CONCAT(x, '-', CAST(i AS STRING))) AS result;
-- 结果: ['a-0', 'b-1', 'c-2']
```

### FILTER

过滤数组元素。

```sql
-- 过滤偶数
SELECT FILTER(ARRAY(1, 2, 3, 4, 5), x -> x % 2 = 0) AS evens;
-- 结果: [2, 4]

-- 过滤长字符串
SELECT FILTER(ARRAY('a', 'hello', 'ab', 'world'), x -> LENGTH(x) > 2) AS result;
-- 结果: ['hello', 'world']

-- 过滤 NULL 值
SELECT FILTER(ARRAY(1, NULL, 2, NULL, 3), x -> x IS NOT NULL) AS result;
-- 结果: [1, 2, 3]
```

### AGGREGATE

对数组元素进行聚合计算。

```sql
-- 数组求和
SELECT AGGREGATE(ARRAY(1, 2, 3, 4), 0, (acc, x) -> acc + x) AS sum;
-- 结果: 10

-- 数组求积
SELECT AGGREGATE(ARRAY(1, 2, 3, 4), 1, (acc, x) -> acc * x) AS product;
-- 结果: 24

-- 数组最大值
SELECT AGGREGATE(ARRAY(5, 2, 8, 1), -999999, (acc, x) -> IF(x > acc, x, acc)) AS max_value;
-- 结果: 8

-- 字符串拼接
SELECT AGGREGATE(ARRAY('Hello', 'World', 'Lambda'), '', (acc, x) -> CONCAT(acc, x, ' ')) AS result;
-- 结果: 'Hello World Lambda '
```

### EXISTS

判断数组中是否存在满足条件的元素。

```sql
-- 判断是否存在偶数
SELECT EXISTS(ARRAY(1, 3, 5, 7), x -> x % 2 = 0) AS has_even;
-- 结果: FALSE

SELECT EXISTS(ARRAY(1, 2, 3, 4), x -> x % 2 = 0) AS has_even;
-- 结果: TRUE

-- 判断是否包含特定字符串
SELECT EXISTS(ARRAY('apple', 'banana', 'orange'), x -> x LIKE '%ana%') AS result;
-- 结果: TRUE
```

### ALL

判断数组中所有元素是否都满足条件。

```sql
-- 判断是否都是偶数
SELECT ALL(ARRAY(2, 4, 6, 8), x -> x % 2 = 0) AS all_even;
-- 结果: TRUE

SELECT ALL(ARRAY(2, 3, 4, 5), x -> x % 2 = 0) AS all_even;
-- 结果: FALSE

-- 判断是否都大于 0
SELECT ALL(ARRAY(1, 2, 3, 4), x -> x > 0) AS all_positive;
-- 结果: TRUE
```

### ANY

判断数组中是否有任意元素满足条件（等价于 EXISTS）。

```sql
-- 判断是否有负数
SELECT ANY(ARRAY(1, -2, 3, 4), x -> x < 0) AS has_negative;
-- 结果: TRUE

-- 判断是否有空字符串
SELECT ANY(ARRAY('a', '', 'b'), x -> LENGTH(x) = 0) AS has_empty;
-- 结果: TRUE
```

### ZIP_WITH

对两个数组的对应元素应用函数。

```sql
-- 对应元素相加
SELECT ZIP_WITH(ARRAY(1, 2, 3), ARRAY(4, 5, 6), (x, y) -> x + y) AS result;
-- 结果: [5, 7, 9]

-- 对应元素相乘
SELECT ZIP_WITH(ARRAY(2, 3, 4), ARRAY(5, 6, 7), (x, y) -> x * y) AS result;
-- 结果: [10, 18, 28]

-- 字符串拼接
SELECT ZIP_WITH(ARRAY('Hello', 'Good'), ARRAY('World', 'Day'), (x, y) -> CONCAT(x, ' ', y)) AS result;
-- 结果: ['Hello World', 'Good Day']
```

### REDUCE

对数组元素进行归约操作（类似 AGGREGATE）。

```sql
-- 数组求和
SELECT REDUCE(ARRAY(1, 2, 3, 4), 0, (acc, x) -> acc + x, acc -> acc) AS sum;
-- 结果: 10

-- 数组连接
SELECT REDUCE(ARRAY('a', 'b', 'c'), '', (acc, x) -> CONCAT(acc, x), acc -> acc) AS result;
-- 结果: 'abc'
```

## 实际应用场景

### 数据转换

```sql
-- 价格打折
SELECT 
    product_id,
    TRANSFORM(price_list, p -> p * 0.8) AS discounted_prices
FROM products;

-- ID 格式化
SELECT 
    user_id,
    TRANSFORM(order_ids, id -> CONCAT('ORDER-', LPAD(CAST(id AS STRING), 8, '0'))) AS formatted_ids
FROM user_orders;

-- 日期格式转换
SELECT 
    TRANSFORM(date_array, d -> DATE_FORMAT(d, 'yyyy-MM-dd')) AS formatted_dates
FROM events;
```

### 数据过滤

```sql
-- 过滤有效订单
SELECT 
    user_id,
    FILTER(orders, o -> o.status = 'COMPLETED' AND o.amount > 100) AS valid_orders
FROM user_data;

-- 过滤异常数据
SELECT 
    sensor_id,
    FILTER(readings, r -> r >= 0 AND r <= 100) AS valid_readings
FROM sensor_data;

-- 移除空值和重复值
SELECT 
    FILTER(values, v -> v IS NOT NULL) AS cleaned_values
FROM raw_data;
```

### 数据聚合

```sql
-- 计算数组总和
SELECT 
    user_id,
    AGGREGATE(purchase_amounts, 0, (sum, amount) -> sum + amount) AS total_spent
FROM purchases;

-- 计算加权平均
SELECT 
    student_id,
    AGGREGATE(
        ZIP_WITH(scores, weights, (s, w) -> s * w),
        0,
        (sum, val) -> sum + val
    ) / AGGREGATE(weights, 0, (sum, w) -> sum + w) AS weighted_avg
FROM student_scores;

-- 字符串拼接
SELECT 
    group_id,
    AGGREGATE(tags, '', (result, tag) -> CONCAT(result, tag, ',')) AS tag_list
FROM groups;
```

### 条件判断

```sql
-- 检查是否包含关键词
SELECT 
    article_id,
    EXISTS(keywords, k -> k IN ('数据', '分析', 'SQL')) AS is_relevant
FROM articles;

-- 检查所有商品是否有货
SELECT 
    order_id,
    ALL(items, i -> i.stock > 0) AS all_in_stock
FROM orders;

-- 检查是否有异常
SELECT 
    machine_id,
    ANY(metrics, m -> m.value > m.threshold) AS has_alert
FROM monitoring;
```

### 复杂计算

```sql
-- 计算数组元素差值
SELECT 
    ZIP_WITH(
        SLICE(values, 2, SIZE(values)),
        SLICE(values, 1, SIZE(values) - 1),
        (current, previous) -> current - previous
    ) AS differences
FROM time_series;

-- 计算移动平均
SELECT 
    TRANSFORM(
        SEQUENCE(1, SIZE(values) - 2),
        i -> (values[i-1] + values[i] + values[i+1]) / 3
    ) AS moving_avg
FROM data_points;

-- 多维数组处理
SELECT 
    TRANSFORM(matrix, row -> TRANSFORM(row, cell -> cell * 2)) AS doubled_matrix
FROM matrices;
```

## 嵌套 Lambda

Lambda 函数可以嵌套使用，处理多维数组或复杂逻辑。

```sql
-- 二维数组元素翻倍
SELECT 
    TRANSFORM(
        ARRAY(ARRAY(1, 2), ARRAY(3, 4)),
        row -> TRANSFORM(row, x -> x * 2)
    ) AS result;
-- 结果: [[2, 4], [6, 8]]

-- 过滤后转换
SELECT 
    TRANSFORM(
        FILTER(ARRAY(1, 2, 3, 4, 5), x -> x > 2),
        x -> x * x
    ) AS result;
-- 结果: [9, 16, 25]

-- 复杂条件过滤
SELECT 
    FILTER(
        products,
        p -> EXISTS(p.tags, t -> t IN ('hot', 'new')) AND p.price < 100
    ) AS featured_products
FROM product_catalog;
```

## Map 数据处理

Lambda 函数也可以用于 Map 数据类型。

```sql
-- 转换 Map 的值
SELECT TRANSFORM_VALUES(
    MAP('a', 1, 'b', 2, 'c', 3),
    (k, v) -> v * 2
) AS result;
-- 结果: {'a': 2, 'b': 4, 'c': 6}

-- 转换 Map 的键
SELECT TRANSFORM_KEYS(
    MAP('a', 1, 'b', 2),
    (k, v) -> UPPER(k)
) AS result;
-- 结果: {'A': 1, 'B': 2}

-- 过滤 Map
SELECT MAP_FILTER(
    MAP('a', 1, 'b', 2, 'c', 3),
    (k, v) -> v > 1
) AS result;
-- 结果: {'b': 2, 'c': 3}
```

## 注意事项

### 变量作用域

Lambda 参数的作用域仅限于 Lambda 函数体内：

```sql
-- ✅ 正确：参数在 Lambda 内部有效
SELECT TRANSFORM(ARRAY(1, 2, 3), x -> x * 2);

-- ❌ 错误：参数 x 在 Lambda 外部无效
SELECT x FROM (SELECT TRANSFORM(ARRAY(1, 2, 3), x -> x * 2) AS result);
```

### 性能考虑

Lambda 函数会对数组的每个元素执行，数组过大时要注意性能：

```sql
-- ❌ 性能较差：复杂 Lambda 处理大数组
SELECT TRANSFORM(large_array, x -> COMPLEX_UDF(x)) FROM big_table;

-- ✅ 性能更好：先过滤再处理
SELECT TRANSFORM(
    FILTER(large_array, x -> x IS NOT NULL),
    x -> COMPLEX_UDF(x)
) FROM big_table;
```

### NULL 值处理

Lambda 函数需要正确处理 NULL 值：

```sql
-- 考虑 NULL 值
SELECT FILTER(ARRAY(1, NULL, 2, NULL, 3), x -> x IS NOT NULL AND x > 1) AS result;
-- 结果: [2, 3]

-- 使用 COALESCE 处理 NULL
SELECT TRANSFORM(ARRAY(1, NULL, 2), x -> COALESCE(x, 0) * 2) AS result;
-- 结果: [2, 0, 4]
```

### 表达式限制

Lambda 函数体必须是单一表达式，不支持多语句或复杂控制流：

```sql
-- ✅ 正确：单一表达式
x -> IF(x > 0, x, 0)

-- ✅ 正确：使用 CASE 表达式
x -> CASE WHEN x > 10 THEN 'high' WHEN x > 5 THEN 'medium' ELSE 'low' END

-- ❌ 错误：不支持多语句
x -> { 
    temp = x * 2;  -- 不支持
    return temp;
}
```

## 最佳实践

1. **简洁表达**：Lambda 函数应保持简洁，复杂逻辑考虑使用 UDF
2. **类型明确**：确保 Lambda 参数类型与数组元素类型匹配
3. **NULL 安全**：始终考虑 NULL 值的处理
4. **性能优化**：对大数组操作时，考虑先过滤再转换
5. **可读性**：复杂 Lambda 可以拆分为多个简单操作
