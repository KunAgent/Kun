# 多维分析（ROLLUP、CUBE、GROUPING SETS）

## 概述

多维分析是 SQL 中用于生成多层聚合结果的强大功能，主要包括 `ROLLUP`、`CUBE` 和 `GROUPING SETS` 三种扩展。这些扩展允许在单个查询中计算多个分组级别的聚合，常用于数据仓库和 OLAP 分析场景。

**SuperSQL 基于 Apache Spark 3.3**，完全支持标准 SQL 的多维分析语法。

## 基本语法

```sql
SELECT column_list, aggregate_function(column)
FROM table_name
WHERE condition
GROUP BY grouping_expressions
HAVING having_condition
ORDER BY order_expression;
```

其中 `grouping_expressions` 可以是：
- 普通的 GROUP BY 列
- `ROLLUP(column_list)`
- `CUBE(column_list)`
- `GROUPING SETS(grouping_set1, grouping_set2, ...)`
- 以上的组合

---

## ROLLUP

### 说明

`ROLLUP` 是 `GROUP BY` 的扩展，用于生成**层次化的小计**和总计。它会按照列的顺序从右到左逐级汇总，生成多个聚合级别。

**特点**：
- 按列的层次顺序汇总（有顺序性）
- 从详细到汇总：`(A, B, C)` → `(A, B)` → `(A)` → `()`（总计）
- 如果有 n 个列，会生成 n+1 个分组级别

### 语法

```sql
GROUP BY ROLLUP(column1, column2, ..., columnN)

-- 或与其他列组合
GROUP BY column0, ROLLUP(column1, column2, ..., columnN)
```

### 示例 1：基本 ROLLUP

**数据准备**：

```sql
CREATE TABLE sales (
    year INT,
    quarter STRING,
    region STRING,
    amount DECIMAL(10,2)
);

INSERT INTO sales VALUES
(2023, 'Q1', 'North', 1000),
(2023, 'Q1', 'South', 1500),
(2023, 'Q2', 'North', 2000),
(2023, 'Q2', 'South', 1800),
(2024, 'Q1', 'North', 2200),
(2024, 'Q1', 'South', 2500);
```

**ROLLUP 查询**：

```sql
SELECT 
    year,
    quarter,
    region,
    SUM(amount) AS total_amount
FROM sales
GROUP BY ROLLUP(year, quarter, region)
ORDER BY year, quarter, region;
```

**等价于以下 UNION 查询**：

```sql
-- 详细级别：按 year, quarter, region 分组
SELECT year, quarter, region, SUM(amount) FROM sales 
GROUP BY year, quarter, region

UNION ALL

-- 小计级别 1：按 year, quarter 分组
SELECT year, quarter, NULL, SUM(amount) FROM sales 
GROUP BY year, quarter

UNION ALL

-- 小计级别 2：按 year 分组
SELECT year, NULL, NULL, SUM(amount) FROM sales 
GROUP BY year

UNION ALL

-- 总计级别：全表汇总
SELECT NULL, NULL, NULL, SUM(amount) FROM sales;
```

**结果示例**：

| year | quarter | region | total_amount |
|------|---------|--------|--------------|
| 2023 | Q1      | North  | 1000.00      |
| 2023 | Q1      | South  | 1500.00      |
| 2023 | Q1      | NULL   | 2500.00      | ← 小计
| 2023 | Q2      | North  | 2000.00      |
| 2023 | Q2      | South  | 1800.00      |
| 2023 | Q2      | NULL   | 3800.00      | ← 小计
| 2023 | NULL    | NULL   | 6300.00      | ← 2023年小计
| 2024 | Q1      | North  | 2200.00      |
| 2024 | Q1      | South  | 2500.00      |
| 2024 | Q1      | NULL   | 4700.00      | ← 小计
| 2024 | NULL    | NULL   | 4700.00      | ← 2024年小计
| NULL | NULL    | NULL   | 11000.00     | ← 总计

### 示例 2：ROLLUP 与固定列组合

```sql
SELECT 
    year,
    quarter,
    region,
    SUM(amount) AS total_amount
FROM sales
GROUP BY year, ROLLUP(quarter, region)
ORDER BY year, quarter, region;
```

**生成的分组**：
- `GROUP BY year, quarter, region`
- `GROUP BY year, quarter`
- `GROUP BY year`

**说明**：`year` 作为固定列，始终参与分组，ROLLUP 只对 `quarter` 和 `region` 进行层次汇总。

## CUBE

### 说明

`CUBE` 是 `GROUP BY` 的扩展，用于生成**所有可能的列组合**的聚合结果。它会计算指定列的所有维度组合，包括所有的交叉小计和总计。

**特点**：
- 生成所有列的笛卡尔积组合（无顺序性）
- 如果有 n 个列，会生成 2^n 个分组级别
- `CUBE(A, B, C)` 生成 8 个分组：`(A,B,C)`, `(A,B)`, `(A,C)`, `(A)`, `(B,C)`, `(B)`, `(C)`, `()`

### 语法

```sql
GROUP BY CUBE(column1, column2, ..., columnN)

-- 或与其他列组合
GROUP BY column0, CUBE(column1, column2, ..., columnN)
```

### 示例 1：基本 CUBE

```sql
SELECT 
    year,
    quarter,
    region,
    SUM(amount) AS total_amount
FROM sales
GROUP BY CUBE(year, quarter, region)
ORDER BY year, quarter, region;
```

**等价于以下所有组合的 UNION**：

```sql
-- 详细级别
GROUP BY year, quarter, region  -- (1,1,1)
UNION ALL
-- 二维组合
GROUP BY year, quarter           -- (1,1,0)
UNION ALL
GROUP BY year, region            -- (1,0,1)
UNION ALL
GROUP BY quarter, region         -- (0,1,1)
UNION ALL
-- 一维组合
GROUP BY year                    -- (1,0,0)
UNION ALL
GROUP BY quarter                 -- (0,1,0)
UNION ALL
GROUP BY region                  -- (0,0,1)
UNION ALL
-- 总计
全表聚合                          -- (0,0,0)
```

**结果示例（部分）**：

| year | quarter | region | total_amount | 说明 |
|------|---------|--------|--------------|------|
| 2023 | Q1      | North  | 1000.00      | 详细数据 |
| 2023 | Q1      | South  | 1500.00      | 详细数据 |
| 2023 | Q1      | NULL   | 2500.00      | year+quarter小计 |
| 2023 | NULL    | North  | 3000.00      | year+region小计 |
| 2023 | NULL    | South  | 3300.00      | year+region小计 |
| 2023 | NULL    | NULL   | 6300.00      | year小计 |
| NULL | Q1      | North  | 3200.00      | quarter+region小计 |
| NULL | Q1      | NULL   | 7200.00      | quarter小计 |
| NULL | NULL    | North  | 5200.00      | region小计 |
| NULL | NULL    | NULL   | 11000.00     | 总计 |

### 示例 2：CUBE 与固定列组合

```sql
SELECT 
    year,
    quarter,
    region,
    SUM(amount) AS total_amount
FROM sales
GROUP BY year, CUBE(quarter, region)
ORDER BY year, quarter, region;
```

**生成的分组**：
- `GROUP BY year, quarter, region`
- `GROUP BY year, quarter`
- `GROUP BY year, region`
- `GROUP BY year`

**说明**：`year` 作为固定列，始终参与分组，CUBE 只对 `quarter` 和 `region` 进行组合。

## GROUPING SETS

### 说明

`GROUPING SETS` 是最灵活的多维分析方式，允许**精确指定需要的分组组合**，避免生成不需要的聚合结果。

**特点**：
- 完全自定义分组组合
- 不会生成不需要的中间结果
- `ROLLUP` 和 `CUBE` 都可以用 `GROUPING SETS` 表达
- 支持空分组 `()`，表示全表聚合

### 语法

```sql
GROUP BY GROUPING SETS (
    (column1, column2, ...),
    (column1, column3, ...),
    (column1),
    ()  -- 空括号表示总计
)
```

### 示例 1：基本 GROUPING SETS

```sql
SELECT 
    year,
    quarter,
    region,
    SUM(amount) AS total_amount
FROM sales
GROUP BY GROUPING SETS (
    (year, quarter, region),  -- 详细级别
    (year, quarter),           -- 按年和季度
    (year, region),            -- 按年和地区
    (year),                    -- 按年
    ()                         -- 总计
)
ORDER BY year, quarter, region;
```

**说明**：上述查询只生成指定的 5 个分组组合，不会生成其他组合。

### 示例 2：等价关系

**ROLLUP 等价表达**：

```sql
-- ROLLUP 写法
GROUP BY ROLLUP(A, B, C)

-- GROUPING SETS 等价写法
GROUP BY GROUPING SETS (
    (A, B, C),
    (A, B),
    (A),
    ()
)
```

**CUBE 等价表达**：

```sql
-- CUBE 写法
GROUP BY CUBE(A, B, C)

-- GROUPING SETS 等价写法
GROUP BY GROUPING SETS (
    (A, B, C),
    (A, B),
    (A, C),
    (B, C),
    (A),
    (B),
    (C),
    ()
)
```

### 示例 3：自定义组合

```sql
-- 只需要年度总计和地区总计，不需要其他组合
SELECT 
    year,
    region,
    SUM(amount) AS total_amount
FROM sales
GROUP BY GROUPING SETS (
    (year),     -- 按年汇总
    (region),   -- 按地区汇总
    ()          -- 总计
)
ORDER BY year, region;
```

**结果示例**：

| year | region | total_amount |
|------|--------|--------------|
| 2023 | NULL   | 6300.00      | ← 2023年总计
| 2024 | NULL   | 4700.00      | ← 2024年总计
| NULL | North  | 5200.00      | ← North地区总计
| NULL | South  | 5800.00      | ← South地区总计
| NULL | NULL   | 11000.00     | ← 总计

## GROUPING 函数

### 说明

`GROUPING()` 函数用于**区分聚合结果中的 NULL 值来源**：
- 返回 `1`：该列的 NULL 是由 ROLLUP/CUBE/GROUPING SETS 生成的聚合行
- 返回 `0`：该列的 NULL 是原始数据中的真实 NULL 值

**使用场景**：
- 识别哪些行是小计或总计
- 在 SELECT 或 HAVING 子句中使用
- 替换聚合行的 NULL 为有意义的标签

### 语法

```sql
GROUPING(column)
```

### 示例 1：基本用法

```sql
SELECT 
    year,
    quarter,
    region,
    SUM(amount) AS total_amount,
    GROUPING(year) AS is_year_total,
    GROUPING(quarter) AS is_quarter_total,
    GROUPING(region) AS is_region_total
FROM sales
GROUP BY ROLLUP(year, quarter, region)
ORDER BY year, quarter, region;
```

**结果示例**：

| year | quarter | region | total_amount | is_year_total | is_quarter_total | is_region_total |
|------|---------|--------|--------------|---------------|------------------|-----------------|
| 2023 | Q1      | North  | 1000.00      | 0             | 0                | 0               |
| 2023 | Q1      | NULL   | 2500.00      | 0             | 0                | 1               | ← region 小计
| 2023 | NULL    | NULL   | 6300.00      | 0             | 1                | 1               | ← quarter 小计
| NULL | NULL    | NULL   | 11000.00     | 1             | 1                | 1               | ← 总计

### 示例 2：使用 GROUPING 添加标签

```sql
SELECT 
    CASE 
        WHEN GROUPING(year) = 1 THEN '全部年份'
        ELSE CAST(year AS STRING)
    END AS year_label,
    CASE 
        WHEN GROUPING(quarter) = 1 THEN '全部季度'
        ELSE quarter
    END AS quarter_label,
    CASE 
        WHEN GROUPING(region) = 1 THEN '全部地区'
        ELSE region
    END AS region_label,
    SUM(amount) AS total_amount
FROM sales
GROUP BY ROLLUP(year, quarter, region)
ORDER BY year, quarter, region;
```

**结果示例**：

| year_label | quarter_label | region_label | total_amount |
|------------|---------------|--------------|--------------|
| 2023       | Q1            | North        | 1000.00      |
| 2023       | Q1            | South        | 1500.00      |
| 2023       | Q1            | 全部地区       | 2500.00      |
| 2023       | 全部季度       | 全部地区       | 6300.00      |
| 全部年份    | 全部季度       | 全部地区       | 11000.00     |

### 示例 3：在 HAVING 子句中使用

```sql
-- 只返回总计行
SELECT 
    year,
    quarter,
    SUM(amount) AS total_amount
FROM sales
GROUP BY ROLLUP(year, quarter)
HAVING GROUPING(year) = 1 AND GROUPING(quarter) = 1;
```

## GROUPING_ID 函数

### 说明

`GROUPING_ID()` 函数返回一个**位向量**，表示哪些列参与了当前行的分组。它是多个 `GROUPING()` 函数结果的二进制组合。

**计算方式**：
- 从左到右，每个列的 GROUPING 结果（0或1）组成二进制数
- 转换为十进制返回

**使用场景**：
- 快速识别不同的聚合级别
- 过滤特定的聚合组合
- 多列判断时比多个 GROUPING() 更简洁

### 语法

```sql
GROUPING_ID(column1, column2, ..., columnN)
```

### 示例 1：理解 GROUPING_ID

```sql
SELECT 
    year,
    quarter,
    region,
    SUM(amount) AS total_amount,
    GROUPING(year) AS g_year,
    GROUPING(quarter) AS g_quarter,
    GROUPING(region) AS g_region,
    GROUPING_ID(year, quarter, region) AS grouping_id
FROM sales
GROUP BY CUBE(year, quarter, region)
ORDER BY grouping_id, year, quarter, region
LIMIT 20;
```

**GROUPING_ID 计算示例**：

| year | quarter | region | g_year | g_quarter | g_region | 二进制 | grouping_id |
|------|---------|--------|--------|-----------|----------|--------|-------------|
| 2023 | Q1      | North  | 0      | 0         | 0        | 000    | 0           |
| 2023 | Q1      | NULL   | 0      | 0         | 1        | 001    | 1           |
| 2023 | NULL    | North  | 0      | 1         | 0        | 010    | 2           |
| 2023 | NULL    | NULL   | 0      | 1         | 1        | 011    | 3           |
| NULL | Q1      | North  | 1      | 0         | 0        | 100    | 4           |
| NULL | Q1      | NULL   | 1      | 0         | 1        | 101    | 5           |
| NULL | NULL    | North  | 1      | 1         | 0        | 110    | 6           |
| NULL | NULL    | NULL   | 1      | 1         | 1        | 111    | 7           |

**计算公式**：
```
GROUPING_ID(year, quarter, region) = 
    GROUPING(year) * 4 + GROUPING(quarter) * 2 + GROUPING(region) * 1
```

### 示例 2：过滤特定聚合级别

```sql
-- 只返回 grouping_id = 3 的行（按 year 分组，不包含 quarter 和 region）
SELECT 
    year,
    quarter,
    region,
    SUM(amount) AS total_amount,
    GROUPING_ID(year, quarter, region) AS gid
FROM sales
GROUP BY CUBE(year, quarter, region)
HAVING GROUPING_ID(year, quarter, region) = 3
ORDER BY year;
```

**结果**：只返回按年份分组的小计行

| year | quarter | region | total_amount | gid |
|------|---------|--------|--------------|-----|
| 2023 | NULL    | NULL   | 6300.00      | 3   |
| 2024 | NULL    | NULL   | 4700.00      | 3   |

### 示例 3：区分不同的聚合类型

```sql
SELECT 
    year,
    quarter,
    region,
    SUM(amount) AS total_amount,
    CASE GROUPING_ID(year, quarter, region)
        WHEN 0 THEN '详细数据'
        WHEN 1 THEN '地区小计'
        WHEN 3 THEN '年度小计'
        WHEN 7 THEN '总计'
        ELSE '其他汇总'
    END AS aggregation_level
FROM sales
GROUP BY ROLLUP(year, quarter, region)
ORDER BY GROUPING_ID(year, quarter, region), year, quarter, region;
```

## 列组合（Grouping Expression）

### 说明

在 Spark SQL 中，可以在 `ROLLUP`、`CUBE` 和 `GROUPING SETS` 中**使用括号将多个列组合成一个单元**，这些列会被视为一个整体进行分组。

**用途**：
- 将多个列作为一个复合键处理
- 控制聚合的粒度
- 减少不必要的中间聚合级别

### 语法

```sql
-- 在 ROLLUP 中使用列组合
GROUP BY ROLLUP((col1, col2), col3, col4)

-- 在 CUBE 中使用列组合
GROUP BY CUBE((col1, col2), col3)

-- 在 GROUPING SETS 中使用列组合
GROUP BY GROUPING SETS (
    (col1, col2, col3),
    (col1, col2),
    ()
)
```

### 示例 1：ROLLUP 中的列组合

```sql
-- 将 year 和 quarter 作为一个组合单元
SELECT 
    year,
    quarter,
    region,
    SUM(amount) AS total_amount
FROM sales
GROUP BY ROLLUP((year, quarter), region)
ORDER BY year, quarter, region;
```

**生成的分组**：
1. `GROUP BY year, quarter, region`  -- 完整分组
2. `GROUP BY year, quarter`           -- (year, quarter) 组合小计
3. `()`                               -- 总计

**说明**：不会生成 `GROUP BY year` 的中间级别，因为 `year` 和 `quarter` 被绑定在一起。

### 示例 2：CUBE 中的列组合

```sql
SELECT 
    year,
    quarter,
    region,
    SUM(amount) AS total_amount
FROM sales
GROUP BY CUBE((year, quarter), region)
ORDER BY year, quarter, region;
```

**生成的分组**：
1. `GROUP BY year, quarter, region`  -- (1, 1)
2. `GROUP BY year, quarter`           -- (1, 0)
3. `GROUP BY region`                  -- (0, 1)
4. `()`                               -- (0, 0) 总计

**对比**：如果没有列组合 `CUBE(year, quarter, region)` 会生成 2³ = 8 个分组。

### 示例 3：复杂的列组合

```sql
-- 数据准备
CREATE TABLE sales_detail (
    country STRING,
    state STRING,
    city STRING,
    product_category STRING,
    product STRING,
    amount DECIMAL(10,2)
);

-- 将地理位置作为一个单元，产品作为另一个单元
SELECT 
    country,
    state,
    city,
    product_category,
    product,
    SUM(amount) AS total_amount,
    GROUPING_ID(country, state, city, product_category, product) AS gid
FROM sales_detail
GROUP BY ROLLUP((country, state, city), (product_category, product))
ORDER BY gid, country, state, city, product_category, product;
```

**生成的分组**：
1. `GROUP BY country, state, city, product_category, product`  -- 完整详细
2. `GROUP BY country, state, city`                              -- 按地理位置聚合
3. `()`                                                          -- 总计

## 性能优化建议

### 1. 选择合适的多维分析方式

| 场景 | 推荐方式 | 原因 |
|------|----------|------|
| 需要层次化汇总（如：国家→省→市） | `ROLLUP` | 高效，生成 n+1 个分组 |
| 需要所有维度的交叉分析 | `CUBE` | 全面，生成 2^n 个分组 |
| 只需要特定的几个组合 | `GROUPING SETS` | 精确，避免不必要的计算 |
| 需要复合键作为单元 | 列组合 `(col1, col2)` | 减少中间聚合级别 |

### 2. 控制维度数量

```sql
-- ❌ 避免：CUBE 的维度过多
GROUP BY CUBE(col1, col2, col3, col4, col5, col6)
-- 会生成 2^6 = 64 个分组，计算成本很高

-- ✅ 推荐：使用 GROUPING SETS 精确指定需要的组合
GROUP BY GROUPING SETS (
    (col1, col2, col3),
    (col1, col2),
    (col1),
    ()
)
```

### 3. 使用 GROUPING_ID 过滤

```sql
-- ✅ 推荐：先生成所有聚合，然后过滤
SELECT *
FROM (
    SELECT 
        year, quarter, region,
        SUM(amount) AS total,
        GROUPING_ID(year, quarter, region) AS gid
    FROM sales
    GROUP BY CUBE(year, quarter, region)
) t
WHERE gid IN (0, 3, 7);  -- 只保留需要的聚合级别
```

### 4. 利用物化视图（如果支持）

```sql
-- 预计算常用的多维聚合结果
CREATE MATERIALIZED VIEW sales_cube AS
SELECT 
    year,
    quarter,
    region,
    SUM(amount) AS total_amount,
    COUNT(*) AS cnt,
    GROUPING_ID(year, quarter, region) AS gid
FROM sales
GROUP BY CUBE(year, quarter, region);
```

## 常见问题和注意事项

### 1. NULL 值的区分

**问题**：如何区分原始数据中的 NULL 和聚合生成的 NULL？

**解决方案**：使用 `GROUPING()` 函数

```sql
SELECT 
    CASE 
        WHEN GROUPING(region) = 0 AND region IS NULL THEN '地区未知'
        WHEN GROUPING(region) = 1 THEN '所有地区'
        ELSE region
    END AS region_label,
    SUM(amount) AS total
FROM sales
GROUP BY ROLLUP(region);
```

### 2. 与 DISTINCT 的兼容性

**Spark SQL 限制**：不支持 `SELECT DISTINCT` 与多维分析同时使用

```sql
-- ❌ 错误
SELECT DISTINCT year, SUM(amount)
FROM sales
GROUP BY ROLLUP(year, quarter);

-- ✅ 正确：使用子查询
SELECT DISTINCT year, total
FROM (
    SELECT year, SUM(amount) AS total
    FROM sales
    GROUP BY ROLLUP(year, quarter)
) t;
```

### 3. ORDER BY 的使用

**建议**：使用 `GROUPING_ID()` 控制排序顺序

```sql
SELECT 
    year,
    quarter,
    SUM(amount) AS total,
    GROUPING_ID(year, quarter) AS gid
FROM sales
GROUP BY ROLLUP(year, quarter)
ORDER BY gid, year, quarter;  -- 先按聚合级别排序，再按维度排序
```

### 4. 与窗口函数的结合

```sql
-- 计算每个聚合级别的占比
SELECT 
    year,
    quarter,
    SUM(amount) AS total,
    GROUPING_ID(year, quarter) AS gid,
    SUM(amount) / SUM(SUM(amount)) OVER (PARTITION BY GROUPING_ID(year, quarter)) AS pct
FROM sales
GROUP BY ROLLUP(year, quarter)
ORDER BY gid, year, quarter;
```

## 三种方式对比总结

| 特性 | ROLLUP | CUBE | GROUPING SETS |
|------|--------|------|---------------|
| **生成分组数** | n+1 个 | 2^n 个 | 自定义 |
| **有序性** | ✅ 层次化（从细到粗） | ❌ 所有组合 | ❌ 指定的组合 |
| **适用场景** | 层次维度（时间、地理） | 所有维度交叉分析 | 精确的自定义组合 |
| **性能** | 最优（生成少） | 较差（生成多） | 中等（按需生成） |
| **易用性** | 高 | 高 | 中（需要明确指定） |
| **灵活性** | 低 | 中 | 高 |

**示例对比**：

```sql
-- ROLLUP: 生成 4 个分组
GROUP BY ROLLUP(A, B, C)
-- (A,B,C), (A,B), (A), ()

-- CUBE: 生成 8 个分组
GROUP BY CUBE(A, B, C)
-- (A,B,C), (A,B), (A,C), (A), (B,C), (B), (C), ()

-- GROUPING SETS: 自定义 3 个分组
GROUP BY GROUPING SETS ((A,B,C), (A), ())
-- (A,B,C), (A), ()
```

## 实战示例：销售报表

### 场景

生成一个完整的销售报表，包含：
- 每年每季度每地区的详细销售额
- 每年每季度的小计
- 每年的小计
- 总计

并且用有意义的标签替换 NULL 值。

### 完整SQL

```sql
WITH sales_data AS (
    SELECT 
        year,
        quarter,
        region,
        SUM(amount) AS total_amount,
        COUNT(*) AS order_count,
        GROUPING(year) AS g_year,
        GROUPING(quarter) AS g_quarter,
        GROUPING(region) AS g_region,
        GROUPING_ID(year, quarter, region) AS gid
    FROM sales
    GROUP BY ROLLUP(year, quarter, region)
)
SELECT 
    CASE 
        WHEN g_year = 1 THEN '所有年份'
        ELSE CAST(year AS STRING)
    END AS year_label,
    CASE 
        WHEN g_quarter = 1 THEN '所有季度'
        ELSE quarter
    END AS quarter_label,
    CASE 
        WHEN g_region = 1 THEN '所有地区'
        ELSE region
    END AS region_label,
    total_amount,
    order_count,
    CASE gid
        WHEN 0 THEN '详细数据'
        WHEN 1 THEN '地区小计'
        WHEN 3 THEN '季度小计'
        WHEN 7 THEN '总计'
    END AS level_type
FROM sales_data
ORDER BY 
    CASE WHEN g_year = 0 THEN year ELSE 9999 END,
    CASE WHEN g_quarter = 0 THEN quarter ELSE 'ZZ' END,
    CASE WHEN g_region = 0 THEN region ELSE 'ZZ' END,
    gid;
```
