# Update语句

## 格式

### 非分区表

```sql
UPDATE table_name SET col_name = expr [, col_name = expr ]* [WHERE where_definition]?
```

### 分区表

```sql
UPDATE table_name [PARTITION (partname) tabalias]? SET col_name = expr [, col_name = expr ]* [WHERE where_definition]?
```

## 说明

Update操作的基本语法如上，从指定的`table_name`表中，使用表达式`expr`更新列`col_name`，set后面可以跟多个col表达式（用逗号分隔开），但不支持多层嵌套，也不支持多表连接。

`WHERE`表达式子句为可选项，如果有则表示只对其中部分数据进行update，where子句只可能有一个，对前面多个set语句都有效。where子句中不可使用exist等带子查询的表达式。

如果是分区表则必须显式指定分区，不支持同时指定多个分区。如果表是二级分区表则必须同时指定一级分区和二级分区。在处理分区表的时候update不支持对分区字段进行update。

## 注意事项

### 多列累计运算限制

update暂不支持多列累计运算的功能。比如`SET a=a+1, b=a`和`SET b=a, a=a+1`在这里的结果是一样的，跟先后顺序无关，这和传统的数据库可能有所不同。

### 重复赋值处理

如果出现`SET a=1, a=2`这种重复赋值的情况，只处理最后一次赋值。

### 类型不匹配处理

如果set的数据类型如目标列不一致，数据会被置为null。

### 不支持的表类型

update不支持hash分区的表，也不支持外表和视图。

### 并发控制

update目前还没有锁机制来保证并发性，需要用户注意，对于update、delete、select并发操作同一张表的时候（同时对一张表做读和写操作），一定要保证这些操作是串行的，否则可能引发正在运行的select操作失败。只并行select操作同一张表是没有问题的。

## 示例

### 示例1：一级分区表更新

```sql
USE db;
UPDATE table_name PARTITION (p_20251029) p SET col1 = 1;
```

### 示例2：二级分区表更新

```sql
USE db;
UPDATE table_name PARTITION (p_20251029, sp_key) p SET col1 = 1;
```
