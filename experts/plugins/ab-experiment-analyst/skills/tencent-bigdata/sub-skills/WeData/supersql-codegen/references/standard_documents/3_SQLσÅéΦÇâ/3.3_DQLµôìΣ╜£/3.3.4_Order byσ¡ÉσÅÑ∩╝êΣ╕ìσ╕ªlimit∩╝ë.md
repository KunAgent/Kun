# Order by子句（不带limit）

## 说明

目前不带limit的order by语句是通过将`mapred.reduce.tasks`变量设置为1，将全部数据在reduce过程拉到同一台机器上做排序来实现。

数据量大时，会造成mapreduce任务无法完成，从而无法完成全局排序。

## 语法

```sql
SELECT key, value FROM src ORDER BY key ASC, value DESC;
```

## Sort By与Order By的区别

- **ORDER BY**：所有结果按指定列排序
- **SORT BY**：让每一个reduce的结果按照指定列排序

如果只有一个reduce，则sort by与order by返回相同的结果。

## 注意事项

- 不带LIMIT的ORDER BY在大数据量场景下会有性能问题
- 建议在生产环境中使用ORDER BY时总是配合LIMIT使用
