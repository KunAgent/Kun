# 2.17.5 引擎执行模式

## 1. Auto引擎模式

### 特点

- **自动改写SQL**：自动改写SQL以适配不同引擎
- **一致性保证**：在已覆盖的语义边界内保障执行结果一致性
- **适用场景**：SQL符合SuperSQL标准

### 示例

```sql
-- 原始SQL
SELECT substr(name, 1, 5) FROM users;

-- 自动改写为（Spark 3.3.7-tq-0.48+）
SELECT tdw_substr(name, 1, 5) FROM users;
```

---

## 2. 透传或指定引擎模式

### 特点

- **直接执行**：SQL直接发送到指定引擎执行，不做改写
- **一致性保证**：SuperSQL不保证执行结果一致性
- **适用场景**：使用引擎特有语法时

### 示例

```sql
-- 使用StarRocks特有的bitmap函数
SELECT bitmap_count(user_ids) FROM stats;

-- 此SQL透传到StarRocks引擎执行，不做改写
```

---

## 模式对比

| 特性 | Auto模式 | 透传模式 |
|-----|---------|---------|
| SQL改写 | ✅ 自动改写 | ❌ 不改写 |
| 一致性保证 | ✅ 保证 | ❌ 不保证 |
| 兼容性 | ✅ 高 | ⚠️ 依赖引擎 |
| 使用场景 | 标准SQL | 引擎特有功能 |
| 推荐度 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |

---

## 使用建议

### 优先使用Auto模式

```sql
-- ✅ 推荐：使用标准语法，Auto模式自动适配
SELECT 
    CAST(col1 AS INT),
    CONCAT(col2, col3),
    DATE_ADD(date_col, 7)
FROM table1;
```

### 必要时使用透传模式

```sql
-- ⚠️ 仅在必要时使用：StarRocks bitmap功能
SELECT bitmap_count(bitmap_col) FROM table2;
```
