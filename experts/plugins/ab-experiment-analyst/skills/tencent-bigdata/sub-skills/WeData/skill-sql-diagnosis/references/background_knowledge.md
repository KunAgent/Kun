# SuperSQL 背景知识

## SuperSQL 简介

SuperSQL 是腾讯内部自研的跨数据源、跨数据中心、跨执行引擎的高性能大数据 SQL 中间件，满足对位于不同数据中心的不同类型数据源的数据联合分析/即时查询的需求。

SuperSQL 是腾讯大数据平台统一的 SQL 入口，支持多种数据源和计算引擎，负责语法适配、引擎选择、权限校验等。当用户执行 SQL 时，SuperSQL 会根据用户输入的 SQL 语句，选择合适的计算引擎，然后进行 SQL 改写，并下放执行。

**关键特性**：
- 语法适配：统一 SQL 方言，屏蔽底层引擎差异
- 引擎选择：根据 SQL 特征自动路由到最合适的计算引擎
- 权限校验：在 SQL 编译阶段即可校验数据访问权限
- SQL 改写：将用户 SQL 改写为目标引擎可执行的形式

## 平台与应用

### TDW（Tencent Distributed Data Warehouse）
腾讯分布式数据仓库，主要支持海量数据的离线存储和计算。

### WeData（天穹大数据平台）
- 网址：wedata.woa.com（原 idex.woa.com）
- 用户执行 SQL 的主要应用平台
- 默认走 SuperSQL 编译

### US（统一调度）
- 网址：US.woa.com
- 用于进行周期性的任务调度执行
- 需要手动选择才能使用 SuperSQL 执行
- 该功能在 WeData 也有实现

## 计算引擎

| 引擎 | 说明 |
|------|------|
| **Spark** | 大数据通用计算引擎，Livy 是 SQL → Spark 的中间引擎 |
| **Presto** | 交互式查询引擎，适合即时查询场景 |
| **Starrocks** | 实时分析数据库，适合亚秒级查询 |
| **Flink** | 流批一体计算引擎 |
| **Native** | 对于简单计算任务未使用专门的计算引擎，或还未下推至专业计算引擎就已由 SuperSQL 检查出问题 |

**重要提示**：
- 各个引擎可能存在 SQL 语法差异
- 相同的 SQL 语句在不同引擎中执行结果可能不同
- Spark 任务使用的计算资源不固定，每次执行需要 Yarn 系统进行资源调度以动态分配

## SuperSQL 层错误标识

以下关键字标识错误来源于 SuperSQL 层（非引擎侧）：
- `org.apache.calcite`
- `SuperSQL`
- `CalciteContextException`

**诊断原则**：当出现语法类、权限类错误时，应关注 SuperSQL 层报错信息，忽略引擎侧报错（即忽略含有 Spark、Presto、Starrocks 的语句）。
