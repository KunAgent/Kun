# 监控管理工具

监控是规则的上层组织单元，每个监控对应一张表。共 3 个只读工具。

## list_monitors

查询空间下的监控列表。

**参数**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| workbench_id | int | 是 | - | 空间ID |
| keyword | str | 否 | "" | 搜索关键词 |
| page_no | int | 否 | 1 | 页码 |
| page_size | int | 否 | 20 | 每页条数 |

**使用场景**：用户问"有哪些监控"、"看看xx库下的监控"

**返回说明**：每个监控对应一张表，包含该表上的所有规则。

---

## list_user_monitors

查询用户负责的所有监控列表。不传 owner 则自动使用当前认证用户。

**参数**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| owner | str | 否 | "" | 负责人RTX，不传则使用当前认证用户 |
| keyword | str | 否 | "" | 搜索关键词，支持库表名模糊匹配 |
| page_no | int | 否 | 1 | 页码 |
| page_size | int | 否 | 20 | 每页条数 |

**使用场景**：用户问"我有哪些监控"、"xx用户负责的监控"

> [TIP] 此接口无需空间权限，可查询当前用户负责的所有空间的监控。

---

## get_monitor_detail

查询监控详情，包括该监控下的所有规则摘要信息。

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| monitor_id | int | 是 | 监控ID |

**使用场景**：用户问"这个监控有几条规则"、"xx表的监控情况"

**返回说明**：返回监控基本信息及该监控下所有规则的摘要，可用于快速了解一张表的整体监控情况。
