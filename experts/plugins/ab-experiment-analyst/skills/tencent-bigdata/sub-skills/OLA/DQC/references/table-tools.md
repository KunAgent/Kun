# 表元数据 & 表质量查询工具

共 7 个只读工具，分为表元数据查询和表质量查询两类。

> [TIP] 表质量查询工具（`get_table_rule_*`、`get_table_baseline_*`）**无需空间权限**，直接通过库名+表名查询。

---

## 表元数据查询

### get_table_meta

获取表的元数据信息，包括字段列表、分区信息、存储格式、负责人等。

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| db_name | str | 是 | 数据库名 |
| table_name | str | 是 | 表名 |

**使用场景**：用户问"这张表有哪些字段"、"表xxx的结构是什么"

---

### get_table_output

获取表分区产出信息，包括分区值、产出时间、产出任务等。

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| db_name | str | 是 | 数据库名 |
| table_name | str | 是 | 表名 |

**使用场景**：用户问"这张表的分区什么时候产出的"、"产出情况"

---

### get_table_task

查询表的生产任务，包括任务ID、名称、调度周期等信息。

**参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| db_name | str | 是 | 数据库名 |
| table_name | str | 是 | 表名 |

**使用场景**：用户问"这张表是什么任务产出的"、"生产任务是什么"

---

## 表质量查询

> [TIP] 以下 4 个工具无需空间权限，直接通过库名+表名查询，是**快捷路径**。

### get_table_rule_configs

查询表的规则配置信息，包括所有监控规则的配置详情。返回规则ID、名称、类型、状态、负责人等信息。

**参数**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| db_name | str | 是 | - | 数据库名 |
| table_name | str | 是 | - | 表名 |
| datasource_type | str | 否 | "HIVE" | 数据源类型 |

**datasource_type 取值**：HIVE / THIVE / MYSQL / STARROCKS / CLICKHOUSE / ICEBERG

**使用场景**：用户问"这张表有哪些规则"、"表的监控配置是什么"

---

### get_table_rule_results

查询表的规则运行结果，包括所有规则的历史执行情况。返回运行状态、告警状态、实际值、阈值等信息。

**参数**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| db_name | str | 是 | - | 数据库名 |
| table_name | str | 是 | - | 表名 |
| datasource_type | str | 否 | "HIVE" | 数据源类型 |
| start_time | str | 否 | "" | 查询开始时间，格式：yyyyMMddHHmmss，默认最近7天 |
| end_time | str | 否 | "" | 查询结束时间，格式：yyyyMMddHHmmss，默认当前时间 |

**使用场景**：用户问"表的规则执行情况"、"最近有什么告警"

---

### get_table_baseline_configs

查询表的基线配置信息，包括所有基线监控的配置详情。返回基线ID、名称、保障任务、承诺时间等信息。

**参数**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| db_name | str | 是 | - | 数据库名 |
| table_name | str | 是 | - | 表名 |
| datasource_type | str | 否 | "HIVE" | 数据源类型 |

**使用场景**：用户问"表有没有基线配置"、"基线是怎么配置的"

---

### get_table_baseline_status

查询表的基线运行状态，包括基线实例的执行情况。返回基线状态、完成时间、问题信息等。

**参数**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| db_name | str | 是 | - | 数据库名 |
| table_name | str | 是 | - | 表名 |
| datasource_type | str | 否 | "HIVE" | 数据源类型 |
| start_time | str | 否 | "" | 查询开始时间，格式：yyyyMMddHHmmss，默认最近7天 |
| end_time | str | 否 | "" | 查询结束时间，格式：yyyyMMddHHmmss，默认当前时间 |

**使用场景**：用户问"基线运行情况"、"基线有没有出问题"
