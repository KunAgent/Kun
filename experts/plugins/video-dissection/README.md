# 视频解剖

专业拆解火爆抖音视频拍摄手法的专家团。输入抖音链接，自动提取视频、转录文案、分析景别运镜、剪辑节奏、色调风格，生成完整拍摄脚本拆解文档，并提供可落地的仿拍建议。

## 类型

Team 型（专家团）

## 功能

- 输入抖音分享链接，自动下载无水印视频
- 提取视频音频，通过 AI 语音识别获取完整口播文案
- 使用火山方舟视频理解 API 深度分析拍摄手法（景别、运镜、剪辑节奏、色调等）
- 生成结构化的拍摄脚本拆解报告
- 按镜头自动裁剪视频片段
- 提供可落地的仿拍建议（内容策划、拍摄执行、镜头复刻、剪辑建议、踩坑提醒）

## 技能

| 技能名 | 说明 |
|--------|------|
| douyin-resolver | 抖音视频解析：三层降级策略（API → Playwright → yt-dlp）下载视频 + 语音识别转录文案 |
| douyin-script-analyzer | 拍摄脚本分析：AI 分析景别/运镜/剪辑节奏/色调 + 镜头裁剪 + 仿拍建议 |

## 环境配置

使用前需配置以下环境变量：

| 变量名 | 用途 | 获取方式 |
|--------|------|---------|
| `SILICONFLOW_API_KEY` | 硅基流动 API Key（语音识别） | https://cloud.siliconflow.cn/ |
| `ARK_API_KEY` | 火山方舟 API Key（视频理解） | https://www.volcengine.com/product/ark |

系统依赖：`ffmpeg` + `ffprobe`
