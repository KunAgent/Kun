# 展示模板：待办流程单列表（todo-instance-list）

## 用途
渲染 `ListParticipateWorkflowInstance` 接口返回的待办流程单列表。

---

## 输出格式

```markdown
## 📬 我的待办流程单（共 {Total} 条）

| 流程单名称 | 流程单ID | 发起人 | 处理节点 | 节点开始时间 |
|-----------|---------|--------|---------|------------|
| {Title截断到25字} | {Id} | {Creator} | {CurrentTaskName} | {TaskCreateTime} |

> 发送流程单 ID（T 开头）可查看详情和审批进度。
```

---

## 空结果处理

```markdown
当前暂无待办流程单 🎉

建议：
- 确认筛选条件（状态/关键字）是否合适
- 尝试不带筛选条件查询全部
```

---

## 分页提示（有更多时追加）

```markdown
> 当前显示前 {Limit} 条，共 {Total} 条。如需查看更多，请告诉我「下一页」或「导出全部」。
```
