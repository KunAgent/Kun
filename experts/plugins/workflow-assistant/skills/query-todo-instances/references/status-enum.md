# 状态枚举说明

---

## 流程单整体状态（DescribeWorkflowInstance.Status）

| 枚举值 | 展示 | 说明 |
|--------|------|------|
| `Running` | 🔄 进行中 | 流程单还在流转中，有节点未完成 |
| `Succeed` | ✅ 已完成 | 所有节点通过，流程单成功结束 |
| `Failed` | ❌ 已失败 | 某节点被拒绝或执行出错，流程单终止 |
| `Revoked` | ↩️ 已撤回 | 申请人主动撤回流程单 |
| `Pending` | ⏳ 待处理 | 流程单创建成功，尚未开始流转 |

---

## 任务节点状态（GetInstanceTaskList.List[].Status）

| 枚举值 | 展示 | 说明 |
|--------|------|------|
| `Running` | 🔄 进行中 | 节点正在等待处理人操作 |
| `Succeed` | ✅ 已完成 | 节点处理完成 |
| `Failed` | ❌ 已失败 | 节点被拒绝或执行失败 |
| `Pending` | ⏳ 待激活 | 等待前置节点完成 |
| `Skipped` | ⏭️ 已跳过 | 条件分支未命中，节点被跳过 |

---

## 审批结果（DealHistory[].JudgeRet）

| 枚举值 | 展示 | 说明 |
|--------|------|------|
| `Agree` | ✅ 同意 | 审批通过，流程继续 |
| `Reject` | ❌ 拒绝 | 审批拒绝，流程终止或退回 |
| `Revoke` | ↩️ 撤回 | 审批人撤回操作 |
| `Transfer` | 🔀 转审 | 转给他人处理 |

---

## 节点类型（TaskType）

| 枚举值 | 展示 | 说明 |
|--------|------|------|
| `approve` | 🔵 审批节点 | 需要指定处理人进行审批 |
| `notify` | 📢 通知节点 | 向指定人发送通知，系统自动完成 |
| `execute` | ⚙️ 执行节点 | 调用外部 API 或执行自动化脚本 |

---

## 流程类型（Type）

| 值 | 说明 |
|----|------|
| `1` | 普通流程 |
| `2` | 测试流程 |

---

## ID 格式规范

| ID 类型 | 前缀 | 示例 |
|---------|------|------|
| 流程 ID (WorkflowId) | `P` | `P2026051400000274` |
| 流程单 ID (InstanceId) | `T` | `T2026051400014945` |
| 任务节点 ID (TaskId) | `N` | `N2026051400073742` |
