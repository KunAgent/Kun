# 展示模板：流程列表（workflow-list）

## 用途
渲染 `ListWorkflow` 接口返回的流程列表数据（场景一/场景三的 Markdown 表格输出）。

## 输出格式

```markdown
## {场景标题}（共 {Total} 条）

| 流程名称 | 流程ID | 分类 | 状态 | 更新时间 | 发起量 |
|---------|--------|------|------|---------|--------|
| {Name} | {Id} | {Category} | {Status_Emoji} | {UpdateTime} | {InstanceCount}次 |

> 输入流程 ID（P 开头）可查看画布详情。
```

### 场景标题规则

| ListType | 标题 |
|----------|------|
| `2` | 我的流程 |
| `0` | 公开流程 |

## 状态 Emoji 映射

| Status 值 | 展示 |
|-----------|------|
| `Published` / 已启用 | ✅ 已启用 |
| `Draft` / 未发布 | 📝 未发布 |
| `Disabled` / 已停用 | ⛔ 已停用 |

## 空结果处理

```markdown
暂无符合条件的流程。

建议：
- 检查关键字拼写是否正确
- 确认当前账号是否有流程查看权限
- 尝试不带关键字查询全部流程
- 切换查询范围（我的流程 ↔ 公开流程）试试
```

## 分页提示（有更多时追加）

```markdown
> 当前显示前 {Limit} 条，共 {Total} 条。如需查看更多，请告诉我「下一页」或「查看全部」。
```
