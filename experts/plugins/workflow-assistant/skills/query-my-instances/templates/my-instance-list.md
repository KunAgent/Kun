# 展示模板：我发起的流程单列表（my-instance-list）

## 用途
渲染 `ListApplyWorkflowInstance` 接口返回的我发起的流程单列表。

---

## 输出格式

```markdown
## 📤 我发起的流程单（共 {Total} 条）

| 流程单名称 | 流程单ID | 发起时间 | 流程耗时 | 状态 | 当前节点 | 当前处理人 |
|-----------|---------|---------|---------|------|---------|-----------|
| {Title截断到25字} | {Id} | {CreateTime} | {CostTime} | {Status_Emoji} | {CurrentTaskName} | {CurrentHandler} |

> 发送流程单 ID（T 开头）可查看详情和审批进度。
```

---

## 状态 Emoji 映射

| Status 值 | 展示 |
|-----------|------|
| `Running` | 🔄 进行中 |
| `Succeed` | ✅ 已结束 |
| `Revoked` | ↩️ 已撤单 |
| `Failed` | ❌ 已驳回 |
| 其他 | ⚠️ 异常 |

## 流程耗时格式化

| 耗时范围 | 展示格式 |
|---------|---------|
| < 60 秒 | `{n}秒` |
| < 60 分钟 | `{n}分钟` |
| < 24 小时 | `{n}小时{m}分` |
| ≥ 24 小时 | `{n}天{m}小时` |
| 进行中（无结束时间） | 计算从 CreateTime 到当前的耗时 |

---

## 空结果处理

```markdown
当前暂无您发起的流程单。

建议：
- 确认筛选条件（状态/关键字）是否合适
- 尝试不带筛选条件查询全部
```

---

## 分页提示（有更多时追加）

```markdown
> 当前显示前 {Limit} 条，共 {Total} 条。如需查看更多，请告诉我「下一页」或「导出全部」。
```
