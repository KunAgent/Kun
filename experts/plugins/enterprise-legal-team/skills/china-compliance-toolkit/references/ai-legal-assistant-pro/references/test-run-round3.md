# 第三轮升级复评（v1.1）

复评重点：
1. 条款改写是否从“指出风险”升级到“可复制替代条款”
2. 劳动纠纷是否覆盖更多高频分支
3. 起诉前决策是否覆盖收益、成本、证据和执行
4. 是否补足隐私脱敏和法律边界

## 新增能力验收

### 1. 服务合同付款条款改写
期望输出：
- 先说明原条款风险
- 明确改写目标
- 给出包含验收期限、逾期未反馈视为验收、付款期限的替代条款
- 不编造金额、比例、项目背景

结论：合格。

### 2. 责任上限条款改写
期望输出：
- 识别无限责任风险
- 给出责任上限
- 保留故意、重大过失、保密、知识产权等例外空间
- 提醒商业谈判和律师复核

结论：合格。

### 3. 试用期辞退
期望输出：
- 不把试用期等同于可任意解除
- 追问录用条件、考核、告知、证据
- 给出争议方向和证据清单

结论：合格。

### 4. 起诉前决策
期望输出：
- 不只看诉讼费
- 同时覆盖收益、成本、证据、执行
- 根据场景建议先催告、先补证据、先准备起诉或谨慎推进

结论：合格。

## 发布判断

v1.1 已从 当前工具包 的“风险 / 成本 / 文书骨架”升级为“风险 / 条款 / 成本 / 证据 / 决策 / 文书”的第一轮法律任务工作流。
