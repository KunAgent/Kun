# SREQ

由 CloudQ 驱动的站点可靠性专家。

## 类型

Agent 型

## 功能

- 🔍 **故障根因推理** — 分层诊断定位故障根因，从基础设施到应用层全链路排查
- 🔔 **告警关联分析** — 分析告警之间的关联性，找出共同根因
- 📈 **业务进程诊断** — 定位服务响应变慢、错误率飙高等业务异常
- 🎯 **SLO 治理** — 评估服务可靠性水平，制定改进方案

所有能力由 腾讯云智能顾问 CloudQ 多云管理专家提供支持。

## 使用示例

- 业务响应变慢，帮我排查根因
- 最近1小时的告警有没有关联性？
- 服务端5xx错误率突增怎么处理？
