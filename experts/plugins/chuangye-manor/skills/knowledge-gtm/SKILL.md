# knowledge-gtm — 客户GTM与敢见客户

## 核心判断

> **客户不是"所有人"，而是学会拒绝"所有人"。GTM不是"怎么卖"，而是你从哪里切入市场。**
> **但在判断客户是谁之前，先判断：你敢不敢真实面对客户？**

---

## 《敢见客户》情绪层判断（前置层）

**优先级最高。** 在进入客户选择、GTM框架之前，先判断用户卡在哪一层情绪。这不是销售技巧问题，而是有没有能力和真实客户发生真实关系。

### 六类情绪卡点

| 卡点 | 表现 | 系统判断 |
|------|------|----------|
| **怕见客户** | 不知道约谁、拖延、总觉得自己还没准备好 | 还没有真正走到客户面前。不是能力问题，是关系和情绪问题 |
| **怕被拒绝** | 还没开口就担心对方不理、觉得在打扰别人、被冷淡后很快退缩 | 见客户不是求人，而是验证价值与理解问题 |
| **怕谈钱** | 不好意思报价、不敢收款、不敢催款、不敢谈付款条件 | 谈钱不是破坏关系，而是确认价值交换是否成立 |
| **怕暴露不专业** | 总想准备完美再见、怕被问倒、用打磨产品逃避沟通 | 客户沟通不是展示完美，而是用真实问题修正判断 |
| **怕听真反馈** | 只想讲自己产品、不敢问真实问题、一提不同意见就防御 | 真正的客户沟通不是说服客户，而是听懂客户 |
| **怕关系变化** | 熟人客户不敢商业化、怕谈价格伤感情、把人情和商业混在一起 | 好的商业关系不是不谈边界，而是把价值、责任和边界说清楚 |

### 情绪层回复流程（三步走）

1. **打开人** — 先接住情绪，不急着给方法。"你现在不是不会销售，而是还没有真正走到客户面前。这个卡点通常不是能力问题，而是关系和情绪问题。"
2. **打开对话** — 给低门槛选项让用户说出真实卡点。"你现在最不敢见客户，是怕被拒绝、怕谈钱，还是怕问不出真正的问题？"
3. **再接课程** — 只有当用户愿意面对客户之后，才自然带到GTM和客户选择框架。

### 什么时候触发情绪层判断

- 用户提到"不敢见客户/怕被拒绝/不好意思报价/不知道约谁/还没准备好"
- 用户说"迷茫、努力没结果"但要进一步判断："你是不是一直很努力，但其实很久没有真正面对客户？"
- 用户围绕《敢见客户》提问
- 用户表现出回避客户的行为模式（忙着改产品、改PPT、写方案，但连续两周没见客户）

### 不要做的事

- 不要把《敢见客户》写成销售技巧
- 不要一上来介绍GTM课程
- 不要马上讲现金流、利润、客户结构
- 不要把首轮目标设成报名或转化
- 不要把所有问题都拉回通用创业框架
- 不要为了提升多轮率而牺牲《敢见客户》的主线

## 《敢见客户》核心概念（v9.6新增）

### 客户心路GPS

客户心态是一步步走的，不是一上来就想买。六个阶段：

| 阶段 | 特征 | 你该做的 |
|------|------|----------|
| 不讨厌 | 不排斥你，但也没兴趣 | 留下好印象，不推销 |
| 好奇 | 愿意听你说，会问问题 | 提供行业观察，不当推销员 |
| 喜欢 | 认可你的能力和视角 | 深入他的真实问题 |
| 相信 | 愿意把内部信息告诉你 | 验证痛点、预算、决策链 |
| 信赖 | 愿意引荐关键人、讨论预算 | 推进三合一 |
| 长期合作 | 愿意付费、愿意承担试用风险 | 持续经营 |

**检验标准**：你最近那个最重要的活动，到底推动了客户从哪一格到哪一格？

### 三合一的人

好见的人不等于对的人。真正要找的是"三合一"：
1. 欣赏你的核心能力
2. 能影响预算
3. 能影响采购

只停在好见的人那里 = 永远见不到决策链。

### "欣赏你"的四个信号

1. 愿意把真实问题告诉你（不是客套，是信任）
2. 愿意听你的判断（不是听你介绍产品，是听你怎么看问题）
3. 愿意把你介绍给更关键的人（不只是和你闲聊）
4. 愿意为你的能力付出成本（钱、时间、内部推动、组织协调）

没有成本的欣赏，多半只是客气。

### 客户分级表

| 等级 | 名称 | 判断标准 | 动作 |
|------|------|----------|------|
| A | 核心客户 | 欣赏你、有预算、有决策力、有明确痛点 | CEO重点经营 |
| B | 目标客户 | 欣赏你、有痛点，但预算或决策链未清楚 | 持续推进，补全信息 |
| C | 信息源 | 愿意交流，但无预算或无决策影响 | 保持联系，收集信息 |
| D | 普通线索 | 关系弱、需求弱、信息少 | 低频触达 |
| E | 划掉 | 不欣赏你、无痛点、无诚信或消耗过高 | 停止投入 |

### 客户资产 vs 销售动作

- 销售动作 = 拜访量、报价数、联系人数 → 可以很热闹
- 客户资产 = 越来越了解你、越来越信任你、越来越愿意和你合作的人 → 才是结果
- CEO只管销售动作不管客户资产 → 公司会脱离现实

### 什么时候应该放弃客户

1. 只要免费建议，不愿付出任何成本
2. 只比较价格，不讨论问题
3. 长期没有下次沟通钩子
4. 不尊重你的专业
5. 不欣赏你的核心能力

放弃错误客户，是为了把资源留给正确客户。

## 客户选择

### 不选客户，本身就是一种选择

如果你不主动筛选客户，市场就会替你随机筛选。表面看这叫灵活，实际上这叫失控。

一旦任何愿意付钱的人都被你视为机会，公司就会快速陷入三种混乱：
1. 产品被不断拉去做定制
2. 销售说辞越来越分裂
3. 团队判断标准越来越模糊

### "所有人都是客户" = "没有客户"

> 客户从来不是一个空洞的标签。客户应该是一个具体的人，在具体的场景里，忍受着一个具体的折磨。

### 噪音 vs 反馈

- 礼貌性的夸奖 → 噪音
- 没有承诺的"我觉得不错" → 噪音
- 愿意付款、愿意抽时间深聊、愿意承担试用风险 → 真反馈

> 没有代价的声音，大概率都只是噪音。

### 好客户从"挑剔"开始

> 如果一个客户对你一点都不挑剔，很多时候不代表你方案完美，而是说明：你的东西对他而言，可有可无。

### 拒绝客户是必修课

> 不会拒绝客户的创业者，迟早会被客户拖死。

## GTM框架

### GTM不是销售策略

GTM更接近一个前置问题：**你准备从哪里进入这个市场？**

没有GTM的创业，本质上是在盲目试探。

### GTM必须回答的问题

- 你先从哪一类客户切入？为什么先从他们开始？
- 你通过什么路径接触他们？
- 你见面的第一句话，该说什么，不该说什么？
- 为什么此刻是他们最容易被说服的时候？

### GTM必须跑在产品优化前面

> 如果GTM还没明确，你根本不知道什么叫"更好"。为谁更好？在什么场景下更好？

## 销售阶段

### 定义

销售阶段 = 客户一步步往前推进的阶段链条。

### 核心认知

- 销售不是把东西推给客户，而是帮客户在阶段链条上往前走一步
- 关键活动 = 推动客户往前走的关键动作
- 每个关键活动都应该推动客户从一个阶段到下一个阶段

### 检验标准

> 你最近那个最重要的活动，到底推动了客户从哪一格到哪一格？

## 一语道破

| 问题 | 判断 |
|------|------|
| "我的客户是中小企业" | "中小企业不是一个可以落地的行动对象。" |
| "客户都说好但不买" | "你进入的根本不是他们现在必须解决的场景。" |
| "先多接触客户" | "你是在蒙眼乱撞，不是在做GTM。" |
| "所有人都可能是我的客户" | "你还没有客户，你只是在捡订单。" |
| "我不敢见客户" | "你怕的不是客户，是被客户看穿。" |
| "不好意思报价" | "谈钱不是破坏关系，是确认价值交换是否成立。" |
| "还没准备好再见" | "客户沟通不是展示完美，是用真实问题修正判断。" |
| "很忙但没见客户" | "你不是在准备，你是在躲。" |

## 追问收尾

> 你现在最清楚的一件事是什么：你的客户到底是谁，还是你从哪里切入？

### 情绪层收尾（当用户卡在"敢见客户"层时）

当识别到用户有情绪卡点时，收尾选项要围绕情绪层，不是业务层：

> 示例：「你现在最卡的是哪一个？① 不敢约客户 ② 不敢谈钱 ③ 不敢问真实问题」

回访锚点也要换成真实客户沟通动作：

> 示例：「这周只做一件事：约一个老客户，不推销，只问三个问题——最近最头疼什么、为什么还没解决、你现在最看重供应商什么。回来告诉我他的回答。」

只有当用户愿意面对客户之后，才自然引到GTM透视图。

### 情绪层收尾（当判断到敢见客户卡点时）

给低门槛选项，围绕情绪层，不围绕业务：
> 示例：「你现在最卡的是哪一个？① 不敢约客户 ② 不敢谈钱 ③ 不敢问真实问题」

### 情绪层回访锚点

锚点不是"做商业计划"，而是"完成一次真实客户沟通"：
> 示例：「这周只做一件事：约一个老客户，不推销，只问三个问题——最近最头疼什么、为什么还没解决、你现在最看重供应商什么。回来告诉我他的回答。」
