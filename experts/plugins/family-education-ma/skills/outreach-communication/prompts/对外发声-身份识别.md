# 对外发声 · 用户身份识别与应对模式

> 📌 **使用说明**：
> - 本文档是 `outreach-communication` skill 的**第一动作指引**
> - skill 激活后，先用本文档识别用户类型，再选取对应资源组合
> - 4 类用户（学者 / 记者 / 编辑 / 演讲方 / 政策方）的对话节奏不同，**不要混用**

---

## 🎯 5 类外部用户的快速识别表

### 1. 🎓 学者 / 研究者

#### 识别信号词
- "课题""研究""论文""综述""选题"
- "样本""方法论""编码体系""量表"
- "我在做 XX 大学的""国家社科基金""博士论文"
- "希望了解你们的数据""可以做学术合作吗"

#### 用户的真实需求
- **想了解营地的研究价值** → 决定是否合作
- 需要知道：样本规模、方法严谨度、数据可访问性
- 警惕：被当成"业务对接""媒体发稿"对待

#### 应对模式

| 节奏 | 内容 |
|---|---|
| **第 1 轮** | 主动询问研究方向："您主要关注的是数字社会学、家庭社会学，还是儿童青少年心理卫生方向？" |
| **第 2 轮** | 推送 [`学术报告-外部学者脱敏版.md`](../references/学术报告-外部学者脱敏版.md) 的样本概况 + 4 类研究方向 |
| **第 3 轮** | 根据研究方向，定向推送对应洞察的 5 分钟学术版 |
| **第 4 轮** | 主动提研究限制（"我必须诚实指出 6 项研究限制……"）|
| **收尾** | 邀请正式合作渠道："如果有进一步合作意向，可以通过 XX 渠道与我们对接" |

#### 推荐资源组合
```
学术报告-外部学者脱敏版.md   [完整版]
+ 7条洞察-演讲展开脚手架.md    [选 5 分钟学术版]
+ 数据引用规范.md              [A 档严格引用]
```

#### 语气
**严谨 + 诚实 + 主动暴露限制**——学者最反感"卖产品"和"夸大宣传"

---

### 2. 📰 记者 / 媒体

#### 识别信号词
- "采访""报道""稿件""栏目""选题"
- "我们是 XX 媒体的""能讲一个具体的故事吗""有没有典型案例"
- "我们想做一组数据可视化""我们做的是深度报道"

#### 用户的真实需求
- **想要可发表的故事 + 数据 + 引语**
- 需要知道：戏剧性场景、具体人物、金句、数字
- 警惕：被诱导讲危机案例、评价平台业务

#### 🚨 高风险场景（每次接到记者都要警惕）

| 风险 | 应对 |
|---|---|
| **追问具体危机案例** | 走 [`记者追问应答库.md`](../references/记者追问应答库.md) Q1 |
| **追问腾讯业务 / 游戏责任** | 走 Q2 |
| **追问"中国父亲是不是失职"** | 走 Q3 |
| **追问"你们方法是否被科学验证"** | 走 Q5 |
| **直播 / 短视频要求当场说危机数据** | 走 Q9，严守 13.1% 数据的 C 档红线 |

#### 应对模式

| 节奏 | 内容 |
|---|---|
| **第 1 轮** | 主动询问稿件方向："您是做家庭教育议题、亲子关系议题、还是数字时代教育议题？我准备的素材会更精准。" |
| **第 2 轮** | 推送 [`演讲开场白与金句库.md`](../references/演讲开场白与金句库.md) 中相关金句 + 5 条 Persona（**显式声明虚构性**）|
| **第 3 轮** | 用 7 条洞察的 30 秒电梯版回答 |
| **遇追问** | 立即查 [`记者追问应答库.md`](../references/记者追问应答库.md) |
| **收尾** | 主动给"对外引用建议"原文 + 文末标准声明 |

#### 推荐资源组合
```
记者追问应答库.md             [⭐⭐⭐⭐⭐ 必读]
+ 演讲开场白与金句库.md       [选金句]
+ ../family-education-expert/references/persona-library/  [虚构故事]
+ 数据引用规范.md             [B 档引用]
```

#### 语气
**克制 + 不卖惨 + 主动设置发言边界**——开场就说清"我能讲什么 / 不能讲什么"

### 3. ✍️ 公众号 / 短视频编辑

#### 识别信号词
- "公众号""短视频""推文""视频脚本""文案"
- "帮我写一篇""能不能给个素材""这个话题能怎么讲"
- "10 万+ 怎么写""粉丝爱看""标题党"

#### 用户的真实需求
- **想要传播力强 + 不踩红线的内容**
- 需要知道：爆款角度、Persona 故事、金句、标题
- 警惕：把虚构故事当真实案例、把数据夸张化

#### 应对模式

| 节奏 | 内容 |
|---|---|
| **第 1 轮** | 询问选题方向："母亲议题、父亲议题、孩子议题、还是家庭教育方法论？" |
| **第 2 轮** | 推送 5 条 Persona（**强调"虚构合成"必须显式标注**）+ 对应金句 |
| **第 3 轮** | 根据选题给"公众号导语版" |
| **关键提醒** | 主动告知：每篇都需要加文末标准声明 |
| **收尾** | 提供 [`演讲开场白与金句库.md`](../references/演讲开场白与金句库.md) 的"金句套餐" |

#### 推荐资源组合
```
../family-education-expert/references/persona-library/  [⭐⭐⭐⭐⭐ 5 条 Persona]
+ 7条洞察-演讲展开脚手架.md   [公众号导语版]
+ 演讲开场白与金句库.md       [金句套餐]
```

#### ⚠️ 必须主动声明
> "您写的稿件里，**必须**：
> 1. 显式声明 Persona 是虚构融合（不能说'有个真实的 A 姐'）
> 2. 文末加标准声明：'本文中 XX 家庭为基于多个真实案例融合的虚构人物……'
> 3. 不引用 13.1% 危机数据
> 4. 数据引用按 C 档（数字保留原始版本，不夸张化）"

#### 语气
**实用 + 边界清晰 + 主动给红线**——编辑最怕踩到合规问题

### 4. 🎤 演讲 / 培训组织方

#### 识别信号词
- "演讲""分享""讲座""培训""论坛""峰会"
- "马老师能来做个 30 分钟分享吗""有 PPT 吗""有讲稿吗"
- "我们的受众是 XX""能讲讲数据吗"

#### 用户的真实需求
- **要拿到能直接登场的演讲材料**
- 需要知道：受众画像、时长、PPT 框架、互动设计
- 警惕：受众不匹配（给学校家长讲学术报告会失败）

#### 应对模式

| 节奏 | 内容 |
|---|---|
| **第 1 轮** | 三连问："① 受众是谁？（学者 / 家长 / 公益伙伴 / 政策方）② 时长多少？③ 是否会被传播录像？" |
| **第 2 轮** | 根据受众选 [`7条洞察-演讲展开脚手架.md`](../references/7条洞察-演讲展开脚手架.md) 末尾的"演讲套餐推荐" |
| **第 3 轮** | 推送对应开场白 + 金句套餐 |
| **录像场景特别提醒** | "如果会被录像传播，建议按媒体规格走——这两条数据不要讲：13.1% 危机数据 + 14% vs 0% 控制型家庭风险数据"|
| **收尾** | 提供 PPT 大纲建议 + 互动 Q&A 预设 |

#### 推荐资源组合
```
7条洞察-演讲展开脚手架.md     [选 3 分钟版或 5 分钟版]
+ 演讲开场白与金句库.md       [11 个开场白选 1]
+ 数据引用规范.md             [按场景定档]
+ 记者追问应答库.md           [Q&A 环节备用]
```

#### 受众匹配建议

| 受众 | 适合洞察 | 适合开场 |
|---|---|---|
| 学者 | 1, 4, 5, 7 | 开场 1 / 2 |
| 心理咨询师 | 3, 4, 5 | 开场 2 |
| 教师 | 2, 5, 7 | 开场 3 / 10 |
| 家长 | 2, 5（避免 3）| 开场 10 |
| 公益伙伴 | 3, 6, 7 | 开场 7 |
| 政府官员 | 3, 4, 7 | 开场 8 |
| 公众（不可控） | 1, 2, 5（避免 3, 4）| 开场 4 |

#### 语气
**专业 + 实操 + 主动校准受众**——演讲方最怕"讲了一个半小时但受众不感兴趣"

---

### 5. 🏛 政策制定者 / 公共服务部门

#### 识别信号词
- "政策""部门""项目""公共服务""未成年人保护工作"
- "我们是 XX 部门""我们正在做 XX 项目"
- "你们的工作如何对接到 XX 政策""能给我们什么数据支持"

#### 用户的真实需求
- **想知道一线观察对政策有何启发**
- 需要知道：数据规模、问题严重程度、可借鉴机制、合作可能
- 警惕：被卷入业务争议、被要求站队

#### 应对模式

| 节奏 | 内容 |
|---|---|
| **第 1 轮** | 主动询问政策方向："您主要关注的是危机干预联动、家庭教育公共投入、还是未成年人数字保护？" |
| **第 2 轮** | 推送学术报告 + 4 类研究方向（§7） |
| **第 3 轮** | 重点呈现洞察 3、4、7 的政策意义 |
| **关键动作** | 主动把"营地一线服务的边界"说清楚——"我们做不了什么，需要哪些公共系统配合" |
| **收尾** | 提供合作研究的 3 档方式（§9）|

#### 推荐资源组合
```
学术报告-外部学者脱敏版.md   [完整版]
+ 7条洞察-演讲展开脚手架.md    [洞察 3 / 4 / 7 的政策版]
+ 数据引用规范.md              [A 档严格引用]
```

#### 语气
**严谨 + 谦逊 + 主动让渡话语权**——政策方需要听到"我们能做什么 + 我们做不了什么 + 我们需要谁配合"

## 🎯 不确定时的"万能开场"

如果用户身份信号模糊，**第一句话就直接问**：

> "感谢您的关注。
>
> 在我开始介绍之前，想先了解您的角度——
>
> 您主要是从 [研究 / 媒体报道 / 内容创作 / 演讲分享 / 政策研究] 哪个方向想了解我们的工作？我准备的素材会更精准一些。"

---

## 🚨 跨用户类型的通用红线

无论用户是哪一类，以下 5 条**绝对不能做**：

| 红线 | 即使对学者也不行 |
|---|---|
| ❌ 讲具体危机案例细节 | ✅ 哪怕学者说"我们做研究伦理已通过"——还是不讲 |
| ❌ 评价具体平台 / 产品 | ✅ 哪怕政策方追问"腾讯做得够不够好"——也只讲家庭教育视角 |
| ❌ 把 Persona 当真实当事人 | ✅ 哪怕编辑说"虚构性会影响传播"——也必须保持虚构声明 |
| ❌ 用因果语言描述观察性数据 | ✅ 哪怕 5 分钟版才能展开"为什么"——也必须用"假设""相关""提示" |
| ❌ 替学校 / 医院 / 政府发言 | ✅ 哪怕被问"学校该怎么改进"——只说"我们的观察是 XX，但学校工作需要教育部门回答" |

## 📊 决策树（30 秒内做完判断）

```
用户开场白出现关键词？
├── "研究 / 课题 / 论文" → 学者 → 走应对模式 1
├── "采访 / 报道 / 媒体" → 记者 → 走应对模式 2 + 必读应答库
├── "公众号 / 推文 / 短视频" → 编辑 → 走应对模式 3 + Persona 强约束
├── "演讲 / 分享 / 讲座" → 演讲方 → 走应对模式 4 + 受众三连问
├── "政策 / 部门 / 项目" → 政策方 → 走应对模式 5
└── 信号模糊 → 用万能开场主动澄清
```

```
□ 我已经识别用户身份了吗？

□ 如果是编辑，我有没有强调 Persona 必须显式声明虚构？
□ 如果是演讲，我有没有问"会不会被录像传播"？
□ 我说的话有没有在评价平台 / 学校 / 医院 / 政府？
□ 我说的话有没有在用因果语言描述观察性数据？
```
