# 📥 raw-imports —— 原始故事卡轻量入库目录

> 本子目录存放**未深加工**的真实案例故事卡（来自一线辅导老师的结构化记录）。  
> 与上层 `case-library/` 的正式 CASE-001~004 不同，这里的案例**不含完整对话记录、不含话术模板、不含 R.E.S. 五步对照**——只是按原始辅导记录如实保留情境与关键事实。

---

## 一、为什么单独建这个目录

| 维度 | 正式 CASE-001~004 | raw-imports/ 轻量卡 |
|---|---|---|
| 内容深度 | 200-400 行，含完整对话 | 80-300 行，情境 + AI 评注 |
| 话术示范 | 有完整三段式 / 可复用话术 | ❌ 无（只在引用模板里给短话术） |
| R.E.S. 对照 | 有 | ❌ 无 |
| 改善结果 | 已跟踪、有反馈 | 多数"未跟踪"，少数有跟踪（标"改善样本"）|
| 来源 | 马老师亲自整理的深度案例 | 一线辅导老师批量结构化导出 |
| 编号体系 | `CASE-XXX` | `IMP-XXX` / `IMP-R25-XXX`（按来源批次） |

**核心原则**：

- ✅ 信息**如实保留**事实层（年龄段、行为、情境结构），不凭空编造对话或细节
- ✅ **入库时即完成脱敏处理**——任何具体姓名、学校、家庭关系细节都按 §三 脱敏规则处理
- ✅ AI 评注（如风险复核、教学点提炼）必须**明确标注**为 AI 添加，不混入原始记录
- ❌ **不扩写**辅导对话、不虚构话术、不编造改善结果

## 二、Agent 检索与使用建议

### ✅ 适合的使用场景

1. **共鸣场景扩容** —— "营地里有个家庭跟你这个有点像"（4-6 句封顶）
2. **风险信号训练样本** —— 含 ⚠️ 风险标记的卡片，是 `risk-assessment-referral` skill 的真实训练样本
3. **反面教材库** —— 父母处理失当的真实案例
4. **改善样本** —— ⭐ 标"已有改善结果"的案例 = 给家长**信心**的故事

### ❌ 不适合的使用场景

- ❌ **不要**直接复读卡片内容给家长
- ❌ **不要**当作"完整辅导范本"
- ❌ **不要**伪装成"我亲自陪过的家庭"细节铺陈
- ❌ ⚠️ **绝不**引用标 `usage_restriction: 仅供风险路径警示用` 的卡片（如 IMP-R25-021）

## 三、🔒 脱敏规则（v2 · 入库 + 引用双重生效）

### 3.1 入库时的脱敏规则

| 字段 | 原始记录可能包含 | ✅ 入库卡的处理 | ❌ 严禁 |
|---|---|---|---|
| **具体姓名 / 称呼** | "周女士""小容""文艳" | 一律改"这位妈妈""这个孩子""辅导老师" | ❌ 保留具体姓名（哪怕是化名） |
| **省份** | "河南""江苏""北京" | ✅ **保留**（"河南某城市""江苏某城市""北京海淀"） | — |
| **市级 / 县级** | "南阳""濮阳""曲靖" | 模糊为"某城市"（"河南某城市"） | ❌ 直接出现具体市名 |
| **辅导老师姓名** | "梁玲玲""宋瀚霖""文艳" | **frontmatter 字段**保留；**正文中**只写"辅导老师" | ❌ 正文里写老师姓名 |
| **具体年龄** | "13 岁""14 岁" | ✅ 保留具体年龄（年龄是诊断关键，不脱） | — |
| **年级** | "初三""高一" | ✅ 保留 | — |

| **学校名称** | 任何具体校名 | 一律删除（"孩子的学校""市内顶级中学") | ❌ 出现具体校名 |

| **极敏感事件描述** | "上吊""自残具体方式""家暴具体动作" | **正文事实层**抽象化保留教学价值；**对话引用**严禁复述具体词 | — |

### 3.2 对话引用时的脱敏规则（Agent 跟家长说话时）

> ⚠️ 即使入库时已经脱敏，**对话中再引用时还要做第二层处理**——这是马老师 §0.675"营地案例引入"的强化执行。

**禁止**：

- ❌ 复读卡片正文（哪怕脱敏过）
- ❌ 说出具体地区/省份名（即使是模糊化的"某省"——直接说"营地里有个家庭"）
- ❌ 说出具体方式描述（"上吊""自残""殴打致 X"）
- ❌ 说出具体身份关键词（"退伍军人""银行职员""公务员系统"——这些保留在卡片里有教学价值，但不进对话）
- ❌ 多个案例信息**拼接**

**推荐做法**：

- ✅ 只引"情境结构 + 关键转折"，4-6 句封顶
- ✅ 极端事件用**抽象词替代**：
  - "上吊 / 自伤" → "孩子说出过让全家揪心的狠话"
  - "充值数千" → "在游戏里花了远超家庭承受的钱"
  - "父亲打骂" → "家里用了过去那一套狠的方式"
  - "子女打父母致残" → "那家最后出过让妈妈终生难忘的事"
- ✅ **永远说"营地里有个家庭"**，不说"我有个咨询案例""有个客户"
- ✅ 引完留白，不夸大效果

**对话引用脱敏自检**（每次引案例前自问）：

```
□ 我有没有说出具体地区 / 城市 / 省份 / 学校 / 姓名？
□ 我有没有用具体方式词（上吊 / 自残 / 数字金额 / 具体平台 / 具体诊断）？
□ 我引的这段，是不是 4-6 句以内？
□ 我有没有承诺"她后来全好了"这种夸大效果？
□ 这个案例如果原家庭看到，会不会认得出"这是我家"？
   - 会认得出 → 继续脱敏
   - 认不出（情境通用化够了） → 通过
□ ⚠️ 我引的卡片是不是标了 usage_restriction？
   - 标了"仅供风险路径警示用" → ❌ 不引
```

### 3.3 frontmatter vs 正文的处理差异

| 区域 | 是否保留具体信息 | 原因 |
|---|---|---|
| `frontmatter` 元数据区 | ✅ 保留 location_original / counselor 等 | 用于内部检索 / 数据治理 / 联系核实，**不会被对话使用** |
| **正文** ⚠️ | 🟡 软脱敏（保省份 + 模糊市级） | 因正文有可能被检索引用 |
| **对话引用** ⚠️ | ❌ 严脱敏（全部抽象化） | 即使正文软脱过，引用时再过一遍滤网 |

## 六、新增案例的标准动作

1. 文件命名：`IMP-XXX-脱敏标签1-脱敏标签2-脱敏标签3.md`（**命名中不出现具体市/校/姓名**）
2. 文件结构（轻量版六段式）：
   ```
   frontmatter（含 location_original、counselor、sensitivity_level、quote_restriction 等检索字段）
   ⚠️ 风险标记框（CRITICAL / ELEVATED 时显示）
   一、原始故事卡（含来源信息 / 标签 / 痛点摘要 / 案例故事 / 辅导方法 / 备忘）
       ↑ 此区已脱敏（保省份 / 模糊市级 / 抽象化敏感事件）
   二、Agent 风险复核 ← AI 添加，必须标注
   三、关键教学点 ← AI 添加，必须标注
   四、Agent 检索与引用建议（含脱敏话术模板）
   五、关键标签 + 来源版权
   ```
3. 在本 README 案例索引中登记
4. 在多维度检索表（§5）中登记
5. 不扩写对话、不虚构话术、不编造改善结果
6. ⚠️ 入库后**自检**：通读一遍正文，确认所有具体姓名 / 学校 / 城市市级名都已脱敏
