## 三、🤖 关键教学点（AI 添加）

### 教学点 1 · "父亲创业失败 → 把希望压在孩子身上"——典型投射模式

这家最深的结构性问题不是游戏，是父亲的：

```
创业失败（中年挫败）
    ↓
对未来失控感强烈
    ↓
"如果儿子走我老路就完了"
    ↓
"我要把我的经验传给他"
    ↓
（但我自己是失败的）
    ↓
对孩子施加超出他承受能力的期待 + 管教
    ↓
孩子反抗 + 摔手机 + 沉迷游戏
    ↓
父亲更焦虑 → 更控制 → 偏执化
```

→ Agent 引用时**核心教学点**：**父亲在管的不是孩子，是自己心里那个"失败的我"**。  
→ 给家长（如果是这位爸爸）的话：**先放过你自己，孩子才能被放过**。

### 教学点 2 · "对腾讯偏执"——找一个外部对象承接挫败感

父亲把所有挫败感投到"腾讯""游戏""平台不作为"上——

→ 这是**心理防御机制**：把"我管不了我儿子"的无力感，转换成"是腾讯害的"。  
→ Agent 接到这种父亲时**不要**:
- ❌ 与父亲辩论腾讯责任 / 防沉迷系统
- ❌ 替平台澄清
→ Agent 应该：
- ✅ 接住父亲的挫败感（"听到您说这么多年下来这么累"）
- ✅ 把对话从"找谁负责"拉回"现在能做什么"
- ✅ 温和指出：**孩子不是被腾讯害的，孩子是被"看不到自己人生路"困住的**

### 教学点 3 · "技校 = 走打工路"——阶层焦虑的放大器

父亲心里那条等式：技校 → 打工 → 失败人生。  
但这其实是**父亲自己的恐惧**，不一定是孩子的现实。

→ Agent 引用时可以提醒：
- 16 岁读技校的孩子，未来路径很多（不只打工）
- 父亲"传管理经验"的执念，是因为他自己**没找到别的路给孩子**
- 真正的支持：**帮父亲先看见技校孩子的多种可能**，而不是逼孩子接父亲的盘

### 教学点 4 · "把孩子放到爷爷奶奶家"——物理隔离 ≠ 解决

父亲已经把孩子送回老家——这是常见的**"我管不了，让别人管"**的逃避。但：
- 爷爷奶奶接不住青春期孩子的复杂需求
- 物理隔离会让孩子感到**被放弃**
- 父亲心理上没解开 → 接回来还是同样问题

→ Agent 给方法时：父亲先**接孩子回来**之前，必须先做**自己的功课**——不然只是把问题循环延后。
