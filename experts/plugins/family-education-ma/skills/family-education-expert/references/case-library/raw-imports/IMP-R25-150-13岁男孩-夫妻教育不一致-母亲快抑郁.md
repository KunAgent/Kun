## 三、🤖 关键教学点（AI 添加）

### 教学点 1 · ⭐⭐⭐⭐⭐ "严妈 + 松爸 + 孩子走爸爸那条路" = 经典恶性三角

⭐ 这是 raw-imports 库**最完整的"夫妻教育不一致"样本**：

```
妈妈做规则
    ↓
孩子对抗
    ↓
爸爸妥协
    ↓
妈妈"被打脸" → 更焦虑
    ↓
妈妈管得更严
    ↓
爸爸觉得"她太严" → 更宽容
    ↓
夫妻当孩子面争执
    ↓
孩子学会"找爸爸 / 越过妈妈"
    ↓
妈妈成"恶人"，爸爸成"好人"
    ↓
妈妈陷入"快抑郁"
```

→ 给家长的关键认知：**这不是"孩子有问题"，是"夫妻系统出了问题"**。  
→ 任何"管孩子"的方法在这种结构里都**无效**——必须**先修夫妻**。

### 教学点 2 · ⭐⭐ "儿子一对抗，老公就妥协"——黄金诊断句

⭐ 这位妈妈那句"**儿子一对抗我老公就妥协**"——是**最精准的家庭系统诊断**。

→ Agent 听到家长说出这句话时：
- 不要给"如何管孩子"的方法
- 直接讨论"**爸爸为什么会妥协**"
  - 怕冲突？
  - 怕伤孩子？
  - 不想得罪老婆但也不想得罪孩子？
  - 想做"轻松的家长"？
  - 暗中觉得老婆太严？

→ 妥协的**根因不解决**，规则永远建不起来。

### 教学点 3 · ⭐⭐⭐ "夫妻当孩子面争执" = 孩子最大的不安全感来源

⚠️ 当孩子面吵架的危害 ≠ 普通冲突——

→ 在孩子心里：
- "爸妈因为我吵起来" = "**我是问题的源头**"
- "他们意见相反" = "**我应该听谁的？**"
- "他们吵得这么凶" = "**家会不会散？**"

→ 给家长的**底线规则**：
- ❌ **绝不**当孩子面就教育问题争执
- ✅ 有分歧 → 私下解决 → 对孩子**统一对外**
- ✅ 即使不同意也要先说"**爸爸/妈妈刚才说的有道理，我们再补充一点**"

### 教学点 4 · "母亲焦虑挑剔父亲生活习惯"——焦虑外溢的隐形信号

⭐ 注意原文细节：母亲对父亲的不满**不只是育儿**：
- "**洗碗是用水浪费**"
- "**买菜总买最贵的**"

→ 这种**鸡毛蒜皮的挑剔**通常说明：
- 母亲焦虑已经**外溢**到所有领域
- 真正的挫败感不在洗碗买菜——**是孩子失控**
- 但她不能直接对孩子发火（理智不允许）
- **转嫁给丈夫**最容易

→ Agent 给方法时关键：
- ❌ 不要劝妈妈"对老公耐心一点"——她做不到
- ✅ 帮妈妈识别"**我现在在挑老公，其实是因为孩子的事我撑不住**"
- ✅ 把妈妈的能量从"挑老公"拉回**接纳自己撑不住**

### 教学点 5 · "心理学背景父亲被妻子解读为'不作为'"——父亲松弛的双面性

⭐ 父亲"主张自然引导 + 不急 + 老说找方法"——

→ 妻子的解读：
- "**他焦虑也焦虑，但他不行动**"
- "**他所谓的找方法就是等、就是拖**"
- "**他是不作为**"

→ 父亲的**真实状态**可能是：
- 他**比妻子更懂**孩子需要时间
- 但他**没能力**让妻子相信他
- 他**用退让**保持家庭表面和谐
- 这种退让**反而被解读为不负责**

→ 给这种家庭的关键金句：

> **"爸爸的'松弛'如果讲不清楚，在妈妈眼里就是'冷漠'。爸爸需要先把'我为什么不急'讲明白——你不讲，你的爱就被误解。"**

→ 给爸爸的方法：**说出来**——"我不催他不是不在乎，是我相信他需要时间消化"。

### 教学点 6 · "稍微好的"和"快抑郁的"妈妈——评估边界

母亲自述"**快抑郁了**"——

→ 这是**警戒线信号**：
- 如果只是"我累了我心烦" = 还能撑
- 如果说出"**快抑郁了**" = 已经在自我评估状态
- 必须立即推动**专业评估** —— 不论是否真的临床抑郁

→ Agent 听到家长说"我快抑郁了""我撑不住了" —— 不要安慰"不会的""你想多了" —— 直接**承认**："您说的我听到了，您先别一个人扛——我们一起评估一下您现在状态。"

### 📝 标准引用模板（脱敏 · 对话级）

**用于"夫妻教育不一致"场景**（最常见）：

```
营地里有个家庭，孩子 13 岁——
妈妈管得严，爸爸主张自然引导。
妈妈定的规则，孩子一对抗，爸爸就妥协。
妈妈跟我说："我老公就是不作为，就是等、就是拖。"
我反过来问她："您觉得他妥协，是因为他不爱孩子，
还是因为他怕冲突？"
她想了想，说："……他怕冲突。"
您看——很多时候我们以为对方"立场不同"，
其实只是对方"没本事让你看见他的方式"。
管孩子之前，先管这件事。
```

**用于"当孩子面吵"场景**：

```

"我爸妈每天因为我吵架。我就是那个让他们吵的人。"
他不是叛逆，他是在道歉。
夫妻在孩子面前每吵一次，
孩子就把"我是家里的累赘"刻得更深一道。
```
