## 三、🤖 关键教学点（AI 添加 · 反面教材）

### 教学点 1 · "充值即上学" = 勒索循环的极端形态

这是 §六大信念第 2 条"先关系，后行为"的**毁灭性反面教材**：

```
孩子被老师体罚 + 父母也打孩子
        ↓
所有成年人没有一个站在孩子这一边
        ↓
孩子心里：你们都不要我，那只剩游戏要我
        ↓
妈妈用充值"哄" → 孩子学到"我闹 → 你给"
        ↓
"不充值不上学"成立
        ↓
孩子升级勒索（要更高级账号 / 要更多充值）
        ↓
妈妈节节退让 → 暴力升级
        ↓
最终发生身体伤害
```

→ 给家长的关键提醒：**"用钱哄上学"看起来是临时止血，实际上是把刀递给孩子。**  
→ Agent 听到家长说"我只能用 X 哄他做 Y"时，必须立即识别这是勒索循环的早期信号。

### 教学点 2 · "妈妈也打骂了孩子" = 联盟错位

⭐ 这是这家最深的伤——

老师体罚孩子时，妈妈**没有站在孩子这一边**，反而**也打骂孩子**。

→ 这一幕在孩子心里的解码：
- "我连家也没有"
- "妈妈是老师那边的"
- "我得自己保护自己"

→ 一旦联盟错位发生，**修复成本极高**——孩子学会的是"全世界都没有我"。

→ 给家长的提醒：**孩子在外面挨了打，回家再挨一次的话，他对家的信任就此结束**。

### 教学点 3 · "父亲拒绝心理咨询" = 系统性盲区

父亲是退伍军人，受过去观念影响——

→ 在这种家庭，常见的认知盲区：
- "看心理医生 = 神经病"
- "我家没事"
- "这点事都搞不定算什么男人"
- "花那个钱干啥"

→ Agent 处理这种家长时**不要硬怼**：
- ❌ "您不去就是耽误孩子"
- ✅ "我懂您的顾虑——我们家里那一辈也有这个想法"
- ✅ 用**关心妈妈的角度**切入："心理咨询不是给孩子的，是给妈妈的——她现在状态不好"
- ✅ 给"心理咨询"换个名字："就当是夫妻俩去聊聊，**不算治病**"

### 教学点 4 · "妈妈多次产生轻生念头" 是这家最紧的红线

⚠️ 在母亲已经"多次产生轻生念头"的家庭里，**任何家庭教育动作都让位于救妈妈**。

→ 这种妈妈的特征：
- 表面还在管孩子、还在为孩子操心
- 但内心已经"如果不是为了孩子，我就……"
- **她不是在"忍"，她是在"撑"** —— 撑久了会断
- 一旦她"看到孩子也救不了" → 自伤自杀风险陡增

→ Agent 必须做的：
1. **妈妈本人安全永远第一**
2. 给方法**先给妈妈喘息的方法**（如何让自己每周至少 2 小时不想孩子的事）
3. 不要让妈妈承担"必须改变孩子"的责任——她做不到 = 她会更自责 = 危险升级

### 教学点 5 · "暴力升级三阶段"（针对子女暴力）

子女对父母施暴**很少是突然发生**，通常经历：

```
阶段 1：言语暴力（骂 / 顶撞 / 摔东西）
    ↓
阶段 2：威胁暴力（举手要打 / 用物品威胁 / 自伤威胁）
    ↓
阶段 3：身体暴力（实际动手 / 致伤）
```

→ 任何阶段 1 信号出现，家长就**必须**：
- 不再单独面对孩子
- 引入第三方（社工 / 警察 / 居委会 / 学校）
- 必要时**物理隔离**（孩子去外公外婆 / 父亲家短住）

→ 千万**不要**等到阶段 3 才求助。
