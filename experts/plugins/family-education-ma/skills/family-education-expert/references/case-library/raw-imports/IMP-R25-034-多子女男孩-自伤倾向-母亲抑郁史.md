## 三、🤖 关键教学点（AI 添加）

### 教学点 1 · "被忽视的老大"——多子女家庭最常见的隐形伤害

这家完美呈现了**"妹妹生病"如何摧毁老大**的链路：

```
妹妹先天性心脏病 → 全家围着妹妹转
        ↓
父亲不堪打击 → 抑郁 → 失能
        ↓
母亲一边照顾病妹妹 + 一边照顾抑郁的丈夫
        ↓
两个大儿子 = 事实上的"自由放任 + 无人陪伴"
        ↓
持续 1-2 年
        ↓
等家庭功能恢复时——老大已经不一样了
```

→ Agent 看到家长描述"我有几个孩子，最近一两年因为 X 没怎么管 Y" 时：
- 必须立即识别 = "**被忽视的孩子**"危险信号
- 这种孩子的崩溃**不是突然的**——是憋了一两年的爆发
- "他变了" = 他**已经独自面对**了大人没看见的事

### 教学点 2 · "偷看妈妈手机 + 独自承受秘密"——孩子在保护父母

⭐ 这是这家最戳心的细节——

孩子偷看了妈妈手机，**早就知道**妹妹病、爸爸抑郁。但他：
- **没告诉妈妈**他知道
- **跟老师哭诉**了很长时间
- **怕妈妈走不出阴影**

→ 这不是叛逆，这是**孩子在保护父母**：
- "我不能再加重妈妈的负担"
- "我替你扛着我知道的事"
- 孩子**事实上承担了成年人的情感劳动**

→ 给家长的关键提醒：**"孩子'懂事'的背后，常常是孩子在替你扛"**。  
→ Agent 引用时：**这种孩子最危险**——因为父母看不到他在扛。

### 教学点 3 · "一道题不会就打自己的头" = 完美主义崩塌

这种**针对自己的攻击**通常出现在：
- 极度自我要求高的孩子
- 长期内化了"我必须好"才能被爱的孩子
- 在巨变家庭中**被迫早熟**的孩子

→ 这种孩子的内部独白：
- "我连这都做不好"
- "我没用"
- "我配不上这个家"
- "我让妈妈更累"

→ Agent 听到家长说"孩子做错一点就特别自责""一不会就崩溃"时：
- 必须立即重视
- 这不是"心理素质差"——是**深层自我厌恶**

### 教学点 4 · "拍照不敢看镜头 + 头低着" = 自我感弱化的可视化信号

身体语言通常比语言更早暴露问题：
- **不敢直视镜头** = 不敢确认"我"的存在
- **拍照时拘谨** = 害怕被看见
- **声音变小 / 不再笑** = 自我表达萎缩

→ Agent 给家长的诊断动作：
- "你看看孩子最近的照片，比起一年前——是不是眼神不一样了？"
- 这是**可观察、可验证**的诊断信号

### 教学点 5 · "等家庭恢复时，孩子已经变了" = 创伤的滞后效应

家庭危机解除后**才发现**孩子已经变了——这是**最常见也最痛**的发现时刻。

→ 给家长的承接：
- 不是"为时已晚"
- 但**也不是"现在好了就好了"**
- 关键是**承认那一两年孩子独自承受了什么**
- 然后**慢慢补回来**

→ 关键句："**孩子那两年的孤单不会消失，但我们可以从今天起一点一点陪他走出来**。"
