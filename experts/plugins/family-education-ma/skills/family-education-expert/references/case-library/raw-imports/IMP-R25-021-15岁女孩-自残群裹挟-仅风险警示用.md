### 1.3 案例事实层（**仅供 Agent 内部识别训练 · 不进入对话**）

#### 1）求助起源

24 年 12 月家长在平台求助——核心诉求（原文要点）：

- 孩子被**有组织、有预谋的网络群体**拉入了**自残自伤自杀群**
- 导致**自伤、自残甚至自杀**行为趋向
- 求助方向：**如何屏蔽 / 找到这个组织**
- **已经报过警** —— 警察"了不了之"
- 联系**移动公司** —— 移动公司说没权限设置屏蔽
- 关键阻碍："**孩子不给手机密码**，进不去微信"
- 家长当时状态："**无望、无助和焦虑**"

#### 2）校园暴力延迟创伤的源头

- 孩子初中时**在班级和同学发生争执**
- **被班级一名有智力障碍的男同学殴打**
- 关键细节："**孩子的头被那个男生摁在地上，周围的同学在旁边看着**"
- 孩子去告老师，老师却说："**某某某都能欺负你，你还能干什么？**"
- 这件事**家长事后才知道**——而且"过了好久了"
- 当时家长**并没有想太多**

> ⚠️ **AI 评注（极重要）**：
> - 此事件构成**多重创伤**：
>   1. 被同学暴力（身体）
>   2. 旁观者效应（心理）
>   3. 老师的二次伤害（"你还能干什么"）
>   4. 父母的"事后才知道 + 没当回事"（情感失联）
> - 这个事件是后续抑郁、躯体化、被网络群体裹挟的**根源**

#### 3）躯体化与重度抑郁的发展轨迹

- 半年后升入高中
- **刚开学，孩子就表示自己头疼**
- 家长带孩子去医院检查后**身体并没有问题**
- 父亲："**孩子一直说了好几个月头疼，检查不出问题**"
- 后期孩子**开始手抖**
- **妈妈坚持带孩子去医院** → 才查出来**重度抑郁**
- ⚠️ **父亲态度**："**到现在我都不认可这个病**"

> ⚠️ **AI 评注（关键）**：
> - **持续躯体化症状**（头疼数月 + 手抖）= 重度心理问题的躯体表达
> - 父亲"不认可这个病"= 援助通道部分关闭——这是 R25-021 的最大阻力点

#### 4）当前状态

孩子上高中后**陆陆续续请假在家**，最近孩子出——

## 三、🤖 关键风险识别教学点（AI 添加 · ⚠️ 仅供内部）

### 教学点 1 · "持续躯体化症状" = 重度心理问题躯体化的标志

孩子持续几个月头疼 + 后期手抖 + 检查不出物理原因——

→ 这是**躯体化障碍**的典型轨迹：
- 心理压力**找不到出口** → 通过身体表达
- 头疼 / 胃疼 / 手抖 / 心慌 / 莫名疲惫
- **越查越查不出毛病** = 越接近心理源头

→ ⚠️ Agent 内部识别规则：
- 家长描述"孩子总说哪里疼但查不出原因 + 持续 1 个月以上"
- = **立即**走 risk-assessment-referral 路径
- = 这不是"装病"，是**身体在替心代偿**

### 教学点 2 · "自残自杀群"是真实存在的群体性风险

⚠️ 这是 raw-imports 库**最重要的风险样本**：

- 这种群体**真实存在**（小红书 / QQ / 某些隐蔽社交平台）
- 形式：约定一起自伤、互晒伤痕、群体裹挟
- 极易**裹挟孤独 / 抑郁的青少年**
- **退群比加群难** —— 群里有"不许走"的舆论压力

→ Agent 内部识别规则：
- 家长描述孩子"加入了某个群" + "群里都鼓励他不上学 / 自伤 / 走极端"
- = 立即识别为**群体裹挟风险**
- = 推动**网信办 / 腾讯安全中心 / 公安网安**等专业渠道
- = **不要**简单建议"屏蔽""断网"——这种群有反屏蔽机制

### 教学点 3 · "校园暴力延迟创伤"——半年到一年后的爆发

校园暴力**当时**家长不知道、孩子也"看起来没事" → 半年到一年后**爆发**为：
- 头疼 / 失眠 / 厌学
- 抑郁 / 自伤
- 突然不想去上学

→ ⚠️ Agent 内部识别规则：
- 听到"我家孩子最近怎么了，但 X 个月前都好好的"
- = 主动追问"X 个月前到一年之间，学校或同学之间有没有发生过什么？"
- = 校园暴力的**孩子不会立即报告**

### 教学点 4 · "老师那句'你还能干什么'" = 二次创伤

- 孩子被打 = 一次伤害
- 父母不知道 = 创伤孤立
- 老师说"你还能干什么" = **二次创伤** —— 整个权威系统对孩子说"你不值得保护"

→ ⚠️ 这种二次创伤往往比第一次更严重——因为：
- 孩子从此**不再信任任何成年人系统**
- 后续遭遇问题不再求助
- 走向更隐蔽的应对（自伤 / 网络极端群体）

### 教学点 5 · "父亲不认可这个病"——援助通道阻断风险

父亲那句"**到现在我都不认可这个病**"——

→ Agent 内部识别规则：
- 家庭中**只要有一个家长不承认孩子的诊断**
- = 治疗依从性会**断断续续**
- = 复发率显著上升
- → 需主动推动**夫妻共识**或者**只让承认的那位家长主导**
