## 三、🤖 关键教学点（AI 添加）

### 教学点 1 · "12 岁独自处理妈妈急救" = 隐性创伤的真正源头

孩子被迫**过早成人化**——12 岁时承担了应该是成年人的责任。

→ 这种孩子的特征：
- 表面"懂事""聪明""成绩好"
- 但**情绪表达通道关闭**
- 巨大压力下**突然崩溃**——青春期最常见
- 用**风险性行为**（打赏、看不该看的、网恋）**释放被压抑的需求**

→ Agent 听到家长说"孩子从小特别懂事"时，要敏感地追问：
- 家里是否有过**重病、丧亲、父母分离、突然搬家**等事件？
- 那时候孩子几岁？**他承担了什么？**
- "懂事"的代价从来不是免费的。

### 教学点 2 · "孩子主动要求看心理医生"——黄金求助窗口

⭐ 这是本案**最重要的资产**。

- 多数青春期孩子**拒绝**心理援助
- 这个孩子**主动**要求 = 他自己知道"我有问题"
- 这是**最容易也最难**的窗口：
  - 容易——孩子愿意去
  - 难——父母可能拒绝（"我们孩子没事""丢人""花那个钱干啥"）

→ Agent 给方法时**绝不能错过**这个窗口：
- 必须**确认**孩子当时是否真的看了医生
- 如果父母拒绝过 → 立即推动**重新启动**
- 这个窗口一旦关上，下次打开极难

### 教学点 3 · "倾尽所有 + 含在嘴里" ≠ 接住孩子

父母态度："**含到嘴里怕化了，拿到手里怕掉了，倾尽所有照顾孩子**"——

→ 这听起来像爱，其实是：
- **过度保护**：剥夺孩子学习面对困难的机会
- **物质化关爱**：用"花了多少钱"替代"陪了多少时间"
- **情感盲点**：父母**不知道**孩子在情绪上需要什么
- **回避负面信息**：父亲"听不得可怜话""最反感负面"——孩子的痛苦没地方说

→ 这是**典型中年得子家庭**的常见模式——父母老了、孩子来得晚、舍不得让孩子吃任何苦——结果**孩子从来没学会处理痛苦**。

### 教学点 4 · "你吓唬谁呢" = 父亲权威已坍塌

孩子对父亲讲道理的回应"**你吓唬谁呢？**"——

→ 这一句话信息量极大：
- 孩子**已经不怕父亲**
- 孩子**看穿了父亲的"道理"是空的**
- 父亲用"犯法的""不能看的"做威慑——但孩子知道这只是话术
- **当父亲只剩道理时，权威就已经坍塌**

→ 给家长的提醒：
- 真正能管住孩子的不是"讲清楚后果"
- 是**孩子相信你能在他真出事时撑住他**
- 这位爸爸缺的不是话术，是**承接力**

### 教学点 5 · "暑假拿到手机就不一样了"——奖励手机的常见陷阱

中考好成绩 → 奖励手机 → 暑假沉迷 = 中国家庭最常见的剧本

→ "奖励手机"在心理上等同于：
- "**辛苦你了，现在你可以放飞了**"——孩子接收到的信息
- 不是"你已经长大可以管自己了"——这是父母**误以为**孩子接收的
- 暑假 60 天 = **没有学校 + 父母在挣钱 + 没人盯**——必然爆发

→ Agent 给方法时**这是高频警告**：
- 孩子第一次拿到自己的手机**永远不应该是"奖励"**
- 应该是"我们一起学怎么用"——**陪伴式开机**
