# 案例 002：高一男生的游戏沉迷与学业挫败

## 一、案例基本信息

| 项目 | 内容 |
|---|---|
| 孩子 | 高一男生（高一下学期） |
| 家庭 | 上海，学校数一数二（名校） |
| 中考前 | 成绩头部，被奖励手机 |
| 暑假后 | 黑白颠倒打游戏，开学没收手机仍继续沉迷 |
| 当前状态 | 成绩从头部跌至年级垫底，亲子关系紧张后已缓和 |
| 本次焦点 | **重新定义问题**：不是"玩手机"，而是"学不会、跟不上" |

---

## 二、完整对话记录

**老师**：您好，请问是孩子妈妈吗？  
**妈妈**：对。  
**老师**：我看到您提到小朋友现在是读高几？  
**妈妈**：高一。  
**老师**：他成绩落差比较大是吗？从什么时候开始的？  
**妈妈**：一个学期都是这个样子。中考考得比较好，我们奖励他一个手机。暑假他就没日没夜、黑白颠倒地打游戏。开学还是这个状态，十月份我们没收了手机。但他住宿，学校里同学有手机，家里还有 pad，他绞尽脑汁、坑蒙拐骗偷，只要看不见就打游戏。  
**老师**：那之前他放假怎么玩？  
**妈妈**：用我的手机玩，基本就一个小时左右，没有这样沉迷。  
**老师**：中考前管得严，中考后完全放松，孩子一下子没收住。  
**妈妈**：对，我们管不了他，叫过警察，也打过闹过，没用。  
**老师**：现在你们跟他的关系怎么样？  
**妈妈**：关系挺好的，但他对手机的隐藏停不下来。  
**老师**：他周末回家作息怎么样？  
**妈妈**：作息不是黑白颠倒，但周末基本不写作业。  
**老师**：他成绩波动大吗？  
**妈妈**：很大，现在到底了，年级垫底。分班后进了普通班，还是垫底。他本来是头部孩子。  
**老师**：那除了不好的地方，有没有哪些进步或闪光点？  
**妈妈**：十月份没收手机后，他其实自己也觉得跟不上。他主动提出要补课，但到了补课的地方也听不进，坚持不了几天。**他是在逃避。**  
**老师**：压力更多来自他自己还是你们？  
**妈妈**：他自己。他自己说"学习不用你们操心，我自己可以改"，但做不到。他考完心情也不好，很要强。从小到大我们没太操心过他的学习。  
**老师**：那他面临的最大困难是什么？  
**妈妈**：**学不会，跟不上。**  
**老师**：他的情绪怎么样？  
**妈妈**：很懊恼。他明确说过"时间太浪费了，太荒废了"。  
**老师**：如果给他负面情绪打分，0 到 10 分，你会打几分？  
**妈妈**：八分。  
**老师**：这么高的负面情绪，他有什么有效的方式疏解吗？除了打游戏？  
**妈妈**：以前他喜欢运动，但自从迷上游戏，胖了 30 斤。之前他看见我们就愤怒，现在关系好了，会跟我们一起吃饭、踏青。但**真正调节情绪的方式只有打游戏**。

**老师**：所以游戏是他解决现实压力的一个出口。打完游戏后他并没有缓解，反而更空虚、更懊恼，这是一个恶性循环。**他的现实问题——学不会、跟不上——没有解决。所以你不能只解决"玩手机"的问题。对于孩子来讲，他的问题不是玩手机，他的问题是学不会、跟不上。你要解决的是他的问题。**  
**妈妈**：对对对。

**老师**：你们现在好像在跟孩子"斗气"，**在等他主动认错、主动说"妈我错了，我想改"**。这种等待和中考后把手机给他让他自我管理是同样的逻辑——他毕竟是小孩子，完全靠自我管理很难做到。

**老师**：你们首先要定位清楚：现在的核心不是"玩手机的行为问题"，而是这个孩子在学习上遇到了很大的竞争压力，他可能第一次经历这种东西，不知道怎么应对，还没有恢复自信、找到自己的节奏。**你们要帮他学会面对竞争压力、调节心态和情绪、从挫折中恢复信心。你们不要只盯着现象去批斗他，而要帮助他成长。**  
**妈妈**：有道理。

**老师**：所以我建议你们不要被动地等。如果他跟你说"我很懊恼"，你要表达对他的理解，而不是评价或鼓励。你可以这样说：

> **【三段式沟通话术 - 第一段：理解压力】**
> "我知道你现在面临很大压力。你一直都表现得好，学习没让我们操心。现在进入高中，遇到实力相当甚至更强的同学，你一定会感受到更大的竞争压力。这个过程中，你的心态和情绪会受到影响，你也会选择不同的方式来缓解压力。儿子，我知道你有很大的压力在这里，我也知道你很想去把事情做好。但有时被手机吸引住了，玩了之后又很懊恼、自责，觉得自己计划好的事情做不到。你陷入了一个恶性循环。"

**老师**：然后你要帮他降压、调整视角：

> **【三段式沟通话术 - 第二段：重构 - 这不是坏事】**
> "你现在经历的这个状态不是坏事。因为你一直顺风顺水，总要经历一些落差。你需要学会的不是非要超过别人，而是找到自己的节奏。这个调整的过程，老师看不到，同学看不到，但它对你个人非常有成长价值。"

**老师**：最后是现实问题——学不走、跟不上怎么办？你问他，因为这是他的问题。你的态度很好——等他主动来找你，而不是你哄着他学。但你的主动不是帮他找老师，而是主动引导他正视问题：

> **【三段式沟通话术 - 第三段：引导找方法】**
> "当下学习上面，你觉得需要什么帮助？你想要什么样的帮助？咱们先不要一步到位，先稳住心态，找到自己的节奏。"

**老师**：你还要问一些很现实的问题：

> "如果同学叫你开黑，你抹不开面子怎么办？"  
> "如果今天心情就是不好，想多玩一会儿怎么办？"

**不是要他给完美答案，而是让他有这个意识、有思考。**

**妈妈**：我经常站在他的角度说话，说完也不做判断、不做要求。  
**老师**：对，很好。你还要帮他把大目标拆成小目标，把抽象的东西变成可落地的操作。**另外，他给自己压力已经很大了，你们不需要再给他额外压力。你们要做的先是理解、心疼、支持、引导，而不是鞭策。**  
**妈妈**：之前的鞭策和压力起了反效果，现在我们不讲了，但他还没走出来。  
**老师**：他给自己的压力一定远远大于你们给他的。一个能做到这么好的孩子，不想落后于人。**你们要先走进他，关心他发生了什么，而不是急于解决问题。**  
**妈妈**：我感觉我问的问题不是他心里想表达的，他自己也不知道怎么表达，或者不愿意说。  
**老师**：对，因为他一直做得很好。你们可以这样说：

> "儿子，你这么优秀、聪明，现在跟以前不一样了，到底发生了什么事？你愿意跟我讲讲吗？"

如果他不愿意，你就说：

> "不管发生了什么事，我觉得都不是坏事。人的成长不是只在试卷上。你现在经历的这些东西，是你人生的财富。需要我的时候随时跟我讲，我一直都在。"

**妈妈**：好的，谢谢老师。  
**老师**：不客气，再见。

## 三、辅导方法总结

### 1. 问题重定义（核心转折点）

> "他的问题不是玩手机，他的问题是学不会、跟不上。"

**方法**：从"行为问题"转为"心理需求问题"。  
**效果**：妈妈当场认可"对对对"，说明抓住了核心。

**普适框架**：
- 表层行为（玩手机 / 抓娃娃 / 沉迷小说）
- 中层情绪（懊恼 / 空虚 / 挫败）
- 深层需求（成就感 / 掌控感 / 逃避现实压力）

### 2. 指出"斗气"心态

> "你们好像在等他主动认错、主动说'妈我错了'。这种等待和当初让他自我管理是同样的错误逻辑。"

**方法**：敏锐识别家长的**被动姿态**——表面"放手"，实际是"等他自取灭亡然后说我对了"。

### 3. 提供**三段式沟通模板**（可直接复用）

| 段 | 目标 | 关键词 |
|---|---|---|
| **理解压力** | 让孩子感到被看见 | "我知道你……""压力""恶性循环" |
| **重构视角** | 帮孩子降压 | "不是坏事""找到自己的节奏""人生财富" |
| **引导方法** | 让孩子主动思考 | "你需要什么帮助？""怎么办？" |

### 4. 强调"理解 ≠ 评价"

> "你要表达对他的理解，而不是评价或鼓励。"

**方法**：反复提醒家长：
- 不给建议
- 不评价
- 不鼓励（鼓励也是一种压力）
- 只**说出孩子的感受**

### 5. 现实情境提问

> "如果同学叫你开黑，你抹不开面子怎么办？"  
> "如果今天心情就是不好，想多玩一会儿怎么办？"

**方法**：不是要标准答案，而是**启发孩子自己思考**。让孩子从"被动接受规则"走向"主动建构规则"。

### 6. 家长赋能

> "你的态度很好""你做得对"

**方法**：多次肯定家长，避免家长在长期挫败感里再被压一根稻草。

## 四、可复用的话术与提问

### 用于评估的提问

| 提问 | 目的 |
|---|---|
| "他成绩从什么时候开始变化的？" | 锚定时间线 |
| "压力更多来自他自己还是你们？" | 识别压力来源 |
| "他面临的最大困难是什么？" | 引导家长看到核心 |
| "0-10 分，他的负面情绪几分？" | 量化情绪 |
| "他有什么有效方式疏解情绪？" | 评估应对资源 |

### 三段式沟通完整话术模板

**段 1：理解压力**

```
我知道你现在面临很大压力。
你一直都表现得好，[具体优势]。
现在 [具体处境]，你一定会感受到 [具体感受]。
我知道你 [情绪]，也知道你想 [正向意图]，
但有时被 [行为] 吸引住了，
玩了之后又很懊恼、自责，觉得计划好的事情做不到。
你陷入了一个恶性循环。
```

**段 2：重构 - 这不是坏事**


## 五、马老师核心洞察

1. **行为只是症状，需求才是病灶**：游戏沉迷只是表层
2. **斗气 = 隐性放弃**：等孩子自己变好的家长，本质上仍在被动
3. **理解先于解决**：先走进他，而不是急于解决问题
4. **顺风顺水的孩子怕落差**：第一次失败时往往最脆弱，需要更多的扶
5. **鼓励也可能是压力**：当孩子正在自我攻击时，赞美反而加重负担
6. **孩子的自我压力远大于家长给的**：不需要再加码
