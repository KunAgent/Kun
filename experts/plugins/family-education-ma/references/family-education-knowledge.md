## 一、各年龄段发展里程碑

### 1. 婴幼儿期（0–3 岁）

- **核心任务**：建立**安全依恋**（埃里克森：信任 vs. 不信任）
- **认知**：感知运动期（皮亚杰），通过感官探索世界
- **关键议题**：哭声回应、入睡、分离焦虑、如厕训练
- **家长重点**：稳定、回应、抱够，**不会"被惯坏"**

### 2. 学龄前（3–6 岁）

- **核心任务**：自主感与主动性 vs. 内疚
- **认知**：前运算期，自我中心、想象力爆发
- **关键议题**：情绪命名、规则建立、社交萌芽、性别认同启蒙
- **家长重点**：用游戏代替说教；接纳情绪、限制行为

### 3. 学龄期（6–12 岁）

- **核心任务**：勤奋感 vs. 自卑（埃里克森）
- **认知**：具体运算期，逻辑、规则意识形成
- **关键议题**：学习习惯、同伴关系、自信心、电子屏幕管理
- **家长重点**：从控制转向陪伴，培养内在动机而非外部奖惩

### 4. 青春期（12–18 岁）

- **核心任务**：自我同一性 vs. 角色混乱
- **认知**：形式运算期，抽象思维、批判精神
- **关键议题**：独立性、隐私、亲子冲突、恋爱与性教育、生涯规划
- **家长重点**：从"权威"转向"顾问"，给空间但保持连接

## 二、各年龄段沟通技巧

### 0–3 岁：非语言为主

- 眼神接触 + 平静的语气
- 简短句子（3–5 字）："要抱抱""我们走吧"
- 命名情绪："你很难过对不对"

### 3–6 岁：游戏化沟通

- 蹲下来，与孩子视线齐平
- 用"如果……会怎样"代替"不许……"
- 角色扮演替代说理
- 限制选择："你想穿红衣还是蓝衣"（而不是开放式）

### 6–12 岁：好奇式提问

- 多问"怎么样了""你是怎么想的"
- 倾听不打断，复述确认
- 避免比较（"你看 XX 家的孩子……"）
- 家庭会议、固定一对一时间

### 12–18 岁：成人式对话

- 把孩子当**朋友**而非小孩
- 不查手机、不偷听
- 用"我"句式而非"你"句式表达感受
- 失败时给空间，而非追问"为什么"

## 三、常见行为问题及处理

| 问题 | 可能原因 | 推荐策略 |
|---|---|---|
| 写作业拖拉 | 任务过难 / 缺乏掌控感 / 关注吸引 | 任务拆分 + 番茄钟 + 高质量陪伴 |
| 发脾气 / 哭闹 | 情绪未被看见 | 情绪命名 → 共情 → 设限行为 |
| 打人 / 咬人（幼儿） | 语言不足以表达 | 教情绪词汇 + 替代行为（如捶枕头） |
| 撒谎 | 害怕惩罚 / 想象与现实未分 | 创造说真话不被惩罚的环境 |
| 沉迷手机 / 游戏 | 现实生活成就感不足 | 增加线下活动 + 共同制定规则 |
| 厌学 | 学业压力 / 师生关系 / 同伴关系 | 先排查情绪与人际，再谈学习 |
| 顶嘴 / 叛逆（青春期） | 自主需求 | 让出可以让的，把握底线 |
| 兄弟姐妹冲突 | 资源争夺 / 关注分配 | 公平 ≠ 平均；不当法官 |

## 四、正面管教（Positive Discipline）核心策略

> 创始人：Jane Nelsen，源自 Adler & Dreikurs 个体心理学

### 核心理念
**和善与坚定并行**：既尊重孩子，也尊重自己；既不惩罚也不娇纵。

### 五大标准

1. 让孩子感受到**归属感与价值感**
2. **互相尊重**与鼓励
3. **长期有效**（而非短期管用但伤害长期关系）
4. 教给孩子**有价值的社会与生活技能**
5. 帮助孩子**发现自己的能力**

### 常用工具

- **专属时间**：每天 10–15 分钟一对一陪伴
- **家庭会议**：每周一次，全家共同决策
- **情绪轮**：让孩子识别情绪
- **积极暂停**："冷静角"而非"惩罚角"
- **启发式提问**："发生了什么？""你的感受是什么？""下次可以怎么做？"
- **错误是学习的机会**：替代羞辱式批评

## 五、非暴力沟通（NVC）四步法

> 创始人：Marshall Rosenberg

### 四步公式

1. **观察**（Observation）：陈述事实，不评判  
   ❌ "你又乱扔玩具" → ✅ "我看到玩具散落在客厅地上"

2. **感受**（Feeling）：表达情绪，不指责  
   ❌ "你让我很生气" → ✅ "我感到有些焦躁"

3. **需要**（Need）：说出需求  
   "我需要一个整洁的环境"

4. **请求**（Request）：具体可执行  
   ❌ "你以后注意点" → ✅ "你愿意现在和我一起把玩具放回箱子里吗？"

### 完整示例

> "我看到玩具散落在地上（观察），  
> 我感到有些焦躁（感受），  
> 因为我需要一个整洁的环境（需要），  
> 你愿意现在和我一起收拾吗？（请求）"

## 六、家长自我成长

### 常见困境

- **育儿焦虑**：信息过载 + 完美主义
- **代际创伤**：把自己童年的伤带给孩子
- **角色冲突**：职场妈妈 / 爸爸的双重压力
- **夫妻教养不一致**

### 成长路径

1. **觉察**：识别自己被触发时的"按钮"
2. **修复**：和孩子真诚道歉是一种力量
3. **照顾自己**：你不能从空杯子里倒水
4. **持续学习**：阅读、咨询、家长成长小组

## 八、何时建议寻求专业帮助

出现以下信号之一，建议家长**及时**联系儿童精神科医生 / 持证心理咨询师：

- 持续 2 周以上的情绪低落、兴趣丧失
- 自伤行为或谈论自杀
- 拒学超过 1 周
- 严重攻击行为（伤害他人或动物）
- 进食 / 睡眠严重紊乱
- 疑似 ADHD、自闭谱系、抽动症、强迫症等
- 家庭暴力 / 虐待 / 遗弃
- 经历重大创伤事件（丧亲、车祸、性侵等）

**马老师只做家庭教育层面的引导，临床问题必须由专业人士处理。**

## 九、常用情绪词汇表（供家长教孩子）

**正向**：开心、兴奋、得意、平静、好奇、骄傲、感激、被爱、放心  
**负向**：生气、难过、害怕、紧张、孤单、嫉妒、羞愧、失望、委屈、烦躁  
**复杂**：又开心又紧张、又爱又生气、又想又怕
