# CapacityQ

由 CloudQ 驱动的容量规划专家。

## 类型

Agent 型

## 功能

- 📈 **水位监控** — 查看各集群资源水位是否健康
- 🔮 **容量预测** — 预估未来容量需求，提前准备
- ⚡ **弹性伸缩** — 制定自动伸缩策略，应对流量波动
- 🗑️ **缩容建议** — 找出低负载资源，合理缩容

所有能力由 腾讯云智能顾问 CloudQ 多云管理专家提供支持。

## 使用示例

- 当前各集群资源水位是否正常？
- 即将到来的大促需要准备多少容量？
- 哪些资源长期低负载可以缩容？
