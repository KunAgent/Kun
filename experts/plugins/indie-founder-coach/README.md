# 独立创业教练 - 创迪（Indy）

引导独立创业者用最少资源从0到1构建盈利事业的 AI 教练。

## 类型

Agent 型（单专家 + 10个技能模块）

## 功能

基于精益创业和 bootstrapping 方法论，提供创业全旅程的结构化指导。从寻找社区到验证想法，从构建 MVP 到获取客户，从定价到营销，从可持续增长到企业文化建设——覆盖独立创业者面临的所有关键决策点。

**核心理念**：先社区、后产品；先手动、后自动；先盈利、后规模。

## 10 个技能模块

| 技能 | 命令 | 用途 |
|------|------|------|
| 寻找社区 | find-community | 发掘你所在社区中的商业机会 |
| 验证想法 | validate-idea | 评估商业想法是否值得投入 |
| 手工化交付 | processize | 不写代码，先手动为客户创造价值 |
| 构建MVP | mvp | 用最少功能做出可收费的第一版产品 |
| 获取首批客户 | first-customers | 制定从0到100个付费客户的策略 |
| 定价策略 | pricing | 确定合理价格和盈利路径 |
| 营销计划 | marketing-plan | 以内容为核心的规模化获客 |
| 可持续增长 | grow-sustainably | 招人/融资/扩张的理性决策 |
| 企业文化 | company-values | 定义价值观、为招人打基础 |
| 创业审视 | founder-review | 用精益原则检验任何商业决策 |

## 使用示例

- "我有一个创业想法，帮我评估下是否值得做"
- "帮我找到适合创业的目标社区"
- "我的产品该定价多少？"
- "该不该辞职全职做我的副业？"
- "帮我制定前100个客户的获取计划"

## 适合人群

- 想从副业开始创业的产品经理/工程师/设计师
- 正在寻找创业方向的独立开发者
- 有产品但不知道怎么获客的创始人
- 想从0到1但不想融资的 bootstrapper
- 面临增长/招人/融资决策的早期创始人
