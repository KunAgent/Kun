# 中国各税种税率速查手册

> 依据现行税法整理，如有政策调整以最新公告为准

---

## 一、增值税

### 1.1 一般纳税人税率

| 税率 | 适用范围 |
|------|---------|
| **13%** | 销售/进口货物（一般）、提供加工修理修配劳务、有形动产租赁 |
| **9%** | 交通运输/邮政/基础电信/建筑/不动产租赁/销售不动产/转让土地使用权/农产品/自来水/暖气/煤气/图书报刊/饲料/化肥/农药/农机 |
| **6%** | 增值电信/金融/现代服务/生活服务/销售无形资产（除土地使用权） |
| **0%** | 出口货物/跨境应税行为（适用免抵退税或免退税） |

### 1.2 小规模纳税人征收率

| 征收率 | 适用范围 |
|--------|---------|
| **3%** | 一般应税行为 |
| **5%** | 销售/出租不动产、劳务派遣差额纳税、安全保护服务差额纳税 |
| **1%** | 阶段性优惠（以最新政策为准） |

### 1.3 增值税优惠政策

| 优惠 | 条件 |
|------|------|
| 免征增值税 | 小规模纳税人季度销售额≤30万元（月度≤10万元） |
| 加计抵减 | 生产性服务业5%加计/生活性服务业10%加计（以最新政策为准） |
| 留抵退税 | 增量留抵税额×进项构成比例×60%（一般企业）或100%（制造业等） |
| 即征即退 | 软件产品：实际税负超3%部分即征即退 |

## 二、企业所得税

### 2.1 基本税率

| 税率 | 适用对象 |
|------|---------|
| **25%** | 居民企业（一般） |
| **15%** | 高新技术企业、技术先进型服务企业、西部大开发鼓励类产业 |
| **20%** | 非居民企业（预提所得税，实际常减按10%） |

### 2.2 小型微利企业优惠

| 应纳税所得额 | 实际税负 | 计算方式 |
|-------------|---------|---------|
| ≤300万元 | **5%** | 减按25%计入应纳税所得额 × 20%税率 |
| >300万元 | **25%** | 全额适用25%税率 |

**小型微利企业认定条件**：
- 年度应纳税所得额 ≤ 300万元
- 从业人数 ≤ 300人
- 资产总额 ≤ 5000万元

### 2.3 常用扣除限额

| 费用项目 | 扣除限额 | 超出部分处理 |
|---------|---------|-------------|
| 业务招待费 | 发生额60%且≤收入0.5% | 纳税调增 |
| 广告费和业务宣传费 | 收入15%（化妆品/医药/饮料30%） | 结转以后年度扣除 |
| 职工福利费 | 工资总额14% | 纳税调增 |
| 工会经费 | 工资总额2% | 纳税调增 |
| 职工教育经费 | 工资总额8% | 结转以后年度扣除 |
| 公益性捐赠 | 年利润总额12% | 结转3年扣除 |
| 手续费和佣金 | 收入5%（保险企业18%） | 纳税调增 |

### 2.4 研发费用加计扣除

| 类型 | 加计扣除比例 |
|------|------------|
| 一般企业研发费用（费用化） | 100%加计扣除 |
| 一般企业研发费用（资本化） | 按200%摊销 |
| 集成电路/工业母机企业 | 120%加计扣除（按220%摊销） |

## 三、个人所得税

### 3.1 综合所得税率表（年度）

| 级数 | 全年应纳税所得额 | 税率 | 速算扣除数 |
|------|----------------|------|-----------|
| 1 | ≤36,000元 | 3% | 0 |

| 4 | 300,001-420,000元 | 25% | 31,920 |
| 5 | 420,001-660,000元 | 30% | 52,920 |
| 6 | 660,001-960,000元 | 35% | 85,920 |
| 7 | >960,000元 | 45% | 181,920 |

### 3.2 专项附加扣除标准

| 项目 | 扣除标准 | 扣除方式 |
|------|---------|---------|
| 子女教育 | 2,000元/月/孩 | 父母各50%或一方100% |
| 继续教育（学历） | 400元/月 | 最长48个月 |
| 继续教育（职业资格） | 3,600元/年 | 取得证书当年 |
| 大病医疗 | 80,000元限额 | 超15,000元部分据实扣除 |
| 住房贷款利息 | 1,000元/月 | 最长240个月 |
| 住房租金 | 800/1,100/1,500元/月 | 按城市等级 |
| 赡养老人（独生） | 3,000元/月 | |
| 赡养老人（非独生） | ≤1,500元/月 | 合计不超3,000 |
| 3岁以下婴幼儿照护 | 2,000元/月/孩 | 父母各50%或一方100% |

### 3.3 年终奖计税

**单独计税**：年终奖 ÷ 12 → 确定适用税率和速算扣除数 → 年终奖 × 税率 - 速算扣除数

| 月均 | 税率 | 速算扣除数 |
|------|------|-----------|
| ≤3,000 | 3% | 0 |
| 3,001-12,000 | 10% | 210 |
| 12,001-25,000 | 20% | 1,410 |
| 25,001-35,000 | 25% | 2,660 |
| 35,001-55,000 | 30% | 4,410 |
| 55,001-80,000 | 35% | 7,160 |
| >80,000 | 45% | 15,160 |

## 四、附加税费

| 税种 | 计税依据 | 税率 | 备注 |
|------|---------|------|------|
| 城市维护建设税 | 增值税+消费税 | 7%(市区)/5%(县镇)/1%(其他) | |
| 教育费附加 | 增值税+消费税 | 3% | 月销售额≤10万免征 |
| 地方教育附加 | 增值税+消费税 | 2% | 月销售额≤10万免征 |

**"六税两费"减半征收**（小型微利企业/个体工商户/小规模纳税人）：
- 资源税、城建税、房产税、城镇土地使用税、印花税（不含证券）、耕地占用税
- 教育费附加、地方教育附加

## 七、纳税申报期限

| 税种 | 申报频率 | 截止日期 |
|------|---------|---------|
| 增值税（一般纳税人） | 月报 | 次月15日 |
| 增值税（小规模） | 季报 | 季后15日 |
| 企业所得税（预缴） | 季报 | 季后15日 |
| 企业所得税（汇缴） | 年报 | 次年5月31日 |
| 个人所得税（代扣） | 月报 | 次月15日 |
| 个人所得税（汇缴） | 年报 | 次年6月30日 |
| 印花税 | 季报/次 | 季后15日 |
| 房产税 | 半年/年 | 各地规定 |
| 城镇土地使用税 | 半年/年 | 各地规定 |

> 注：申报期限遇法定节假日顺延
