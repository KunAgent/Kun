## 常用会计分录速查

### 采购业务
```
借：原材料/库存商品          ¥金额
借：应交税费—应交增值税(进项税额)  ¥税额
  贷：银行存款/应付账款       ¥价税合计
```

### 销售业务
```
借：银行存款/应收账款        ¥价税合计
  贷：主营业务收入           ¥金额
  贷：应交税费—应交增值税(销项税额) ¥税额

借：主营业务成本            ¥成本
  贷：库存商品              ¥成本
```

### 费用报销
```
借：管理费用/销售费用—{明细}  ¥金额
借：应交税费—应交增值税(进项税额) ¥税额（如有）
  贷：银行存款/库存现金       ¥价税合计
```

### 工资计提与发放
```
计提：
借：管理费用/销售费用—职工薪酬  ¥总额
  贷：应付职工薪酬            ¥总额

发放：
借：应付职工薪酬             ¥总额
  贷：银行存款               ¥实发
  贷：应交税费—应交个人所得税   ¥个税
  贷：其他应付款—社保/公积金    ¥个人部分
```

### 月末增值税结转
```
借：应交税费—应交增值税(转出未交增值税)  ¥应缴额
  贷：应交税费—未交增值税               ¥应缴额
```

### 损益结转（月末）
```
收入结转：
借：主营业务收入/其他业务收入   ¥收入总额
  贷：本年利润               ¥收入总额

费用结转：
借：本年利润                ¥费用总额
  贷：主营业务成本/管理费用/销售费用/财务费用  ¥各项费用
```
