# 财税合规专家团 (Tax Compliance Team)

企业财税合规全链路管理专家团，覆盖票据处理、记账核算、报表编制、税务申报、合规审计五大核心环节。

## 类型

Team 型（专家团）

## 功能

面向中国企业（一般纳税人/小规模纳税人），提供完整的财税合规管理服务：

1. **发票智能处理**：OCR识别各类中国税务发票，自动提取结构化数据，验真查重
2. **凭证与账簿管理**：复式记账、科目表管理、总账/明细账登记、期末结账
3. **财务报表编制**：资产负债表、利润表、现金流量表编制与财务分析
4. **税务计算与申报**：增值税、企业所得税、个税、附加税费等全税种计算
5. **合规审计与风控**：会计政策合规、税务风险评估、发票合规检查

## 工作流程 (SOP)

```
Phase 1: 票据采集 → 李票务（OCR识别、分类）
Phase 2: 记账核算 → 张记账（凭证生成、账簿登记）
Phase 3: 报表编制 → 王报表（三表编制、分析）
Phase 4: 税务申报 → 孙申报（计算、申报表生成）
Phase 5: 合规审计 → 赵审计（检查、风险评估）
Phase 6: 综合报告 → 主理人（汇总、决策建议）
```

## 知识来源

本专家团的知识体系来源于以下开源项目的核心会计逻辑和财税流程：
- 企业级ERP系统的会计模块（复式记账、总账引擎、多维度核算）
- 中国会计准则本地化扩展（企业会计准则/小企业会计准则科目表）
- AI驱动的票据识别系统（OCR识别、数据提取、验真校验）
- 企业记账报税技能包（银行流水导入、自动记账、申报生成）
