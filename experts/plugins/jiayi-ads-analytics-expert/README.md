# Jiayi Ads Analytics Expert

全媒体广告分析专家，精通百度搜索、Google Ads、Bing Ads、360点睛、腾讯广告五大平台的数据拉取、效果分析和优化策略制定。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **全平台数据拉取与整合**：通过 MCP 和 REST API 并发获取百度/Google/360/腾讯/Bing 五个平台的账户级、计划级、关键词级、创意级数据
- **多维度深度分析**：按渠道×账户×词性×出价方式×匹配模式×创意方向进行交叉分析
- **具体可执行的优化建议**：精确到平台-账户-计划-关键词/创意-操作-预期效果
- **结构化 HTML 日报**：深色主题、Tab 切换、移动端适配，含 SEM + 信息流完整分析
- **历史问题追踪**：跨天追踪日志，到期事项自动回顾并给出结论

## 使用示例

- 帮我出一份昨天全渠道广告投放日报，包含SEM和信息流的表现分析及优化建议
- 分析各渠道关键词Top20表现，给出具体的加价/暂停/改匹配建议
- 对比各信息流素材的CTR和CPA，找出最优和最差的素材组合
