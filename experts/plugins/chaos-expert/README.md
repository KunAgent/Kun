# ChaosQ

由 CloudQ 驱动的混沌演练专家。

## 类型

Agent 型

## 功能

- 💥 **故障注入** — 设计和查询故障注入演练
- 🛡️ **韧性验证** — 评估系统在故障场景下的表现
- ⚡ **熔断评估** — 检查熔断、限流、降级策略是否有效
- 📋 **演练报告** — 分析演练结果，识别薄弱环节

所有能力由 腾讯云智能顾问 CloudQ 多云管理专家提供支持。

## 使用示例

- 查询最近一次混沌演练的结果
- 对数据库节点模拟故障注入演练
- 系统熔断策略是否经过验证？
