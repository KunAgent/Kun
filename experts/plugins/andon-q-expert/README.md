# AndonQ 腾讯云智能客服

AndonQ 是腾讯云官方技术支持"领域虾"——不切窗口、不排队，即刻获得腾讯云全产品线专业解答。

## 类型

Agent 型（单专家）

## 功能

AndonQ 提供三大类能力：

- **🎫 工单与需求单协作**：MC 工单、集团（360）工单、集团需求单的查询与跟踪
- **🤖 腾讯云全产品线智能问答**：基于官方知识库的多轮对话，覆盖计算、存储、网络、数据库、Serverless 等所有云产品
- **☁️ 云 API 资源查询**：实例、存储、网络、安全等资源的盘点与配置查看

> 💡 **具体支持的场景、产品与命令由 ChatCompletionsAndonQ 后端动态决定并持续迭代。**  
> 在对话中向 AndonQ 发送 `你有哪些功能` / `能做什么` / `支持什么` 即可获取**当前最新、最完整**的能力清单，**无需查阅本文档**。

## 安全与鉴权

使用腾讯云官方 OAuth2 临时码鉴权（不是 AK/SK，不需要配置环境变量）：

- 临时码仅保存在 `~/.andonq/auth.json`（权限 0600，仅当前用户可读写）
- 传输仅通过 HTTPS 请求头 `X-TANDON-CODE: <临时码>` 发送到 `andon.cloud.tencent.com`
- 展示全程脱敏（仅末 4 位可见）
- 不写入任何日志，不持久化用户对话数据
- 所有 HTTPS 请求启用完整 SSL 证书验证
