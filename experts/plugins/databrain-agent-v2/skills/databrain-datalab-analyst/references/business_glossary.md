# 业务术语表

> 本文件定义了 Datalab 平台及游戏行业的常用术语。
> Agent 在回答用户问题时应使用标准术语，并在必要时解释含义。

## 用户与活跃

| 术语 | 英文 | 含义 |
|------|------|------|
| 日活 | DAU (Daily Active Users) | 日活跃用户数，当日登录过的去重用户数 |
| 周活 | WAU (Weekly Active Users) | 自然周内登录过的去重用户数 |
| 月活 | MAU (Monthly Active Users) | 自然月内登录过的去重用户数 |
| 新增 | New Users | 首次登录/注册的用户数 |
| PCCU | Peak Concurrent Users | 最高同时在线用户数 |
| ACCU | Average Concurrent Users | 平均同时在线用户数 |

## 留存与回流

| 术语 | 英文 | 含义 |
|------|------|------|
| 留存 | Retention | 用户在初始行为后，在后续时间点再次活跃的比例 |
| 次留 | D1 Retention | 次日留存率，首日活跃后次日再次活跃的比例 |
| 7留 | D7 Retention | 7日留存率，首日活跃后第7日再次活跃的比例 |
| 30留 | D30 Retention | 30日留存率，首日活跃后第30日再次活跃的比例 |
| 回流 | Reactivation | 流失用户重新活跃 |
| 流失 | Churn | 用户在一定时间内未再活跃 |

## 收入与付费

| 术语 | 英文 | 含义 |
|------|------|------|
| ARPU | Average Revenue Per User | 每活跃用户平均收入 |
| ARPPU | Average Revenue Per Paying User | 每付费用户平均收入 |
| LTV | Lifetime Value | 用户生命周期价值，预估用户在整个生命周期内贡献的收入 |
| 付费率 | Pay Rate | 付费用户占活跃用户的比例 |
| 首充 | First Payment | 用户首次付费 |
| 复购 | Repeat Purchase | 用户再次付费 |

## 广告与获客

| 术语 | 英文 | 含义 |
|------|------|------|
| ROI | Return On Investment | 投资回报率 |
| ROAS | Return On Ad Spend | 广告支出回报率 |
| CPI | Cost Per Install | 每安装成本 |
| CPA | Cost Per Action | 每行动成本 |
| CPM | Cost Per Mille | 千次展示成本 |
| CTR | Click-Through Rate | 点击率 |
| CVR | Conversion Rate | 转化率 |
| 素材 | Creative | 广告投放使用的图片/视频素材 |
| 买量 | User Acquisition (UA) | 通过广告投放获取用户 |

## 数据分析

| 术语 | 英文 | 含义 |
|------|------|------|
| BMK | Benchmark | 基准值，用于对比分析 |
| 大盘 | Overall | 全部数据的汇总值，不限定市场/渠道/版本 |
| 分市场 | By Market | 按地区/国家维度拆分查看 |
| 环比 | MoM / WoW / DoD | 与前一周期相比的变化率（月环比/周环比/日环比） |
| 同比 | YoY | 与去年同期相比的变化率 |
| 下钻 | Drill Down | 从汇总数据进入更细粒度查看 |
| 归因 | Attribution | 分析某个结果的原因/来源 |
| 漏斗 | Funnel | 用户在各步骤的转化流程 |
| 分群 | Cohort | 按特定条件分组的用户群体 |

## Datalab 平台

| 术语 | 英文 | 含义 |
|------|------|------|
| Dashboard | 仪表盘/报表 | Datalab 平台上的数据报表页面 |
| Chart | 图表 | Dashboard 中的单个数据可视化组件 |
| Filter | 筛选器 | 用于限定数据范围的条件 |
| Dimension | 维度 | 数据分组依据（如国家、平台、渠道） |
| Metric | 指标 | 衡量数据的度量（如 DAU、收入） |
| game_code | 业务代码 | Datalab 中标识一个业务/游戏的唯一编码 |
