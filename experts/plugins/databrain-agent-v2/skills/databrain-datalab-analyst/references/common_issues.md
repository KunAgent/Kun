# 常见问题速查

> 本文件整理了 Datalab 平台使用中的常见问题和快速解答。
> Agent 可直接参考本文件回答用户的基础问题，无需调用 MCP 知识库。

## 数据口径问题

### Q: DAU 和 MAU 的关系？
**A**: DAU 是日维度的活跃用户，MAU 是月维度的活跃用户。MAU ≠ DAU × 30，因为同一用户多日活跃只计一次。

### Q: 留存率怎么计算的？
**A**: D{N} 留存率 = 第 N 日再次登录的用户数 / 基准日活跃用户数。例如 D1 留存率 = 次日活跃用户数 / 首日活跃用户数。

### Q: ARPU 和 ARPPU 的区别？
**A**: 
- ARPU = 总收入 / 活跃用户数（包含未付费用户）
- ARPPU = 总收入 / 付费用户数（仅计付费用户）
- ARPPU 通常远大于 ARPU，差异取决于付费率

### Q: ROI 和 ROAS 的区别？
**A**:
- ROI = (收入 - 成本) / 成本，衡量净利润率
- ROAS = 收入 / 广告花费，衡量广告回报
- ROI 考虑了利润，ROAS 只看收入

## 数据延迟问题

### Q: 数据什么时候更新？
**A**: 
- T+1 数据：大部分指标在次日凌晨更新完成
- 实时数据：部分核心指标（如在线人数）支持实时查看
- BigQuery 数据：通常 T+1，偶尔因数据导入延迟到 T+2

### Q: 为什么今天的数据还没有？
**A**: 大部分报表使用 T+1 数据，今天的完整数据需要明天才能看到。如果是 T+1 之后仍无数据，可能是数据导入异常，需联系数据团队排查。

## 筛选器问题

### Q: 筛选不生效怎么办？
**A**: 
1. 检查筛选字段名是否与报表字段匹配
2. 检查操作符是否正确（include vs exclude）
3. 日期筛选会覆盖默认值，非日期筛选是追加
4. 确认 value 格式为数组 `["val1", "val2"]`

### Q: 怎么同时筛选多个条件？
**A**: 在 filters 数组中添加多条筛选，多条之间是 AND 关系（取交集）。

## 权限问题

### Q: 看不到某个报表怎么办？
**A**: 
1. 检查是否有该 game_code 的访问权限
2. 联系报表创建者授权
3. 检查是否在正确的环境（内网/外网）

### Q: Token 过期了怎么办？
**A**: 
- 内网用户：Token 由 OpenClaw 自动刷新，重新打开即可
- 外网用户：到 Token 管理页面重新生成
- 平台服务：由上层服务负责 Token 刷新
