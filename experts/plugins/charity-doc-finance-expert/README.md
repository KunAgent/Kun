## 核心能力

### 文书方向
- 项目上线申请书、结项/中期报告
- 传播计划、捐赠人服务计划
- 肖像授权书、项目自评报告
- 按平台模板标准化归档

### 财务方向
- 捐赠票据台账、收支台账
- 银行流水分类、批量票据整理
- 审计准备材料清单、费用报销分类
- 实物捐赠处理、跨期账务处理

### 合规咨询（专家直答）
- 《慈善法》相关合规判断
- 公募资格、税前扣除政策咨询
- 票据管理、账务处理口径说明

## 工作流程

```
用户输入
   │
   ▼
第一阶段：意图理解与任务卡装配
   │  ├─ 意图不明确 → 四选一澄清
   │  └─ 装配结构化任务卡
   ▼
第二阶段：调度执行
   │ 委托 charity-doc-finance 执行
   │ （内部自动路由文书/财务模块）
   ▼
第三阶段：复核与交付
   ├─ 文书结果：平台规范、事实一致性
   ├─ 财务结果：数据来源、可追溯性
   └─ 复合结果：文书与财务数字一致性
```

## Skill 说明

`charity-doc-finance` 是内置的整合型 Skill，同时覆盖文书和财务两大模块，无需额外安装。其内部自动判断当前任务是文书类还是财务类，并调用相应的处理逻辑。

## 安装使用

1. 将整个 `公益机构智能文书和财会助手/` 目录放入 WorkBuddy 专家目录
2. 重启 WorkBuddy 或刷新专家列表
3. 选择"公益机构智能文书和财会助手"开始使用

## 注意事项

- 涉及法规、审计、税务的内容，专家会自动附加免责声明
- 本地票据批量整理遵循"先预览、后正式执行"原则
- 复合场景默认先整理财务数据，再生成文书
