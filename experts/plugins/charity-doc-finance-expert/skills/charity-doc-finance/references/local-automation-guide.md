# 本地自动化工具使用指南

> 从 `SKILL.md` 运行时正文外置。用于明确需要处理本地文件夹、批量票据或银行流水时，说明脚本能力、依赖、运行方式与安全边界。

## 🧰 本地自动化工具清单

当用户明确要处理本地文件夹、批量票据或银行流水时使用。本节只说明可用工具；是否运行工具，要先确认用户提供的目录、文件类型、数量和期望输出。

### 工具一：票据扫描与分类（`scripts/receipt_organizer.py`，v1.2）

**定位**：给票据整理打草稿，不是直接入账工具。

**支持范围**：
- PDF 电子发票：可用 `pdfplumber` 抽取文字层和关键字段
- JPG/PNG 等图片：可选 `easyocr` 识别，结果默认进入人工复核
- DOCX 打印版票据/报销单：可用 `python-docx` 抽取文本
- Excel/CSV：可作为待归档材料扫描，但核心字段仍需人工确认

**输出**：
- 六大类归档目录：`01_增值税发票/`、`02_电子发票/`、`03_公益捐赠票据/`、`04_差旅报销/`、`05_餐饮/`、`06_其他/`
- `票据台账_自动生成.xlsx`；如缺少 `openpyxl`，降级为 `票据台账_自动生成.csv`
- `整理汇总报告.md`，列出需人工复核的票据和复核要点

**运行方式**：
```bash
# 仅扫描预览，不复制文件
python scripts/receipt_organizer.py "D:/机构名/2025年4月票据" --scan-only

# 正式整理：复制文件到新目录 + 生成台账和报告
python scripts/receipt_organizer.py "D:/机构名/2025年4月票据" --output "D:/机构名/整理结果"
```

### 工具二：银行流水分类（`scripts/bank_statement_sorter.py`）

**定位**：读取银行导出的 Excel/CSV 流水，按摘要和对方户名做初步分类，标记疑似捐赠收入、政府补助收入、支出类别和大额交易。

**依赖**：
- CSV：无需额外依赖
- Excel：需 `pip install openpyxl`

**运行方式**：
```bash
python scripts/bank_statement_sorter.py "D:/机构名/2025年银行流水.xlsx"
python scripts/bank_statement_sorter.py "D:/机构名/流水.csv" --output "D:/机构名/流水_分类后.csv"
```

### 自动化整理安全边界

- **默认先预览**：涉及用户本地目录时，先运行 `--scan-only` 或只读取文件清单，向用户展示预分类结果后再继续。
- **只复制不移动**：票据脚本只把文件复制到输出目录，不删除、不移动、不改名原始文件。
- **输出目录必须明确**：正式整理前确认输出目录；不要把结果直接混入原始票据目录的深层历史归档中。
- **人工复核不可省略**：任何金额、日期、发票号、票据类型和科目建议都必须由财务对照原票复核。
- **能力诚实**：OCR、PDF 正则和文件名关键词都有误识别可能；不确定的内容宁可进入“需人工复核”，不要猜。
