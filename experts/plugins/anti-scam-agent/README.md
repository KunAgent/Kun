# 天御金融反诈 (Anti-Scam Agent)

> 由金融黑灰产情报驱动的反诈智能体，覆盖电信网络诈骗、职业背债、贷款包装、反催收、诈骗洗钱等常见金融黑灰产领域 —— **看得懂趋势、拆得开手法、出得了报告**。

## 简介

**腾讯云天御反诈专家**是面向金融机构的 AI 反诈专家，依托腾讯天御黑灰产情报与反诈智能体能力，帮助风控、合规、反洗钱团队实现更科学、高效、可持续的黑灰产对抗。

无论是趋势研判、手法拆解，还是风险评估、研判报告产出，只需用自然语言提问，即可获得专业级的分析结论与处置建议。

## 适用场景

- 风控策略团队 —— 跟踪诈骗手法演变，及时迭代反诈规则
- 反洗钱团队 —— 识别诈骗洗钱新模式，定位异常资金链路
- 信贷风控团队 —— 拆解贷款包装、职业背债套路，强化贷前/贷中拦截
- 催收与客诉团队 —— 监测反催收黑产动态，应对模板化投诉冲击
- 安全与情报团队 —— 按地域、机构维度评估风险分布，输出研判报告

## 核心能力

- **电信网络诈骗趋势研判**：分析刷单、贷款、投资交友、公检法、冒充客服等诈骗类型的占比、变化趋势与新型手法
- **涉诈银行卡与洗钱链路分析**：研判涉诈银行卡数量变化、诈骗洗钱新模式（多层转账、虚拟币兑换、跑分平台等），识别异常资金流向
- **职业背债人识别**：基于黑灰产情报识别职业背债人特征，辅助贷前/贷中风险拦截
- **贷款包装手法研判**：梳理贷款黑中介常用的资质包装手法（流水包装、征信修复、伪造工作证明等），输出对抗策略
- **反催收黑产监测**：监测反催收联盟动态、投诉模板与话术演变，评估对机构催收业务的冲击
- **地域与机构风险评估**：按省份、城市、机构维度分析涉诈/涉黑风险分布，识别高风险区域与重点防控对象
- **黑灰产研判报告生成**：综合多维度情报，生成包含趋势分析、手法拆解、风险评估、应对建议的完整研判报告
