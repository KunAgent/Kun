# Kun Remote 手机 Work / 论文验收清单

适用：通过 Kun Remote 登录的 iOS Safari / Android Chrome，不适用桌面窄窗口。请分别在两种浏览器按下表实测；未打勾不代表通过。底部仅显示 Code / Rooms / Work，Work 内「文档 / 论文」是手机本地导航，**不写入桌面 `write.paperMode.enabled`**。

## 功能路径

- [ ] 登录后进入 Work → 文档；主机工作区可切换，根目录、子目录、最近资源、白板显示正确。搜索能找到未打开的子目录文件；超过 200 个目录或 300 个结果时显示范围提示。
- [ ] 创建 Markdown、文件夹、白板；打开资源、编辑并返回；改名/删除前保存或显式阻止未保存稿；下载落在手机而不是主机保存对话框。
- [ ] 文档编辑出现外部文件修改/保存失败时，不静默放弃手机草稿；可选择覆盖主机或放弃草稿重读。AI 审阅、待确认操作和不支持提问的文件类型不误发送。
- [ ] Work → 论文时桌面设置中的 `write.paperMode.enabled` 保持原值；浏览器前进/后退恢复「文档 / 论文」、文件夹、论文子视图；URL 不含主机绝对路径、正文、凭证。
- [ ] 论文库搜索、状态/分组/标签筛选、排序、分页；创建/移动分组；切换已配置文献库不会修改桌面 `activeLibrary`。元数据修改重载后仍在。
- [ ] DOI/arXiv/URL、手机 PDF、BibTeX 导入：进度、取消、重复项、失败重试可见；离线/重连后刷新列表核对最终结果，不把主机任意文件路径作为手机上传来源。
- [ ] PDF 翻页/缩放/选中原文、标注、翻译、引用提问；大 PDF 的 Range 分段读取与异常范围拒绝；刷新后页码、标注可恢复。无 PDF 时只显示可用信息；仅用户明确点击时尝试从来源获取 PDF。
- [ ] 修改 NOTES.md 后点返回、底栏、浏览器返回、设置或换视图会提示先保存；并发主机修改能选择保留手机稿或放弃。标注写入失败保留待重试状态。
- [ ] 论文提问、研究会话分别绑定正确的文献库和资源线程；异步发消息期间换页不会将旧问题发往新资源；不自动触发桌面论文模式。
- [ ] 发现搜索支持部分来源失败且逐来源可见；多选批量导入显示逐篇进度、可取消；研究会话可创建、继续、切换，研究候选池展示去重条目、推荐与入库状态，批量导入不误发往其他文献库。

## 安全与断线

- [ ] Remote 未登录、失效会话、跨会话上传/取消、超出工作区的绝对路径、路径穿越、跨源请求均被拒绝；取消一个任务不取消其他客户端任务。
- [ ] 导入中断网/关闭浏览器再登录：列表可重新加载并核对是否导入；无法确认时须显示错误而不是宣称成功。
- [ ] iOS Safari 的 PDF 文本选择与下载、键盘出现后的编辑区/底栏、安全区；Android Chrome 同样检查缩放、下载、文件选择和触控尺寸（至少 44px）。
- [ ] 非中文界面下检查手机 Work / 论文按钮、表单、错误与辅助技术可读名称；不应夹杂未翻译的中文文案。

## 自动检查

在隔离 worktree 运行 `npm run typecheck`、针对性 Vitest、`npm run build`、`npm run check:file-lines`、`git diff --check`。上述设备项须人工实测，自动化检查不能代替真实 Remote 登录和设备验证。
