# 论文检索：交互与导入流程

Work 里「论文发现」的检索页（Agent 检索 / 快速检索）和「找到论文 → 导入文件夹」的整条路径。设计稿见 2026-10 的 Design 画板（论文检索重设计）。

## 原则

1. 一个检索 = 一个会话。历史只在侧栏「会话」和首页「最近检索」，页内没有第二套历史栏。
2. 论文只在两处出现：对话里的推荐清单（结论）和右侧论文池（全部候选）。检索过程卡只给数字（「新入池 n 篇」），不再逐篇列出，也没有导入按钮。
3. 选择只有一份：清单、论文池、快速检索共用 `paper-import-selection`（按会话分组，用论文的全部标识 key 匹配，所以任何视图里的勾选都落在同一篇论文上）。
4. 导入只有一个入口：所有「导入 N 篇」都打开 `PaperImportSheet`。行内不再有自己的导入按钮。
5. 导入不打断对话：逐篇状态、侧栏高亮、Toast 可撤销。

## 页面

- 首页（没有打开检索会话时）：`PaperResearchEmpty`。两个文字标签（Agent / 快速）+ 一个输入框（`PaperResearchComposer`：文本、范围胶囊、模型、发送）+「最近检索」卡片（Agent 会话与快速检索合并，按时间倒序）。
- 范围胶囊（`PaperScopePill`）：一行摘要「标准 · 4 个来源 · 2023 年至今」，点开面板设置深度 / 来源 / 年份。快速检索复用同一个，只是没有深度。
- 检索会话：中间是会话（`PaperResearchStage`），右侧是论文池（`PaperResearchPool`，标题栏图标开关）。论文池可展开一行看理由、摘要、来源、链接。
- 推荐清单（`PaperListCard`）：按方向分组的紧凑行（标题 2 行、作者年份 1 行、理由 1 行、状态 1 行），预览和 PDF 链接悬停才出现。助手停靠在右侧窄栏时同一个组件直接用，右上角可展开到论文发现。
- 快速检索（`PaperSearchView` + `PaperSearchResults`）：同一套行和勾选；选中后底部浮动条：导入、BibTeX、发给助手、「交给 Agent，以这些为种子」。行左侧的把手可以把论文拖到侧栏文件夹。

## 导入

- `PaperImportAction`：分体按钮「导入 N 篇 | 到 <文件夹> ▾」；导入中变成进度和停止。
- `PaperImportSheet`：
  - 新建文件夹（默认按检索主题起名，可改，`/` 建子文件夹）或放进现有文件夹；
  - 推荐清单有 ≥2 个方向时，可按方向建子文件夹（最多 3 层，和文献库扫描深度一致）；
  - 已在库的论文默认保持原位，也可以移到目标文件夹；
  - 没有公开 PDF 的论文只保存元数据，行上有「补 PDF」。
- 规划与执行分开：`paper-import-plan.ts`（纯函数，按文件夹拆批）→ `paper-import-job.ts`（建文件夹、逐篇 `paperImportBatch`、状态、取消、撤销、补 PDF）。每篇一次调用，所以每行有自己的状态，停止在两篇之间生效。
- 导入之后：
  - 侧栏目标文件夹自动展开并带「新 N」（`paper-import-fresh.ts`，点开后清除）；
  - 推荐清单顶部出现「已导入 N 篇到 X · 打开文件夹 · 撤销」，下面给下一步（批量解读 / 对比表 / 相关工作 / 在文献库中查看）；
  - Toast 同样带「撤销」和「打开文件夹」（`PaperNotice.secondaryAction`）；
  - 撤销 = 把这次创建的论文单元移到废纸篓（`trashPaperUnits`），已在库的不动。
- 拖放：`paper-import-drag.ts` 保存正在拖的候选（`dragover` 时浏览器读不到 `dataTransfer` 内容），`PaperTree` 的文件夹行是放置目标，悬停时显示「松手导入 n 篇到「X」」。

## 没有改的

- arXiv 今日 / 顶会论文 / 订阅这几个发现子页仍用行内导入按钮（`ImportButton` + `PaperImportFolderPicker`）。
- 对话里的输入框（`FloatingComposer`）保持原样：它要承载附件、技能、队列等，首页的精简输入框不替代它。
